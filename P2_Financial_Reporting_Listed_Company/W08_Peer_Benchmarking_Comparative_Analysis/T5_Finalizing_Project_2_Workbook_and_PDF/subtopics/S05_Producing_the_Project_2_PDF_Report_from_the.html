Subtopic note

Producing the Project 2 PDF Report from the Workbook

Scope: PDF report: print areas, consistent chart styling, executive summary first, appendix with definitions

Why it matters

Most readers of Project 2 — a hiring manager, a research head, a panel in the Saturday presentation — will see the PDF, not the workbook. The PDF must stand alone: the conclusion first, exhibits that look like one family, tables that fit the page, and an appendix that lets a sceptical reader check definitions and sources without opening Excel. Badly set print areas (charts cut in half, tables spilling onto a second page with no headers) are the most common reason an otherwise strong analysis looks amateur. The skills transfer directly to monthly MIS packs, board papers and research notes.

Core notes

Report structure in the PDF

  1. Cover: title, peer set, period, basis (consolidated, Ind AS, ₹ crore, FY ending 31 March), author, version, date.
  2. Executive summary (one page): governing conclusion, three quantified pillars, key risks, one summary exhibit (e.g., the capital efficiency matrix or ROIC vs growth chart).
  3. Peer context: business models, peer-selection rationale, policy and period alignment.
  4. Financial pillars: growth and margins (with EBITDA bridges), returns (DuPont, ROIC), cash conversion and working capital (CCC), leverage.
  5. Forensic notes: Week 7 flags and how they adjust or caveat the ranking.
  6. Risks and monitorables.
  7. Appendix: definitions, standardized 3-year statements, adjustments log summary, sources list, check status.

The executive summary comes first because readers decide in the first page whether to read further (Pyramid Principle: answer first).

Print areas and page setup in Excel

  • Set print areas on each output sheet: select the range → Page Layout → Print Area → Set Print Area. For multiple non-contiguous blocks, hold Ctrl while selecting — each becomes a separate page.
  • Orientation and scaling: landscape for wide year-by-peer tables; Page Setup → Fit to 1 page wide by automatic tall so columns never split; avoid shrinking below about 70% — use smaller tables instead.
  • Print titles: Page Layout → Print Titles → Rows to repeat at top (header row with years) and Columns to repeat at left (line labels) for multi-page tables.
  • Page Break Preview (View tab) to drag breaks so a table or chart is never split.
  • Margins consistent across sheets (e.g., Normal or Narrow, but the same everywhere); centre horizontally.
  • Headers/footers: report title and version in the header; page number ("Page &[Page] of &[Pages]"), file name and print date in the footer; a confidentiality or "for educational use" note if appropriate.
  • Gridlines and headings: untick Print gridlines and Print row and column headings.
  • Black-and-white check: preview in greyscale; ensure colour codes still read.

Consistent chart styling

  • Apply the saved chart template (.crtx) and theme to every chart.
  • Set identical sizes for charts of the same type (Format → Size, e.g., 7.5 cm × 13 cm), aligned to cell gridlines (hold Alt while dragging to snap).
  • Same fonts and sizes (title 11–12 pt bold, labels 8–9 pt), same company colours, same unit placement and source line position.
  • Action titles on every chart, linked to cells; subtitles with metric, unit, period, basis.
  • Check that no chart refers to cells outside the print area for labels you expect to see.

Producing the PDF

  • File → Export → Create PDF/XPS, or File → Save As → PDF. In Options, choose Active sheet(s) after grouping the output sheets in report order (Ctrl-click tabs), or Entire workbook; leave Ignore print areas unticked.
  • Sheet order in the PDF follows tab order — arrange tabs or use a dedicated "Report" set of sheets.
  • Alternatively, write the report in Word or PowerPoint with charts pasted as linked objects; before export, refresh links (File → Info → Edit Links to Files → Update Values) and then break links or paste as pictures in the final version to freeze it.
  • Set document properties (title, author) and remove personal or hidden information (File → Info → Check for Issues → Inspect Document) if sharing externally.
  • Name the file with version and date, e.g., Project2_JewelleryPeers_v1.3_2026-11-28.pdf.

Appendix with definitions

The appendix makes the report verifiable:

  • Definitions table: metric, formula in words, numerator and denominator lines, average or closing balances, treatment of leases and other income, direction (higher is better or worse) — printed from the definitions sheet so it cannot diverge from the workbook.
  • Standardized statements: 3-year P&L, BS and CFS per peer in ₹ crore.
  • Adjustments summary: material normalization and policy adjustments with amounts and rationale.
  • Sources: list of documents with dates.
  • Check status: master check "OK" with the check count, demonstrating integrity.

Final PDF review

Before issue, read the PDF (not the workbook) end to end:

  • Every number quoted in text matches the exhibit and the appendix.
  • No #REF!, #N/A, #DIV/0! or "0" where a dash is intended.
  • Page numbers, version and date are correct; table headers repeat on continuation pages.
  • Charts are crisp (vector, not blurry screenshots); text is searchable.

Edge cases & judgement calls

  • Very wide tables (three peers × three years × several metrics): split by peer or by metric group instead of shrinking to unreadable font sizes.
  • Hidden rows inside a print area are not printed — useful for helper rows, dangerous if a hidden row contains something the reader needs.
  • Excel vs PowerPoint as the report medium: Excel PDFs are faster and stay linked; Word/PowerPoint give better typography and narrative flow. For interviews, a short PowerPoint deck plus the PDF appendix is common.
  • Page size: A4 is the Indian norm; US Letter defaults can crop content when printed in India.
  • Fonts: uncommon fonts may substitute on another machine; embed fonts or use standard ones.

Key takeaways

  • Executive summary first, appendix last; the PDF must stand alone.
  • Set print areas, fit-to-width, print titles and page breaks deliberately for every output sheet.
  • One chart template, identical sizes, consistent fonts and colours across exhibits.
  • Print definitions, standardized statements, adjustments and sources in the appendix from the workbook itself.
  • Review the PDF, not the workbook, before issue: numbers, errors, headers, version.

Practice Questions

Q1. Page setup specification [L1]

Write the page setup settings (orientation, scaling, print titles, margins, header, footer, gridlines) for a ratio engine sheet with 45 rows of metrics and nine data columns (three peers × three years) that must print legibly on A4.

Q2. Report outline [L2]

Draft the page-by-page outline of a 12–15 page Project 2 PDF on Infosys, TCS and Wipro, stating for each page its action title placeholder, the exhibit(s) and the workbook sheet that feeds it.

💡 Hint: Start from the governing conclusion and work down the pyramid; the appendix follows the analysis pages.

Q3. Linked-deck workflow [L2]

You build charts in Excel and the report in PowerPoint. Describe the workflow from final workbook check to issued PDF that ensures the deck shows the final numbers, cannot later change accidentally, and records the version.

Q4. Diagnose a bad PDF [L1]

A reviewer reports: the CCC table splits across two pages without headers, one chart is cut off on the right, the EBITDA bridge shows "#REF!" in a label, and the footer shows "v0.9". List the cause and fix for each.
