Subtopic note

Source Referencing for Every Figure in the Workbook

Scope: Source referencing: annual report page/note, Reg 33 filing date, XBRL tag or investor presentation slide

Why it matters

An unsourced number is an unverifiable number. In equity research compliance reviews, credit committees and due diligence, every figure in a report must be traceable to a public document, so that a reviewer can check it in under a minute and so the analyst can defend it when challenged. Source referencing also protects you: when a company restates comparatives or a peer's investor presentation defines EBITDA differently from its financial statements, the reference shows exactly which version you used. For Project 2, a figure without a source is treated as a defect in the same way as a failed check.

Core notes

What a complete source reference contains

Source type Reference elements Example
Annual report Company, FY, document, consolidated/standalone, page number, note number, line caption Titan AR FY25, consolidated, p.212, Note 28 "Other expenses"
Reg 33 quarterly/annual results Company, quarter, filing date, exchange, statement, line Kalyan Q3 FY25 results, filed with NSE/BSE on [date], consolidated, "Revenue from operations"
XBRL filing Exchange or MCA filing, period, taxonomy element name, context (consolidated/standalone) NSE XBRL, FY25 results, element for revenue from operations, consolidated context
Investor presentation / earnings call Company, quarter, slide number or transcript page, metric definition Senco Q4 FY25 investor presentation, slide 9, "Gold volume (kg)"
IFRS 20-F Company, fiscal year, Item/Note, page Infosys Form 20-F FY25, Note 2.x, page reference
Analyst calculation Formula reference to source cells "Calc: DSO per Definitions!D14"

Reg 33 context: SEBI LODR Regulation 33 requires listed entities to submit quarterly financial results within 45 days of quarter-end and audited annual results within 60 days of the financial year-end, with a limited review or audit report. The filing date matters because figures are sometimes revised in the subsequent annual report (reclassification, restatement) and because calendarization uses quarterly filings. Record the date of the filing you used.

XBRL context: listed companies file financial results in XBRL on the stock exchanges, and specified classes of companies file financial statements in XBRL with the MCA (AOC-4 XBRL) under the Companies (Filing of Documents and Forms in Extensible Business Reporting Language) Rules, 2015. XBRL element names provide machine-readable, unambiguous references and are the natural key when extraction is automated with Power Query (Week 10). Element names follow the applicable Ind AS taxonomy; record the exact element and context rather than paraphrasing.

Where references live in the workbook

  1. Source column on raw extracts: every raw line has a source ID (e.g., TIT-AR25-P212-N28) and, optionally, a hyperlink to the PDF page (=HYPERLINK("file:///...Titan_AR_FY25.pdf#page=212","p.212") — works in many PDF viewers; test on your machine).
  2. Sources register (a sheet): one row per document — ID, company, document title, FY/quarter, date, URL or file name, date downloaded, basis (consolidated/standalone), framework (Ind AS / IFRS).
  3. Adjustments log: each adjustment cites the note or disclosure that supports it (e.g., "Note 41 exceptional items: ₹63 crore impairment").
  4. Definitions sheet: where a metric relies on non-statement data (gold volume, headcount, store count), the source document type is named.
  5. Charts and tables: a source line under each exhibit summarising documents and basis.
  6. Report appendix: a bibliography-style list of documents with dates.

Referencing conventions

  • Use the page number printed on the document and the PDF page if they differ (annual reports often have a 15–30 page offset); state which convention you use.
  • Prefer note numbers over page numbers where possible — they survive reformatting.
  • Name the line caption exactly as printed; paraphrased captions make verification slower.
  • For restated comparatives, cite the latest document (e.g., FY24 figures as restated in the FY25 annual report) and record the original source in the change log.
  • For derived non-financial KPIs (e.g., store count, attrition), cite the slide and quarter; these are unaudited and should be flagged as such.
  • For calculations, reference the definitions sheet rather than writing the formula in prose.

Verification workflow

  • Sampling: the reviewer picks, say, 10% of raw-extract cells at random plus every figure quoted in the executive summary and traces them to source.
  • Totals tie: reported subtotals (total income, PAT, total assets) are checked against source first; if subtotals tie, line-level errors are less likely.
  • Cross-source reconciliation: annual report revenue versus sum of four Reg 33 quarters; investor-presentation EBITDA versus computed EBITDA (definition differences documented).

Edge cases & judgement calls

  • Conflicting sources: if the investor presentation and the annual report disagree, the audited annual report prevails for financial statement figures; the difference is noted.
  • Quarterly figures not separately reported: Q4 is often derived as annual audited minus nine-month figures; reference both filings and mark Q4 as derived.
  • Paywalled databases (Capitaline, Prowess, Bloomberg): acceptable as a cross-check, but the primary reference should be the company document so any reader can verify.
  • Links breaking: URLs on company websites change; store downloaded PDFs with a consistent file-naming convention and record the download date.
  • Standalone vs consolidated pages: annual reports contain both; references must specify which.

Key takeaways

  • Every typed number gets a source ID linking to a sources register.
  • Annual report references: page and note and exact caption; Reg 33: quarter and filing date; XBRL: element and context; presentations: slide and quarter.
  • Cite restated comparatives from the latest document and log the original.
  • Unaudited KPIs are flagged as such; audited statements prevail in conflicts.
  • Reviewers sample raw cells and all headline figures back to source.

Practice Questions

Q1. Write source references [L1]

Write complete source references for: (a) Titan's FY25 consolidated lease liabilities from the notes; (b) Kalyan's Q2 FY25 consolidated revenue from the Reg 33 results; (c) TCS's FY25 headcount from the earnings presentation; (d) Infosys's FY25 revenue in USD from Form 20-F.

Q2. Sources register design [L2]

Design the columns of a sources register and the source-ID naming convention for a three-peer, three-year project using annual reports, 12 quarterly Reg 33 filings per company, XBRL files and investor presentations. Explain how you would make IDs sortable and unambiguous.

💡 Hint: Think about which elements (company, document type, period) must appear in the ID and in what order.

Q3. Conflicting figures [L2]

Senco's investor presentation reports FY25 EBITDA of ₹590 crore, while your computation from the audited statements gives ₹548 crore. Explain how you would investigate, which figure the report uses, and how both the source references and the definitions sheet should document the difference.

Q4. Derived Q4 data [L1]

Explain how you would derive and reference Q4 FY25 revenue for a company whose Reg 33 filing provides only the audited annual and the nine-month figures, and what flag you would attach to the derived value.
