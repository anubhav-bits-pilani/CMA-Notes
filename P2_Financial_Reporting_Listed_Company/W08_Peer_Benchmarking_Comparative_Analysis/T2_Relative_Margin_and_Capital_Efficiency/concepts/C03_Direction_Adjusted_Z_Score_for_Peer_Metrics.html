Key concept

Direction-Adjusted Z-Score for Peer Metrics

Concept: Z-score = (Metric − Peer mean) ÷ Peer standard deviation; multiply by −1 for lower-is-better metrics

Statement

\[ z_{i,m} = d_m \times \frac{x_{i,m} - \bar{x}_m}{s_m}, \qquad d_m = \begin{cases} +1 & \text{higher is better} \\ -1 & \text{lower is better} \end{cases} \]

where \(x_{i,m}\) is peer \(i\)'s value on metric \(m\), \(\bar{x}_m\) is the mean across the peer set, and \(s_m\) is the peer standard deviation (sample, STDEV.S, unless stated otherwise). Lower-is-better metrics in the matrix are CCC, net debt/EBITDA (after cap/floor) and margin CV.

Excel (dynamic, one row per metric with the direction in column H):

=LET(rng, $B5:$F5, d, $H5, sd, STDEV.S(rng),
     IF(sd=0, 0, d*(B5-AVERAGE(rng))/sd))

Explanation

A z-score expresses each value as a number of standard deviations from the peer mean. That makes metrics with different units (%, days, x) addable in a composite (c04). The direction multiplier makes "positive = better" true on every row, so weights can be applied without sign errors.

Properties to remember:

  • For any metric, z-scores across the peer set sum to zero and (with STDEV.S) have a sample standard deviation of 1.
  • Multiplying the raw metric by −1 before standardising gives exactly the same result as multiplying the z-score by −1. Direction can be applied either way, but only once.
  • Small samples. With \(n\) peers and STDEV.S, no z-score can exceed \((n-1)/\sqrt{n}\) in absolute value, which is about 1.15 for \(n = 3\) and 1.79 for \(n = 5\). Three-peer z-scores are therefore compressed and very sensitive to any single value.
  • Outliers inflate \(s_m\) and compress everyone else. Cap z-scores (for example ±2) or winsorise raw values (s04).
  • Zero dispersion. If all peers are equal, \(s_m = 0\). Return 0 (no information), not an error.
  • Relative, not absolute. A positive z-score means "better than this peer set", not "good". A whole peer set can be below WACC, which is why c05 adds an absolute anchor.

Z-score vs Altman Z. This concept is a statistical standardisation. Do not confuse it with the Altman Z-score bankruptcy model (Week 7 forensic toolkit), which is a weighted sum of specific ratios.

Illustration

CCC (days, lower is better) for four jewellers: 160, 190, 210, 250.

Mean = 202.5. STDEV.S = \(\sqrt{[(-42.5)^2 + (-12.5)^2 + 7.5^2 + 47.5^2]/3} = \sqrt{4{,}275/3} = 37.75\).

Peer CCC Raw z Direction-adjusted z
J4 160 −1.13 +1.13
J1 190 −0.33 +0.33
J3 210 +0.20 −0.20
J2 250 +1.26 −1.26

The direction-adjusted scores sum to zero, and the shortest CCC (J4) scores highest, as intended.

Practice Questions

Q1. Compute direction-adjusted z-scores [L1]

Net debt/EBITDA (after floor at 0x) for five peers is 0.0x, 0.4x, 1.2x, 1.9x and 2.5x. Compute direction-adjusted z-scores using STDEV.S, and confirm they sum to zero.

Q2. Prove the equivalence [L2]

Using CCC values 120, 150 and 210 days, show numerically that z-scoring the negated values (−120, −150, −210) gives the same result as multiplying the ordinary z-scores by −1. Then explain the error that arises if an analyst does both.

💡 Hint: Negation flips both the deviation and the mean, while the standard deviation is unchanged.

Q3. Small-sample limitation in an interview [L2]

An interviewer asks: "With only three peers, is a z-score composite meaningful?" Prepare a 120-word answer covering the bound on z-scores, sensitivity to one value, alternatives (rank, raw values with thresholds) and how you would present the result honestly.
