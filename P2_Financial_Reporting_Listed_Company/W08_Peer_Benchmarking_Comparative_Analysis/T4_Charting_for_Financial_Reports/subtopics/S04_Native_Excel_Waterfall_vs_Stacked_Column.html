Subtopic note

Native Excel Waterfall vs Stacked-Column Workaround

Scope: Excel native waterfall (2016+) with "set as total" vs stacked-column workaround for older versions

Why it matters

Every EBITDA bridge, net-debt walk, cash-flow bridge and budget-versus-actual variance in Project 2 and in later FP&A work is drawn as a waterfall. Excel offers two routes: the native Waterfall chart (Excel 2016 and Microsoft 365) and the older stacked-column construction. Practitioners need both — the native chart is fast, but many corporate environments, banks' model templates and clients' files still require charts that open correctly in older versions, support cell-linked labels and allow fine formatting control. Knowing the trade-offs, and being able to build the workaround from scratch, is a frequent test in modelling interviews.

Core notes

Native waterfall (Excel 2016+)

Build steps

  1. Lay out two columns: labels (FY24 EBITDA, Volume, Price, Raw material, Employee cost, Other opex, FY25 EBITDA) and values. Driver values carry their sign (cost increases negative); the start total is the opening value; the end total can be the closing value or left to Excel.
  2. Select the range → Insert → Insert Waterfall, Funnel, Stock, Surface or Radar Chart → Waterfall.
  3. Excel plots every value as a floating step. The first and last bars must be converted to totals: double-click the bar (select the single data point), right-click → Set as Total, or in Format Data Point → Series Options tick Set as total. A total bar is anchored to zero and shows the cumulative value at that point.
  4. Subtotals (e.g., "Gross profit FY25" midway in a long bridge) are also created with Set as Total. Excel does not compute the running total for a total bar: it plots the cell value from zero, and later drivers float from that value. The subtotal and end-total cells must therefore be formulas equal to the running total, otherwise the chart silently "resets" at that bar.
  5. Format: the legend shows Increase, Decrease, Total; click a legend entry to recolour all bars of that type (e.g., increases in dark grey, decreases in red/orange, totals in the company colour). Delete the legend afterward and use the action title instead. Show connector lines (Series Options) for readability.

Strengths

  • Fast; handles bars crossing zero (e.g., a net-debt walk from net cash to net debt) automatically.
  • Increase/decrease colouring is automatic and updates when signs flip.
  • Values update from the source range, so it is still formula-driven.

Limitations (version-dependent; test in your build)

  • Not available or not editable in Excel 2013 and earlier — the chart appears as an unsupported object.
  • The new chart family (waterfall, histogram, treemap, sunburst, box & whisker, funnel) has historically not supported Value From Cells data labels, secondary axes or combination with other chart types, and in many builds chart titles could not be linked to cells.
  • Set as Total is a manual, per-point setting; if the number of driver rows changes, totals must be reset.
  • Limited control over individual label placement and over category gap behaviour.
  • Cannot easily add a target or prior-year reference marker.

Stacked-column workaround (any version)

The idea: a stacked column chart with an invisible base series that lifts each driver bar to float at the right height, plus visible series for increases, decreases and totals.

Helper table — for each row \(k\), with signed driver \(d_k\) and cumulative before the step \(C_{k-1}\) and after \(C_k = C_{k-1} + d_k\):

Series Formula (driver rows) Formula (total rows)
Base (no fill) \(\min(C_{k-1}, C_k)\) 0
Increase \(\max(d_k, 0)\) 0
Decrease \(\max(-d_k, 0)\) 0
Total 0 the total value

In Excel (with named columns in a Table called Bridge):

Cum    = IF([@Type]="Total", [@Value], previous Cum + [@Value])
Base   = IF([@Type]="Total", 0, MIN(previous Cum, [@Cum]))
Up     = IF([@Type]="Total", 0, MAX([@Value], 0))
Down   = IF([@Type]="Total", 0, MAX(-[@Value], 0))
Total  = IF([@Type]="Total", [@Value], 0)

Insert a Stacked Column chart on Base, Up, Down, Total; format Base with No fill and No border; set gap width ≈ 50%; colour Up, Down and Total; add data labels to Up and Down (and use Value From Cells pointing at a signed-label column so decreases show "(27.0)" rather than "27.0").

Bars that cross zero

The simple base method fails when the cumulative path crosses zero (a stacked negative and positive value stack separately on each side of the axis). Options:

  • Up/down bars on a line chart: create two line series, Start of step \(C_{k-1}\) and End of step \(C_k\); add Up/Down Bars (Chart Design → Add Chart Element → Up/Down Bars); hide both lines. Excel draws a bar between the two values regardless of sign; up-bars and down-bars take different fills. Totals are handled by setting start = 0 and end = total.
  • Split series: separate positive-side and negative-side base and bar series (four to six helper columns). Works but is fiddly.
  • Error-bar method: plot the end-of-step value as an invisible series and draw a custom minus error bar of length \(d_k\); thick error bars look like columns. Rarely worth the complexity.

Choosing between them

Criterion Native waterfall Stacked workaround
Build time Minutes 20–30 minutes first time; reusable template thereafter
Older Excel / client compatibility No Yes
Crossing zero Automatic Needs up/down bars or split series
Cell-linked labels and title Limited, version-dependent Full
Fine formatting, reference markers Limited Full
Robust to adding rows Totals must be re-set Formula-driven via Type column

A practical rule for Project 2: use the stacked or up/down-bar method for the report exhibits (full control, cell-linked labels), and the native chart for quick analysis.

Edge cases & judgement calls

  • Subtotal values: in the native chart, if the cell value of a "Set as Total" bar differs from the running total of the preceding bars, the total bar is still drawn at the cell value, so the connector from the previous bar does not meet it — a visible jump that is easy to miss in a busy bridge. Drive the subtotal cell from the running total and add a zero-check.
  • Zero-value drivers still occupy a category slot; drop or group them.
  • Label signs: decreases should display with a minus sign or parentheses; the stacked method shows absolute heights, so labels must come from a signed label column.
  • Copying to PowerPoint: paste as linked chart or picture consistently; native waterfalls pasted into older PowerPoint builds may not render.
  • Vertical vs horizontal bridges: IBCS recommends horizontal waterfalls for structural (line-item) bridges with long labels; Excel's native chart is vertical only, whereas a stacked bar workaround can be horizontal.

Key takeaways

  • Native waterfall: insert, then Set as Total for start, subtotals and end; fast and sign-aware.
  • Its limitations are compatibility, cell-linked labels, and manual total settings.
  • The stacked workaround uses an invisible Base = MIN(cumulative before, after), plus Up, Down and Total series.
  • For paths crossing zero, use up/down bars on two hidden line series.
  • Drive every helper column by formula from a Type column so rows can be added safely.
  • Labels for decreases must come from a signed label column.

Practice Questions

Q1. Helper table build [L2]

Build the full Base/Up/Down/Total helper table for this net-debt walk (₹ crore): Opening net debt 450; EBITDA −620; working capital increase +140; capex +310; dividends +180; lease payments +60; tax paid +95; Closing net debt (total). State whether the cumulative path crosses zero and, if so, which construction you would use.

💡 Hint: In a net-debt walk, cash generation reduces net debt, so check the sign convention before computing the cumulative.

Q2. Native chart anomaly [L1]

In a native waterfall, the "Gross profit FY25" subtotal bar shows ₹4,820 crore, but the connector line from the preceding driver bar ends at ₹4,780 crore, leaving a visible step. Explain the cause and the permanent fix.

Q3. Up/down-bar construction [L2]

Describe step by step how to build a bridge from FY24 PAT of −₹35 crore to FY25 PAT of +₹48 crore with drivers EBITDA +110, depreciation −12, finance cost +8 and tax −23, using up/down bars on a line chart. Specify the start and end series values for every category.

Q4. Template decision [L3]

Your firm's Project 2 template must open correctly for a lender using Excel 2013 and must support cell-linked dynamic titles. Write a short decision memo choosing the waterfall method and listing the controls you would add so the chart cannot silently go out of sync with the bridge calculation.
