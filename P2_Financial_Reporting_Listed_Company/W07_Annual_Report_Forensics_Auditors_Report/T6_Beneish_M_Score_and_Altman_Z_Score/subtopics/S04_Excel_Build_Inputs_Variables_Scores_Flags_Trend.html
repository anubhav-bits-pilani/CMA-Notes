Subtopic note

Excel Build: Inputs, Variables, Scores, Flags, Trend and Peers

Scope: Excel build: input block, variable block, score, threshold flags, multi-year trend and peer comparison

Why it matters

A forensic score is only credible if a reviewer can trace every number to the annual report and re-perform every calculation. In FP&A and research roles, M-score and Z-score sheets are reused across many companies and years, so the build must separate inputs from calculations, use consistent formulas across columns, flag thresholds automatically, and roll into a trend and peer view. This note specifies a build that meets Week 9 model-hygiene standards and feeds a Week 12 Power BI dashboard.

Core notes

Workbook architecture

Sheet Contents Rules
Cover Company, CIN, NSE symbol, standalone/consolidated, units (₹ crore), FY range, version, preparer, reviewer No calculations
Inputs Raw Schedule III line items per year, with source column (note number, page) Hard-coded values only, blue font; one row per line item; years across columns
Map Proxy definitions (SGA, COGS, LTD, PPE scope) with switches Switch cells (e.g. include leases = 1/0) drive calculations
Calc_M Eight Beneish variables per year, contributions, M-score Formulas only, black font; same formula across each row
Calc_Z X1–X5, Z, Z', Z'' per year Formulas only
Checks Balance sheet ties, sign checks, division-by-zero, CFO tie to cash flow All checks roll into one master flag
Output Scores, zone flags, trend chart, peer table Links only
Peers Same block for 4–6 peers, or a long table for Power BI Consistent mapping

Use an Excel Table (e.g. tblInputs) with columns Company, LineItem, FY, Value, Source if you plan to pivot or load into Power BI; use a wide layout (years across) for the single-company sheet.

Input block

Minimum line items per year (three years for two scores): revenue from operations; cost of materials consumed; purchases of stock-in-trade; changes in inventories; employee benefits expense; other expenses and its separable components (power and fuel, freight); depreciation and amortisation (with ROU split); finance costs; PBT before exceptional items; exceptional items; PAT from continuing operations; trade receivables (current and non-current); contract assets; total current assets; PPE, ROU assets, CWIP, intangibles, intangibles under development; total assets; total current liabilities; non-current borrowings; non-current lease liabilities; total liabilities; share capital; retained earnings; other equity; CFO; shares outstanding; year-end share price.

Variable block — formulas

Assume years in columns D (FY23), E (FY24), F (FY25), with named rows. For FY25 in column F:

DSRI   =IFERROR((F_Rec/F_Sales)/(E_Rec/E_Sales),1)
GMI    =IFERROR(((E_Sales-E_COGS)/E_Sales)/((F_Sales-F_COGS)/F_Sales),1)
AQI    =IFERROR((1-(F_CA+F_PPE)/F_TA)/(1-(E_CA+E_PPE)/E_TA),1)
SGI    =F_Sales/E_Sales
DEPI   =IFERROR((E_Dep/(E_Dep+E_PPE))/(F_Dep/(F_Dep+F_PPE)),1)
SGAI   =IFERROR((F_SGA/F_Sales)/(E_SGA/E_Sales),1)
LVGI   =((F_CL+F_LTD)/F_TA)/((E_CL+E_LTD)/E_TA)
TATA   =(F_PATcont-F_CFO)/F_TA

In a real sheet, replace the placeholder names with cell references (e.g. =(F12/F5)/(E12/E5)) or with LET for readability:

=LET(rec_t,F12, s_t,F5, rec_p,E12, s_p,E5, IFERROR((rec_t/s_t)/(rec_p/s_p),1))

Proxies are computed in Map with switches, for example:

F_SGA =F_Employee + F_OtherExp - Sw_ExclPower*F_Power - Sw_ExclFreight*F_Freight
F_LTD =F_NCBorrowings + Sw_InclLeases*F_NCLease
F_PPE =F_PPEnet + Sw_InclLeases*F_ROU + Sw_InclCWIP*F_CWIP

Score block

Coefficients sit in a single input row (Coef_M), so the score is one SUMPRODUCT:

M_FY25 =Const_M + SUMPRODUCT(Coef_M, F_DSRI:F_LVGI)

with Const_M = -4.84 and Coef_M = {0.920, 0.528, 0.404, 0.892, 0.115, -0.172, 4.679, -0.327} aligned to the variable order DSRI, GMI, AQI, SGI, DEPI, SGAI, TATA, LVGI. Keep a contribution row for each variable (=Coef*Variable) so the drivers are visible.

Altman scores:

Z_FY25   =1.2*F_X1 + 1.4*F_X2 + 3.3*F_X3 + 0.6*F_X4mkt + 1.0*F_X5
Zp_FY25  =0.717*F_X1 + 0.847*F_X2 + 3.107*F_X3 + 0.420*F_X4book + 0.998*F_X5
Zpp_FY25 =6.56*F_X1 + 3.26*F_X2 + 6.72*F_X3 + 1.05*F_X4book

Threshold flags

M_Flag   =IF(M_FY25>-1.78,"Likely manipulator",IF(M_FY25>-2.22,"Watch (grey)","Unlikely"))
Z_Flag   =IF(Z_FY25>2.99,"Safe",IF(Z_FY25>=1.81,"Grey","Distress"))
Zpp_Flag =IF(Zpp_FY25>2.60,"Safe",IF(Zpp_FY25>=1.10,"Grey","Distress"))

Apply conditional formatting (red/amber/green) to the flag cells and to any variable above the Beneish manipulator mean (DSRI > 1.465, GMI > 1.193, AQI > 1.254, SGI > 1.607, DEPI > 1.077, TATA > 0.031) as a driver highlight.

Checks block

Check Formula idea Tolerance
Balance sheet ties =ABS(TA-(TL+Equity+NCI))<0.5 ₹0.5 crore
CFO ties to cash flow statement =ABS(CFO_input-CFO_from_CF_sheet)<0.5
Revenue positive, TA positive =AND(Sales>0,TA>0)
Proxy switches identical across years =COUNTIF(SwitchRow,"<>"&Sw_Base)=0
No IFERROR fallbacks triggered count of variables equal to exactly 1 due to error Investigate
Master check =AND(all checks) shown on Output Must be TRUE

Multi-year trend and peers

  • Compute M and Z'' for at least five years (needs six years of data). Plot a line chart with threshold lines at −1.78/−2.22 and 1.10/2.60.
  • A trend crossing upward through −2.22 toward −1.78 is more informative than a single breach.
  • Peer comparison: same mapping switches for 4–6 sector peers; show the score, rank, and each variable's z-score versus the peer median, so a high SGI caused by a sector boom is visible.
  • For Power BI (Week 12), unpivot the input table with Power Query and compute variables as measures; keep the Excel version as the audit trail.

Edge cases & judgement calls

  • IFERROR defaults to 1 hide data problems; always count and report them.
  • Hard-coded numbers inside formulas (other than the published coefficients in a labelled block) break auditability.
  • Mixed standalone and consolidated inputs across years — enforce with a single basis switch on the cover.
  • Units (₹ lakh vs ₹ crore) differ between small-cap and large-cap reports; normalise at input.
  • Fiscal year changes (15-month periods after a year-end change) distort SGI; annualise with a note.

Key takeaways

  • Separate Inputs (with sources), Map (proxy switches), Calc, Checks and Output.
  • One formula per row across years; coefficients in a labelled input block; score via SUMPRODUCT.
  • Flags via nested IF with both −1.78 and −2.22 for M, and zone cut-offs for each Altman variant.
  • Checks must tie the balance sheet and CFO and expose IFERROR fallbacks.
  • Trend and peer views turn a single score into evidence.

Practice Questions

Q1. Write the formulas [L1]

In a sheet where FY25 data is in column F and FY24 in column E, with revenue in row 5, trade receivables in row 12, COGS in row 7, current assets in row 15, PPE in row 16, total assets in row 18, depreciation in row 9, SGA in row 22, current liabilities in row 25, LTD in row 26, PAT from continuing operations in row 30 and CFO in row 32, write the Excel formulas for all eight Beneish variables in column F.

Q2. Design the checks [L2]

List six checks you would add to the Checks sheet for a five-year, two-model build covering one target and five peers, and write the formula for a master check that turns the output header red if any check fails.

💡 Hint: Think about balance ties, proxy consistency, error fallbacks and units.

Q3. Build and present [L3]

Build (in Excel) an M-score and Z''-score workbook for one NSE-listed manufacturing company and three peers for FY 2021-22 to FY 2024-25 using the architecture in this note. Deliverables: Inputs with note/page references, proxy switches, scores and flags, a trend chart with threshold lines, a peer table with variable z-scores, and a one-paragraph interpretation of the top drivers.

Q4. Power Query handoff [L2]

Describe the Power Query steps to convert a wide Inputs sheet (line items in rows, years in columns, multiple companies in blocks) into a long table suitable for computing Beneish variables as Power BI measures.
