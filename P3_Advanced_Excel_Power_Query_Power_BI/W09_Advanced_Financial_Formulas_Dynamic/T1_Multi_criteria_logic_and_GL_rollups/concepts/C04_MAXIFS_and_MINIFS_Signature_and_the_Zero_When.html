Key concept

MAXIFS and MINIFS: Signature and the Zero-When-Empty Trap

Concept: =MAXIFS(AP[Amount], AP[Vendor], F2, AP[Status], "Open"): MINIFS has the same signature; both return 0 when nothing matches

Statement

\[ \text{MAXIFS} = \max\{\, x_i : i \in S \,\}, \qquad \text{MINIFS} = \min\{\, x_i : i \in S \,\} \]

where \(x_i\) is the numeric value in max_range/min_range for row \(i\), and \(S\) is the set of rows meeting all criteria (here: Vendor equals F2 and Status equals "Open"). Non-numeric values in the value range are excluded. If \(S\) is empty (or contains no numeric values), both functions return 0 rather than an error.

Signature: MAXIFS(max_range, criteria_range1, criteria1, [criteria_range2, criteria2], …); MINIFS is identical with min_range.

Explanation

Same grammar as SUMIFS. The value range comes first; criteria pairs follow, ANDed together, each criteria range the same size as the value range (otherwise #VALUE!). Criteria accept operators, concatenated cells, wildcards and date bounds.

The zero trap. Returning 0 for "no match" makes an empty result indistinguishable from a genuine zero, and for dates it displays as 00-Jan-1900. A vendor with no open invoices shows "largest open payment: ₹0" — harmless — but "oldest open invoice: 00-Jan-1900" feeding an ageing formula produces an age of about 46,000 days and can push a vendor into the >180-days bucket. Guard every MAXIFS/MINIFS with a COUNTIFS on the same criteria:

=IF(COUNTIFS(AP[Vendor],F2,AP[Status],"Open")=0, "", MAXIFS(AP[Amount],AP[Vendor],F2,AP[Status],"Open"))

Sign conventions. On AP data stored as negative credits, MAXIFS returns the smallest liability (closest to zero) and MINIFS the largest. Know the sign of your sub-ledger extract.

Finding the row. MAXIFS returns the value, not the invoice. Use a boolean XLOOKUP — XLOOKUP(1,(AP[Vendor]=F2)*(AP[Status]="Open")*(AP[Amount]=G2),AP[InvNo]) — or FILTER for ties.

Versions. Excel 2019 / Microsoft 365. In Excel 2016, the legacy equivalent is the array formula MAX(IF((AP[Vendor]=F2)*(AP[Status]="Open"),AP[Amount])) entered with Ctrl+Shift+Enter, or AGGREGATE(14,6,AP[Amount]/((AP[Vendor]=F2)*(AP[Status]="Open")),1).

AP open-items extract (₹):

Connections

Belongs to the AVERAGEIFS/MAXIFS/MINIFS subtopic; contrasts with AVERAGEIFS, which errors with #DIV/0! when nothing matches. The guard pattern links to the week's error-discipline theme. The "which row holds the max?" follow-up uses the boolean-array XLOOKUP from the lookups topic, and the oldest-invoice measure feeds working-capital and MSME (Section 43B(h)) ageing analysis in FP&A reporting.
