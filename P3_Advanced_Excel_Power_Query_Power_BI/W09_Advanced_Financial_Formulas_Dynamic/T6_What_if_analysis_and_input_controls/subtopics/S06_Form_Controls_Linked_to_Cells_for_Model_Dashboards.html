Subtopic note

Form Controls Linked to Cells for Model Dashboards

Scope: Form controls (combo box, check box, scroll bar) linked to cells for model dashboards

Why it matters

A model presented to a CFO, promoter or investment committee is often driven live in the meeting: "what if volume grows 6% instead of 9%?", "show me the downside", "turn off the new plant". Form controls — combo boxes, check boxes, scroll bars, option buttons and spin buttons — give non-Excel users a clean, safe way to flex the model without typing into input cells. Each control writes a value into a linked cell, and the model reads that cell like any other input. Used well, they turn a model's output sheet into an interactive dashboard; used badly, they hide inputs behind objects nobody can audit.

Core notes

Enabling and inserting

  1. Show the Developer tab: File → Options → Customize Ribbon → tick Developer.
  2. Developer → Insert → Form Controls (top group). Avoid the ActiveX group for models: ActiveX controls need VBA, behave inconsistently across versions and security settings, and are not supported on Mac or Excel for the web.
  3. Draw the control; right-click → Format Control → Control tab to set the linked cell and parameters.

Form controls work without macros; the workbook can stay .xlsx.

Combo box (dropdown)

Setting Meaning Example
Input range The list to display Lists!B2:B5 (Base, Upside, Downside, Stress)
Cell link Receives the position number of the selection Inputs!C2 → 1, 2, 3 or 4
Drop down lines Number of items visible 8

The linked cell holds an index, not the text — ideal for CHOOSE(C2, …) or INDEX(CaseValues, , C2) scenario switches (w9_t2). To display the name: =INDEX(ScenarioList, C2). The input range must be a plain range (not a spill reference or structured reference); point it at a fixed reserved range or a defined name.

Comparison with a Data Validation dropdown (s04):

Aspect Data Validation list Combo box
Lives in The cell itself A floating object
Returns The selected text The index number
Dynamic source Yes (names, spill refs) Fixed range or name
Keyboard use / paste Keyboard-friendly; paste bypasses Mouse-driven; cannot be pasted over
Best for Input sheets Dashboards and presentations

Check box (on/off switches)

Cell link returns TRUE when ticked, FALSE when unticked (and #N/A if set to "mixed"). Use as a switch:

=Capex_NewPlant * NewPlantOn          TRUE/FALSE coerces to 1/0 when multiplied
=IF(IncludeSynergies, Synergies, 0)

Typical switches: include the new plant, apply the PLI incentive, show figures in ₹ crore vs ₹ lakh, include a proposed acquisition, apply the 115BAA tax regime vs the old regime for comparison.

Scroll bar (sliders)

Setting Constraint
Minimum / Maximum value Integers 0 to 30,000
Incremental change Step per click on the arrows
Page change Step per click on the bar
Cell link Receives the integer value

Because only non-negative integers are allowed, scale the linked value to the real input:

Linked cell (Lists!D2): 0 … 200
Volume growth:   =Lists!D2/1000 - 0.05      maps 0 … 200 to −5.0% … +15.0% in 0.1% steps

A spin button works the same way with only up/down arrows — handy for "number of years" or "top-N" inputs.

Option buttons

A group of option buttons (drawn inside a Group Box) shares one linked cell that returns 1, 2, 3 … for the selected button — another way to choose a scenario or a reporting unit.

Dashboard design pattern

Layer Contents
Controls panel (output sheet) Combo box for scenario, check boxes for switches, scroll bars for 2–3 key drivers
Linked cells (Inputs or a "Control" block) Index and raw integers, clearly labelled, never typed over
Translation cells Formulas mapping raw values to model inputs (scaling, CHOOSE)
Model Reads translation cells only
Outputs KPIs, charts, "active scenario" label driven by INDEX on the linked cell

Key disciplines:

  • Link to cells on the Inputs sheet, labelled "Controlled by dashboard — do not type", so the model's inputs remain visible and auditable in one place.
  • Display the active settings on every printed output ("Scenario: Downside; New plant: Off; Volume growth: 6.0%").
  • Reset button logic: document base values so the model can be returned to base before saving (or include a check that flags when controls are not at base).
  • Lock position: Format Control → Properties → "Don't move or size with cells" to stop controls drifting when rows are inserted; protect the sheet with "Edit objects" disallowed to prevent accidental resizing.

Illustration

An FMCG company's dashboard: combo box (Base/Upside/Downside) linked to Inputs!C2; check box "Include Nagpur plant" linked to Inputs!C3; scroll bar for volume growth linked to Inputs!C4 (0–200, step 5).

Control state Linked cells Translated inputs FY28 EBITDA (₹ crore)
Base, plant on, slider 130 1, TRUE, 130 growth 8.0%, plant capacity included 412
Downside, plant off, slider 80 3, FALSE, 80 growth 3.0%, plant excluded 296

The EBITDA figures are illustrative outputs of the underlying model; the point is that every number on the dashboard traces to three visible linked cells.

Edge cases & judgement calls

  • Hidden logic. Controls are objects; a reviewer reading the grid does not see them. Document each control and its linked cell on the model map sheet.
  • Index fragility. If the combo box input range is reordered, index 2 changes meaning. Keep list order stable and add a check that INDEX(ScenarioList, C2) equals the expected label in the output header.
  • Scroll-bar resolution is limited to integers; plan the scale so steps are meaningful (0.1% or 0.5%).
  • Excel for the web/Mac. Form controls generally work on Mac and display on the web, but editing them online is limited; test the distribution environment.
  • Data Tables and controls. A Data Table can use a linked cell as its input cell if on the same sheet — a neat way to tabulate all scenarios — but the control will appear to "jump" during recalculation.
  • Overuse. More than five or six controls make a dashboard a puzzle; put the rest on the Inputs sheet.

Key takeaways

  • Form controls (not ActiveX) drive models without macros by writing values to linked cells.
  • Combo boxes return an index — perfect for CHOOSE/INDEX scenario switches; Data Validation lists return text.
  • Check boxes return TRUE/FALSE for on/off switches; scroll bars return integers 0–30,000 that you scale.
  • Keep linked cells on the Inputs sheet, display active settings on outputs, and lock control positions.
  • Document every control; objects are invisible to formula auditing tools.

Practice Questions

Q1. Configure three controls [L1]

Specify the Format Control settings and the translation formulas for: (a) a combo box selecting among four scenarios; (b) a check box switching an ₹85 crore acquisition in or out of the FY27 model; (c) a scroll bar setting EBITDA margin between 12.0% and 22.0% in 0.25% steps.

Q2. Combo box vs Data Validation [L2]

Your dashboard and your Inputs sheet both need a scenario selector. Explain which control you would use in each place, how you would keep them consistent (so there is only one source of truth for the selected scenario), and what check you would add.

💡 Hint: One of them should drive the other, not both drive the model.

Q3. Dashboard audit [L2]

You inherit a dashboard with nine form controls, some linked to cells on a hidden sheet and two linked to the same cell. List the review steps to map every control to its linked cell and its effect on outputs, and the redesign you would propose.

Q4. Board meeting design [L3]

The promoter of a mid-cap NSE-listed company wants to flex volume growth, realisation per tonne, coal cost and the commissioning date of a new kiln live in a board meeting, with outputs of FY28 EBITDA, net debt/EBITDA and DSCR. Design the control panel (control type, ranges, scaling), the linked and translation cells, the outputs and the safeguards to ensure the model is saved in its base state afterwards.
