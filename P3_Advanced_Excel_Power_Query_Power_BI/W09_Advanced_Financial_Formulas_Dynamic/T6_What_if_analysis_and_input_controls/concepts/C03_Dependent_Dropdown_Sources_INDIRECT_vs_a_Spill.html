Key concept

Dependent Dropdown Sources: INDIRECT vs a Spill Reference

Concept: Dependent list source =INDIRECT($B2), or a spill reference =$H$2# pointing at a UNIQUE output

Statement

Two ways to supply the Source of a Data Validation list:

1. INDIRECT for dependent lists

=INDIRECT($B2)

Returns the range whose name is the text in B2. If B2 holds "Sales" and a defined name Sales refers to the Sales cost-centre list, the dropdown in C2 shows those cost centres. Column B is locked, row relative, so the rule copied down column C looks at each row's own department.

2. A spill reference to a dynamic list

Source: =$H$2# — an absolute reference to the anchor H2 plus the spill operator #, where H2 contains, for example:

=SORT(UNIQUE(GL[Dept]))

The dropdown always lists exactly the values currently in the spill, growing and shrinking with the data.

Explanation

INDIRECT method — how it works and why it is fragile. Data Validation evaluates the source formula each time the dropdown opens. INDIRECT converts text to a reference, so each department name must match a defined name exactly. Constraints:

  • Names cannot contain spaces or start with digits: "Plant Pune" must map to Plant_Pune via =INDIRECT(SUBSTITUTE($B2, " ", "_")).
  • Renaming a department in the parent list breaks the child silently (the dropdown shows nothing).
  • Every new department needs a new named range created by hand.
  • INDIRECT is volatile, though inside validation the performance cost is negligible.

It is the only formula-only method that works row by row for long input templates in all Excel versions, which is why it remains widespread.

Spill-reference method — dynamic and maintenance-free. Data Validation accepts a spill reference (in Microsoft 365) as a list source, either directly or via a defined name (DeptList referring to =Lists!H2#, stored absolute by Name Manager). New departments appear automatically when the GL or mapping Table grows. For a dependent list from a single selector, put a FILTER spill on the Lists sheet:

=SORT(FILTER(Map[CostCentre], Map[Dept]=Inputs!B2, "—"))

and point the child validation at that spill. The limitation: one spill serves one selector cell, so row-by-row dependent lists need either INDIRECT or a helper spill per row.

Absolute vs relative. For the spill source, the reference must be absolute so every validated cell points at the same list. For the INDIRECT source, the parent reference is usually column-absolute, row-relative, so each row reads its own parent.

Clean-up rule. Neither method clears the child value when the parent changes. Add a validity check such as =COUNTIFS(Map[Dept], B2, Map[CostCentre], C2)=1 with conditional formatting.

Illustration

Mapping Table Map:

Dept CostCentre
Sales S-North
Sales S-West
Marketing M-Digital
Marketing M-Events
Plant Pune P-Assembly

INDIRECT set-up: names Sales (S-North, S-West), Marketing (M-Digital, M-Events), Plant_Pune (P-Assembly); child source uses SUBSTITUTE. Adding "Plant Chakan" requires a new name Plant_Chakan.

Spill set-up: Lists!H2 =SORT(UNIQUE(Map[Dept])) feeds the department dropdown (via the absolute spill reference); Lists!J2 =SORT(FILTER(Map[CostCentre], Map[Dept]=Inputs!B2, "—")) feeds the cost-centre dropdown. Adding "Plant Chakan" rows to Map updates both lists with no other change.

Practice Questions

Q1. Build both versions [L1]

For entities (India, UAE, UK) and their cost centres, write the named ranges and validation sources for an INDIRECT-based dependent dropdown, then the UNIQUE/FILTER spills and validation sources for the spill-based version.

Q2. Why is the dropdown empty? [L2]

After the department "Plant Pune" was renamed "Pune Plant" in the master list, users report that the cost-centre dropdown is empty for that department, while previously entered rows still show old cost centres. Explain both symptoms and propose a robust redesign.

💡 Hint: Consider what INDIRECT is looking for and whether validation re-checks existing entries.

Q3. Choosing a method for a 300-row template [L2]

A capex budget template needs department and cost-centre dropdowns on each of 300 rows and will be used by colleagues on Microsoft 365 and Excel 2019. Recommend a method, explain the trade-offs, and describe the checks you would add before consolidation.
