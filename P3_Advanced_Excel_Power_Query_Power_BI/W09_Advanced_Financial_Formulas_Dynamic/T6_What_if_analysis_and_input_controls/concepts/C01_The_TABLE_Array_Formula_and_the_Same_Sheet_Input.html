Key concept

The TABLE Array Formula and the Same-Sheet Input Rule

Concept: A Data Table creates {=TABLE(row_input_cell, column_input_cell)}; input cells must be on the same sheet as the table

Statement

When you run Data → What-If Analysis → Data Table, Excel writes into every result cell the multi-cell array formula

{=TABLE(row_input_cell, column_input_cell)}
  • row_input_cell — the model input that receives each value in the table's top row (blank for a column-oriented 1D table: {=TABLE(, C4)}).
  • column_input_cell — the model input that receives each value in the table's left column (blank for a row-oriented 1D table: {=TABLE(C4, )}).

For a 2D table, the value in result cell \((i, j)\) is

\[ V_{ij} = f\big(\text{row\_input} = r_j,\ \text{column\_input} = c_i\big) \]

where \(f\) is the model output referenced in the table's corner cell, \(r_j\) the \(j\)-th top-row value and \(c_i\) the \(i\)-th left-column value, with all other inputs at their current values.

Both input cells must be on the same worksheet as the Data Table.

Explanation

TABLE is not a function you can type — it can only be created through the Data Table dialog. The braces show it is a legacy multi-cell array: the whole result block is one object. You cannot edit, clear or overwrite a single result cell ("Cannot change part of a data table"); select the entire result block to delete it.

Why the same-sheet rule exists. A Data Table works by temporarily substituting each value into the input cell and recalculating. Excel implements this only for input cells on the table's own sheet; the dialog rejects a reference to another sheet ("Input cell reference is not valid"). Practitioners handle the constraint in three ways:

  1. Put the sensitivity on the Inputs sheet (simplest; keeps the substitution local).
  2. Local driver cells. Place WACC and growth "driver" cells on the valuation sheet and make them the model's true inputs, with the Inputs sheet displaying them — this breaks the "all inputs on one sheet" convention, so document it.
  3. Override cells. On the table's sheet, create blank override cells; the model's input formula becomes =IF(ISBLANK(WACC_Override), WACC_Base, WACC_Override) and the Data Table uses the override cell as input. Because the Data Table only substitutes temporarily, the override stays blank and the model runs on base. Add a check that overrides are blank.

Row vs column input. "Row input cell" means "the input that the row of values across the top represents" — a frequent source of confusion. Swapping them gives a plausible but wrong grid. The base-case cell of the grid must equal the live output; build that check (s08).

Calculation. Each TABLE recalculates the model once per cell, which is why "Automatic except for data tables" exists.

Illustration

Valuation sheet: corner cell C5 =EV; growth rates 4%, 5%, 6% in D5:F5; WACC 11%, 12%, 13% in C6:C8. The WACC and growth inputs are local driver cells H3 and H4 on the same sheet.

Dialog: Row input cell = H4 (growth), Column input cell = H3 (WACC). Excel writes {=TABLE(H4,H3)} into D6:F8. With EV = 100 ÷ (WACC − g) (₹ crore), D6 (11%, 4%) shows 1,428.6 and F6 (11%, 6%) shows 2,000.0.

Had the inputs been entered the other way round ({=TABLE(H3,H4)}), D6 would compute WACC = 4%, g = 11% — an error value or a negative EV — which is how swaps are often spotted, though with closer ranges the swapped grid can look plausible.

Connections

Underlies s01 (1D and 2D Data Tables) and s08 (calculation mode). The same-sheet rule is a checklist item and a common interview question. It interacts with model hygiene (inputs/calcs/outputs separation, a related item in this topic) and with the WACC × terminal growth grids of Weeks 15–16.

Practice Questions

Q1. Write the TABLE formula [L1]

For each layout, state the TABLE formula Excel will create: (a) prices down B6:B12, outputs across C5:E5, price input in G2; (b) volumes across C4:J4, outputs down B5:B8, volume input in G3; (c) a 2D grid with WACC down and margin across, inputs in H3 (WACC) and H5 (margin).

Q2. Inputs on another sheet [L2]

All assumptions live on an Inputs sheet, and the sensitivity must be presented on a Valuation sheet. Design the override-cell approach in full (formulas on both sheets, Data Table set-up, checks) and explain why the override cell remains blank after the table calculates.

💡 Hint: The Data Table substitutes values only during its own calculation pass.

Q3. Editing a table [L1]

A colleague tries to overwrite one cell of a Data Table result with a hard-coded number for a presentation and gets an error. Explain why, and how they should produce a presentation version of the grid.
