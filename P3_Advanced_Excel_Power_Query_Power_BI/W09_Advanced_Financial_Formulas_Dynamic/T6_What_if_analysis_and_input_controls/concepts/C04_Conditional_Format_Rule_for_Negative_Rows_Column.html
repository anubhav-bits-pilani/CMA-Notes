Key concept

Conditional Format Rule for Negative Rows: Column Locked, Row Relative

Concept: Conditional format rule =$E5<0 (column locked, row relative) applied to the whole P&L block

Statement

  • Applies to: the whole P&L block, e.g. B5:H64.
  • Rule formula: =$E5<0, written for the top-left cell of the Applies-to range (row 5).
  • Effect: for any cell in row \(r\) of the block, the rule evaluates

\[ \text{Format}(r, c) = \big[\,E_r < 0\,\big] \]

for every column \(c\) from B to H — the format depends only on the value in column E of the same row.

Explanation

Conditional formatting rules behave like a formula entered in the top-left cell and copied over the Applies-to range. The dollar sign before E locks the column, so every cell in the row looks at column E; the row number 5 is relative, so row 6 looks at E6, row 7 at E7, and so on. The result: whole rows shade when that row's variance is negative.

Comparison of reference styles for the same Applies-to range:

Rule What cell D9 tests Result
=$E5<0 E9 Whole row shaded by column E — intended
=E5<0 G9 (every cell tests the cell three columns to its right) Each cell tests a different column — wrong
=E$5<0 G5 Every row tests row 5 — wrong
=E5<0 with Applies-to E5:E64 only — Shades only the variance column

(With =E5<0 applied to B5:H64, cell B5 tests E5, C5 tests F5, D5 tests G5 — the offset from the top-left is applied to the reference, so D9 tests G9.)

Practical points:

  • Sign convention first. Make column E a sign-normalised variance (negative = adverse for both revenue and cost lines), otherwise favourable cost under-runs (negative Actual − Budget) shade red.
  • Subtotal and blank rows. Blank E cells evaluate as 0, so they do not shade; text headers in E evaluate as not < 0 (text compares greater than numbers), so headings are unaffected — but avoid relying on that; restrict the Applies-to range to data rows or add ISNUMBER($E5) in an AND.
  • Applies-to must start at the row the formula is written for. If the range starts at row 6 but the rule says $E5, every row tests the row above — a silent off-by-one.
  • Inserted rows inside the block extend the range; rows added below the block do not.
  • Combine with a named materiality threshold (c05) to avoid shading trivial variances.

Illustration

Budget vs actual block (₹ lakh), Applies-to B5:H8:

Row B Line C Budget D Actual E Variance (adverse < 0) Shaded?
5 Revenue 1,200 1,145 −55 Yes (B5:H5)
6 Raw materials 640 612 +28 No
7 Employee cost 180 191 −11 Yes
8 Freight 45 45 0 No

For cost lines, variance = Budget − Actual; for revenue, Actual − Budget — so both adverse results are negative and a single rule works.

Practice Questions

Q1. Predict the shading [L1]

A rule =$F6>0 is applied to B6:K40. For cells D10, K25 and B40, state which cell each one tests. Then state which cells cell D10 would test under =F6>0 and under =F$6>0.

Q2. Fix the off-by-one [L2]

The Applies-to range of a rule is B7:H70 but the rule formula is =$E6<0. Describe the symptom a reviewer would see, how to confirm the cause in Manage Rules, and the fix.

💡 Hint: Compare the first row of the Applies-to range with the row in the formula.

Q3. Mixed line types [L2]

A P&L block mixes revenue lines, cost lines and subtotal rows, with a raw variance column (Actual − Budget). Design the helper column(s) and a single conditional formatting rule that shades adverse rows only, excluding subtotals and blanks.
