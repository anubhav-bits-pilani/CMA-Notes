Key concept

Variance Flag Rule with a Named Threshold Input

Concept: Variance flag rule =ABS($F5)>Threshold, with Threshold as a named input cell

Statement

  • Rule formula: =ABS($F5)>Threshold, written for the top-left cell of the Applies-to range (row 5).
  • Column F holds the variance (₹ or %); $F locks the column, row 5 is relative.
  • Threshold is a defined name for a single input cell (e.g. Inputs!C12 = 10,00,000).

For each row \(r\):

\[ \text{Flag}_r = \big[\, \lvert F_r \rvert > \tau \,\big] \]

where \(F_r\) is the variance in row \(r\) and \(\tau\) the threshold. ABS makes the rule two-sided: large favourable and large adverse variances are both flagged.

Explanation

Why ABS. Management commentary is required for material variances in either direction. A large favourable cost variance can signal a missed accrual, a timing difference or a budgeting error — exactly what a reviewer wants to see. Use a separate colour for direction if needed (a second rule =$F5<0 for adverse).

Why a named input. Materiality changes: the controller may use ₹10 lakh for monthly MIS, ₹25 lakh for the board pack, or a percentage for small departments. With the threshold in a named cell:

  • The controller changes one input, not the rule.
  • The threshold is visible and documented (input message: "Monthly variance commentary threshold; approved by CFO").
  • The same name can drive a COUNTIF of flagged lines (=COUNTIF(F5:F64, ">"&Threshold) + COUNTIF(F5:F64, "<"&-Threshold)) and a FILTER exception list (w9_t4) — formatting, counts and lists all use one definition.

Absolute and percentage thresholds together. Percentage variances explode on small budgets (₹10,000 budget, ₹25,000 actual = 150%). A common design flags only when both tests are met:

=AND(ABS($F5)>Threshold, ABS(G5)>PctThreshold)

applied to a single column (so only one locked reference is needed), or built with a helper flag column that the rule simply tests.

Mechanics. The named cell is absolute by nature, so every cell in the block compares against the same value. Names in CF rules also survive sheet renames and are easier to read in Manage Rules than cross-sheet addresses.

Data types. If F contains text (e.g. "n/a" for new lines), ABS returns #VALUE! and the rule silently evaluates to no format. Use =ABS(N($F5))>Threshold or ensure numeric variances.

Illustration

Threshold = ₹10,00,000 (named input). Applies-to B5:H9.

Row Line Variance F (₹) Flagged?
5 Revenue −18,40,000 Yes
6 Raw materials +12,10,000 Yes (favourable, still material)
7 Power and fuel −6,50,000 No
8 Freight −10,00,000 No (not strictly greater)
9 Advertising +2,30,000 No

Changing Threshold to ₹5,00,000 flags rows 5–8 instantly. Use >= if the policy is "₹10 lakh and above".

Connections

Extends c04 (column-locked row rules) and s05 (threshold bands with priority). Named inputs reflect the model-hygiene principle of separating inputs from logic (topic related item). The same threshold drives variance commentary workflows in department-wise budget vs actual MIS (Weeks 17–20), and in Power BI becomes a what-if parameter or a measure-based conditional format (Week 11).

Practice Questions

Q1. Bands from one name [L1]

Using named inputs Thr_Amber (₹10 lakh) and Thr_Red (₹25 lakh), write two rules, their priority order and the Stop If True setting for a variance block B5:H64 with ₹ variances in column F.

Q2. Small-budget noise [L2]

A department pack flags 38 of 60 lines because the rule uses variance % only. Redesign the rule using both an absolute and a percentage threshold, write the formula(s), and explain how you would count flagged lines in a summary cell using the same names.

💡 Hint: Keep the definition in one place so formatting and counts cannot disagree.

Q3. Boundary and direction [L2]

The policy says "explain all adverse variances of ₹10 lakh and above, and favourable variances above ₹20 lakh". Write the rule(s) needed, state which inequality operators you use, and explain why a single ABS rule is insufficient here.
