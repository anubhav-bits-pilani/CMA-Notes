Key concept

Goal Seek Rules: Formula Set Cell, Hard-Coded Changing Cell

Concept: Goal Seek: the Set cell must hold a formula, and the By-changing cell must be a hard-coded input

Statement

Goal Seek solves

\[ f(x) = T \]

for one input \(x\), where:

  • Set cell — holds the formula \(f(x)\), the output to be driven to a target (EBIT, margin, NPV, DSCR).
  • To value — the target \(T\), typed as a number (it cannot be a cell reference).
  • By changing cell — holds \(x\), a constant (hard-coded input) on which the Set cell depends, directly or through a chain of formulas.

Goal Seek iterates on \(x\) until \(\lvert f(x) - T \rvert\) is within the Maximum Change tolerance (File → Options → Formulas; default 0.001) or the iteration limit (default 100) is reached, then writes the solved \(x\) into the changing cell.

Explanation

Why the Set cell must be a formula. Goal Seek observes how the Set cell responds to changes in the changing cell. A constant does not respond; Excel rejects it ("Cell must contain a formula").

Why the changing cell must be a constant. Goal Seek overwrites the changing cell with trial values. If it held a formula, solving would destroy model logic; Excel rejects it ("Cell must contain a value"). If your driver is itself calculated (e.g. volume = prior year × (1 + growth)), Goal Seek the underlying input (growth), not the calculated volume.

The dependency must exist. If the Set cell does not depend on the changing cell — for example because of a broken link or a hard-coded value somewhere in the chain — Goal Seek reports it may not have found a solution, or returns the unchanged value. Use Trace Dependents from the changing cell to confirm the path.

Target as a reference. Because "To value" must be typed, build a gap cell =Output - TargetCell and set it to 0. The target then lives visibly in the model.

Consequences for governance. After solving, the changing cell holds a hard-coded result that no longer tracks the logic that produced it. If other assumptions change, the solved value is stale. Record solves in a log, use a dedicated solve cell where possible, and keep a gap cell to detect drift.

Illustration

Break-even: price ₹1,500, variable cost ₹900 per unit, fixed costs ₹2.4 crore.

Cell Content Type
C4 Volume 30,000 Constant (changing cell)
C5 Contribution =C4*(1500-900) Formula
C6 EBIT =C5-24000000 Formula (Set cell)

Goal Seek: Set C6, To 0, By changing C4 → 40,000 units.

Errors to recognise:

  • Set cell = C4 (a constant) → "must contain a formula".
  • Changing cell = C5 (a formula) → "must contain a value".
  • If C6 were typed as −60,00,000 (pasted as value earlier), Goal Seek cannot find a solution because C6 no longer depends on C4.

Connections

Applies s02 (Goal Seek uses) and supports CVP break-even and margin-of-safety work in Week 21. The pitfall "Goal Seek overwrites an input with no audit trail" follows directly from the hard-coded changing-cell requirement. Model hygiene (blue inputs, black formulas — a related item) makes the two cell types visually distinct, so the right cells are chosen quickly in the speed test.

Practice Questions

Q1. Diagnose the error messages [L1]

For each Goal Seek attempt, predict the outcome and explain: (a) Set cell = the revenue growth input; (b) By changing cell = FY27 revenue (a formula); (c) Set cell = FY27 PAT, By changing = FY27 volume growth, but PAT links to a pasted-values copy of the P&L.

Q2. Target held in a cell [L2]

The CFO's target ROCE of 18% is held in a named input ROCE_Target, and the model's ROCE depends on price through revenue and working capital. Design a Goal Seek set-up that uses the named target without typing 18% into the dialog, and explain how you would detect that the solved price has become stale after a later change in capex.

💡 Hint: Create a cell whose zero value means the target is met.

Q3. Calculated drivers [L2]

In a model, FY27 volume = FY26 volume × (1 + growth), where growth is an input, and EBITDA depends on volume. A junior asks why Goal Seek will not change FY27 volume to hit an EBITDA of ₹120 crore. Explain, and set out the correct Goal Seek.
