XLOOKUP Returning Rows, Columns and Range References

Scope: XLOOKUP returning whole rows/columns (spill), and as a range reference: SUM(XLOOKUP(..):XLOOKUP(..))

Why it matters

Two XLOOKUP features change how finance grids are built. First, the return array can be several columns (or rows) wide, so one lookup returns an entire record — all twelve months of a ledger, or the full vendor master row — and spills it. Second, XLOOKUP returns a reference, not just a value, so two XLOOKUPs joined by the range operator : define a dynamic range. That gives a non-volatile way to sum "from month X to month Y" for YTD, QTD, rolling-12 and custom window reports, replacing OFFSET-based formulas that recalculate constantly and are hard to audit.

Core notes

Returning a whole row

With a P&L grid where Lines holds MIS line names (A6:A60), Months the 12 month headers (C4:N4) and Data the values (C6:N60):

=XLOOKUP("Employee cost", Lines, Data)

Because Data is 12 columns wide and the lookup is vertical, XLOOKUP returns the entire matching row — 12 values that spill horizontally from the formula cell. Point a chart or a variance row at it with the spill operator (H10#).

Returning a column: =XLOOKUP(DATE(2025,11,1), Months, Data) returns the November column (55 values) and spills vertically.

Returning part of a record: the return array can be any contiguous block aligned with the lookup array, e.g. =XLOOKUP(F2, Vendor[Code], Vendor[[Name]:[PAN]]) returns Name, GSTIN, State and PAN in one formula — a quick way to build a vendor card.

Spill rules: the destination cells must be empty (otherwise #SPILL!), and spilling is not allowed inside an Excel Table. Wrapping in an aggregator (SUM, AVERAGE, MAX) collapses the spill to one value.

XLOOKUP as a range reference

Unlike most functions, XLOOKUP (like INDEX) returns a cell reference when its return array is a range. Therefore:

=SUM(XLOOKUP(StartM, Months, Rev):XLOOKUP(EndM, Months, Rev))

where Rev is the revenue row (C8:N8). Mechanics:

  1. XLOOKUP(StartM, Months, Rev) returns a reference to, say, E8 (June).
  2. XLOOKUP(EndM, Months, Rev) returns a reference to I8 (October).
  3. The : operator joins them into the range E8:I8.
  4. SUM adds June to October.

Change StartM or EndM (dropdown cells) and the window moves — no OFFSET, no INDIRECT, no volatility. The same works with INDEX: SUM(INDEX(Rev, MATCH(StartM,Months,0)):INDEX(Rev, MATCH(EndM,Months,0))) — the legacy-compatible version.

Requirements:

  • Both XLOOKUPs must return references into the same range (here Rev), so the joined range is well-formed.
  • The return array must be an actual range, not a computed array (Rev*1 would return values, and : would fail with #VALUE!).
  • If StartM is after EndM, Excel still builds the range (from the later to the earlier cell), so the SUM silently covers the same window reversed — validate StartM<=EndM with a check cell or Data Validation.

Typical finance windows

Window StartM EndM
YTD FY start (01-Apr) selected month
QTD EOMONTH(Sel, -1-MOD(MONTH(Sel)-4, 3))+1 (fiscal quarter start) selected month
Last 3 months EDATE(Sel, -2) selected month
Rolling 12 EDATE(Sel, -11) selected month (needs a 24-month grid)
Custom user dropdown user dropdown

For rolling-12 the grid must contain at least 12 months before the selection; otherwise the start lookup fails (#N/A) — set if_not_found deliberately or validate the selection.

Worked illustration

Revenue row (₹ crore), FY26:

Apr May Jun Jul Aug Sep Oct Nov
12.4 13.1 12.8 14.0 14.6 15.2 16.9 15.5
  • StartM = 01-Apr-2025, EndM = 01-Oct-2025 → YTD to October = 12.4 + 13.1 + 12.8 + 14.0 + 14.6 + 15.2 + 16.9 = ₹99.0 crore.
  • StartM = 01-Aug-2025, EndM = 01-Oct-2025 → last three months = ₹46.7 crore.
  • Average monthly revenue over the window: =AVERAGE(XLOOKUP(…):XLOOKUP(…)), and the window length is =COLUMNS(XLOOKUP(…):XLOOKUP(…)).

Spill vs reference — when to use which

Need Use
Display a whole record somewhere else spill (=XLOOKUP(key, keys, block))
Aggregate a dynamic window range reference with : inside SUM/AVERAGE
Feed a chart that updates with a selection spill range referenced with # in a named range
Compatibility with Excel 2016/2019 INDEX:INDEX version

Combining with two-way logic

YTD for a selected line: =SUM(XLOOKUP(StartM, Months, XLOOKUP(Line, Lines, Data)):XLOOKUP(EndM, Months, XLOOKUP(Line, Lines, Data))). This works because the inner XLOOKUP returns a reference to the line's row. In practice wrap it in LET to compute the row once:

=LET(r, XLOOKUP(Line, Lines, Data),
     SUM(XLOOKUP(StartM, Months, r):XLOOKUP(EndM, Months, r)))

Edge cases & judgement calls

  • Reversed window (start after end) gives a plausible total — add validation.
  • Not-found start or end gives #N/A; an if_not_found returning a text value breaks the : operator (#VALUE!). Better to validate inputs than to default.
  • Hidden columns inside the window (e.g. a quarterly subtotal column) are summed too. Keep subtotal columns outside the data block or use a separate quarter grid.
  • Grids with text in the window are ignored by SUM but counted by COUNTA-based lengths.
  • Spilled records are values, not live links — if the source changes layout (column added within the block), the spill grows; downstream references using # adapt, fixed references do not.

Key takeaways

  • A multi-column return array makes XLOOKUP return a whole row or record, which spills.
  • XLOOKUP returns a reference, so XLOOKUP(…):XLOOKUP(…) builds a dynamic, non-volatile range.
  • Both ends must reference the same range; computed arrays cannot be joined with :.
  • Use the pattern for YTD, QTD, rolling-12 and custom windows driven by dropdown cells.
  • Validate start ≤ end and the availability of enough history; INDEX:INDEX is the legacy equivalent.

Practice Questions

Q1. Dynamic window sum [L1]

Months (01-Apr-2025 … 01-Mar-2026) are in C3:N3 and EBITDA in C20:N20 (named EBITDA). Write a formula that sums EBITDA from the month in StartM to the month in EndM, and a check cell that returns "Invalid window" if the start is after the end.

Q2. Rolling-12 KPI [L2]

A 36-month revenue history sits in a row named Rev with month-start headers in Hdr. Write a formula for trailing-twelve-month revenue at the selected month Sel, and explain what happens (and how to handle it) when Sel is within the first 11 months of history.

💡 Hint: The start of the window is eleven months before the selected month.

Q3. Vendor card [L1]

Table Vend has columns Code, Name, GSTIN, State, PAN, MSE, CreditDays. Write one formula that returns Name through CreditDays for the code in B2, and explain why it fails if entered inside an Excel Table.

Q4. Legacy-compatible version [L2]

Rewrite your Q1 formula so it works in Excel 2016, and explain why both versions are non-volatile while SUM(OFFSET(C20, 0, MATCH(StartM,C3:N3,0)-1, 1, n)) is volatile.

Q5. Why does it return #VALUE!? [L2]

An analyst writes =SUM(XLOOKUP(StartM, Months, Rev*1):XLOOKUP(EndM, Months, Rev*1)) "to force numbers". Explain why the formula fails and what the correct approach is if the revenue row contains numbers stored as text.
