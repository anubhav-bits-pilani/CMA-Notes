Subtopic note

Fiscal-Year Helpers: FY Start, FY End and Fiscal Month

Scope: Fiscal-year helpers: FY start/end and fiscal month number derived from a date

Why it matters

Excel's date functions think in calendar years: YEAR, MONTH and QUARTER-style logic assume January is month 1. Indian reporting runs April to March — the Companies Act FY (Sec 2(41)), the Income-tax previous year, GST annual returns and SEBI LODR quarterly results all use it. Every GL export, budget file and MIS grid therefore needs fiscal attributes derived from the transaction date: which FY it belongs to, the FY start and end dates, the fiscal month (April = 1), the fiscal quarter and YTD flags. Done inconsistently — >3 in one sheet, >=4 in another, a typed "FY" column in a third — these helpers are a common source of cut-off and comparative errors. Done once, cleanly, they underpin YTD vs prior-YTD comparisons, budget phasing and the date table of every Power BI model.

Core notes

The core formulas

Let d be a date.

Attribute Formula d = 17-Aug-2025 d = 12-Feb-2026
FY end year =YEAR(d) + (MONTH(d) >= 4) 2026 2026
FY label ="FY" & RIGHT(YEAR(d) + (MONTH(d) >= 4), 2) FY26 FY26
Long label =(YEAR(d) - (MONTH(d) < 4)) & "-" & RIGHT(YEAR(d) + (MONTH(d) >= 4), 2) 2025-26 2025-26
FY start date =DATE(YEAR(d) - (MONTH(d) < 4), 4, 1) 01-Apr-2025 01-Apr-2025
FY end date =DATE(YEAR(d) + (MONTH(d) >= 4), 3, 31) 31-Mar-2026 31-Mar-2026
Fiscal month (Apr = 1) =MOD(MONTH(d) + 8, 12) + 1 5 11
Fiscal quarter =INT((MOD(MONTH(d) + 8, 12)) / 3) + 1 2 4
Days in FY =FYEnd - FYStart + 1 365 365

How the logic works:

  • (MONTH(d) >= 4) is TRUE (1) for April–December, so those dates belong to the FY ending in the next calendar year.
  • (MONTH(d) < 4) is TRUE for January–March, so the FY started in the previous calendar year.
  • Fiscal month: MONTH + 8 maps April (4) to 12, MOD(…,12) maps it to 0, +1 gives 1. March: 3 + 8 = 11 → 11 → 12. In general, for an FY starting in month \(s\):

\[ \text{FM} = \text{MOD}(M - s + 12,\ 12) + 1 \]

where \(M\) is the calendar month. For \(s = 4\), \(M - 4 + 12 = M + 8\).

Generalising the start month

Store the FY start month as an input FYStartM (4 for India, 1 for a US subsidiary, 7 for an Australian one):

FY end year   =YEAR(d) + (FYStartM > 1) * (MONTH(d) >= FYStartM)
Fiscal month  =MOD(MONTH(d) - FYStartM + 12, 12) + 1
FY start      =DATE(YEAR(d) - (MONTH(d) < FYStartM), FYStartM, 1)
FY end        =EOMONTH(DATE(YEAR(d) - (MONTH(d) < FYStartM), FYStartM, 1), 11)

The (FYStartM > 1) factor prevents a January-start entity from being shifted a year. These can be wrapped as LAMBDAs (w9_t4 c06) for reuse.

YTD and prior-YTD logic

With a report date RD (e.g. 31-Aug-2025), YTD is FY start to RD; prior YTD is the same window one year earlier:

YTD start     =DATE(YEAR(RD) - (MONTH(RD) < 4), 4, 1)
PYTD end      =EDATE(RD, -12)
PYTD start    =EDATE(YTDStart, -12)
YTD revenue   =SUMIFS(GL[Amt], GL[FSLine], "Revenue", GL[Date], ">=" & YTDStart, GL[Date], "<=" & RD)

Using EDATE for prior-year dates keeps month-ends aligned (28/29 February handled automatically when RD is 29-Feb-2028 → 28-Feb-2027).

A YTD flag on GL rows, for slicers or SUMPRODUCT: =(GL[Date] >= YTDStart) * (GL[Date] <= RD).

Budget phasing by fiscal month

Annual budgets are phased by fiscal month — e.g. a seasonality vector with April = 1. Pick the phasing weight with =INDEX(Phasing, FM) where FM is the fiscal month of the header date. Using the calendar month here would put January's weight on April.

Fiscal attributes as a dimension table

Rather than computing these on every GL row, build a date table: one row per day (or month) with Date, FY, FYLabel, FM, FQ, MonthEnd, IsYTD. Map GL rows by date with XLOOKUP, or in Power BI relate the GL to the date table (Week 11). A month-level version with SEQUENCE:

=LET(m, EOMONTH(DATE(2023,4,1), SEQUENCE(60, 1, 0)),
     HSTACK(m, YEAR(m) + (MONTH(m) >= 4), MOD(MONTH(m) + 8, 12) + 1,
            INT(MOD(MONTH(m) + 8, 12) / 3) + 1))

Edge cases & judgement calls

  • Non-March year-ends. Some Indian subsidiaries of foreign groups have Tribunal approval under Sec 2(41) for a different FY (e.g. December). Parameterise the start month rather than hard-coding 4.
  • 52/53-week years. Retail groups abroad sometimes use 4-4-5 calendars; formulas here do not apply — use a mapping table of period start/end dates.
  • Text dates from ERP exports break all helpers; convert first.
  • Quarter labels for LODR are FY quarters (Q1 = April–June), not calendar quarters; label "Q1 FY26" accordingly to avoid confusion with "Q1 2025".
  • Time stamps in dates do not affect MONTH/YEAR but do affect <=RD criteria; use <RD+1.
  • Comparatives after restatement. If prior-year figures are restated (Ind AS 8), the prior-YTD window must point at the restated data set, not the original GL.

Key takeaways

  • FY end year = YEAR(d) + (MONTH(d) >= 4); FY start = DATE(YEAR(d) - (MONTH(d) < 4), 4, 1).
  • Fiscal month = MOD(MONTH(d) + 8, 12) + 1; fiscal quarter = INT(MOD(MONTH(d)+8,12)/3) + 1.
  • Parameterise the FY start month for group entities with different year-ends.
  • Build YTD and prior-YTD windows from a report-date input, with EDATE for the prior year.
  • Centralise fiscal attributes in a date table rather than recomputing them in every formula.

Practice Questions

Q1. Fill the attributes [L1]

For the dates 1-Apr-2025, 31-Dec-2025, 1-Jan-2026 and 31-Mar-2026, write the formulas and state the FY label, FY start, FY end, fiscal month and fiscal quarter for each.

Q2. YTD vs PYTD revenue [L2]

Given a GL Table with Date, FSLine and Amount (revenue negative as credits) covering FY24–FY26, and a report-date input RD, write formulas for YTD revenue, prior-YTD revenue and growth %, presenting revenue as positive. Test your logic for RD = 29-Feb-2028 in a future-year scenario and explain what the prior-YTD end date becomes.

💡 Hint: EDATE handles the 29 February case; the sign flip belongs in the presentation step.

Q3. Group entities with different year-ends [L2]

An Indian parent (April–March) has a US subsidiary (January–December) and an Australian subsidiary (July–June). Using a FYStartM column in the entity master, write generalised formulas for FY end year, fiscal month and FY start date, and show the results for the date 15-Aug-2025 for each entity.

Q4. Budget phasing bug [L2]

A budget model phases annual revenue of ₹240 crore using a seasonality vector (April 6%, May 7% … March 11%) with =INDEX(Phasing, MONTH(Hdr)). Explain exactly which months receive the wrong weights, the effect on Q1 FY26 budget, and the fix.

Q5. Date table design [L3]

Design a month-level date table for FY22–FY31 for an MIS model and a Power BI model: list the columns, write the spill formula(s) that generate it, and explain how the GL, budget and forecast tables would connect to it.
