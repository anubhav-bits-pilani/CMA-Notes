Subtopic note

SEQUENCE for Monthly Timelines, Loan Schedules and Period Counters

Scope: SEQUENCE for monthly timelines, loan schedules and period counters

Why it matters

Every model has a time axis. Hard-typed month headers ("Apr-25", "May-25" as text) are the single most common reason an MIS grid breaks: SUMIFS cannot match text months to real dates, roll-forwards need manual retyping, and a 12-month forecast cannot become 18 months without rework. SEQUENCE generates the axis from one start-date input and a period count, so the timeline, the period counter used in discounting and the row numbers of a loan schedule all flow from assumptions. This is the foundation for the rolling forecast headers of Weeks 17–20 and the self-updating debt and lease schedules of Weeks 13–16.

Core notes

Syntax

=SEQUENCE(rows, [columns], [start], [step])
Argument Default Notes
rows — Number of rows to return
columns 1 Number of columns
start 1 First value
step 1 Increment; may be negative or fractional

The fill runs across the row first, then down. SEQUENCE(2,3) returns {1,2,3;4,5,6}.

Monthly timelines

Month-end dates are the correct header: they are real dates, so SUMIFS can use ">"&EOMONTH(hdr,-1) and "<="&hdr ranges.

=EOMONTH(StartDate, SEQUENCE(1, Months, 0))      horizontal month-ends
=EOMONTH(StartDate, SEQUENCE(Months, 1, 0))      vertical month-ends
=EDATE(StartDate, SEQUENCE(1, Months, 0))        same day each month
=EOMONTH(StartDate, SEQUENCE(1, Qtrs, 2, 3))     quarter-ends (Jun, Sep, Dec, Mar if StartDate is in April)
=DATE(YEAR(StartDate)+(MONTH(StartDate)>=4)+SEQUENCE(1, Yrs, 0), 3, 31)   fiscal year-ends

With StartDate = 1-Apr-2025 and Months = 12, the first formula returns 30-Apr-2025 … 31-Mar-2026. Format the spill as mmm-yy; the underlying values remain dates. Downstream formulas reference the header with C4# (the spill operator, s01), so the grid widens to 18 months when Months is changed to 18.

Period counters

DCF and project models need t = 1, 2, 3 … and sometimes stub fractions:

=SEQUENCE(1, Years)                       1 … n
=SEQUENCE(1, Years, 0)                    0 … n-1 (for t=0 investment column)
=SEQUENCE(1, Years, 0.5)                  0.5, 1.5, 2.5 … mid-year convention
=YEARFRAC(ValDate, C4#)                   exact year fractions to each dated header

A discount-factor row then becomes =1/(1+WACC)^C6#.

Flags are built from the same counter: =--(C4#<=LoanEnd) returns 1 for months within the loan tenor, 0 after; =--(MOD(SEQUENCE(1,Months),3)=0) flags quarter-end months for GST-style quarterly filings or quarterly interest.

Loan schedule rows

A vertical schedule where the number of rows equals the tenor:

=SEQUENCE(Tenor*12)                        period numbers 1 … 60 for a 5-year EMI loan
=EDATE(FirstEMIDate, SEQUENCE(Tenor*12, 1, 0))  EMI dates
=PMT(Rate/12, Tenor*12, -Principal)        constant EMI (single cell)
=IPMT(Rate/12, A8#, Tenor*12, -Principal)  interest per period (spills, since per is an array)
=PPMT(Rate/12, A8#, Tenor*12, -Principal)  principal per period

Because IPMT and PPMT accept an array for per, the whole schedule spills from four formulas. The closing balance column uses SCAN (c07) or =Principal - SCAN(0, PPMT_col, LAMBDA(a,x,a+x)). Change Tenor from 5 to 7 years and the schedule extends to 84 rows with nothing copied down.

Illustration: ₹50 lakh term loan

Inputs: Principal ₹50,00,000; Rate 9.6% p.a. (monthly rate 0.8%); Tenor 5 years; first EMI 30-Apr-2025.

Formula Result
=SEQUENCE(Tenor*12) 1 … 60
=EOMONTH(FirstEMI, SEQUENCE(60,1,0)) 30-Apr-2025 … 31-Mar-2030
=PMT(0.008, 60, -5000000) ₹1,05,254 (approx.)
Interest in period 1 ₹50,00,000 × 0.8% = ₹40,000
Principal in period 1 ₹1,05,254 − ₹40,000 = ₹65,254

The final period's closing balance should be zero (to rounding) — make it a check cell.

Two-dimensional sequences

SEQUENCE(Rows, Cols) gives a numbered grid, useful for cohort triangles (acquisition month × months since acquisition) or for a MAKEARRAY-style calendar: =StartDate + SEQUENCE(6, 7, 0) with StartDate a Monday builds a 6-week close calendar block.

Text or fiscal labels from dates

Keep dates as the header value and derive labels separately when needed:

="Q" & INT(MOD(MONTH(C4#)-4, 12)/3) + 1            fiscal quarter label (Apr–Jun = Q1)
="FY" & RIGHT(YEAR(C4#) + (MONTH(C4#)>=4), 2)         FY label, e.g. FY26

Labels are for display; criteria should always use the dates.

Edge cases & judgement calls

  • EOMONTH vs EDATE. Chaining EDATE (each date one month after the previous cell) drifts: 31-Jan → 28-Feb → 28-Mar → 28-Apr. Offsetting from the original date with SEQUENCE avoids drift: EDATE(31-Jan, {0,1,2}) returns 31-Jan, 28-Feb, 31-Mar. For month-end headers always use EOMONTH, which cannot drift.
  • Stub periods. If a model starts mid-month (acquisition on 14-Sep-2025), the first column is a stub; compute its fraction with (EOMONTH(Start,0)-Start+1)/DAY(EOMONTH(Start,0)) and apply it to the first period's flows.
  • Spill references downstream. All grid formulas must use C4#; any fixed range like C4:N4 breaks when Months changes.
  • Table conflict. SEQUENCE cannot be used to generate headers of an Excel Table (headers are static text). Keep the time axis as a spill on a normal range.
  • Zero or negative inputs. SEQUENCE(0) returns #CALC!. Validate period inputs (whole number ≥ 1).
  • Leap years affect day-based accruals, not EOMONTH headers; handle with YEARFRAC basis (w9_t5).

Key takeaways

  • SEQUENCE generates the time axis and counters from a start date and a period-count input.
  • Wrap it in EOMONTH for month-end headers — real dates that SUMIFS can range on.
  • Counters with start 0 or 0.5 support t=0 and mid-year discounting; MOD-based flags mark quarter-ends.
  • IPMT/PPMT accept array per, so a whole loan schedule spills from a SEQUENCE column.
  • Reference headers with # and validate inputs so changing tenor or horizon resizes everything.

Practice Questions

Q1. Headers for an 18-month rolling forecast [L1]

The forecast starts in the month after the last actual month (input LastActual = 31-Oct-2025). Write formulas for (a) 18 horizontal month-end headers; (b) a row of fiscal-quarter labels; (c) a row of 1/0 flags that are 1 for months in FY26.

Q2. Spilling loan schedule [L2]

A ₹2.4 crore machinery loan carries 10.2% p.a., repayable in 84 equal monthly instalments starting one month after disbursement on 15-May-2025. Write the SEQUENCE-based formulas for period number, EMI date, EMI, interest, principal and closing balance, and state the check you would place at the bottom.

💡 Hint: IPMT and PPMT accept the period-number spill directly; closing balance needs a running total.

Q3. Mid-year discount counter [L2]

A 5-year DCF with valuation date 31-Mar-2026 uses mid-year discounting. Write a SEQUENCE formula for the discount periods and a discount-factor row at WACC 12.5%. Explain how the period row would change if the valuation date moved to 30-Sep-2026 (a stub of six months in FY27).

Q4. Why did the grid not extend? [L1]

A planner changed the Months input from 12 to 15. The header row extended, but the SUMIFS block below still shows 12 columns, and the total column double-counts. Identify the likely formula-reference mistakes and how to fix them.

Q5. Quarterly interest flags [L2]

A debenture pays interest quarterly on 30 June, 30 September, 31 December and 31 March. Using a 36-month EOMONTH timeline starting April 2025, write a flag row identifying payment months and an interest row computing ₹10 crore × 8.4% ÷ 4 only in those months.
