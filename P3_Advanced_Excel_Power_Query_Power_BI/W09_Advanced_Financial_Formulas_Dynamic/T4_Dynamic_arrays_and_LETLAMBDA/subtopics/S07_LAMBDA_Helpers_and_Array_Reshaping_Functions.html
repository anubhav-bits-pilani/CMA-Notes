Subtopic note

LAMBDA Helpers and Array Reshaping Functions

Scope: Helper functions BYROW, BYCOL, MAP, SCAN, REDUCE, MAKEARRAY; reshaping with VSTACK, HSTACK, TAKE, DROP, CHOOSECOLS

Why it matters

Plain dynamic arrays handle "same operation on every element". Real schedules need more: a running closing balance (each row depends on the previous), a total per row of a spilled grid, a per-row MAX that ordinary MAX would collapse into a single value, or stitching an actuals block and a forecast block into one continuous output. The LAMBDA helper functions supply these iteration patterns without VBA, and the reshaping functions let you assemble report blocks — header row, body, total row — inside a single self-sizing formula. Together they are what make a "self-updating schedule" genuinely formula-only, from depreciation roll-forwards to deferred revenue waterfalls.

Core notes

The LAMBDA helpers

Each helper takes an array and a LAMBDA, and calls the LAMBDA repeatedly. The LAMBDA's parameter names are yours to choose.

Function Signature Calls LAMBDA with Returns
BYROW BYROW(array, LAMBDA(row, …)) each row (1 × n) one value per row (column)
BYCOL BYCOL(array, LAMBDA(col, …)) each column (n × 1) one value per column (row)
MAP MAP(arr1, [arr2 …], LAMBDA(a, [b …], …)) each element (paired across arrays) array same size as inputs
SCAN SCAN(initial, array, LAMBDA(acc, x, …)) accumulator + each element every intermediate accumulator
REDUCE REDUCE(initial, array, LAMBDA(acc, x, …)) accumulator + each element final accumulator only
MAKEARRAY MAKEARRAY(rows, cols, LAMBDA(r, c, …)) each row and column index rows × cols array

BYROW and BYCOL — totals and stats per row/column of a spill

A department × month expense grid spills from G5 (G5#). Ordinary =SUM(G5#) gives one grand total. Per-department totals:

=BYROW(G5#, LAMBDA(r, SUM(r)))           row totals, spills down
=BYCOL(G5#, LAMBDA(c, SUM(c)))           month totals, spills across
=BYROW(G5#, LAMBDA(r, MAX(r)))           peak month spend per department
=BYROW(G5#, LAMBDA(r, COUNTIF(r, ">0"))) active months per department

BYROW must return a single value per row; returning an array produces #CALC!. In current builds you may pass a function name directly (BYROW(G5#, SUM)), known as eta-reduced LAMBDA.

MAP — element-wise logic that ordinary operators cannot express

Arithmetic like A2#*B2# is already element-wise. MAP is needed when the per-element logic uses functions that aggregate, such as AND/OR, or multi-step IFs.

=MAP(AR[DaysOverdue], AR[Balance],
     LAMBDA(d, b, IF(AND(d>90, b>500000), "Escalate", IF(d>30, "Follow up", "OK"))))

AND(AR[DaysOverdue]>90, …) without MAP would collapse the whole column to one TRUE/FALSE; MAP evaluates AND for each pair.

SCAN — running balances

SCAN carries an accumulator through the array and returns each step — exactly a roll-forward.

=SCAN(Opening, Movements, LAMBDA(acc, m, acc + m))

With an opening debtor balance of ₹80 lakh and monthly net movements {+12, −7, +5, −20} lakh, the result is {92, 85, 90, 70}. Uses: closing balances in a loan schedule (Principal − cumulative PPMT), cumulative capex, inventory roll-forward, cumulative YTD figures (SCAN(0, monthly, LAMBDA(a,x,a+x))).

SCAN processes a 2-D array row by row, left to right, so a running total over a multi-row block threads through all rows — usually not what you want. Apply SCAN to a single row or column.

REDUCE — single result from iteration, and the stacking pattern

REDUCE is SCAN that returns only the end state:

=REDUCE(Opening, Movements, LAMBDA(acc, m, acc + m))      closing balance only
=REDUCE(1, Rates, LAMBDA(acc, r, acc*(1+r)))              compound growth factor

A powerful finance pattern uses REDUCE with VSTACK to build a variable-length table by looping over a list:

=REDUCE({"Dept","Ledger","Amount"}, UNIQUE(GL[Dept]),
   LAMBDA(acc, d, VSTACK(acc, TAKE(SORTBY(FILTER(GL[[Dept]:[Amount]], GL[Dept]=d),
                                           FILTER(GL[Amount], GL[Dept]=d), -1), 3))))

This returns the top 3 entries for each department stacked under one header — something a single SORT/TAKE cannot do.

MAKEARRAY — generating grids from indices

MAKEARRAY passes the row index r and column index c to the LAMBDA and builds the grid cell by cell. Simple case: =MAKEARRAY(3, 4, LAMBDA(r, c, r*c)) returns a 3 × 4 multiplication grid. Finance case: a straight-line depreciation waterfall where capex added in year r is depreciated over Life years (here 5):

=MAKEARRAY(ROWS(Capex), Years,
   LAMBDA(r, c, IF(AND(c >= r, c < r + Life), INDEX(Capex, r) / Life, 0)))

Row r is the vintage, column c the year; summing columns (BYCOL) gives total depreciation per year — the standard capex-vintage depreciation build in a 3-statement model.

Reshaping functions

Function Signature Use
VSTACK VSTACK(a1, a2, …) Append arrays vertically (header + body + total; actuals over forecast)
HSTACK HSTACK(a1, a2, …) Place arrays side by side (labels + amounts + %)
TAKE TAKE(array, rows, [cols]) First n rows (negative n = last n) — top-N, latest month
DROP DROP(array, rows, [cols]) Remove first n rows (negative = last n) — strip headers or total rows
CHOOSECOLS CHOOSECOLS(array, c1, [c2 …]) Pick and reorder columns; negative numbers count from the right

Companion functions: CHOOSEROWS, TOCOL/TOROW (flatten), WRAPROWS/WRAPCOLS, EXPAND (pad an array to a size).

Examples:

=VSTACK({"FS line","Amount"}, HSTACK(Lines, Amts), HSTACK("Total", SUM(Amts)))
=TAKE(C5#, , -3)                  last three months of a P&L grid
=DROP(ImportRange, 1)             remove the ERP export's header row
=CHOOSECOLS(GL, 1, 4, -1)         Date, Account and the last column (Amount)
=VSTACK(Actuals_FY26, Forecast_FY26)   unified data set for a chart

VSTACK of arrays with different widths pads short rows with #N/A; wrap with IFNA(…, "").

Illustration: deferred revenue roll-forward

A SaaS company bills annual contracts in advance. Opening deferred revenue ₹4.8 crore; monthly billings B and monthly revenue recognised R are spills of 12 values each.

=LET(mov, B - R,
     close, SCAN(Opening, mov, LAMBDA(a, m, a + m)),
     open,  VSTACK(Opening, DROP(close, -1)),
     HSTACK(open, B, R, close))

Opening column = prior month's closing (built with VSTACK + DROP), closing = SCAN. The final closing should equal the deferred revenue ledger in the TB — a check cell.

Edge cases & judgement calls

  • Readability vs cleverness. A REDUCE/VSTACK loop is hard for reviewers. If a visible calculation sheet would do the job, prefer it; reserve helpers for repeated, well-tested patterns.
  • Performance. Helpers call the LAMBDA once per element; MAP over 100k rows with nested FILTERs is slow. Pre-aggregate.
  • #CALC! from nested arrays. BYROW/MAP cannot return arrays per element ("arrays of arrays"); restructure with REDUCE+VSTACK or MAKEARRAY.
  • Version. All functions in this note need current Microsoft 365 (or Excel 2024); Excel 2021 lacks the LAMBDA helpers and VSTACK family.
  • SCAN on 2-D arrays threads row-wise across the whole block; use BYROW-style logic or one SCAN per row.
  • DROP/TAKE beyond size. TAKE with n larger than the array returns all rows; DROP with n ≥ rows returns #CALC!.

Key takeaways

  • BYROW/BYCOL aggregate per row or column of a spill; MAP applies per-element logic that needs AND/OR or multi-step IF.
  • SCAN returns running balances (roll-forwards); REDUCE returns the end state and can loop with VSTACK.
  • MAKEARRAY builds grids from row/column indices, e.g. capex vintage depreciation waterfalls.
  • VSTACK/HSTACK assemble report blocks; TAKE/DROP/CHOOSECOLS slice them.
  • Use these for compact, self-sizing schedules, but keep them documented and testable.

Practice Questions

Q1. Match the function [L1]

For each requirement, name the best function and write the formula: (a) total of each row of a spilled grid in B5#; (b) cumulative YTD revenue from a monthly spill in C10#; (c) final balance after applying 12 monthly movements to an opening ₹2.5 crore; (d) the last 6 months of a P&L grid in D5#; (e) the GL export with its first two rows removed.

Q2. Capex vintage depreciation [L2]

Capex for FY26–FY30 is ₹10, ₹14, ₹8, ₹12 and ₹20 crore (named Capex, vertical). Assets are depreciated straight-line over 4 years with a full year's charge in the year of addition. Write a MAKEARRAY formula for the vintage × year depreciation grid and a BYCOL formula for total annual depreciation. Describe the check you would add.

Q3. Escalation flags with MAP [L2]

Explain why =IF(AND(AR[Days]>90, AR[Bal]>500000), "Escalate", "OK") returns a single value instead of one per row, and give two fixes: one with MAP and one with Boolean multiplication.

💡 Hint: AND aggregates all its arguments into one result.

Q4. Lease roll-forward [L3]

An Ind AS 116 lease liability opens at ₹3.6 crore. Monthly interest is 0.75% of the opening balance and the monthly payment is ₹7.5 lakh for 60 months. Design a formula-only schedule (opening, interest, payment, closing) using SCAN and VSTACK/DROP, and explain why the interest calculation makes a simple SCAN of fixed movements insufficient.

Q5. Top 3 per department [L3]

Using REDUCE with VSTACK, write a formula listing the three largest GL entries for each department with a header row. Then discuss whether you would put this in a monthly MIS pack used by six reviewers, and what alternative you would offer.
