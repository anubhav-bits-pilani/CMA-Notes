Subtopic note

PY YTD, YTD Growth, MoM % and YoY % Measures

Scope: PY YTD, YTD growth, MoM % and YoY % measures

Why it matters

The first page of almost every Indian MIS pack is a KPI strip: Revenue YTD ₹ x crore, +y% YoY; EBITDA margin; month-on-month trend. Analysts on the sell side compute the same YoY and QoQ growth from published SEBI results. In a model these numbers are derived measures built by branching from a small number of base measures. Getting the branching right — and blanking growth where it is meaningless — is what separates a usable dashboard from one the CFO stops trusting.

Core notes

Measure branching tree

Actual       = SUM ( GL[Amount] )                                   -- base
YTD Actual   = CALCULATE ( [Actual], DATESYTD ( 'Date'[Date], "3/31" ) )
PY Actual    = CALCULATE ( [Actual], SAMEPERIODLASTYEAR ( 'Date'[Date] ) )
PY YTD       = CALCULATE ( [YTD Actual], SAMEPERIODLASTYEAR ( 'Date'[Date] ) )
PM Actual    = CALCULATE ( [Actual], DATEADD ( 'Date'[Date], -1, MONTH ) )

YTD Growth ₹ = [YTD Actual] - [PY YTD]
YoY %        = DIVIDE ( [YTD Actual] - [PY YTD], [PY YTD] )
MoM ₹        = [Actual] - [PM Actual]
MoM %        = DIVIDE ( [Actual] - [PM Actual], [PM Actual] )

Each derived measure references other measures, never raw columns, so a change to the base (say, excluding inter-company accounts) flows everywhere.

How PY YTD evaluates

PY YTD = CALCULATE([YTD Actual], SAMEPERIODLASTYEAR('Date'[Date])). For a cell showing December 2025:

  1. Filter context: 1–31 December 2025.
  2. SAMEPERIODLASTYEAR replaces it with 1–31 December 2024.
  3. [YTD Actual] runs inside that context: DATESYTD takes the last visible date (31 December 2024) and returns 1 April 2024 – 31 December 2024.
  4. [Actual] sums that window.

An equivalent single-step form is CALCULATE([Actual], DATESYTD(SAMEPERIODLASTYEAR('Date'[Date]), "3/31")).

Growth definitions

\[ \text{YoY \%} = \frac{\text{YTD}_{t} - \text{YTD}_{t-1}}{\text{YTD}_{t-1}} \qquad \text{MoM \%} = \frac{A_{m} - A_{m-1}}{A_{m-1}} \]

where \(\text{YTD}_{t}\) is current-year YTD, \(\text{YTD}_{t-1}\) the same window last year, \(A_{m}\) the month's actual and \(A_{m-1}\) the previous month's actual. YoY can also be computed at month level ([Actual] vs [PY Actual]) or quarter level — make the label explicit ("YoY % (YTD)" vs "YoY % (Month)").

Sign-awareness

Revenue in the GL is credit (negative). If the base measure is not sign-flipped, both numerator and denominator are negative and YoY % still works for revenue (−120 vs −100 gives +20%). It breaks when the base changes sign — a loss turning into a profit — or for expense lines where an increase in spend is adverse. Rules:

  • Compute growth on presentation-signed measures (revenue positive).
  • If the PY base can be negative (EBIT, PAT), divide by ABS([PY YTD]) so that moving from −50 to +30 shows as positive growth (+160%), and consider blanking or labelling "n.m." (not meaningful) when the base is negative or tiny.
  • For cost lines, a separate favourable/adverse indicator is clearer than a raw growth %.
YoY % (sign-aware) =
VAR cy = [YTD Actual]
VAR py = [PY YTD]
RETURN
    IF ( NOT ISBLANK ( py ) && py <> 0, DIVIDE ( cy - py, ABS ( py ) ) )

Blanking at the wrong grain

MoM % is meaningful only at month level. At a quarter or FY total, DATEADD(..., -1, MONTH) shifts the whole selection by a month and produces a "Q3 vs July–November" style number. Guard it:

MoM % (safe) =
IF (
    ISINSCOPE ( 'Date'[MonthYear] ),
    DIVIDE ( [Actual] - [PM Actual], [PM Actual] )
)

Similarly, blank PY-based measures for the first year of data (PY is blank, so growth would be blank anyway with DIVIDE, but a YTD Growth ₹ subtraction would show the full current YTD as "growth").

YTD Growth ₹ (safe) =
VAR py = [PY YTD]
RETURN IF ( NOT ISBLANK ( py ), [YTD Actual] - py )

Worked illustration

Revenue (₹ crore):

Oct 2025 Nov 2025 YTD Nov FY26 YTD Nov FY25
Revenue 42.0 39.9 301.5 268.0

MoM % for November = (39.9 − 42.0) / 42.0 = −5.0%. YTD growth ₹ = 33.5 crore; YoY % (YTD) = 33.5 / 268.0 = 12.5%. A seasonal business (festive sales in October) shows a negative MoM every November, which is why FP&A reviews lean on YoY and YTD rather than MoM.

Presentation

  • Format growth measures with a percentage format and one decimal; apply conditional formatting (green/red) but reverse the colour logic for cost lines.
  • Put growth measures in a "Growth" display folder; keep ₹ and % variants adjacent.
  • In a matrix with months on columns, MoM % next to each month is noisy — a separate trend chart is usually better.

Edge cases & judgement calls

  • Partial current month: YoY at month level compares a partial November with a full prior-year November (s05).
  • Base effects: a PY month depressed by a one-off (plant shutdown, demonetisation-style shock) inflates YoY; commentary should separate base effect from underlying growth.
  • Acquisitions and disposals: reported YoY mixes organic and inorganic growth. Like-for-like growth needs a flag on entities or branches (e.g., Branch[IsLFL]) applied to both periods.
  • Currency: for export businesses, YoY in ₹ includes FX translation; constant-currency growth re-prices both years at one rate.
  • Ratios: YoY change of a margin is expressed in basis points ([EBITDA %] - [PY EBITDA %]), not as a % growth of a %.

Key takeaways

  • Build PY YTD by wrapping the YTD measure in SAMEPERIODLASTYEAR; the inner DATESYTD re-evaluates in the shifted context.
  • Derived measures reference measures, not columns: one base, many branches.
  • Use DIVIDE and ABS for growth on bases that can be zero or negative; label "n.m." where appropriate.
  • Blank MoM above month level with ISINSCOPE; blank growth where PY does not exist.
  • Margin changes are in percentage points or basis points, not growth %.

Practice Questions

Q1. Write the KPI strip [L1]

Using base measure [Actual] (presentation-signed) and a Date table marked as date table, write measures for YTD Revenue, PY YTD Revenue, YTD Growth ₹, YoY % and MoM %, including the guards described in this note.

Q2. EBIT turning positive [L2]

EBIT YTD December was −₹ 6.4 crore in FY25 and +₹ 3.2 crore in FY26. Compute what a naive DIVIDE(cy − py, py) returns and what the sign-aware version returns, and recommend what the board pack should show for this line.

💡 Hint: Think about the sign of the denominator before deciding whether a percentage is meaningful at all.

Q3. Seasonal MoM noise [L2]

A consumer durables company has monthly revenue (₹ crore) of Sep 55, Oct 92, Nov 61, Dec 48 in FY26 and Sep 50, Oct 70, Nov 76, Dec 45 in FY25 (Diwali fell in early November 2024 and late October 2025). Compute MoM % and month YoY % for October and November FY26, and draft a two-line commentary explaining which measure the sales head should focus on.

Q4. Like-for-like growth [L3]

The company acquired a 12-branch chain on 1 October 2024. Design a branch-level flag and the DAX measures needed to show reported YoY %, inorganic contribution and like-for-like YoY % for YTD December FY26, explaining exactly which branches are included in each period.
