Key concept

Prior-Month Actual with DATEADD and the MoM % Measure

Concept: PM Actual = CALCULATE([Actual], DATEADD('Date'[Date], -1, MONTH)); MoM % = DIVIDE([Actual] - [PM Actual], [PM Actual])

Statement

PM Actual = CALCULATE ( [Actual], DATEADD ( 'Date'[Date], -1, MONTH ) )
MoM %     = DIVIDE ( [Actual] - [PM Actual], [PM Actual] )

\[ \text{MoM \%}_{m} = \frac{A_{m} - A_{m-1}}{A_{m-1}} \]

where \(A_{m}\) is the actual for the month in context and \(A_{m-1}\) the actual for the immediately preceding month. DIVIDE returns BLANK when \(A_{m-1}\) is zero or blank.

Explanation

DATEADD('Date'[Date], -1, MONTH) takes the visible dates and shifts each back by one month, returning a contiguous set of the same shape. For a full-month context (1–30 November) it returns the full prior month (1–31 October), including the month-end extension when the current month is shorter than the previous one (all of 1–31 January for a February context). CALCULATE applies the shifted set, and the base measure is re-evaluated.

Key behaviours:

  • Crosses fiscal-year boundaries naturally. April 2025's PM is March 2025 — the last month of FY25. No year-end argument is involved.
  • Meaningless above month level. At a quarter context (1 October – 31 December), DATEADD(-1, MONTH) returns 1 September – 30 November: a shifted quarter, not a "previous month". At FY total it gives March prior year to February. Guard with ISINSCOPE('Date'[MonthYear]) or HASONEVALUE('Date'[MonthEnd]).
  • Partial months. If the current month is capped at the last actuals date (18 November), the shifted set is 1–18 October — like-for-like, which is good for a flash report but means the "PM Actual" shown is not October's full number. Label accordingly.
  • QoQ variant. DATEADD('Date'[Date], -1, QUARTER) gives sequential-quarter comparisons, which listed-company results commentary often uses alongside YoY.
  • Interpretation. MoM % is dominated by seasonality (festive quarter, March year-end billing push, monsoon impact on construction). It is a monitoring metric, not a performance verdict.
MoM % (guarded) =
VAR cur = [Actual]
VAR pm  = [PM Actual]
RETURN
    IF ( ISINSCOPE ( 'Date'[MonthYear] ), DIVIDE ( cur - pm, ABS ( pm ) ) )

Illustration

A logistics company's freight revenue (₹ lakh):

Month [Actual] [PM Actual] [MoM %]
Feb 2026 1,240 1,310 −5.3%
Mar 2026 1,580 1,240 +27.4%
Apr 2026 1,190 1,580 −24.7%
Q4 FY26 row 4,130 (Dec–Feb shifted: 3,860) blank (guarded)

The April drop is the reversal of the March year-end push, not a business collapse — the commentary should say so, and a YoY comparison (April 2026 vs April 2025) is the better performance indicator.

Q1. Compute and guard [L1]

Q2. QoQ for a results table [L2]

Write measures for prior-quarter revenue and QoQ % suitable for a SEBI results presentation that shows Q3 FY26, Q2 FY26 and Q3 FY25 columns, and state at which matrix level each should be visible.

💡 Hint: Quarter-level guards use a quarter column with ISINSCOPE, and the YoY column uses a different shift.

Q3. Flash report labelling [L2]

Actuals are posted to 18 November 2025. The flash report shows November MoM % of −22%. Explain how the guarded measure computed this number, whether the comparison is like-for-like, and what label you would put on the visual.
