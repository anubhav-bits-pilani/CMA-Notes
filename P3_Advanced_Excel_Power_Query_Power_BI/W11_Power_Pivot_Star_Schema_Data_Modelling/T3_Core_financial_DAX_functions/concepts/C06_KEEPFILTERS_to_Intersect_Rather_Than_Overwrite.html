Key concept

KEEPFILTERS to Intersect Rather Than Overwrite

Concept: KEEPFILTERS(CoA[FSLine] IN {"Revenue","Other Income"}) intersects with existing filters instead of overwriting them

Statement

Total Income (row-aware) =
CALCULATE (
    [Actual],
    KEEPFILTERS ( CoA[FSLine] IN { "Revenue", "Other Income" } )
)
  • CoA[FSLine] IN { … } is a boolean filter equivalent to FILTER(ALL(CoA[FSLine]), CoA[FSLine] IN { … }).
  • Without KEEPFILTERS, CALCULATE replaces the existing filter on CoA[FSLine] with this list.
  • With KEEPFILTERS, the new filter is added alongside the existing one, and the result uses their intersection:

\[ \text{Filter}_{new} = \text{Filter}_{existing} \cap \{\text{Revenue}, \text{Other Income}\} \]

Explanation

In a P&L matrix with FSLine on rows:

  • On the "Revenue" row, existing filter {Revenue} ∩ {Revenue, Other Income} = {Revenue} → revenue.
  • On the "Other Income" row → other income.
  • On the "Employee benefits expense" row → empty set → blank (row hidden if all measures blank).
  • On the grand total (no FSLine filter) → both lines → total income.

Without KEEPFILTERS every row would show total income (revenue + other income) — correct for a KPI card, misleading in a matrix.

When to use KEEPFILTERS:

  • Row-aware line measures in matrices where users put FSLine or AccountName on rows.
  • Slicer-respecting measures. If a user has sliced FSLine to just "Revenue", a plain filter would bring "Other Income" back; KEEPFILTERS respects the slicer.
  • Iterators: SUMX(KEEPFILTERS(VALUES(Branch[Branch])), …) and in FILTER(KEEPFILTERS(ALL(col)), …) patterns to preserve outer filters on the iterated column.

When not to use it: denominators of ratios (DIVIDE([EBITDA], [Revenue]) must get revenue on every row — overwrite is what you want there), and KPI cards that must ignore an FSLine slicer.

Alternative with the same intersection semantics but slower: FILTER(VALUES(CoA[FSLine]), CoA[FSLine] IN {…}) — it iterates only visible values. FILTER(GL, …) also preserves filters but is expensive (s04).

Q1. Predict the matrix [L1]

A matrix with Branch on rows uses West Sales = CALCULATE([Revenue], KEEPFILTERS(Branch[Region] = "West")). What does it show for a North-region branch and for the grand total? What changes without KEEPFILTERS?

Q2. Choose overwrite or keep [L2]

For each measure decide whether to use KEEPFILTERS and why: (a) EBITDA margin denominator; (b) "Employee cost" line shown in a matrix by FSLine; (c) a KPI card showing total income regardless of an FSLine slicer; (d) count of active branches in the selected region.

💡 Hint: Ask whether the measure should respond to the same column on rows or in slicers.
