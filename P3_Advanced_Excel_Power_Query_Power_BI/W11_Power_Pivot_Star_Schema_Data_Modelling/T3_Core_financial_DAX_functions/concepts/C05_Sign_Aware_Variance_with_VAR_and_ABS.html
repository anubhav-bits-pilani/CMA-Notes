Key concept

Sign-Aware Variance % with VAR and ABS

Concept: Var % = VAR a = [Actual] VAR b = [Budget] RETURN DIVIDE(a - b, ABS(b))

Statement

Var % =
VAR a = [Actual]
VAR b = [Budget]
RETURN
    DIVIDE ( a - b, ABS ( b ) )

\[ \text{Var\%} = \frac{a - b}{\lvert b \rvert} \]

where \(a\) is actual and \(b\) is budget for the current filter context, both in the same sign convention. Returns BLANK when \(b\) is 0 or blank.

Explanation

Why ABS. With the plain formula \((a - b)/b\), a negative denominator flips the sign of the result. Negative budgets are common: in a credit-negative GL convention revenue budgets are negative; in a sign-adjusted convention loss-making units have negative EBITDA budgets. Example: budget EBITDA −₹50 lakh (a planned loss), actual −₹30 lakh (a smaller loss). \((a - b) = +20\); divided by \(b = -50\) gives −40%, suggesting an adverse result when the unit actually beat budget. Dividing by \(\lvert b \rvert\) gives +40%: the sign of the result now follows the sign of \(a - b\).

What the sign then means. With ABS, a positive Var % means "actual is numerically higher than budget". Whether that is favourable depends on the line type:

Line type Higher actual is Favourable when
Revenue, other income, profit lines Good \(a - b > 0\)
Expense lines Bad \(a - b < 0\)

So combine Var % with a favourable/adverse flag driven by a line attribute (e.g. CoA[IsExpense] or a layout sign factor) rather than reversing the percentage itself:

Fav/Adv =
VAR d = [Actual Signed] - [Budget Signed]
VAR isExp = SELECTEDVALUE ( CoA[AccountType] ) = "Expense"
RETURN
    IF ( ISBLANK ( d ), BLANK (), IF ( ( d >= 0 ) <> isExp, "F", "A" ) )

Variables. a and b are evaluated once in the current filter context; the measure is easy to read and debug (RETURN b temporarily to inspect budget).

Consistency. Actual and Budget must use the same sign convention. If budget is loaded as positive expenses while GL expenses are positive debits but revenue budget is positive while GL revenue is negative, \(a - b\) for revenue is nonsense. Normalise both through the same SignFactor.

Materiality and blanks. DIVIDE returns blank for zero budget; consider blanking variance % for tiny budgets (n.m. — not meaningful) to avoid 5,000% rows.

Illustration

Sign-adjusted (income and expense positive), FY2025-26 Q2, ₹ lakh:

Line Actual \(a\) Budget \(b\) \(a - b\) \((a - b)/b\) \((a - b)/\lvert b \rvert\) Fav/Adv
Revenue 2,400 2,500 −100 −4.0% −4.0% A
Employee cost 310 300 10 3.3% 3.3% A
EBITDA (Unit X) −30 −50 20 −40.0% 40.0% F
EBITDA (Unit Y) 15 −10 25 −250.0% 250.0% F

Unit Y's swing from a planned loss to a profit shows +250%; many MIS packs replace such values with "n.m." and show only the ₹ variance.

Practice Questions

Q1. Compute and interpret [L1]

For a cost centre: budget opex ₹80 lakh, actual ₹92 lakh (both positive). Compute Var % using the formula, and state whether it is favourable, explaining how the measure and a Fav/Adv flag together communicate that.

Q2. Credit-negative convention [L2]

In a raw-sign GL (credits negative), revenue budget is −₹500 crore and actual is −₹540 crore. Compute \((a - b)/b\) and \((a - b)/\lvert b \rvert\), interpret each, and state which sign convention you would use for MIS.

💡 Hint: Watch the sign of \(a - b\) when both values are negative.

Q3. n.m. logic [L2]

Extend the measure so it returns blank when \(\lvert b \rvert\) is below ₹5 lakh or when budget and actual have opposite signs, and justify both rules to a CFO.
