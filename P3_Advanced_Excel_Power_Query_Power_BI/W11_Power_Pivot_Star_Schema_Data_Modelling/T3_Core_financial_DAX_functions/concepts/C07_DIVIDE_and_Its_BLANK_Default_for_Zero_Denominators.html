Key concept

DIVIDE and Its BLANK Default for Zero Denominators

Concept: DIVIDE(numerator, denominator, [alternate_result]) returns BLANK by default when the denominator is 0 or blank

Statement

DIVIDE ( <numerator>, <denominator> [, <alternate_result>] )

\[ \text{DIVIDE}(n, d, r) = \begin{cases} n / d & \text{if } d \ne 0 \text{ and } d \text{ is not blank} \\ r & \text{if } d = 0 \text{ or blank, and } r \text{ is supplied} \\ \text{BLANK} & \text{otherwise} \end{cases} \]

Explanation

  • Default BLANK. A ratio with no meaningful denominator shows nothing, rather than Infinity, NaN or an error.
  • Blank numerator. DIVIDE(BLANK(), 100) returns BLANK; DIVIDE(0, 100) returns 0.
  • Alternate result. Supply 0 when you want the row visible with 0% (e.g. a coverage ratio where zero is informative), or a sentinel value only if a format string handles it. Avoid a text alternate such as "n.m.": the measure would then return mixed data types, which breaks numeric format strings, sorting and conditional formatting. Produce "n.m." in a separate text measure for display if needed.
  • Versus /. n / 0 returns Infinity (or NaN for 0/0) in DAX; Excel's / returns #DIV/0!. DIVIDE is the DAX equivalent of IFERROR(n/d, "") with better semantics — it catches only the zero/blank denominator, not other errors, and it is optimised by the engine.
  • Performance. DIVIDE is generally preferred for measure denominators; for division by a non-zero constant ([Amount] / 1E7 for crores), / is fine and slightly faster.
  • Visual behaviour. Blank values let matrices hide empty rows and columns and keep conditional formatting clean; Infinity would dominate colour scales.

Finance applications:

Gross Margin % = DIVIDE ( [Gross Profit], [Revenue] )
ROCE           = DIVIDE ( [EBIT], [Capital Employed] )
Interest Cover = DIVIDE ( [EBIT], [Finance Costs] )
DSO            = DIVIDE ( [Avg Trade Receivables], [Revenue] ) * [Days in Period]

For DSO, note the * [Days in Period] — if DIVIDE returns blank, blank × days = blank, which is the desired output.

Illustration

Branch Revenue (₹ lakh) Gross Profit (₹ lakh) [GP] / [Revenue] DIVIDE([GP], [Revenue]) DIVIDE([GP], [Revenue], 0)
Indore 900 270 30.0% 30.0% 30.0%
Raipur (pre-launch) 0 −12 −Infinity blank 0.0%
Bhopal (no data) blank blank blank blank 0.0%

With the alternate result 0, both Raipur and Bhopal rows appear, and Bhopal's "0.0%" is misleading because it had no activity at all. The default blank is usually the right choice.

Practice Questions

Q1. Predict outputs [L1]

State the result of: DIVIDE(50, 0), DIVIDE(50, BLANK()), DIVIDE(BLANK(), 0, 0), DIVIDE(0, 25), 50 / 0, and DIVIDE(50, 0, -1).

Q2. Interest cover [L2]

Write an Interest Cover measure that returns blank when finance costs are zero, and a separate text measure for a card that shows "No debt" in that case and the ratio formatted "0.0x" otherwise.

💡 Hint: FORMAT can convert the ratio to text for the card only.

Q3. Alternate result judgement [L2]

For a branch-wise matrix of collection efficiency (collections ÷ opening receivables + billing), decide whether to use the default blank or an alternate result of 0, considering new branches, closed branches and data gaps.
