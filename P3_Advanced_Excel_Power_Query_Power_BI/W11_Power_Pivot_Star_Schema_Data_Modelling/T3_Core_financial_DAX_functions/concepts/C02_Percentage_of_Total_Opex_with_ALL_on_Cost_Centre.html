Key concept

Percentage of Total Opex with ALL on Cost Centre

Concept: % of Total Opex = DIVIDE([Actual], CALCULATE([Actual], ALL(CostCentre)))

Statement

% of Total Opex =
DIVIDE (
    [Actual],
    CALCULATE ( [Actual], ALL ( CostCentre ) )
)

\[ \text{Share}_{cc} = \frac{A(cc)}{A(\text{all cost centres})} \]

where \(A(\cdot)\) is [Actual] evaluated in the current filter context, and the denominator is the same measure with all filters on the CostCentre table removed — filters on Date, CoA, Branch remain.

Explanation

The numerator responds to the matrix row (one cost centre); the denominator ignores every CostCentre filter — rows, slicers on CostCentre columns, page filters on CostCentre — so it is the total for all cost centres within the other active filters. For this to be "opex", the visual or the measure must also filter CoA to operating expense lines (e.g. a page filter CoA[Statement] = "Profit and Loss" and FS lines for expenses), because a denominator of all accounts in a balanced GL nets to nil.

Points:

  • Slicer behaviour. If the user slices CostCentre[Function] = "Sales", the denominator still includes Admin and Plant — visible shares sum to the sales share of the total (say 42%), not 100%. Use ALLSELECTED(CostCentre) for "share of selection" (s05).
  • Grand total row shows the share of total for all visible cost centres — 100% without slicers.
  • Explicit opex filter makes it robust:
Opex = CALCULATE ( [Actual Signed], CoA[FSLine] IN { "Employee benefits expense", "Other expenses" } )
% of Total Opex (robust) = DIVIDE ( [Opex], CALCULATE ( [Opex], REMOVEFILTERS ( CostCentre ) ) )
  • ALL(CostCentre) vs ALL(GL[CostCentreKey]). Remove filters on the dimension; a visible fact key would be a separate filter (and should be hidden).
  • Snowflakes. If Department is a separate table filtering CostCentre, ALL(CostCentre) does not remove the Department filter; flatten the model or remove both.

Illustration

FY2025-26 opex (₹ crore), all cost centres:

Cost centre Function Opex % of Total Opex
HO-FIN Admin 9.0 15.0%
HO-HR Admin 6.0 10.0%
MUM-SALES Sales 15.0 25.0%
DEL-SALES Sales 12.0 20.0%
PUN-PLANT Plant 18.0 30.0%
Total 60.0 100.0%

With a slicer Function = Sales: MUM-SALES 25%, DEL-SALES 20%, total 45%.

Practice Questions

Q1. Share of selection [L1]

Rewrite the measure so that shares always sum to 100% of whatever cost centres the user has selected in slicers, and describe one situation where the original ALL version is preferable.

Q2. Department share [L2]

Write a measure showing each cost centre's share of its own Department's opex (CostCentre has a Department column), and explain why ALL(CostCentre) is not suitable.

💡 Hint: Keep the Department filter while removing the cost-centre-level filter.

Q3. Balanced GL denominator [L2]

A colleague's version shows 0% or blank everywhere when the page has no CoA filter. Explain why, using double-entry logic, and fix the measure so it works on any page.
