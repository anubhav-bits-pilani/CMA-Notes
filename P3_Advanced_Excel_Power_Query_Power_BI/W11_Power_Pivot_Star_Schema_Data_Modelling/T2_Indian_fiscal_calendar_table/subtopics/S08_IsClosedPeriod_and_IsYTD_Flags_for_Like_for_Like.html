Subtopic note

IsClosedPeriod and IsYTD Flags for Like-for-Like Comparisons

Scope: Flags such as IsClosedPeriod and IsYTD (date on or before the last actuals date) for clean comparisons

Why it matters

Mid-year, the Date table runs to 31 March but actuals stop at the last posted date. Without guard rails, a "FY2025-26 vs FY2024-25" chart compares eight months of this year with twelve months of last year; a YTD growth % looks like a 35% decline; budget for unclosed months inflates variance; and the November column shows half-posted figures as if final. Two Date-table flags fix this cleanly: IsClosedPeriod (the month's books are closed and signed off) and IsYTD (the date falls on or before the last actuals date — or, for prior years, on or before the same point in the fiscal year). They turn like-for-like comparison into a slicer or a single filter inside measures.

Core notes

Defining the reference date

Choose one source of truth for "how far actuals go":

Source Pros Cons
MAX(GL[PostingDate]) Automatic Future-dated or provisional entries move it; partial months included
Last closed month-end from a Close parameter table Controlled by the controller; aligns with sign-off Manual step each month
Latest TB[MonthEnd] snapshot Ties to audited/approved TB Lags if TB is loaded later

For management reporting the last closed month-end is usually best for IsClosedPeriod, while MAX posting date can drive IsYTD for flash (intra-month) reports.

IsClosedPeriod

IsClosedPeriod =
VAR LastClosed = MAX ( Close[LastClosedMonthEnd] )
RETURN
    'Date'[MonthEnd] <= LastClosed

All days of a closed month are TRUE; all days of open months FALSE. Uses:

  • Variance reports filtered to IsClosedPeriod = TRUE so budget for open months is excluded.
  • Restatement control: journals posted into closed periods flagged as exceptions.
  • Forecast logic in Weeks 17–20: closed months use actuals, open months use forecast (IF(IsClosedPeriod, [Actual], [Forecast]) evaluated per month and summed with SUMX over months).

IsYTD (current year) and the like-for-like version

The literal flag in the scope: date on or before the last actuals date.

IsYTD =
VAR LastActual = CALCULATE ( MAX ( GL[PostingDate] ), REMOVEFILTERS () )
RETURN
    'Date'[Date] <= LastActual

For comparisons across years, you need the same position within each fiscal year. Use the day of the fiscal year (or fiscal month number for month-level cut-offs):

IsYTDComparable =
VAR LastActual   = MAX ( Close[LastClosedMonthEnd] )
VAR LastFYEnd    = IF ( MONTH ( LastActual ) >= 4, YEAR ( LastActual ) + 1, YEAR ( LastActual ) )
VAR LastFMNo     = MOD ( MONTH ( LastActual ) + 8, 12 ) + 1
RETURN
    'Date'[FiscalMonthNo] <= LastFMNo
        && 'Date'[FYEnd] <= LastFYEnd

With last closed month-end 30-Nov-2025 (fiscal month 8), every date in April–November of every FY is TRUE. FY2025-26 YTD vs FY2024-25 YTD then compares April–November with April–November, simply by filtering IsYTDComparable = TRUE. For daily flash reports use DayOfFiscalYear instead of FiscalMonthNo, taking care with 29 February (a leap FY has one extra day; compare by calendar day-month or accept the one-day shift).

Using flags in measures vs slicers

  • Slicer / page filter: simplest; users toggle "Closed periods only".
  • Inside measures: robust for KPI cards that must always be like-for-like:
YTD Actual (closed) =
CALCULATE ( TOTALYTD ( [Actual], 'Date'[Date], "3/31" ), 'Date'[IsClosedPeriod] = TRUE () )

PY YTD (comparable) =
CALCULATE (
    [Actual],
    REMOVEFILTERS ( 'Date' ),
    'Date'[FYEnd] = MAX ( 'Date'[FYEnd] ) - 1,
    'Date'[IsYTDComparable] = TRUE ()
)

Note the interaction with marked-Date-table behaviour: filtering a Date column other than 'Date'[Date] (like IsClosedPeriod) does not trigger the automatic REMOVEFILTERS('Date'), so the flag intersects with existing month filters — usually what you want.

Calculated column vs measure flags

Calculated-column flags are evaluated at refresh, so they are static between refreshes — ideal for slicers and fast filters. If the as-of date must change interactively (a "what-if as-of" slicer), compute the condition in a measure instead (topic 4 c05: MIN('Date'[Date]) <= [Last Actual Date]).

Illustration

Last closed month-end 30-Nov-2025. Revenue (₹ crore):

FY Apr–Nov Dec–Mar Full year
FY2024-25 640 360 1,000
FY2025-26 704 — —

Without flags: FY2025-26 "YTD" 704 vs FY2024-25 full year 1,000 → apparent decline of 29.6%. With IsYTDComparable: 704 vs 640 → growth of \(\frac{704 - 640}{640} = 10.0\%\). Budget variance filtered by IsClosedPeriod excludes the December–March budget of FY2025-26.

Edge cases & judgement calls

  • Circular dependency. A calculated column on Date that reads GL is fine when Date is a Power Query or fixed CALENDAR table; if Date is a DAX table derived from GL (CALENDARAUTO or MIN/MAX of GL) you may hit circular dependency errors — use a Close parameter table instead.
  • Post-close adjustments. Audit adjustments booked into March after the April close: IsClosedPeriod stays TRUE, but numbers change; track "reopened" periods separately.
  • Partial months. IsYTD using posting date includes the current partial month; for monthly MIS prefer closed-period cut-offs, and label flash reports explicitly.
  • Budget flags. Budget dated MonthStart: IsYTD for 1 December is TRUE if last actual date is 15 December, pulling in the full December budget — use MonthEnd-based flags for budget comparisons.
  • Multiple entities closing on different days need entity-level closed flags in a separate table, not the Date table.

Key takeaways

  • IsClosedPeriod marks months whose books are signed off; IsYTD marks dates on or before the last actuals date.
  • For year-on-year, use a comparable flag based on fiscal month (or day of FY) applied to every year.
  • Drive flags from a controlled as-of date (Close parameter table) rather than raw MAX posting date for MIS.
  • Column flags are static between refreshes; use measure-based caps when the as-of date must be interactive.
  • Flags prevent comparing partial current periods with full prior periods and open-month budget variance.

Practice Questions

Q1. Evaluate the flags [L1]

With last closed month-end 31-Aug-2025 and last GL posting date 17-Sep-2025, state IsClosedPeriod, IsYTD and IsYTDComparable for 10-Aug-2024, 17-Sep-2025, 20-Sep-2025, 31-Mar-2025 and 15-May-2023.

Q2. Fix a misleading KPI [L2]

A CEO dashboard card shows "Revenue YoY: −31%" in December 2025, computed as FY2025-26 total versus FY2024-25 total. Rewrite the measures using comparable flags, and specify which flag(s) the card's filter should use.

💡 Hint: Both years must be cut at the same fiscal month.

Q3. Forecast blend [L3]

Write a measure for full-year outlook that uses actuals for closed months and budget for open months, evaluated month by month so it works at quarter and FY totals. Explain why a simple IF on the flag at FY level fails.

Q4. Leap-year flash report [L2]

A daily flash compares FY2023-24 (366 days) with FY2022-23 using DayOfFiscalYear. Explain what goes wrong for dates after 28 February and propose a comparison key that avoids it.
