Subtopic note

Fiscal Calendar Columns: FY, Quarter, Month, Week and Period Key

Scope: Columns: FY label, fiscal quarter, fiscal month number, month name, month-end, fiscal week, period key (YYYYMM)

Why it matters

The columns on the Date table are the vocabulary of every finance report: "FY2025-26", "Q3", "Dec", "P09", "Week 38", "202512". They drive slicers, matrix headers, sort order, budget joins and custom time intelligence (for non-standard calendars and calculation groups). Each column must be computed with April–March logic, typed correctly, and paired with a numeric sort column where the label is text. An error in any one — say, a fiscal quarter that treats January as Q1 — propagates silently into every MIS pack.

FY label

Indian practice varies: Companies Act and Ind AS financial statements say "year ended 31 March 2026"; the Income-tax Act uses "previous year 2025-26" and "assessment year 2026-27"; MIS decks commonly use "FY26" or "FY2025-26". Choose one display convention, but always keep the numeric FYEnd for sorting and arithmetic. Do not confuse FY with AY in tax-related reports.

FYEnd = IF ( MONTH ( 'Date'[Date] ) >= 4, YEAR ( 'Date'[Date] ) + 1, YEAR ( 'Date'[Date] ) )
FY    = "FY" & ( 'Date'[FYEnd] - 1 ) & "-" & RIGHT ( 'Date'[FYEnd], 2 )

"FY2025-26" sorts correctly as text because the start year leads; "FY26" also sorts correctly within the same century. Still set Sort by Column to FYEnd for safety.

Fiscal quarter and fiscal month

Fiscal month number maps April → 1 … March → 12 with MOD(MONTH([Date]) + 8, 12) + 1 (concept c03). Quarter:

FiscalQuarterNo = ROUNDUP ( 'Date'[FiscalMonthNo] / 3, 0 )
FiscalQuarter   = "Q" & 'Date'[FiscalQuarterNo]

So Q1 = Apr–Jun, Q2 = Jul–Sep, Q3 = Oct–Dec, Q4 = Jan–Mar — consistent with SEBI LODR Reg 33 quarterly results (quarters ending 30 June, 30 September, 31 December, 31 March). "Q4" alone is not unique across years; use FYQuarter ("FY26 Q4") on axes spanning several years.

Month name and month-end

FORMAT([Date], "mmm") gives "Jan"; "mmmm" gives "January". Text month names must be sorted by FiscalMonthNo (s04). MonthEnd via EOMONTH([Date], 0) is the join key for TB snapshots and TREATAS budget patterns, and the anchor for month-level closing balances. MonthYear ("Jan-26") is a unique label for trend charts and must sort by PeriodKey, not alphabetically.

Fiscal week

FiscalWeek = INT ( ( 'Date'[Date] - DATE ( 'Date'[FYEnd] - 1, 4, 1 ) ) / 7 ) + 1

Week 1 is 1–7 April regardless of weekday; week 52 ends on day 364 (30 March in a 365-day year), so week 53 holds 31 March alone (or 30–31 March in a leap fiscal year, e.g. FY2023-24 which contains 29 Feb 2024). If weeks must start on Monday (sales reporting, payroll), use an alternative based on WEEKDAY([Date], 2) and accept a partial week 1. See concept c04.

Period key (YYYYMM)

PeriodKey = YEAR([Date]) * 100 + MONTH([Date]) gives 202601 for January 2026. It is an integer, sorts chronologically, and matches budget and ERP period fields (SAP fiscal period with year). Some teams prefer a fiscal period key (FYEnd × 100 + FiscalMonthNo = 202610) that matches ERP posting periods (period 10 of FY2026). Label it clearly — mixing the two is a common reconciliation error.

Power Query equivalents

AddFYEnd  = Table.AddColumn(Src, "FYEnd", each if Date.Month([Date]) >= 4 then Date.Year([Date]) + 1 else Date.Year([Date]), Int64.Type),
AddFMNo   = Table.AddColumn(AddFYEnd, "FiscalMonthNo", each Number.Mod(Date.Month([Date]) + 8, 12) + 1, Int64.Type),
AddFQ     = Table.AddColumn(AddFMNo, "FiscalQuarter", each "Q" & Text.From(Number.RoundUp([FiscalMonthNo] / 3)), type text),
AddMEnd   = Table.AddColumn(AddFQ, "MonthEnd", each Date.EndOfMonth([Date]), type date),
AddPKey   = Table.AddColumn(AddMEnd, "PeriodKey", each Date.Year([Date]) * 100 + Date.Month([Date]), Int64.Type),
AddFWeek  = Table.AddColumn(AddPKey, "FiscalWeek", each Number.IntegerDivide(Duration.Days([Date] - #date([FYEnd] - 1, 4, 1)), 7) + 1, Int64.Type)

Edge cases & judgement calls

  • Quarter labels for listed companies. Board and SEBI results use "quarter ended 31 December 2025"; build a QuarterEnd date column for formal labels.
  • 13 periods / special periods. SAP special periods 13–16 for year-end adjustments map to 31 March; do not create fake dates.
  • Fiscal year changes. Sec 2(41) of the Companies Act requires a 31 March year-end for Indian companies (with Tribunal-approved exceptions, e.g. subsidiaries of foreign companies); a Date table for an Indian group consolidating a December-year-end foreign parent needs both calendar and fiscal attributes.
  • Week numbering conflicts. ISO weeks, Monday-start weeks and FY-anchored weeks give different numbers; state the definition in the column description.

Key takeaways

  • Keep a numeric FYEnd alongside the text FY label; choose one label convention (FY2025-26 or FY26).
  • Fiscal month MOD(MONTH + 8, 12) + 1; fiscal quarter ROUNDUP(FiscalMonthNo / 3, 0) gives Apr–Jun as Q1.
  • MonthEnd is the snapshot and TREATAS key; MonthYear needs PeriodKey as its sort column.
  • FY-anchored fiscal weeks start 1 April and produce a short week 53.
  • Distinguish calendar PeriodKey (202601) from fiscal period key (202610).

Practice Questions

Q1. Fill the row [L1]

For 29-Feb-2024 compute FYEnd, FY label, FiscalQuarter, FiscalMonthNo, MonthEnd, FiscalWeek, PeriodKey and fiscal period key, showing the arithmetic for the week.

Q2. Quarter-end label [L2]

Write a DAX calculated column returning a formal label such as "Quarter ended 31 December 2025" for every date, and state its sort column.

💡 Hint: The quarter end is the month-end of the last fiscal month of the quarter.

Q3. Period key mismatch [L2]

The budget file uses a period field "2026-10" meaning FY2025-26 period 10. A developer relates it to the Date table's PeriodKey after converting it to 202610. Explain what the report will show for January 2026 and correct the design.

Q4. Week definition for sales [L3]

Sales wants Monday-to-Sunday weeks numbered within the fiscal year, with week 1 being the week containing 1 April. Write the DAX for this column and compare it with the FY-anchored week from the notes for a 52-week trend chart.
