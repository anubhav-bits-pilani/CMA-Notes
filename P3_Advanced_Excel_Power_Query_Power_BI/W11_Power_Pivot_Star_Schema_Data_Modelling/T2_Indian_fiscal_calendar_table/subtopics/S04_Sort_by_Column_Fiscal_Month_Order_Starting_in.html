Subtopic note

Sort by Column: Fiscal Month Order Starting in April

Scope: Sort by Column: month name by fiscal month number so April appears first

Why it matters

Text columns sort alphabetically: Apr, Aug, Dec, Feb, Jan, Jul, Jun, Mar, May, Nov, Oct, Sep. A finance matrix with months in that order is unusable, and one that starts in January splits the Indian fiscal year across two halves of the chart — Q4 (Jan–Mar) appears before Q1. Sort by Column is the model-level setting that fixes this once for every visual, slicer and Analyze-in-Excel PivotTable, rather than each report author fixing sort order visual by visual.

Core notes

How Sort by Column works

Every column in a VertiPaq model can be assigned a sort-by column: another column in the same table whose values determine the display order. When 'Date'[MonthName] is sorted by 'Date'[FiscalMonthNo], the engine orders members Apr (1), May (2) … Mar (12) wherever MonthName is displayed.

Steps in Power BI Desktop:

  1. Data view or Model view → select 'Date'[MonthName].
  2. Column tools → Sort by column → choose FiscalMonthNo.
  3. Repeat for other label columns (table below).

In Excel Power Pivot: Power Pivot → Manage → Home → Sort by Column, choose the label column and the sort column.

Columns that need a sort column

Label column Sort by Why
MonthName ("Apr") FiscalMonthNo April first
MonthNameLong ("April") FiscalMonthNo Same
MonthYear ("Apr-25") PeriodKey (202504) Chronological across years
FY ("FY2025-26") FYEnd Safe even if labels change format
FiscalQuarter ("Q1") FiscalQuarterNo Usually alphabetic works, but be explicit
FYQuarter ("FY26 Q1") FYEnd × 10 + FiscalQuarterNo Chronological across years
DayName ("Mon") WeekdayNo (Mon = 1) Mon–Sun rather than alphabetic
CoA FSLine (from topic 1) LineSort Statement order

The one-to-one rule

Each value of the label column must map to exactly one value of the sort column. Otherwise Power BI raises: "We can't sort the 'X' column by 'Y'. There can't be more than one value in 'Y' for the same value in 'X'."

Consequences:

  • MonthName can be sorted by FiscalMonthNo (Apr is always 1) but not by PeriodKey (Apr has 202204, 202304 …).
  • MonthYear ("Apr-25") maps to one PeriodKey and to one FiscalMonthNo, so both sorts are technically allowed — but sorting by FiscalMonthNo interleaves years (Apr-24, Apr-25, May-24 …), which is wrong for a trend. Use PeriodKey.
  • A sort column that depends on the label column in DAX (e.g. a calculated column computing the sort number from MonthName) can cause a circular dependency; derive both from [Date].

Interaction with visuals

  • Sort by Column defines the default order of the axis or rows. A user can still sort a visual by a measure (e.g. revenue descending); for a P&L or month axis, set the visual's sort to the month field ascending.
  • In a matrix with FY on columns and MonthName on rows, rows run Apr → Mar within each FY.
  • Slicers listing months follow the same order.
  • When a visual uses MonthName and another field from Date, DAX queries include the sort column automatically (the sort-by column joins the group-by). This matters in DAX measures that use ALL('Date'[MonthName]) or REMOVEFILTERS('Date'[MonthName]): the sort-by column FiscalMonthNo is also in the filter context, so you must remove it too — REMOVEFILTERS('Date'[MonthName], 'Date'[FiscalMonthNo]) — or the filter is not fully cleared. This is a frequent cause of "% of total" measures returning 100% on every month row.

Hiding sort columns

Hide FiscalMonthNo, PeriodKey, FYEnd and WeekdayNo from report view (they are technical), unless users need them. Hidden sort columns still work.

Illustration

A Hyderabad-based pharma company's monthly revenue chart (FY2025-26) initially shows months alphabetically: Apr ₹82 crore, Aug ₹91 crore, Dec ₹96 crore, Feb ₹88 crore… making the trend line zig-zag meaninglessly. After sorting MonthName by FiscalMonthNo the axis reads Apr, May, Jun … Mar, and the expected seasonal build to a March peak (₹104 crore, year-end stocking) becomes visible.

A measure written as

% of FY = DIVIDE ( [Actual], CALCULATE ( [Actual], REMOVEFILTERS ( 'Date'[MonthName] ) ) )

shows 100% on every month row in a matrix that has MonthName on rows, because FiscalMonthNo (the sort column) is also filtering. The corrected denominator is CALCULATE([Actual], REMOVEFILTERS('Date'[MonthName], 'Date'[FiscalMonthNo])) or, more robustly, CALCULATE([Actual], ALLEXCEPT('Date', 'Date'[FY])).

Edge cases & judgement calls

  • Excel PivotTables connected to Power Pivot respect Sort by Column, but an Excel custom list (Jan–Dec) or manual drag can override it. Set PivotTable options so custom lists are not used for sorting.
  • Calendar-year reports. If a US parent wants Jan–Dec, add a separate MonthName column sorted by calendar month number rather than changing the fiscal one.
  • Field parameters and calculation groups have their own ordinal/precedence columns; Sort by Column on the Date table does not order them.
  • DirectQuery sources honour Sort by Column, but the sort column must exist in the source query.

Key takeaways

  • Text month names sort alphabetically unless sorted by FiscalMonthNo.
  • Each label value must map to exactly one sort value (MonthName → FiscalMonthNo; MonthYear → PeriodKey).
  • Set sort columns for every text label in Date and CoA; hide the numeric helpers.
  • Measures removing filters from a sorted label must also remove the sort column.
  • Excel PivotTables can override model sorting with custom lists — check the option.

Practice Questions

Q1. Set up the sorts [L1]

List every column in a fiscal Date table that needs a Sort by Column setting, the sort column for each, and the error you would see if you sorted MonthName by PeriodKey.

Q2. 100% on every row [L2]

A matrix with FY on columns and MonthName on rows uses % of FY = DIVIDE([Actual], CALCULATE([Actual], ALL('Date'[MonthName]))). Every cell shows 100%. Explain why, and write two corrected versions.

💡 Hint: Look at which columns the generated DAX query groups by.

Q3. Mixed audiences [L2]

The Indian entity reports April–March but the Singapore parent wants January–December charts from the same model. Design the Date table columns and sort settings to serve both without duplicating the table.

Q4. Excel board pack [L3]

An Excel board pack uses PivotTables on a Power Pivot model; after a colleague's edit, months appear Jan–Dec even though the model sorts by FiscalMonthNo. List the possible causes and the steps to restore and protect fiscal order.
