Key concept

Fiscal Week Number Anchored on 1 April

Concept: Fiscal week: INT(([Date] - DATE([FYEnd] - 1, 4, 1)) / 7) + 1

Statement

FiscalWeek = INT ( ( 'Date'[Date] - DATE ( 'Date'[FYEnd] - 1, 4, 1 ) ) / 7 ) + 1

\[ \text{FiscalWeek}(d) = \left\lfloor \frac{d - \text{FYStart}(d)}{7} \right\rfloor + 1, \qquad \text{FYStart}(d) = \text{DATE}(\text{FYEnd}(d) - 1, 4, 1) \]

  • \(d - \text{FYStart}(d)\) is the number of days elapsed since 1 April of the date's fiscal year (0 on 1 April).
  • Dividing by 7 and truncating gives completed weeks; adding 1 makes week 1 the first seven days.

Explanation

This defines FY-anchored weeks: week 1 is always 1–7 April, week 2 is 8–14 April, and so on, regardless of the weekday on which 1 April falls. Properties:

  • Weeks 1–52 have exactly seven days (days 0–363 elapsed).
  • Week 53 contains the remaining day(s): 31 March in a 365-day fiscal year; 30 and 31 March in a 366-day fiscal year (one containing 29 February, e.g. FY2023-24 and FY2027-28).
  • Each fiscal year has the same week boundaries in day-of-year terms, which makes "week 20 this year vs week 20 last year" a like-for-like comparison of the same 7-day span.

Limitations:

  • Weeks do not start on a fixed weekday, so weekday mix varies (week 1 of FY2025-26 starts Tuesday 1-Apr-2025; of FY2026-27, Wednesday 1-Apr-2026). Retail and sales teams that think in Monday–Sunday weeks find this confusing.
  • Week 53 is a stub: exclude it or merge it into week 52 in weekly trend charts, or it shows as a dip.
  • DAX date subtraction returns a number of days only when both operands are dates; ensure 'Date'[Date] has no time part, or wrap with INT.

Monday-start alternative (week 1 = the week containing 1 April):

FiscalWeekMon =
VAR FYStart = DATE ( 'Date'[FYEnd] - 1, 4, 1 )
VAR FirstMonday = FYStart - WEEKDAY ( FYStart, 2 ) + 1
RETURN
    INT ( ( 'Date'[Date] - FirstMonday ) / 7 ) + 1

WEEKDAY(date, 2) returns 1 for Monday through 7 for Sunday; FirstMonday is the Monday on or before 1 April. This yields a partial week 1 and possibly a week 53, but every week runs Monday to Sunday.

Power Query equivalent of the FY-anchored version: Number.IntegerDivide(Duration.Days([Date] - #date([FYEnd] - 1, 4, 1)), 7) + 1.
