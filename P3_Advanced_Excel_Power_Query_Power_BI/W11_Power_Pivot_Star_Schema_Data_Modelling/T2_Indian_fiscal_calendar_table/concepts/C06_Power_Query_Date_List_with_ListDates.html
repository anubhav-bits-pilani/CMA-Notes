Key concept

Power Query Date List with List.Dates

Concept: Power Query version: List.Dates(#date(2022,4,1), Duration.Days(#date(2027,3,31) - #date(2022,4,1)) + 1, #duration(1,0,0,0))

Statement

List.Dates(
    #date(2022, 4, 1),                                         // start
    Duration.Days(#date(2027, 3, 31) - #date(2022, 4, 1)) + 1,  // count of dates
    #duration(1, 0, 0, 0)                                      // step: 1 day
)

List.Dates(start as date, count as number, step as duration) returns a list of count dates beginning at start, each step apart.

  • #date(y, m, d) constructs a date literal.
  • Subtracting two dates yields a duration; Duration.Days extracts the whole days (1,825 here).
  • + 1 makes the range inclusive of the end date, giving 1,826 dates.
  • #duration(days, hours, minutes, seconds) — here one day.

\[ \text{count} = (\text{End} - \text{Start})_{\text{days}} + 1 = 1{,}825 + 1 = 1{,}826 \]

Explanation

The list must be converted into a typed table and enriched with fiscal columns:

let
    pStart  = #date(2022, 4, 1),
    pEnd    = #date(2027, 3, 31),
    Dates   = List.Dates(pStart, Duration.Days(pEnd - pStart) + 1, #duration(1, 0, 0, 0)),
    Tbl     = Table.FromList(Dates, Splitter.SplitByNothing(), type table [Date = date]),
    FYEnd   = Table.AddColumn(Tbl, "FYEnd",
                  each if Date.Month([Date]) >= 4 then Date.Year([Date]) + 1 else Date.Year([Date]), Int64.Type),
    FY      = Table.AddColumn(FYEnd, "FY",
                  each "FY" & Text.From([FYEnd] - 1) & "-" & Text.End(Text.From([FYEnd]), 2), type text),
    FMNo    = Table.AddColumn(FY, "FiscalMonthNo", each Number.Mod(Date.Month([Date]) + 8, 12) + 1, Int64.Type),
    MEnd    = Table.AddColumn(FMNo, "MonthEnd", each Date.EndOfMonth([Date]), type date)
in
    MEnd

Points:

  • Off-by-one. Omitting + 1 drops 31 March 2027 — the calendar then fails the whole-fiscal-year requirement and CLOSINGBALANCEYEAR for FY2026-27 returns blank.
  • Types. Table.FromList with a typed table schema (or Table.TransformColumnTypes) ensures the Date column is date, not any or datetime; untyped columns load as text or datetime and break relationships.
  • Parameters. Make pStart and pEnd Power Query parameters (Manage Parameters) so the range is changed in one place each year, or compute them from facts: Date.StartOfYear is calendar-based, so derive FY starts manually (#date(if Date.Month(d) >= 4 then Date.Year(d) else Date.Year(d) - 1, 4, 1)).
  • Alternative generator: List.Generate or {Number.From(pStart)..Number.From(pEnd)} converted back with Date.From are equivalent; List.Dates is clearest.
  • Reuse: publish the query as a Power BI dataflow so every model consumes one corporate fiscal calendar.
  • Works in Excel Power Query too, then Close & Load To → Only create connection + Add to Data Model.
