Key concept

Fiscal Month and Fiscal Quarter Formulas

Concept: Fiscal month: MOD(MONTH([Date]) + 8, 12) + 1; fiscal quarter: "Q" & ROUNDUP([FiscalMonthNo] / 3, 0)

Statement

FiscalMonthNo = MOD ( MONTH ( 'Date'[Date] ) + 8, 12 ) + 1
FiscalQuarter = "Q" & ROUNDUP ( 'Date'[FiscalMonthNo] / 3, 0 )

In general, for a fiscal year starting in calendar month \(s\) (April: \(s = 4\)) and calendar month \(m\):

\[ \text{FiscalMonthNo} = ((m - s + 12) \bmod 12) + 1 = ((m + 8) \bmod 12) + 1 \text{ for } s = 4 \]

\[ \text{FiscalQuarterNo} = \left\lceil \frac{\text{FiscalMonthNo}}{3} \right\rceil \]

Explanation

Adding 8 and taking the remainder mod 12 shifts the month numbering so April maps to 0 and March to 11; adding 1 makes the result run 1–12. The general form \((m - s + 12) \bmod 12 + 1\) works for any start month: July-start (Australia) uses \(s = 7\), i.e. MOD(MONTH + 5, 12) + 1; January-start gives the calendar month.

The quarter divides fiscal month by 3 and rounds up: months 1–3 → Q1 (Apr–Jun), 4–6 → Q2 (Jul–Sep), 7–9 → Q3 (Oct–Dec), 10–12 → Q4 (Jan–Mar), consistent with quarterly results under SEBI LODR Reg 33 and Ind AS 34 interim periods for a March year-end.

Implementation notes:

  • Store FiscalQuarterNo as an integer column too; the text "Q1" is for display and sorts correctly only by coincidence of alphabet. Sort FiscalQuarter by FiscalQuarterNo.
  • "Q4" is not unique across years; for multi-year axes add "FY" & RIGHT([FYEnd], 2) & " " & [FiscalQuarter] ("FY26 Q4") sorted by [FYEnd] * 10 + [FiscalQuarterNo].
  • Power Query equivalents: Number.Mod(Date.Month([Date]) + 8, 12) + 1 and "Q" & Text.From(Number.RoundUp([FiscalMonthNo] / 3)).
  • Excel equivalent (for checking): =MOD(MONTH(A2)+8,12)+1 and ="Q"&ROUNDUP(B2/3,0).
  • An alternative fiscal-month formula, IF(MONTH(d) >= 4, MONTH(d) - 3, MONTH(d) + 9), gives identical results and is easier to read; the MOD version generalises better.

Q1. Generalise [L1]

Q2. Find the bug [L2]

A Date table uses FiscalQuarter = "Q" & ROUNDUP(MONTH([Date]) / 3, 0). Describe exactly which months land in the wrong quarter, the effect on a "Q3 FY26 results" report and on a TOTALQTD measure, and how you would test it.

Write DAX calculated columns for a unique fiscal-quarter label like "FY26 Q3" and its integer sort key, and explain why sorting the label alone is insufficient for an eight-quarter trend chart covering FY25–FY26.
