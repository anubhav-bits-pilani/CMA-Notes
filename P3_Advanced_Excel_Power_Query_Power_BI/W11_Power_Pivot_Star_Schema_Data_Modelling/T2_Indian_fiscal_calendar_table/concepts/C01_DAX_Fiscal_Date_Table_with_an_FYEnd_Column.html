Key concept

DAX Fiscal Date Table with an FYEnd Column

Concept: Date = ADDCOLUMNS(CALENDAR(DATE(2022,4,1), DATE(2027,3,31)), "FYEnd", IF(MONTH([Date]) >= 4, YEAR([Date]) + 1, YEAR([Date])))

Statement

Date =
ADDCOLUMNS (
    CALENDAR ( DATE ( 2022, 4, 1 ), DATE ( 2027, 3, 31 ) ),
    "FYEnd", IF ( MONTH ( [Date] ) >= 4, YEAR ( [Date] ) + 1, YEAR ( [Date] ) )
)
  • CALENDAR(start, end) — a single-column table [Date] containing every date from 1-Apr-2022 to 31-Mar-2027 inclusive (1,826 rows: five fiscal years, one containing 29-Feb-2024).
  • ADDCOLUMNS(table, name, expression) — iterates the table in row context and adds the computed column.
  • FYEnd — the calendar year in which the date's fiscal year ends:

\[ \text{FYEnd}(d) = \begin{cases} \text{YEAR}(d) + 1 & \text{if } \text{MONTH}(d) \ge 4 \\ \text{YEAR}(d) & \text{if } \text{MONTH}(d) \le 3 \end{cases} \]

Explanation

The single column FYEnd encodes the Indian April–March year: 1-Apr-2025 to 31-Mar-2026 all carry FYEnd = 2026. Everything else derives from it:

  • FY label: "FY" & ([FYEnd] - 1) & "-" & RIGHT([FYEnd], 2) → "FY2025-26".
  • Fiscal week start: DATE([FYEnd] - 1, 4, 1).
  • FY offset: [FYEnd] - FYEnd(as-of date).
  • Custom time intelligence: "same FY last year" = FYEnd - 1.

Why a numeric FYEnd rather than only the text label: integers sort, subtract and compare; the label is for display.

Conditions:

  • The hard-coded bounds must start on 1 April and end on 31 March and must cover all fact dates (s02). Revisit them every year when the next budget is loaded — or derive them from parameters or the facts.
  • Because ADDCOLUMNS evaluates every new column against the original table, a second column cannot reference [FYEnd] within the same ADDCOLUMNS call; nest another ADDCOLUMNS or add calculated columns afterwards.
  • Calculated tables are not available in Excel Power Pivot; use Power Query there (c06).
  • After creating the table, set [Date] data type to Date (CALENDAR returns datetime with 00:00 time — harmless, but set the format), mark it as the date table, and set sort columns.

Illustration

Date MONTH YEAR FYEnd FY label
31-Mar-2025 3 2025 2025 FY2024-25
01-Apr-2025 4 2025 2026 FY2025-26
31-Dec-2025 12 2025 2026 FY2025-26
01-Jan-2026 1 2026 2026 FY2025-26
31-Mar-2026 3 2026 2026 FY2025-26

The boundary between 31 March and 1 April is the only place the FY changes; testing those two rows plus 31 December → 1 January (where YEAR changes but FY does not) validates the logic.

Practice Questions

Q1. Extend the table [L1]

Extend the formula so that the table also returns FY label, FiscalMonthNo and MonthEnd, using nested ADDCOLUMNS or VAR so that FY label can reuse FYEnd.

Q2. Off-by-one review [L2]

A junior writes "FYEnd", IF(MONTH([Date]) > 4, YEAR([Date]) + 1, YEAR([Date])). Identify which dates are mislabelled, the effect on April YTD and on a TB tie-out for the year, and how you would catch it with a test query.

💡 Hint: Test the boundary rows listed in the illustration.

Q3. Dynamic bounds [L2]

Rewrite the formula so that the start is 1 April of the FY containing the earliest GL posting date and the end is 31 March of the FY containing the latest Budget MonthStart, and state one risk of making the table depend on facts.
