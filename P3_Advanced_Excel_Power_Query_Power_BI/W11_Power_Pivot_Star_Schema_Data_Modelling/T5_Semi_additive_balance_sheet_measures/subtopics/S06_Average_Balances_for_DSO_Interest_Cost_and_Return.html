Subtopic note

Average Balances for DSO, Interest Cost and Return Ratios

Scope: Average balances for ratios (average receivables for DSO, average debt for interest cost)

Why it matters

Ratios that relate a flow to a balance — DSO (receivables to revenue), DIO, DPO, interest cost on debt, ROCE, asset turnover, NBFC yield on advances — should use the average balance over the period of the flow, not the closing balance. Closing balances distort ratios whenever balances move within the period: a company that collects heavily in March shows a flattering closing DSO; a borrower that draws a large loan on 25 March shows an absurdly low "effective interest rate". Credit rating agencies, bankers' CMA data analyses and equity analysts all compute averages, and your DAX measures must replicate the convention used by the reader.

Core notes

Averaging conventions

Convention Formula Data needed Typical use
Two-point \(\frac{\text{Opening} + \text{Closing}}{2}\) Opening and closing Published-accounts analysis, annual ratios
Month-end average \(\frac{1}{n}\sum_{m=1}^{n} \text{Closing}_{m}\) n month-end balances Internal MIS, quarterly ratios
13-point \(\frac{1}{13}\left(\text{Opening}_{\text{FY}} + \sum_{m=1}^{12} \text{Closing}_{m}\right)\) Opening plus 12 month-ends Banks, NBFCs, rigorous ROCE
Daily average \(\frac{1}{D}\sum_{d=1}^{D} \text{Bal}_{d}\) Daily balances Treasury, interest on CC/OD accounts, NBFC yield

The more points, the closer the average follows intra-period movement; daily averages match how banks charge interest on cash credit facilities.

DAX patterns

Month-end average over whatever period is visible:

Avg AR = AVERAGEX ( VALUES ( 'Date'[MonthEnd] ), [Closing AR] )

VALUES('Date'[MonthEnd]) lists the month-ends in the current period (one for a month, three for a quarter, twelve for a year); AVERAGEX evaluates [Closing AR] for each through context transition and averages. AVERAGEX skips blanks, so future months without balances do not drag the average down — but zero balances are counted.

Two-point average at month grain, using the opening function for the matching grain (the previous month-end):

Avg AR 2pt (month) =
VAR openBal  = OPENINGBALANCEMONTH ( [Closing AR], 'Date'[Date] )
VAR closeBal = [Closing AR]
RETURN DIVIDE ( openBal + closeBal, 2 )

At year grain, use the year variant with the fiscal year-end:

Avg AR 2pt (year) =
VAR openBal  = OPENINGBALANCEYEAR ( [Closing AR], 'Date'[Date], "3/31" )
VAR closeBal = [Closing AR]
RETURN DIVIDE ( openBal + closeBal, 2 )

13-point average for a fiscal year:

Avg Debt 13pt =
VAR openBal = OPENINGBALANCEYEAR ( [Closing Debt], 'Date'[Date], "3/31" )
VAR sumMonth = SUMX ( VALUES ( 'Date'[MonthEnd] ), [Closing Debt] )
VAR n = COUNTROWS ( VALUES ( 'Date'[MonthEnd] ) )
RETURN DIVIDE ( openBal + sumMonth, n + 1 )

Daily average (movement fact, cumulative measure):

Avg Debt Daily = AVERAGEX ( VALUES ( 'Date'[Date] ), [Cum Bal Debt] )

Daily averages iterate every date and evaluate a running total for each — heavier, but fine for a few accounts.

Using averages in ratios

Effective Interest Rate =
DIVIDE ( [Finance Cost on Borrowings], [Avg Debt 13pt] ) * DIVIDE ( 365, [Days in Period] )

DSO = DIVIDE ( [Avg AR], [Revenue] ) * [Days in Period]

Annualisation: interest for a quarter divided by average debt gives a quarterly rate; multiply by 365 ÷ days in the period. DSO does not need annualising because revenue and days cover the same period.

Worked illustration

Term loan balance (₹ crore): 31 March 2025 = 100; month-ends April–February = 100 each; a ₹ 60 crore drawdown on 25 March 2026 gives 31 March 2026 = 160. Interest for FY26 = ₹ 9.2 crore (9% on ≈100 for the year plus a few days on the new tranche).

Average used Value Implied rate
Closing balance 160 5.75%
Two-point (100 + 160) / 2 = 130 7.08%
13-point (100 + 11 × 100 + 160) / 13 = 104.6 8.79%
Daily ≈ 101.0 ≈ 9.1%

Only the daily and 13-point averages give a rate close to the contractual 9%; the closing-balance figure would mislead a lender's review into thinking the company borrows cheaply.

Edge cases & judgement calls

  • Grain mismatch: Avg AR on a month row averages one month-end, which equals the closing balance; if a monthly DSO needs a two-point average, use the two-point version at month grain.
  • Partial periods: in an incomplete FY, VALUES('Date'[MonthEnd]) includes future months; AVERAGEX skips blanks on a snapshot fact, but on a movement fact [Cum Bal] returns the latest cumulative value for future dates (no new postings) — cap at the last actual date or the average is biased toward the latest balance.
  • Seasonal businesses: sugar, fertiliser and seed companies have huge intra-year swings; a two-point average on 31 March balances can be far from typical working capital. Prefer month-end averages and disclose the convention.
  • Gross vs net receivables: DSO on gross (before ECL allowance under Ind AS 109) vs net receivables differs; pick one and state it. Receivables include GST while revenue excludes it; either gross up revenue or disclose the bias (see the DSO concept, c06).
  • Debt definitions: include current maturities and short-term borrowings; lease liabilities under Ind AS 116 only if finance cost includes lease interest — numerator and denominator must match.

Key takeaways

  • Flow-to-balance ratios use average balances; closing balances distort when balances move.
  • AVERAGEX(VALUES('Date'[MonthEnd]), [Closing X]) gives a month-end average at any grain; add the opening for 13-point.
  • Two-point averages need an opening balance from the matching grain's opening function.
  • Annualise period rates by 365 ÷ days in period; DSO needs no annualising.
  • Match numerator and denominator definitions (gross/net, with/without leases, with/without GST).

Practice Questions

Q1. Compute three averages [L1]

Trade receivables (₹ lakh) at month-ends: 31 Mar 2025 1,200; Apr 1,260; May 1,310; Jun 1,180. Compute the two-point, month-end (3-point, April–June) and 4-point (opening plus three month-ends) averages for Q1 FY26, and state which DAX measure in this note produces each.

Q2. Effective interest rate [L2]

A cash-credit facility had daily balances averaging ₹ 42 crore in Q3 FY26, month-end balances of ₹ 30 crore, ₹ 55 crore and ₹ 38 crore, an opening balance of ₹ 35 crore, and interest charged for the quarter of ₹ 0.95 crore. Compute the annualised rate under each averaging convention, and recommend which the treasury dashboard should show.

💡 Hint: Use 92 days for October–December and keep the quarterly interest unannualised until the last step.

Q3. Future months in the average [L2]

In November 2025 a movement-based model shows FY26 average debt of ₹ 148 crore, while month-end balances April–November average ₹ 131 crore and the November balance is ₹ 172 crore. Explain how the future months distort the measure and rewrite it to average only closed months.

Q4. Ratio convention for a rating presentation [L3]

A CRISIL-style rating presentation needs FY25 and FY26 ROCE, DSO, DPO and interest coverage. Design the measures, specifying the averaging convention for each denominator, how lease liabilities and current maturities are treated, and how you would document the conventions so that the rating analyst can reproduce your numbers from the audited accounts.
