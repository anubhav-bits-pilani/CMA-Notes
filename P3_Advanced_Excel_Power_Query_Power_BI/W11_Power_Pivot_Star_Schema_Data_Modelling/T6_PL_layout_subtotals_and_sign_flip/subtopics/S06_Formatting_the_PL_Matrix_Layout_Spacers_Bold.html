Subtopic note

Formatting the P&L Matrix: Layout, Spacers, Bold Subtotals, Empty Rows

Scope: Matrix formatting: stepped layout off, blank spacer rows, bold subtotals via conditional formatting, hiding empty rows

Why it matters

The DAX can be perfect and the report still look wrong: indented hierarchy levels where a flat statement is expected, subtotal rows indistinguishable from account rows, header rows that vanish, accounts with no activity cluttering the page, or a "Total" row at the bottom summing EBITDA, GM % and PAT together. CFOs judge a P&L report by whether it looks like the board pack they already know. The formatting settings in this note are the difference between a model that is used and one that is exported to Excel and re-typed every month.

Core notes

Stepped layout off and row subtotals off

  • Stepped layout (Format visual → Row headers → Options → Stepped layout) shows hierarchy levels in one indented column. For a flat statement driven by Layout[Line], turn it off; if you drill to accounts (Layout line → account), off gives two separate columns (Line, Account), which reads like a schedule.
  • Row subtotals (Format → Row subtotals): the layout already contains its own subtotal rows; the matrix's automatic subtotal and grand total would add GP + EBITDA + … together. Turn row subtotals off, or blank them in DAX with ISINSCOPE (c05). Column subtotals (e.g., FY total across months) are fine — they are just another filter context, and every measure recomputes there.

Blank spacer rows

Spacer rows (Type = "Spacer", label a single space or a non-breaking space) separate blocks. Their measure value is BLANK, so by default the matrix hides them along with headers. Options:

  1. Show items with no data: right-click Layout[Line] in the Rows well → Show items with no data. All layout rows appear, including spacers and headers. Side-effect: Account lines with no postings in the period also appear (often desirable in a fixed-format statement).
  2. Return a hidden value: the dispatcher returns 0 for Header/Spacer rows and the dynamic format string for those types is ";;;" (or " "), which renders nothing. Rows stay visible without "Show items with no data". Test that exports do not show the zeros as values.
  3. Visual-level filter on a "Show Row" measure: Show Row = IF((SELECTEDVALUE(Layout[Type]) IN {"Header","Spacer"}) || NOT ISBLANK([PnL]), 1) combined with Show items with no data gives fine control (hide empty accounts, keep structural rows).

Because spacer labels must be unique for Sort by Column, use one, two, three spaces or invisible characters per spacer row.

Bold or highlighted subtotals

Power BI's conditional formatting for matrix values supports background colour, font colour, data bars, icons and web URL, driven by rules or by a field value (a measure returning a colour hex code). Font weight is not a conditional formatting option in most versions, so "bold subtotals" is implemented as:

  • A style measure returning colours by row type:
Row Background =
SWITCH (
    SELECTEDVALUE ( Layout[Type] ),
    "Subtotal", "#E8EEF7",
    "Ratio",    "#FFFFFF",
    BLANK ()
)

Row Font Colour =
SWITCH (
    SELECTEDVALUE ( Layout[Type] ),
    "Subtotal", "#0B2545",
    "Ratio",    "#5C677D",
    "#000000"
)

Apply via Cell elements → Background colour / Font colour → Field value → the style measure, for each value column (and for row headers where the version allows). - Label-based emphasis: uppercase labels for subtotals ("GROSS PROFIT"), or a Unicode bold label column (risky for screen readers and exports). - Excel PivotTables on Power Pivot allow true bold on selected rows (manual or via PivotTable styles), which is one reason finance teams still render board packs in Excel (s07).

Check the current Power BI release notes — matrix formatting gains options regularly (per-row styling via visual calculations or new cell element settings may make true bold possible).

Hiding empty rows

By default the matrix hides rows where every value measure is blank. Consequences and controls:

  • An account line with zero activity disappears (good for drill-down, bad for a fixed statement); force it with Show items with no data or a hidden zero.
  • A measure returning 0 instead of BLANK (e.g., [Actual] + 0, or COALESCE([Actual], 0)) shows every account in the CoA, even those not used for years. Return BLANK for "no data" and 0 only when a real zero is meaningful.
  • With multiple value columns (Actual, Budget, PY), a row shows if any column is non-blank — a budget-only line appears with blank actuals, which is correct for variance analysis.

Other finishing touches

  • Column headers: rename measures in the visual ("Actual", "Budget", "Var ₹", "Var %") without renaming the model measures.
  • Word wrap off on row headers for a compact statement; fix column widths.
  • Ratio rows in italics or lighter font via the font-colour style measure; percentage format via dynamic format string (s05).
  • Freeze headers: matrix headers stay visible when scrolling by default.
  • Tooltips: add the as-of date and data source to the matrix tooltip page for audit trail.
  • Accessibility: rely on more than colour for emphasis (label text, position), and keep contrast high.

Edge cases & judgement calls

  • Show items with no data plus a cross-filtering slicer can resurrect lines from other layouts or statements; filter the visual to the current layout name.
  • Drill-down to accounts with "Show items with no data" on the account level shows every account under every line — enable it only on the Line level.
  • Hidden-zero trick can mislead: a header row with a hidden 0 sorts and exports as 0; document it.
  • Mobile layout: wide matrices with monthly columns are unreadable on phones; design a separate mobile view with key lines only.
  • Printing/PDF export: matrix pagination may split the statement; check the PDF export or use paginated reports (Power BI Report Builder) for statutory-style output.

Key takeaways

  • Turn stepped layout and row subtotals off for a flat, layout-driven statement.
  • Keep spacer and header rows visible with "Show items with no data", a hidden-zero format or a Show Row measure.
  • Emphasise subtotals with field-value conditional formatting (background/font colour) driven by a style measure.
  • Return BLANK for "no data" and avoid + 0 patterns that list every account.
  • Treat formatting as part of the specification: document the settings so the report can be rebuilt.

Practice Questions

Q1. Configure the matrix [L1]

List the exact Power BI settings (field wells, format pane options, conditional formatting) needed to render a monthly trend P&L for FY26 with April–March columns, an FY total column, spacer rows between blocks, shaded subtotal rows and no grand total row.

Q2. Vanishing headers [L2]

The header row "Expenses" and two spacer rows do not appear in the matrix, while "Other income" (no postings in November) also disappears. Explain why each row is hidden and design a solution that shows headers and spacers but still hides account lines with no postings.

💡 Hint: Combine "Show items with no data" with a visual-level filter measure that knows the row type.

Q3. Style measures [L2]

Write style measures that return (a) a light blue background for Subtotal rows, (b) a grey italic-looking lighter font for Ratio rows, and (c) red font for any Var ₹ cell that is adverse, given a [Var ₹] measure in the profit-signed convention. Explain where each is applied in the format pane.

Q4. Board-pack fidelity [L3]

The CFO insists the Power BI P&L must look identical to the existing Excel board pack: bold subtotals, brackets for negatives, ₹ lakh with one decimal, margin rows in italics, and a fixed set of lines even when zero. Assess which requirements Power BI's matrix meets natively, which need workarounds, and which might justify an Excel PivotTable or cube-formula output instead, and recommend an approach.
