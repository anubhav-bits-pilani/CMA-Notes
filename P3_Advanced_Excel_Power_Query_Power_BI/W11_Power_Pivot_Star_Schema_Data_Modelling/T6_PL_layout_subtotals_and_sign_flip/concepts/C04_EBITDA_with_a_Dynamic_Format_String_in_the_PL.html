Key concept

EBITDA % with a Dynamic Format String in the P&L Matrix

Concept: EBITDA % = DIVIDE([EBITDA], [Revenue]), with IF(SELECTEDVALUE(Layout[Type]) = "Ratio", "0.0%", "#,##0") as a dynamic format string

Statement

EBITDA % = DIVIDE ( [EBITDA], [Revenue] )

-- Format string expression on the [PnL] dispatcher (Format: Dynamic)
IF ( SELECTEDVALUE ( Layout[Type] ) = "Ratio", "0.0%", "#,##0" )

\[ \text{EBITDA \%} = \frac{\text{EBITDA}}{\text{Revenue}} \]

where both are profit-signed measures evaluated in the same filter context (period, branch, scenario). DIVIDE returns BLANK when revenue is zero or blank. The format string expression returns a format per cell: percentage on Ratio rows, whole ₹ on all others.

Explanation

The ratio. EBITDA % is non-additive: it is recomputed from EBITDA and Revenue in every context, so the YTD column shows YTD EBITDA ÷ YTD revenue, not an average of monthly margins, and a region row shows that region's margin. In the dispatcher, the Ratio branch calls a margin measure that picks numerator and denominator from the layout row (s05), or a dedicated measure such as this one.

The format. A matrix column has one measure, but rows mix ₹ values and percentages. A dynamic format string lets a measure's format be a DAX expression evaluated for each cell. In Power BI Desktop: select the measure, set Format to Dynamic, and enter the expression in the format-string box. SELECTEDVALUE(Layout[Type]) gives the row type, so Ratio rows get "0.0%" and others "#,##0". The underlying value remains a number (0.1708, not "17.1%"), which keeps:

  • conditional formatting rules working (colour EBITDA % red below 15%),
  • sorting and totals numeric,
  • exports to Excel numeric (with the format applied where supported).

Contrast with FORMAT([EBITDA %], "0.0%"), which returns text: it left-aligns, cannot be conditionally formatted by value, breaks column totals and exports as text.

Refinements:

  • Brackets for negatives and dash for zero: "#,##0;(#,##0);-" and "0.0%;(0.0%);-".
  • Scale for ₹ lakh or crore in the measure (÷ 1e5, ÷ 1e7) — format strings can scale only by thousands.
  • Guard against negative revenue: return BLANK when [Revenue] <= 0 for margin rows.
  • In a calculation group, the item's format string expression overrides the measure's; use SELECTEDMEASUREFORMATSTRING() to defer to the dynamic format of [PnL] for non-% items.
  • Dynamic format strings for measures became generally available in Power BI in 2024; Excel clients connected to the model may not honour them in every version — test.

Connections

Margin rows and layout-driven numerator/denominator references are in s05; the dispatcher that calls it is c01 and s03; EBITDA itself is the subtotal of c03. The DIVIDE semantics come from Topic 3 (c07). EBITDA margin is the second measure in this week's Saturday test, alongside R12M Revenue (Topic 4), and in Weeks 17–20 margin variances in bps are standard MIS commentary.

Practice Questions

Q1. Write the format expression [L1]

Write a dynamic format string expression for [PnL] that shows Ratio rows as 0.0% with brackets for negatives, Account and Subtotal rows as whole numbers with brackets for negatives and a dash for zero, and Header/Spacer rows as nothing.

Q2. Monthly vs YTD margin [L2]

Monthly revenue (₹ lakh) Oct 1,200, Nov 1,050, Dec 1,350 and EBITDA 228, 147, 270. Compute the monthly EBITDA %, the Q3 EBITDA %, and the simple average of the monthly margins, and explain which one the Q3 column of the matrix must show.

💡 Hint: The ratio is recomputed from the quarter's numerator and denominator.

Q3. FORMAT() migration [L2]

A report uses IF(t = "Ratio", FORMAT([Margin %], "0.0%"), FORMAT([Subtotal], "#,##0")) in its P&L measure. List what breaks for the finance user in the report and in Analyze in Excel, and rewrite the measure and its format string.
