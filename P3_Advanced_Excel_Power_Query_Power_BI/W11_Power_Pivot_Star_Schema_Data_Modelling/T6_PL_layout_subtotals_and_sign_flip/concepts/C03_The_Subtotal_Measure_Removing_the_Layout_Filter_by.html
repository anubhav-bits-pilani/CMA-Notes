Key concept

The Subtotal Measure: Removing the Layout Filter by Sort Order

Concept: Subtotal = VAR s = MAX(Layout[SortOrder]) RETURN CALCULATE([Actual Signed], REMOVEFILTERS(Layout), Layout[SortOrder] < s, Layout[Type] = "Account")

Statement

Subtotal =
VAR s = MAX ( Layout[SortOrder] )
RETURN
    CALCULATE (
        [Actual Signed],
        REMOVEFILTERS ( Layout ),
        Layout[SortOrder] < s,
        Layout[Type] = "Account"
    )

\[ \text{Subtotal}(s) = \sum_{\ell \,:\, \text{Type}_{\ell} = \text{Account},\ \text{SortOrder}_{\ell} < s} \text{ActualSigned}_{\ell} \]

where \(s\) is the sort order of the subtotal row being evaluated and \(\ell\) ranges over account lines of the layout.

Explanation

On a subtotal row (say Gross Profit, SortOrder 40) the filter context contains Layout[LineID] = "PL040". No CoA account maps to that line, so any measure evaluated as-is returns blank. The subtotal measure:

  1. Captures the row's position in a variable (s = 40) before changing the context — MAX is evaluated in the original filter context.
  2. Removes all Layout filters (REMOVEFILTERS(Layout)) — the subtotal line, its label and its sort order are no longer filtering.
  3. Applies a new Layout filter: account lines whose sort order is below 40. These lines have CoA accounts, which carry the filter through to GL.
  4. Evaluates [Actual Signed] in that context, with all non-Layout filters (Date, Branch, Scenario) unchanged.

Because the convention is profit-signed (income positive, expenses negative), the sum of everything above is the profit measure at that point: Gross Profit, then EBITDA, EBIT, PBT, PAT as sort order increases.

Requirements and refinements:

  • REMOVEFILTERS(Layout) is essential. Without it, the boolean filter Layout[SortOrder] < s replaces only the filter on SortOrder; the filter on Layout[Line] or LineID from the matrix row stays, intersects, and leaves no accounts — the topic's "blank subtotal" pitfall.
  • Variable before CALCULATE. Writing Layout[SortOrder] < MAX(Layout[SortOrder]) inline also evaluates MAX in the outer context, but the variable makes intent explicit and avoids confusion.
  • Non-cumulative subtotals ("Total expenses") need explicit range columns (s02).
  • Memo lines must not be of type Account, or they are double-counted.
  • Budget and PY reuse it by swapping the inner measure, or through a calculation group applied to [PnL].

Illustration

YTD December FY26 (₹ crore), sort orders from the s01 layout:

Subtotal row s Account lines included Value
Gross Profit 40 10, 20, 30 480.0 − 268.0 + 6.0 = 218.0
EBITDA 70 10–60 218.0 − 62.0 − 74.0 = 82.0
EBIT 90 10–80 82.0 − 21.0 = 61.0
PBT 120 10–110 61.0 + 7.0 − 13.0 = 55.0
PAT 140 10–130 55.0 − 14.0 = 41.0

Inserting "Exceptional items" (−9.0) at sort order 115 changes PBT to 46.0 and PAT to 32.0 with no DAX change, while EBIT stays 61.0.

Connections

Detailed in s02 (CoA mapping, range subtotals); called by the dispatcher (c01) and by the margin measure (c04) through the referenced numerator line. REMOVEFILTERS and boolean filter semantics come from Topic 3 (s02, s04). The pitfall of blank subtotal rows and the pitfall of hard-coded LineIDs are both avoided by this pattern.

Practice Questions

Q1. Missing REMOVEFILTERS [L1]

Explain, in terms of the filters on the matrix row, why CALCULATE([Actual Signed], Layout[SortOrder] < s, Layout[Type] = "Account") returns blank on the EBITDA row, and show the corrected measure.

Q2. Subtotals by quarter [L2]

Quarterly profit-signed values for FY26 (₹ crore) — Revenue Q1 150, Q2 158, Q3 172; Materials −84, −88, −96; Changes in inventories 2, 1, 3; Employee −20, −20, −22; Other expenses −23, −24, −27; D&A −6.5, −6.5, −8. Compute Gross Profit, EBITDA and EBIT for each quarter and YTD, and confirm that the YTD column equals the sum of the quarters for subtotals.

💡 Hint: Subtotals are additive over time even though margin rows are not.

Q3. Range or cumulative [L2]

For a Schedule III layout, decide for each of these rows whether the cumulative Subtotal or a range subtotal is correct, and specify SubtotalFrom/SubtotalTo where needed: Total income, Total expenses, Profit before exceptional items and tax, Profit before tax, Profit for the period, Total comprehensive income.
