Key concept

Selected FY Measure for Dynamic Titles

Concept: Selected FY = SELECTEDVALUE('Date'[FY], "All years") for dynamic titles via fx: "P&L – " & [Selected FY]

Statement

Selected FY = SELECTEDVALUE ( 'Date'[FY], "All years" )

PnL Title = "P&L – " & [Selected FY]

SELECTEDVALUE(column, alternate) returns the single value of column if exactly one distinct value is visible in the current filter context; otherwise it returns alternate (BLANK if omitted). It is shorthand for IF(HASONEVALUE(column), VALUES(column), alternate).

The title measure is bound via fx next to Title text (Format visual > General > Title > Text > fx > Format style: Field value > [PnL Title]).

Explanation

Static titles ("P&L FY2025-26") go stale and do not reflect slicers. A dynamic title states the context the user is looking at — a basic control for an executive pack, especially for exported PDFs, where slicers may not be visible.

Behaviour to understand:

  • No selection or multiple FYs. With nothing selected (or two years), the Date table has several FY values, so the alternate "All years" is returned. For a pack where measures assume one FY, "All years" doubles as a warning.
  • Context from the visual. In a title, the measure evaluates in the visual's filter context excluding its own row/column members — i.e. slicers, page/report filters and cross-filters. In a table row, it evaluates per row.
  • Multiple selections listed. For a richer title, use CONCATENATEX(VALUES('Date'[FY]), 'Date'[FY], ", "), capped by COUNTROWS to avoid very long strings.
  • Fiscal months. Combine with a month: SELECTEDVALUE('Date'[MonthName], "Full year"), and with a YTD flag.
  • BU and Region. SELECTEDVALUE(BU[BusinessUnit], "All BUs"), combined with ISFILTERED (Concept c04) to distinguish "no filter" from "several selected".

Dynamic titles also serve buttons, card labels, alt text and tooltip headers — anywhere fx accepts a text measure.

Illustration

Page1 Title =
VAR fy  = [Selected FY]
VAR bu  = IF ( ISFILTERED ( BU[BusinessUnit] ),
               CONCATENATEX ( VALUES ( BU[BusinessUnit] ), BU[BusinessUnit], ", " ),
               "All BUs" )
VAR mth = SELECTEDVALUE ( 'Date'[MonthName], "YTD" )
RETURN "P&L – " & fy & " · " & mth & " · " & bu
Slicer state Title shown
FY2025-26, Oct, no BU filter P&L – FY2025-26 · Oct · All BUs
FY2025-26, no month, Agro + Pharma P&L – FY2025-26 · YTD · Agro, Pharma Intermediates
No FY selected P&L – All years · YTD · All BUs

Practice Questions

Q1. Write the Page 2 title [L1]

Write a title measure for Page 2 reading "Balance Sheet as at 31-Oct-2025 – FY2025-26", using the last date in the selected period.

Q2. HASONEVALUE equivalence [L2]

Rewrite [Selected FY] without SELECTEDVALUE and explain the difference between HASONEVALUE and ISFILTERED in this context, with an example where they give different answers.

💡 Hint: Consider a report filter that leaves exactly one FY without any slicer selection.

Q3. Warning title [L2]

Design a title measure that shows "⚠ Select a single FY" in red when more than one FY is in context, and the normal title otherwise. Explain how you would colour only the warning case.
