Key concept

Slicer-Responsive Vendor Ranking with RANKX and ALLSELECTED

Concept: Vendor Rank = RANKX(ALLSELECTED(Vendor[Name]), [Expense], , DESC) for slicer-responsive Top N

Statement

Vendor Rank =
RANKX ( ALLSELECTED ( Vendor[Name] ), [Expense], , DESC )

RANKX(<table>, <expression>, [value], [order], [ties]):

  • <table> = ALLSELECTED(Vendor[Name]) — the vendors visible after slicers and outer filters, but ignoring the filter that the current visual row places on the vendor.
  • <expression> = [Expense], evaluated for each vendor in that table (context transition) and for the current row.
  • [value] omitted — the current row's [Expense] is used.
  • DESC — highest expense gets rank 1. [ties] default is SKIP (1, 2, 2, 4); DENSE gives 1, 2, 2, 3.

The Top N filter measure is

\[ \text{Show}_v = \begin{cases} 1 & \text{if } \text{Rank}_v \le N \\ 0 & \text{otherwise} \end{cases} \]

with \(N\) from a What-if parameter, applied as a visual-level filter "is 1".

Explanation

Why ALLSELECTED rather than ALL: ALL(Vendor[Name]) returns every vendor name and removes any filter on the Name column itself. Filters on other columns (BU, FY, Vendor[Category]) still apply when [Expense] is evaluated for each vendor, so out-of-scope vendors evaluate to blank and sink to the bottom — that part works. The problem arises when the user filters vendor names directly: a slicer that excludes inter-company vendors, a visual-level filter removing "One-time vendor", or a multi-select of a dozen vendors. ALL ignores those selections, so excluded vendors still occupy ranks and the visible list shows gaps (1, 3, 4, 7 …) and a Top 10 that contains fewer than ten bars. ALLSELECTED respects every filter coming from outside the visual (slicers, filter pane, cross-filters) and removes only the visual's own row-level vendor filter, so ranks restart within the user's scope: "top 10 non-group vendors of Pharma in FY2025-26, West".

Practical refinements:

  • Blank or zero spend. Vendors with no expense in scope get the bottom ranks (or tie); filter them out with IF(NOT ISBLANK([Expense]), RANKX(...)).
  • Totals. At the total row, ALLSELECTED and the current context are the same set; RANKX returns 1. Blank it with IF(ISINSCOPE(Vendor[Name]), ...).
  • Ties and determinism. Add a tiny tie-breaker: rank on [Expense] + DIVIDE(RANKX(ALLSELECTED(Vendor[Code]), ...), 1e9) or use the newer RANK window function with an ORDERBY on expense then vendor code.
  • Ranking a different grain. If the visual shows vendor within cost centre, ALLSELECTED of vendor alone ranks within each cost centre row context; decide whether that is intended.
  • Cross-filter behaviour. Clicking a BU in another visual cross-filters the vendor chart; ALLSELECTED treats that as an outer filter, so ranks recompute within the clicked BU.
  • Performance. RANKX iterates vendors per row: ~650 vendors × 650 rows is trivial; 2 lakh customers is not — pre-filter or use TOPN in a table expression.

Illustration

FY2025-26, BU = Polymers. Expense by vendor (₹ Cr): Gujarat Industries Power 8.94; Reliance Polymers 7.20; IOCL 6.85; Gujarat Gas 6.85; BASF India 4.10; others below 3.0.

Vendor Expense Rank (SKIP) Rank (DENSE)
Gujarat Industries Power 8.94 1 1
Reliance Polymers 7.20 2 2
IOCL 6.85 3 3
Gujarat Gas 6.85 3 3
BASF India 4.10 5 4

With N = 4 from the slider, SKIP shows four vendors (BASF is rank 5), whereas DENSE would show five because BASF becomes rank 4 — choose the tie rule deliberately. Changing BU to Agro recomputes all ranks within Agro.

Practice Questions

Q1. ALL vs ALLSELECTED [L1]

A visual-level filter on the vendor chart excludes three inter-company vendors whose spend would rank 2nd, 5th and 6th. Explain what ranks the visible vendors receive with ALL(Vendor[Name]) compared with ALLSELECTED(Vendor[Name]), and what a "Top 10" filter would then show in each case.

Q2. Top N with a slider [L2]

Write the What-if parameter, the rank measure (blank-safe and total-safe) and the visual filter measure for a vendor chart showing the top N vendors (N = 5 to 25, default 10).

💡 Hint: The What-if parameter creates both a table and a value measure.

Q3. Ranking cost centres within BU [L3]

A matrix has BU on rows and cost centres nested below. The CFO wants ranks of cost centres within each BU and a separate rank across all cost centres in the selection. Write both measures and explain the difference in their table arguments.
