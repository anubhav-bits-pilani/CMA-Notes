Bookmarks, Buttons and the Selection Pane for View Toggles

Scope: Bookmarks, buttons and the selection pane for view toggles (Actual vs Budget, ₹ vs %)

Why it matters

CFOs want to flip views without hunting for options: "show me this against budget", "now as % of revenue", "monthly or YTD". Building a separate page for every view multiplies maintenance. Bookmarks capture the state of a page — which visuals are visible, which filters apply — and buttons trigger them, so one page can hold two or three alternative views. The selection pane is the tool that controls visibility and layering. Done well, toggles feel like an app; done badly, they reset the user's FY slicer every time they click.

Core notes

The selection pane

View > Selection lists every object on the page (visuals, shapes, buttons, text boxes) with:

  • Eye icon — show/hide the object. Hidden objects are not rendered (and not queried).
  • Layer order — drag to reorder; higher items sit on top.
  • Groups — select objects, right-click > Group. Groups can be shown or hidden together, which makes a view ("Actual vs Budget group", "% of revenue group") a single unit.
  • Tab order tab — keyboard navigation order (accessibility).

Name objects meaningfully ("Matrix – ₹", "Matrix – %") so bookmarks are understandable later.

Bookmarks

View > Bookmarks > Add captures the current page state. Each bookmark's options (… menu) decide what it stores:

Option Captures Use in toggles
Data Filters, slicer selections, sort order, drill location, cross-filter selections Usually off for view toggles, so the user's FY/BU selection survives
Display Visibility (selection pane state), spotlight, focus mode On — this is the toggle
Current page Navigates to the bookmarked page On for page-navigation bookmarks; for in-page toggles either works
All visuals / Selected visuals Scope of the capture Selected visuals lets a bookmark affect only the toggled group, leaving everything else untouched

The key configuration for a view toggle: Data off, Display on, Selected visuals (select both groups before updating the bookmark). With Data on, clicking "Show ₹" would also restore the FY that was selected when the bookmark was created — a frequent bug where the pack "jumps back" to last year.

Building an Actual vs Budget / ₹ vs % toggle

  1. Build two matrices on the same spot: Matrix A shows Actual, Budget, Var (₹); Matrix B shows Actual % of revenue, Budget %, Var pp.
  2. In the selection pane, group each with its title text box: "View ₹" and "View %".
  3. Hide "View %" → add bookmark "BM ₹"; hide "View ₹" and show "View %" → add bookmark "BM %". For both, set Data off, Display on, Selected visuals (with both groups selected).
  4. Insert two buttons (or a bookmark navigator, Insert > Buttons > Navigator > Bookmark navigator, which builds a button per bookmark in a bookmark group). Action type = Bookmark, Bookmark = BM ₹ / BM %.
  5. Style the selected state: bookmark navigators highlight the active bookmark automatically; for manual buttons, duplicate buttons with "selected" formatting inside each view group.

Alternatives to bookmarks for toggles

  • Field parameters (s07) switch measures or dimensions inside a single visual — no duplicate visuals, no bookmarks. Best when only the measure changes and formatting is similar.
  • Calculation groups switch time intelligence (MTD/QTD/YTD) or units for all measures via a slicer.
  • Disconnected "View" table + SWITCH measure with a button slicer.

Bookmarks remain the best option when the layout itself changes (different visual types, different columns, explanatory text), or for "Reset filters" and story-telling sequences.

Other button uses in a pack

  • Page navigation: Action = Page navigation, Destination = page; or the page navigator (auto-builds buttons for all visible pages).
  • Reset filters: a bookmark with Data on, capturing default slicers (e.g. Current FY, all BUs).
  • Drill-through (s04) and Back buttons.
  • Q&A, Web URL (link to the SharePoint folder of source files or the user guide).

In Desktop, buttons require Ctrl+click; in the Service, a single click.

Illustration

Page 1's P&L matrix area holds two groups: "View ₹" (Actual, Budget, Var ₹ Cr, Var %) and "View %" (each line as % of revenue: e.g. Material cost 54.7% actual vs 55.2% budget, Var +0.5 pp favourable). A bookmark navigator with "₹ crore" and "% of revenue" sits above the matrix. A third bookmark "Reset" (Data on, all visuals) returns slicers to Current FY, all BUs, all regions.

Edge cases & judgement calls

  • Updating bookmarks. After editing a visual, existing bookmarks still reference it, but newly added visuals are not in "Selected visuals" bookmarks; update each bookmark (… > Update) after layout changes.
  • Hidden visuals and performance. Hidden objects are not queried, so two hidden-shown matrices cost no more than one at render time.
  • Personal bookmarks in the Service let users save their own views; they are separate from report bookmarks.
  • Bookmarks and drill-through pages. A bookmark with Current page on that points to a drill-through page opens it without drill context — avoid.
  • Mobile layout supports bookmark buttons, but overlapping groups must be positioned on the mobile canvas too.
  • Exports. PDF/PowerPoint export captures the current state of each page; document which toggle state the board pack should be exported in.

Key takeaways

  • The selection pane controls visibility, grouping and layering; bookmarks capture that state.
  • For view toggles, set Data off, Display on and Selected visuals, so slicers are preserved.
  • Use bookmark navigators for clean toggle buttons with an automatic selected state.
  • Prefer field parameters or calculation groups when only the measure changes.
  • Re-update bookmarks after layout changes and test in the Service.

Practice Questions

Q1. Bookmark settings [L1]

For each bookmark — "View ₹", "View %", "Reset filters", "Go to Expenses" — state the Data, Display, Current page and All/Selected visuals settings and why.

Q2. Pack jumps to last year [L2]

Users report that clicking the "% view" button on Page 1 changes the FY from FY2025-26 to FY2024-25. Diagnose the cause and give the exact fix.

💡 Hint: Think about what the bookmark captured when it was created.

Q3. Monthly vs YTD toggle design [L2]

Compare implementing a Month/YTD toggle across five KPI cards, the P&L matrix and the waterfall using (a) bookmarks with duplicate visuals, (b) a calculation group with a slicer, (c) field parameters. Recommend one for the Project 3 pack.

Q4. Story-telling sequence [L3]

Design a bookmark sequence for a monthly CFO review meeting (five steps from headline to vouchers), including which bookmarks capture data, which navigate pages, and how you would prevent the sequence from overriding the meeting's chosen FY and BU.
