Subtopic note

FY, BU and Region Slicers: Hierarchy, Relative Date and Sync

Scope: Slicers for FY, Business Unit and Region: hierarchy slicer, relative date slicer, Sync slicers across pages

Why it matters

Every question a CFO asks of the pack is scoped: "this year", "Pharma only", "West region". Slicers carry that scope across the report. Badly designed slicers are the biggest source of "the numbers don't match" complaints — Page 1 showing FY2025-26 while Page 3 still shows FY2024-25, or a BU slicer that filters actuals but not budget. Three slicer techniques matter for a finance pack: hierarchy slicers (FY → Quarter → Month, or Region → BU), relative date slicers (last N months), and synced slicers across pages.

Core notes

Slicer fundamentals for finance

  • Slice on dimensions. FY, Quarter and Month come from 'Date'; Business Unit from BU[BusinessUnit]; Region from Region[Region] (or a column on BU if region is an attribute of the BU). Never slice on GL[BU] — a fact column filters only that fact, so Budget and TB are not filtered (Topic pitfall).
  • Selection mode. Single select for FY (most measures assume one year); multi-select with Select all for BU and Region. Ctrl+click multi-select is the default for list slicers.
  • Style. Dropdown style saves space in the title band; Tile (button) style is quicker for 3–5 BUs. Newer slicer visuals (button and list slicers) have been introduced in recent releases with richer formatting — check availability in your Desktop version before standardising on them.
  • Default selection that does not go stale. If you save the report with FY2025-26 selected, it stays selected after April 2026. Add a dynamic label column to the Date table:
FY Label =
VAR Cur = IF ( MONTH ( TODAY () ) >= 4, YEAR ( TODAY () ) + 1, YEAR ( TODAY () ) )
RETURN IF ( 'Date'[FYEnd] = Cur, "Current FY", 'Date'[FY] )

Saving the slicer on "Current FY" keeps the default moving each April. Because calculated columns are evaluated at refresh, the label updates on the first refresh after 1 April (TODAY() in the Service is UTC-based, which matters only near midnight IST).

Hierarchy slicer

Dragging several fields into the slicer's Field well (e.g. 'Date'[FY], 'Date'[FiscalQuarter], 'Date'[MonthName]) creates a hierarchy slicer with expand/collapse arrows. Selecting a parent selects all its children; you can tick individual months under a quarter. Finance uses:

Hierarchy Use
FY → Quarter → Month Period selection on one control
Region → BU Geographic roll-up when a BU sits in one region
Statement → FS Line Rarely; better as a matrix drill-down (s03)

Design points: sort months by FiscalMonthNo so April appears first; switch off Show Select all for FY to force a choice; and remember that a multi-month selection under a hierarchy means "sum of months" for flow measures but "last month selected" for closing-balance measures (Week 11 semi-additive logic).

Relative date slicer

Set a slicer on 'Date'[Date] to style Relative Date (or use a relative date filter in the Filters pane): Last / Next / This, a number, and a unit (days, weeks, months, years; calendar variants align to whole periods). Example: "Last 12 calendar months" for a trend page. Finance caveats:

  • Calendar, not fiscal. "This year" means January–December. For fiscal windows, use the Week 11 MonthOffset or an FYOffset column: filter FYOffset = 0 for current FY, MonthOffset between −11 and 0 for the trailing 12 months.
  • Today vs last close. Relative windows are anchored on today, not on the last closed month. On 5 May, "last 1 calendar month" is April — which may not be closed yet. A CloseOffset column computed against [Last Actual Date] (or a parameter) aligns windows to the close.
  • Time zone. The Service evaluates "today" with a UTC basis in many contexts; test around midnight IST if the window boundary matters.

Sync slicers across pages

View > Sync slicers opens a pane listing every page with two checkboxes per slicer:

  • Sync — this page's copy of the slicer shares the selection.
  • Visible — the slicer is shown on that page (it can sync while hidden, filtering the page invisibly).

Copying a slicer to another page prompts "Sync visuals?"; answer Sync to link it. Advanced options assigns a group name: slicers with the same group name stay in sync, and options control whether field changes and filter changes propagate. For the Project 3 pack: FY, BU and Region slicers synced and visible on Pages 1–3; synced but hidden on the drill-through GL Detail page and on tooltip pages (they receive context anyway); the Controls page synced for FY only, so control checks can still be viewed for all BUs.

An alternative to synced slicers is a report-level filter (s08) — but users cannot see or change report filters as easily, so for FY/BU/Region, visible synced slicers are better.

Edge cases & judgement calls

  • Slicer on a field used in drill-through. If BU is a drill-through field, the drill-through page receives BU from the source visual; a synced BU slicer on that page may conflict — keep it synced, hidden.
  • Bookmarks capture slicer state. A bookmark with "Data" checked overwrites slicer selections; for view toggles, uncheck Data (s06).
  • Hierarchy slicer and single select. Single select applies to the leaf level; users may still select a whole FY by clicking the parent depending on settings — test.
  • Region–BU many-to-many. If a BU operates in several regions, Region must be a dimension related to the facts (GL carries RegionKey), not a BU attribute.
  • RLS interaction. With BU-level RLS, a BU head sees only permitted BUs in the slicer; do not hard-code a BU default that some users cannot see.

Key takeaways

  • Slice only on dimension columns so every fact (Actual, Budget, TB) responds.
  • Use a hierarchy slicer for FY → Quarter → Month, with fiscal sort order.
  • Relative date slicers are calendar-based; use fiscal offset columns for fiscal windows.
  • Sync FY/BU/Region across pages, visible where useful, hidden on drill-through and tooltip pages.
  • Save defaults on a dynamic "Current FY" label so the pack does not go stale.

The pack has pages Overview, Balance Sheet, Expenses, GL Detail (drill-through), Vendor Tooltip and Controls. Draw the Sync slicers matrix (Sync/Visible) for FY, BU and Region slicers and justify each hidden-but-synced choice.

Q2. Fiscal relative window [L2]

On 10 November 2025 the CFO wants a trend page that always shows the last 12 closed months (actuals are closed to 31 October). Explain why a relative date slicer "Last 12 calendar months" is wrong and write the calculated column and filter you would use instead.

💡 Hint: Anchor the offset on the last actual date rather than TODAY().

Q3. Stale default [L2]

A report saved in March 2026 with FY2025-26 selected opens in May 2026 showing FY2025-26. Write the DAX for a "Current FY" label column, explain when it updates, and describe one risk of the approach.

Q4. Budget does not move [L2]

Selecting "Pharma" on a BU slicer changes Actual on all visuals but Budget stays at the company total. List two model or slicer causes and the fix for each.
