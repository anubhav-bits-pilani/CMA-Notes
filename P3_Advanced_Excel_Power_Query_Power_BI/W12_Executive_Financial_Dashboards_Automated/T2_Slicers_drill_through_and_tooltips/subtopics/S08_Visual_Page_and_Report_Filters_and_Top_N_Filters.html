Subtopic note

Visual, Page and Report Filters, and Top N Filters

Scope: Visual, page and report-level filters, and Top N filters

Why it matters

Slicers are the visible filters; the Filters pane holds the structural ones — "only P&L accounts on this page", "exclude inter-company eliminations from the whole report", "top 10 vendors only". Misplaced filters are a quiet source of wrong numbers: a visual-level filter hiding a ledger that the card includes, or a report filter that excludes a BU nobody remembers. Top N filters are the standard way to show "top vendors" or "top cost centres", and they interact with slicers in ways that matter for a CFO pack.

Core notes

The three filter levels

The Filters pane has three sections, applied in combination (logical AND) with slicers and cross-filters:

Level Scope Finance examples
Visual One visual Exclude "Inter-company" from the vendor bar; show only FSLines in EBITDA on the waterfall-adjacent table
Page All visuals on one page Page 2 filtered to CoA[Statement] = "Balance Sheet"; Page 3 to expense lines
Report All pages Entity = "Sahyadri Chemicals Ltd (standalone)"; exclude VoucherType = "Year-end closing"

Drill-through fields appear as a fourth section on drill-through pages.

Filter types available per field: Basic (tick list), Advanced (contains, starts with, is blank, greater than, with AND/OR), Top N, and Relative date for date fields. Measures can be used in visual-level filters only (e.g. [Expense] is greater than 0), because a measure needs the visual's grain.

Filter pane governance

  • Lock a filter (padlock icon) so report consumers cannot change it; hide it (eye icon) so they cannot see it. Structural filters (entity, statement type) are usually locked and visible, or hidden with documentation.
  • Rename filter cards ("Showing: P&L lines only") for clarity.
  • Format the Filters pane (Format page > Filter pane) or hide it entirely from consumers (eye icon on the pane header in Desktop; Service users then see only slicers).
  • Require single selection on a filter card forces exactly one value, useful for FY on a page that assumes one year.
  • Document every hidden filter in the measure/control documentation — hidden report filters are a review risk.

Top N filters

A Top N filter on a field: Show items Top/Bottom N by value where the value is a measure. Example: on the vendor bar chart, Vendor[Name], Top 10 by [Expense].

How it evaluates: the ranking is computed in the context of slicers and page/report filters and (in current behaviour) before the visual's other filters are applied, using the "by value" measure. Consequences:

  • Changing the BU slicer re-ranks vendors within the BU — correct.
  • A visual-level filter on another field may or may not be applied before ranking; test it.
  • N is static in the filter card. For a user-selectable N, use a What-if parameter (Modeling > New parameter > Numeric range) and a rank measure (Concept c05):
Vendor Rank = RANKX ( ALLSELECTED ( Vendor[Name] ), [Expense], , DESC )

Show Vendor =
IF ( [Vendor Rank] <= SELECTEDVALUE ( 'Top N'[Top N Value], 10 ), 1, 0 )

Apply [Show Vendor] is 1 as a visual-level filter. An "Others" bucket requires a separate disconnected category table or a calculated "Others" row pattern, because Top N filters simply drop the rest — totals in a table visual then show only the top N sum, not the grand total.

Totals under Top N

A table with Top 10 vendors and a total row shows the total of the ten vendors. If users compare it with the expense card (all vendors), they see a mismatch. Fix by labelling ("Top 10 total") or by adding an "All other vendors" line, and show "Top 10 = 62% of spend" in the title.

Order of evaluation, summarised

  1. Report filters, page filters, slicers (with sync), drill-through filters and cross-filters define the context.
  2. Visual-level filters (including Top N) restrict the visual's rows.
  3. Measures evaluate per cell within that context; ALLSELECTED sees the context after slicers and outer filters.

Illustration

Page 3, FY2025-26, Polymers: vendor bar with Top 10 by [Expense] shows ₹62.4 Cr of total vendor expense ₹101.3 Cr (61.6%). Report filter excludes VoucherType = "Year-end closing" (locked, visible as "Excludes closing entries"); page filter CoA[Statement] = "Profit and Loss" and CoA[FSLineGroup] = "Expenses" (locked, hidden, documented). A visual-level filter on the vendor bar excludes Vendor[IsIntercompany] = TRUE.

Edge cases & judgement calls

  • Ties in Top N. If the tenth and eleventh vendors have equal spend, Top 10 may show 11 items; rank measures with a tie-breaker (e.g. add vendor code) give deterministic results.
  • Filters on fact columns. A page filter on GL[BU] filters Actual but not Budget — same pitfall as slicers.
  • Hidden report filters and RLS confusion. A hidden report filter excluding one BU looks like an RLS issue to users; audit hidden filters before go-live.
  • Measure filters with blanks. "is not blank" on a measure removes zero-activity rows; useful for voucher tables, but it can hide accounts that should show zero.
  • Persistent filters. In the Service, users' filter changes persist by default ("Persistent filters"); a user may see a stale filter next month. Provide a "Reset to default" button, or disable persistent filters in report settings.

Key takeaways

  • Visual, page and report filters apply with AND logic on top of slicers and cross-filters.
  • Lock, hide, rename and document structural filters; avoid surprise hidden filters.
  • Top N filters rank by a measure within the current context; N is static unless a parameter and rank measure are used.
  • Top N tables total only the shown items; label or add an "Others" line.
  • Filter on dimension columns, and decide on persistent filters for Service users.

Practice Questions

Q1. Place the filters [L1]

For the Project 3 pack, decide the level (visual, page or report), lock/hide status and wording for: standalone entity only; exclude year-end closing vouchers; Page 2 balance sheet lines only; vendor chart excludes inter-company vendors.

Q2. Dynamic Top N with Others [L2]

Write measures and describe model objects so that the vendor bar shows the top N vendors (N from a What-if slider, 5–25) plus a final bar "All other vendors" whose value makes the chart total equal total vendor expense.

💡 Hint: The "Others" label must exist as a row in some table the axis can use.

Q3. Mismatched totals [L2]

A table shows Top 15 cost centres with a total of ₹188.2 Cr while the opex card shows ₹261.6 Cr for the same slicers. Explain both numbers and how you would present them to avoid a CFO query.

Q4. Persistent filters incident [L3]

In May 2026, a BU head says the pack "shows no budget for April". Investigation shows a filter he set in March on 'Date'[Month] persisted. Write an incident note covering root cause, immediate fix, report settings changes and user guidance.
