Subtopic note

Drill-Down vs Drill-Through: P&L Hierarchy and Voucher Detail

Scope: Drill-down vs drill-through: a matrix hierarchy (Statement → FS Line → Ledger) vs a voucher-detail page

Why it matters

The CFO sees "Other expenses ₹4.2 Cr over budget" and asks "what is in it?". There are two ways to answer in Power BI. Drill-down expands the same visual to a lower level of a hierarchy — FS line to ledger — keeping the user on the page. Drill-through jumps to a different page filtered to the clicked item — typically a voucher-detail page listing the GL lines. A finance pack needs both: drill-down for analysis by line and ledger, drill-through for evidence at voucher level. Auditors, internal audit and forensic reviewers (Weeks 5–8) rely on that last step.

Core notes

Drill-down in a matrix

Place a hierarchy on the matrix Rows well: CoA[Statement] → CoA[FSLine] → CoA[Ledger] (and optionally CoA[AccountCode]). The matrix then supports:

Control Effect
+/− row icons (Format > Row headers > +/- icons) Expand/collapse individual members inline (stepped layout)
Drill mode (down arrow icon) Clicking a member drills into that member only
Go to next level (double down-arrow) Shows all members at the next level, without parent grouping
Expand all down one level (forked arrow) Shows next level nested under all parents
Drill up (up arrow) Returns one level

For a P&L, Expand all down one level with stepped layout is the natural view: Statement subtotals, FS lines, then ledgers under each FS line, with subtotals controlled per level (Format > Row subtotals > per row level). The Week 11 P&L layout measure uses ISINSCOPE to return the right logic at each level, e.g.:

PnL Drill =
IF (
    ISINSCOPE ( CoA[Statement] ),   -- TRUE at Statement, FS Line and Ledger levels
    [Actual Signed]                 -- signed so subtotals net income and expense
)                                   -- BLANK at grand total: P&L and BS must not be added

Drill-down keeps context, totals and variance columns; it is the analysis path. It stops at the lowest hierarchy level in the dimension — it cannot show individual vouchers unless you add voucher number to the hierarchy, which explodes the matrix.

Drill-through to a voucher-detail page

A drill-through page is a separate, usually hidden, page whose Drill through well contains one or more fields (e.g. CoA[Ledger]). Any visual in the report that uses that field gets a right-click Drill through > GL Detail option. The target page opens filtered to the clicked ledger plus (with Keep all filters, s04) the source's slicers and cross-filters: FY, month, BU, region. The page shows a table of GL[VoucherNo], GL[Date], GL[VoucherType], GL[Narration], Vendor[Name], CostCentre[Name] and GL[Amount] (Concept c01), plus a header card showing the ledger, the period and the total, which must equal the number clicked.

Choosing between them

Aspect Drill-down Drill-through
Where Same visual Different page
Levels Hierarchy levels of a dimension Any detail, including fact rows
Context carried Visual's own context Drill-through fields plus (optionally) all filters
Typical depth Statement → FS line → Ledger Ledger → vouchers
User action Click arrows / +/− Right-click > Drill through, or a button
Performance Aggregated queries Row-level detail; must be filtered

The two combine: drill down in the P&L matrix to the ledger "Power & fuel – Plant 2 electricity", then right-click it and drill through to the GL Detail page.

Building the path from a variance line

To drill from an EBITDA variance to vouchers, the source visual must contain the drill-through field. A matrix row "Power and fuel" (FSLine level) can drill through if CoA[FSLine] is also a drill-through field on the target, or if the target accepts CoA[Ledger] and the user first drills down to ledger. Adding both FSLine and Ledger as drill-through fields lets the target accept either; a field missing from the source simply is not filtered.

Illustration

October 2025 YTD, Performance Polymers, P&L matrix: Other expenses ₹31.4 Cr vs budget ₹28.7 Cr. Expanding shows ledgers: Power and fuel ₹14.9 Cr (budget ₹12.6 Cr), Stores and spares ₹6.2 Cr, Repairs ₹5.8 Cr, others ₹4.5 Cr. Right-click "Power and fuel" → GL Detail: 46 vouchers, including a ₹1.18 Cr MSEDCL bill for September posted on 3 October and a ₹0.62 Cr diesel purchase for a DG set during a grid outage. The header card total ₹14.9 Cr ties to the matrix cell.

Edge cases & judgement calls

  • Ragged hierarchies. Some FS lines have a single ledger with the same name; the drill level repeats the label. Hide duplicate levels with ISINSCOPE logic or flatten in the CoA.
  • Sign display. Drill-down rows use [Actual Signed]; the voucher page shows raw Dr/Cr amounts. Show both a signed amount and Dr/Cr columns, or explain the sign convention in the page header.
  • Drill-down on Date. Auto date/time hierarchies on dates are calendar-based; disable auto date/time and use the fiscal hierarchy from the Date table.
  • Users who do not discover right-click. Add a "View vouchers" button that is enabled when a single ledger is selected (a drill-through button with a destination page).
  • Matrix exports. Exporting a drilled matrix exports the current level; for audit evidence, export from the voucher page.

Key takeaways

  • Drill-down navigates hierarchy levels inside the same matrix; drill-through jumps to a filtered detail page.
  • Use Statement → FS Line → Ledger as the matrix hierarchy, with ISINSCOPE-aware measures.
  • Use a hidden GL Detail page for voucher-level evidence, with ledger (and FS line) as drill-through fields.
  • The detail page total must tie to the clicked number.
  • Combine both: drill down to ledger, then drill through to vouchers.

Practice Questions

Q1. Matrix controls [L1]

Explain the difference between "Go to next level" and "Expand all down one level" on a matrix with rows Statement → FS Line → Ledger, and state which you would use for a board P&L and why.

Q2. Drill path design [L2]

A user wants to right-click the "Employee benefits" FS line on Page 1 and land on vouchers. The GL Detail page has only CoA[Ledger] in the Drill through well. Explain what happens today and two ways to make the path work.

Q3. Tie-out on the detail page [L2]

The GL Detail page shows a voucher total of ₹15.3 Cr for Power and fuel while the matrix cell showed ₹14.9 Cr. List four possible causes involving filters, signs or dates, and how you would confirm each.

💡 Hint: Compare what context the source visual had with what the target received.

Q4. Forensic drill [L3]

Internal audit wants to review all vouchers above ₹10 lakh posted on Sundays or after 10 pm in the last quarter, starting from any expense ledger in the P&L. Design the drill-down/drill-through path, the detail page filters and any measures or calculated columns needed.
