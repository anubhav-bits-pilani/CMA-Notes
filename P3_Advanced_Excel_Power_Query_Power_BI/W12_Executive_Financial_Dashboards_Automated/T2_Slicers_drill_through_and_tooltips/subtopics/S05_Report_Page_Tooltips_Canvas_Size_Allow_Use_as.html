Subtopic note

Report Page Tooltips: Canvas Size, "Allow Use as Tooltip", Field Tooltips

Scope: Report page tooltips: tooltip canvas size, "Allow use as tooltip", field-specific tooltips

Why it matters

Executive pages must stay uncluttered, yet the CFO hovering over a vendor bar or a month in the trend chart wants more than one number: actual vs budget, the variance, the top three ledgers, perhaps a mini trend. Report page tooltips deliver a small, fully designed page on hover — context without clicks, and without adding visuals to the main canvas. They are a cheap way to answer the "why?" behind a data point before committing to a drill-through.

Core notes

Default vs report page tooltips

Every visual has a default tooltip listing the fields in the visual plus any fields added to its Tooltips well. That is fine for "Revenue: ₹101.6 Cr" but cannot format, chart or compare. A report page tooltip is a hidden report page rendered in a small pop-up, filtered to the hovered data point.

Creating a tooltip page

  1. Add a page, name it "TT Vendor", hide it.
  2. Canvas settings (Format page > Canvas settings): Type = Tooltip, which sets 320 × 240 pixels. Custom sizes are allowed (e.g. 400 × 300) but keep it small: the tooltip must not cover the visual being explored. Set Page view > Actual size in Desktop while designing so you see the real scale.
  3. Page information > Allow use as tooltip = On. Only pages with this toggle appear in the tooltip page picker.
  4. Design: a title with the hovered item (SELECTEDVALUE(Vendor[Name])), two or three cards (Actual, Budget, Var), a small bar of top ledgers, or a sparkline-style column chart of 12 months.
  5. Set the page background and wallpaper deliberately; transparent backgrounds look broken over visuals.

Assigning tooltips to visuals

Two ways:

  • Manual assignment. Select the source visual > Format > General > Tooltips > Type = Report page, Page = "TT Vendor". The tooltip shows for every data point of that visual.
  • Field-specific (automatic) tooltips. On the tooltip page, drag fields to the Tooltip fields well ("Add tooltip fields here"), e.g. Vendor[Name]. Then any visual whose category uses Vendor[Name], with its tooltip page set to Auto, uses this page automatically. This is how one tooltip page serves the vendor bar, the vendor table and the decomposition tree.

The tooltip page receives the filter context of the hovered data point: the visual's category member(s), series, plus slicers and page filters of the source page. Measures on the tooltip page therefore compute for "this vendor, this BU, this FY".

What to put in finance tooltips

Source visual Tooltip content
Monthly trend combo Month Actual, Budget, PY, Var, Var %, YTD to that month
Vendor Top N bar Spend, budget (if vendor-budgeted), number of invoices, top 3 ledgers, MSME flag and payable days
EBITDA waterfall step Line description, Actual vs Budget, top 3 ledgers driving the step
Net Debt trend point Borrowings by lender, cash by bank, Net Debt / LTM EBITDA

Measures that behave on tooltip pages

Because the tooltip is filtered to one data point, SELECTEDVALUE works well for titles. Top-N lists inside the tooltip use TOPN or a visual-level Top N filter (s08). Example title:

TT Vendor Title =
SELECTEDVALUE ( Vendor[Name], "Multiple vendors" ) & " · " &
FORMAT ( [Expense] / 1e7, "#,##0.00" ) & " Cr"

Modern tooltips

Newer "modern" visual tooltips (Options > Report settings) add drill actions (drill down, drill through) inside the default tooltip. They do not replace report page tooltips but make drill-through discoverable from hover; check that they are enabled consistently.

Illustration

On Page 3, hovering "Gujarat Industries Power Co" in the Top 10 vendors bar (Polymers, FY2025-26) shows the TT Vendor page: spend ₹8.94 Cr vs PY ₹7.60 Cr (+17.6%), 31 invoices, top ledgers Power and fuel ₹8.71 Cr and Other repairs ₹0.23 Cr, average payable days 18. The CFO sees the power-cost driver without leaving the page.

Edge cases & judgement calls

  • Tooltip shows totals instead of the hovered item. The tooltip page's visuals use fields from a table not filtered by the hovered item (for example a disconnected table, or interactions disabled). Check the relationship path.
  • Multiple categories. If the source has month on the axis and BU as legend, the tooltip receives both; titles should handle both.
  • Mobile. Tooltips appear on tap-and-hold; dense tooltips are hard to read on phones.
  • Performance. Each hover runs the tooltip page's queries; heavy measures or large tables on a tooltip page make hovering sluggish.
  • Hidden page discoverability. Users cannot navigate to tooltip pages; make sure they are hidden and excluded from page navigators.
  • Accessibility. Keyboard users can trigger tooltips via focus, but screen readers may not read report page tooltip content well; do not put essential information only in tooltips.

Key takeaways

  • Report page tooltips are hidden, tooltip-sized pages filtered to the hovered data point.
  • Set canvas type Tooltip (320 × 240) and switch on "Allow use as tooltip".
  • Assign manually per visual, or use Tooltip fields for automatic field-specific tooltips.
  • Keep tooltip content small and fast: a title, two or three cards, one mini chart.
  • Never put information only in tooltips that must be in the printed pack.

Practice Questions

Q1. Build the trend tooltip [L1]

List the steps and measures to build a tooltip page for the monthly revenue combo chart that shows Actual, Budget, PY, Var %, and YTD Actual to the hovered month.

Q2. Automatic tooltip not appearing [L2]

A tooltip page has Vendor[Name] in Tooltip fields, but hovering the vendor table on Page 3 shows the default tooltip. The table uses GL[VendorName]. Explain why and how to fix it.

💡 Hint: Field-specific tooltips match on the exact column.

Q3. Waterfall step tooltip [L3]

Design a tooltip for the disconnected-table EBITDA waterfall that lists the top three ledgers behind the hovered step. Explain how the tooltip page can know which step is hovered and write the measure pattern.

Q4. Tooltip vs drill-through [L2]

For each of (a) vendor invoice count, (b) list of 46 power vouchers, (c) Net Debt by lender at a month-end, decide whether it belongs in a tooltip or a drill-through page, and justify.
