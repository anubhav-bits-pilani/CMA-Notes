Key concept

One-Click Excel Refresh Macro or Power Automate Flow

Concept: Excel one-click macro: ThisWorkbook.RefreshAll then Application.CalculateUntilAsyncQueriesDone; or a Power Automate flow

Statement

Sub RefreshPack()
    Dim t As Double
    t = Timer
    Application.ScreenUpdating = False
    ThisWorkbook.RefreshAll                      ' refresh every connection flagged for Refresh All
    Application.CalculateUntilAsyncQueriesDone   ' wait for asynchronous cube/OLAP queries to finish
    Application.CalculateFull                    ' recalculate checks that depend on refreshed values
    ThisWorkbook.Worksheets("Cover").Range("RefreshStamp").Value = Now
    Application.ScreenUpdating = True
    MsgBox "Pack refreshed in " & Format(Timer - t, "0") & " s. Status: " & _
           ThisWorkbook.Worksheets("Cover").Range("AllChecksFlag").Value
End Sub
  • ThisWorkbook.RefreshAll — same as Data > Refresh All: refreshes every connection with "Refresh this connection on Refresh All" ticked, plus PivotTables.
  • Application.CalculateUntilAsyncQueriesDone — runs calculation until all pending asynchronous OLAP data requests (CUBEVALUE, CUBEMEMBER, CUBESET) are completed.
  • The macro assumes background refresh is off for each query, so RefreshAll returns only when queries finish (s03).

Alternative: a Power Automate cloud flow — e.g. trigger "When a file is created in a folder" (SharePoint /GL/) → action "Refresh a dataset" (Power BI) → optionally notify the owner in Teams.

Explanation

Without the wait, VBA moves on immediately after starting the refresh: cube formulas may still show #GETTING_DATA, the "All checks OK" flag may read stale values, and a subsequent ExportAsFixedFormat to PDF captures placeholders. CalculateUntilAsyncQueriesDone closes that gap for cube functions; background refresh off closes it for Power Query.

Design notes:

  • Save as .xlsm; sign the macro or store in a trusted location so it runs on the CFO's machine.
  • Assign the macro to a button on the cover ("Refresh pack"). Show the stamp and the checks flag after refresh.
  • The Now stamp in Excel is the workbook refresh time (local PC clock, IST for Indian users); the model's own IST stamp (Topic 4 c05) shows when the Service model refreshed. Display both.
  • Error handling: wrap with On Error GoTo to report which connection failed, and restore ScreenUpdating.
  • Excel for the web does not run VBA; Office Scripts can call workbook.refreshAllDataConnections(), but support for refreshing Power Query and model connections in Excel for the web is limited — test before relying on it.

Power Automate options:

Goal Flow
Refresh the Service model when a branch file arrives SharePoint trigger "When a file is created (properties only)" in /GL/ → delay/condition (wait for all branches or a cut-off) → Power BI "Refresh a dataset"
Notify on failure Trigger on refresh failure is not native; poll refresh history via the Power BI REST API, or use data alerts on a "Checks Failing" tile → email/Teams
Refresh a desktop Excel pack unattended Power Automate Desktop: open workbook, run RefreshPack macro, save, close, upload to SharePoint

Flow-triggered refreshes count against the model's refresh limits (c02); debounce triggers so 14 branch files do not start 14 refreshes.

Illustration

A Kochi seafood exporter's board pack: 8 queries, 1 cube connection, 340 cube formulas. Clicking "Refresh pack" takes 52 seconds; the message box reads "Pack refreshed in 52 s. Status: All checks OK". Without CalculateUntilAsyncQueriesDone, a test run exported a PDF in which 37 cells showed #GETTING_DATA.

A Power Automate flow triggers when the last of 6 branch files lands (condition: count of files for the month = 6), calls "Refresh a dataset", and posts "Finance Pack refresh started – May 2026 files complete" to the Finance Teams channel.

Practice Questions

Q1. Extending the macro [L2]

Extend the macro so that after refreshing it exports the Cover, P&L and Balance Sheet sheets to a PDF named BoardPack_<yyyy-mm>.pdf in a folder, but only if the "All checks OK" flag is true; otherwise it shows the failing checks and stops.

💡 Hint: Read the flag cell after the async wait and branch before calling the export method.

Q2. Debouncing a flow [L2]

Fourteen branch files arrive between 04:30 and 05:45 IST. Design a Power Automate flow that refreshes the Power BI model once, after all files are present or at 06:00 at the latest, and notifies the owner if files are missing.

Q3. Interview: why not just Refresh All? [L1]

Explain to an interviewer why your pack uses a macro with CalculateUntilAsyncQueriesDone instead of telling the CFO to press Ctrl+Alt+F5.
