Key concept

SharePoint.Files for Gateway-Free Cloud Refresh

Concept: SharePoint.Files("https://tenant.sharepoint.com/sites/Finance", [ApiVersion=15]) refreshes in the cloud with no gateway, unlike local Folder.Files

Statement

let
    Source  = SharePoint.Files("https://tenant.sharepoint.com/sites/Finance", [ApiVersion = 15]),
    GLFiles = Table.SelectRows(
                Source,
                each Text.StartsWith([Folder Path],
                       "https://tenant.sharepoint.com/sites/Finance/Shared Documents/GL/")
                  and [Extension] = ".csv"
              )
in
    GLFiles
  • SharePoint.Files(siteUrl, options) — returns one row per file in all document libraries of the site, with Content (binary), Name, Extension, Date modified, Folder Path and other attributes.
  • siteUrl — the site URL (not the library or folder URL).
  • [ApiVersion = 15] — uses the SharePoint REST API version for SharePoint Online/2013+; the default UI-generated option.
  • Contrast: Folder.Files("C:\Users\...\OneDrive - Contoso\Finance\GL") reads a local or network path, which the Power BI Service cannot reach without an on-premises data gateway.

Explanation

Power BI Service runs in Microsoft's cloud. A local path (laptop drive, OneDrive sync folder, \\fileserver\finance) is invisible to it; the only way to refresh such a source is a gateway on a machine that can see the path. SharePoint Online is itself a cloud service, so the Service connects directly using OAuth2 credentials set in the semantic model's data source settings — no gateway, no always-on server.

Practical points:

  • OneDrive is SharePoint. OneDrive for Business folders live on a personal SharePoint site (https://tenant-my.sharepoint.com/personal/user_contoso_com). You can connect with SharePoint.Files to that URL, but personal OneDrive ties the pack to one employee; prefer a team site.
  • Performance. SharePoint.Files enumerates every file in the site before filtering, which is slow for large sites. SharePoint.Contents(siteUrl, [ApiVersion = 15]) navigates library → folder lazily and is usually faster for deep structures: e.g. SharePoint.Contents(SiteUrl){[Name = "Shared Documents"]}[Content]{[Name = "GL"]}[Content].
  • Filtering. Filter on Folder Path and Extension early; exclude temp files (names starting with ~$) and an /Archive/ folder.
  • Credentials. In the Service, set OAuth2 with an account that has read access to the library; if that user leaves, refresh fails. Use a dedicated service account where policy allows, or ensure ownership transfer.
  • Privacy level. Set to Organizational; combining with other sources at different levels can raise firewall errors.
  • Parameterise the site URL (s02) so Dev/Prod switching and templates work.
  • Switching an existing query from Folder.Files to SharePoint.Files: replace the source step and ensure the downstream column names match (Folder Path and Content exist in both; path formats differ — URLs with forward slashes vs Windows backslashes — so adjust any path-based filters).

Illustration

Before: Folder.Files("C:\Users\priya\OneDrive - Contoso\Finance\GL"). Desktop refresh works; after publishing, the Service shows "You can't schedule refresh for this semantic model because it contains a data source that requires a gateway". Options: install a gateway on Priya's laptop (fragile) or switch to SharePoint.Files("https://contoso.sharepoint.com/sites/Finance", [ApiVersion = 15]) with a folder-path filter. After switching, the scheduled 06:30 IST refresh runs in the cloud; the laptop can be off.

Practice Questions

Q1. Converting a local query [L1]

Rewrite a query that starts with Folder.Files("D:\Finance\GL\FY2025-26") and filters .csv files so that it reads the same files from the /GL/FY2025-26/ folder of the site https://contoso.sharepoint.com/sites/Finance. State the credential type you would set in the Service.

Q2. Slow enumeration [L2]

A Finance site holds 40,000 files across 25 libraries; the GL query using SharePoint.Files takes 9 minutes before filtering. Explain why and rewrite the source using SharePoint.Contents to navigate directly to the GL folder.

💡 Hint: Navigate by record lookup on [Name] through the library and folder levels.

Q3. Credential ownership [L2]

The analyst whose OAuth credentials were used for the SharePoint source has resigned and her account is disabled. Describe the symptom, the fix, and a governance rule to prevent recurrence.
