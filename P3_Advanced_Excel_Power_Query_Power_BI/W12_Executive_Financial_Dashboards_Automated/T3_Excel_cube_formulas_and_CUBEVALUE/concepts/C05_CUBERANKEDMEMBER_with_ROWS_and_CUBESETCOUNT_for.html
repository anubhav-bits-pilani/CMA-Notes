Key concept

CUBERANKEDMEMBER with ROWS() and CUBESETCOUNT for Ranked Lists

Concept: =CUBERANKEDMEMBER("ThisWorkbookDataModel", $B$2, ROWS($A$5:A5)) with =CUBESETCOUNT($B$2) to size the list

Statement

A5:  =CUBERANKEDMEMBER("ThisWorkbookDataModel", $B$2, ROWS($A$5:A5))
C2:  =CUBESETCOUNT($B$2)
  • B2 holds a CUBESET (Concept c04), absolute-referenced so every row points at the same set.
  • The ROWS argument is an expanding range — its first cell (A5) is fully anchored, its last cell is relative — so ROWS returns the count of rows from the first list row to the current one: 1 in row 5, 2 in row 6, …, n in row \(n + 4\). It is the rank to fetch.
  • CUBERANKEDMEMBER(connection, set, rank) returns the member at that position of the set; the cell displays its caption and can be used as a member argument in CUBEVALUE.
  • CUBESETCOUNT(set) returns the number of members \(k\) in the set.

The list is valid for ranks \(r\) with

\[ 1 \le r \le \min(N, k) \]

where \(N\) is the desired list length (Top N) and \(k\) the set size; beyond \(k\) CUBERANKEDMEMBER returns #N/A.

Explanation

The ROWS-based counter is preferred over typing 1, 2, 3 in a helper column because rows can be inserted or the block moved without renumbering, and preferred over ROW()-4 because it does not depend on the sheet position.

A complete, guarded list row (row-anchored references keep it fill-down safe):

A5:  =IF(ROWS(A$5:A5) > MIN(TopN, C$2), "", CUBERANKEDMEMBER(Conn, B$2, ROWS(A$5:A5)))
B5:  =IF(A5 = "", "", CUBEVALUE(Conn, MsrExpense, Slicer_BU, A5))
  • TopN is a named input (e.g. 10), C2 the CUBESETCOUNT, Conn the connection name cell.
  • The IF guard prevents #N/A when the set has fewer members than the pre-filled rows (a BU with only 6 vendors).
  • CUBESETCOUNT also feeds captions: ="Top " & MIN(TopN, C2) & " of " & C2 & " vendors".
  • The ranked member cells are live: after refresh, ranks change and the values beside them follow.
  • If the set is built with context (selected FY in the sort tuple), the list re-ranks when the selection cell changes.

Practice Questions

Q1. Trace the counter [L1]

For a list starting in row 12, state what the ROWS-based rank expression returns in rows 12, 15 and 30, and what happens if a row is inserted between rows 13 and 14.

Q2. Guard the list [L2]

The set has 7 members, the list is pre-filled to 25 rows and TopN = 10. Describe what each row shows with and without the IF/MIN guard, and write the guarded formula.

💡 Hint: Compare the rank with both TopN and the set count.

Q3. Two lists, one set [L2]

Using a single CUBESET of cost centres sorted by [Variance Fav/Adv] descending, build a "Top 5 favourable" list and a "Top 5 adverse" list. Write the rank expressions for both.
