Key concept

Sorted CUBESET of Vendors: sortorder 2 for Descending

Concept: =CUBESET("ThisWorkbookDataModel", "[Vendor].[Name].Children", "Top vendors", 2, "[Measures].[Expense]"), where sort_order 2 = descending

Statement

=CUBESET("ThisWorkbookDataModel",
         "[Vendor].[Name].Children",
         "Top vendors",
         2,
         "[Measures].[Expense]")
Argument Value Meaning
connection "ThisWorkbookDataModel" Workbook Data Model
set_expression "[Vendor].[Name].Children" All members of the Vendor Name attribute below the All member
caption "Top vendors" Text displayed in the cell (the cell holds a set, not a value)
sort_order 2 Descending by sort_by
sort_by "[Measures].[Expense]" Measure used to order the members

The sort_order codes: 0 = no sort (set order), 1 = ascending by sort_by, 2 = descending by sort_by, 3 = alphabetic ascending, 4 = alphabetic descending, 5 = natural (key) ascending, 6 = natural descending. Codes 1 and 2 require sort_by.

Explanation

CUBESET returns a set stored in the cell; the cell shows only the caption. It is used by CUBERANKEDMEMBER (to pick the n-th member — Concept c05), CUBESETCOUNT (to size the list), and CUBEVALUE (to aggregate over the set).

Behaviour to understand:

  • Sort context. The sort measure is evaluated in the model's default context — all FYs, all BUs — because CUBESET has no slicer arguments. To rank within the selected FY, include context in sort_by as a tuple, e.g. "([Measures].[Expense], [Date].[FY].&[FY2025-26])", or build the tuple text from a selection cell (s07).
  • Members with no data. .Children includes every vendor in the dimension, even those with no expense in the period; they sort to the end with blank values. Wrap with NonEmpty(...) to drop them: "NonEmpty([Vendor].[Name].Children, [Measures].[Expense])".
  • Ties keep the set order between them; add a tie-break if order must be deterministic.
  • Large dimensions. Sorting thousands of members is done once by the engine — still faster than thousands of CUBEVALUE cells — but use TopCount for very large sets.
  • Dynamic caption. The caption can be a formula: "Top vendors – " & SelFY.

Illustration

Vendor expense for Sahyadri (all years in the model, ₹ Cr): Gujarat Industries Power 24.8; Reliance Polymers 21.0; IOCL 19.6; BASF India 14.3; … The CUBESET above returns the set in that order. For FY2025-26 only, with sort_by "([Measures].[Expense], [Date].[FY].&[FY2025-26])", the order becomes Gujarat Industries Power 8.94, Reliance Polymers 7.20, IOCL 6.85, Gujarat Gas 6.85, BASF India 4.10 — Gujarat Gas, a new FY2025-26 supplier, moves above BASF. Without the tuple, a pack filtered to FY2025-26 would list vendors in all-years order while showing FY2025-26 values beside them.
