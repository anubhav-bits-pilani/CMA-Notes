Key concept

Building Cube Members from Cell Labels with CUBEMEMBER

Concept: =CUBEMEMBER("ThisWorkbookDataModel", "[CoA].[FSLine].&[" & $A5 & "]") builds members from cell labels

Statement

=CUBEMEMBER("ThisWorkbookDataModel", "[CoA].[FSLine].&[" & $A5 & "]")
  • The second argument is an MDX member expression assembled by text concatenation: the fixed prefix [CoA].[FSLine].&[, the key text from cell A5, and the closing ].
  • $A5 is column-anchored and row-relative, so the formula can be filled down a list of FS line keys in column A and across columns without losing the key column.
  • The cell returns a member; it displays the member's caption (here, the FS line name), and other formulas (CUBEVALUE, CUBESET) can reference the cell as a member argument.

Explanation

A board pack's rows are defined by a list of keys. Typing the full unique name in every formula is error-prone; assembling it from a cell means:

  • One place to change. If the FS line "Revenue" is renamed in the model to "Revenue from operations", only the key cell changes.
  • Copyable formulas. The same formula serves all 20 P&L lines.
  • Readable layout. Column A holds keys (hidden or grey), column B the Schedule III wording, and CUBEVALUE cells reference the member cell (column-anchored to the member column).

Practical rules:

  • Keys must match exactly — no trailing spaces, same spelling. Wrap with TRIM() if labels are typed: "[CoA].[FSLine].&[" & TRIM($A5) & "]".
  • Escape brackets. If keys can contain ], use SUBSTITUTE($A5, "]", "]]") inside the concatenation.
  • Captions. The optional third argument sets a display caption, e.g. B5 for Schedule III wording: =CUBEMEMBER(Conn, "[CoA].[FSLine].&[" & $A5 & "]", B5) — wording on screen, key in the formula.
  • Validation. An invalid key returns #N/A in the member cell, and every CUBEVALUE referencing it also returns #N/A — visible, which is good. Count errors in a check cell: =SUMPRODUCT(--ISNA(C5:C40)).
  • Dates. For date members, build the key with TEXT(d,"yyyy-mm-dd") & "T00:00:00" (s04).

Illustration

A (key, hidden) B (Schedule III label) C (member) D (Actual ₹ Cr)
Revenue Revenue from operations =CUBEMEMBER(Conn,"[CoA].[FSLine].&["&$A5&"]",B5) 1,240.6
Other income Other income (same formula, row 6) 10.4
Material cost Cost of materials consumed (row 7) 678.9
Employee cost Employee benefits expense (row 8) 110.2

Column D: =CUBEVALUE(Conn, MsrActualCr, Slicer_FY, $C5) filled down. Renaming "Material cost" to "Materials consumed" in the model needs one edit in A7, and the check cell immediately shows any key that no longer matches.
