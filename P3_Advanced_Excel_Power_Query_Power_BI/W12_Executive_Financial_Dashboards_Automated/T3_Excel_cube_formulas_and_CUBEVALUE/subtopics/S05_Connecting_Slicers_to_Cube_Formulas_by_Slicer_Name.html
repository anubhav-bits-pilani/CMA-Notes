Connecting Slicers to Cube Formulas by Slicer Name

Scope: Connecting slicers to cube formulas by slicer name

Why it matters

A board pack that cannot change year or BU without editing formulas is a static report. Excel slicers give the same click-to-filter experience as Power BI — and cube formulas can read them directly, by name. One FY slicer can drive a Schedule III P&L, a balance sheet, a waterfall and a vendor list on different sheets, which is exactly the checklist item "an Excel board-pack page with CUBEVALUE formulas that responds to an FY slicer".

Core notes

Creating a slicer on the model

Three ways:

  1. From a PivotTable on the model: PivotTable Analyze > Insert Slicer.
  2. Without a PivotTable: Insert > Slicer with no pivot selected opens Existing Connections; choose the Data Model (or the Power BI connection) under the Data Model tab, then pick the field (e.g. Date > FY).
  3. Kept from a PivotTable that was converted to formulas (s02).

A slicer must be built on the same connection as the cube formulas it feeds. A slicer on the workbook Data Model cannot filter formulas pointing to a Power BI connection.

Similarly, Insert > Timeline creates a date timeline on a date column — usable in cube formulas, but its quarters and years are calendar-based, so fiscal selection needs an FY slicer.

The slicer name

Each slicer has two names:

  • Caption (header shown on screen), e.g. "Financial year".
  • Name to use in formulas, shown in Slicer > Slicer Settings, e.g. Slicer_FY. Excel generates it from the field name (Slicer_FY, Slicer_BusinessUnit, Slicer_Region), adding 1, 2 for duplicates. It is a workbook-level name and appears in Name Manager-like IntelliSense.

Pass the name — unquoted — as a member argument:

=CUBEVALUE("ThisWorkbookDataModel", MsrActual, Slicer_FY, Slicer_BusinessUnit, $A5)

The slicer passes its current selection as a set: one item (single FY), several items (Agro + Pharma, aggregated) or All (no selection). CUBEVALUE intersects it with the other arguments.

One slicer, many sheets

A slicer name is global to the workbook, so formulas on any sheet can reference it. Place the slicer on a "Control" or cover sheet, or on each printable page (cut/paste a slicer to another sheet keeps its name). For a pack that prints, consider a small selection display cell instead of the slicer on every page:

=CUBERANKEDMEMBER("ThisWorkbookDataModel", Slicer_FY, 1)

shows the first selected FY; combine with CUBESETCOUNT(Slicer_FY) to warn when several are selected:

=IF(CUBESETCOUNT(Slicer_FY)>1, "Several FYs selected", CUBERANKEDMEMBER(Conn, Slicer_FY, 1))

Slicers and PivotTables together

The same slicer can also filter PivotTables on the same connection via Report Connections, so a supporting pivot (e.g. a reviewer's analysis sheet) stays aligned with the formula pages.

Single-select and forced selection

Excel slicers allow multi-select by default (Ctrl+click or the multi-select button). Excel has no forced single-select setting; protect the pack by:

  • the warning formula above,
  • a measure that returns BLANK when more than one FY is in context (IF(HASONEVALUE('Date'[FY]), [Actual])),
  • or replacing the FY slicer with a data-validation dropdown whose value builds a member string (Concept c02) — less interactive but deterministic.

Slicers that should not filter some cells

A PY column should use the year before the slicer selection. CUBEVALUE cannot shift a slicer; options are a PY measure in the model ([PY] via SAMEPERIODLASTYEAR — the slicer still passes FY2025-26 and the measure returns FY2024-25) or a separate member built from text. The measure approach keeps logic in the model and is preferred.

Illustration

Sahyadri board pack: cover sheet with Slicer_FY (FY2023-24 to FY2026-27) and Slicer_BusinessUnit. The P&L sheet uses =CUBEVALUE(Conn, MsrActual, Slicer_FY, Slicer_BusinessUnit, $A6) in column C, MsrBudget in column D and MsrPY (a [PY] measure) in column E. Selecting FY2024-25 and Agro changes all three columns; the title cell reads "Agro – FY2024-25" using CUBERANKEDMEMBER on each slicer.

Edge cases & judgement calls

  • Renamed slicer (Slicer Settings > Name) breaks formulas with #NAME?; fix names before writing formulas and record them in the documentation sheet.
  • Deleted slicer leaves #NAME? everywhere; protect the control sheet.
  • Slicer showing items with no data — in Slicer Settings tick Hide items with no data or Visually indicate items with no data to avoid selecting empty future FYs.
  • Cross-filtering between slicers (BU slicer shows only BUs with data for the selected FY) works on the Data Model; it can be slow on large models.
  • Power BI live connections support slicers the same way; RLS filters what the slicer shows.
  • Excel for the web supports cube formulas and slicers on the workbook Data Model with limitations; test the pack in the environment the board uses.

Key takeaways

  • Build the slicer on the same connection as the formulas; reference it by its formula name (e.g. Slicer_FY).
  • A slicer passes its selection as a set: single, multiple (aggregated) or All.
  • Slicer names are workbook-global, so one slicer drives every sheet.
  • Guard against multi-select with CUBESETCOUNT warnings or measures returning BLANK.
  • Shift periods (PY) with model measures, not by manipulating slicers.

Practice Questions

Q1. Wire up the slicer [L1]

Describe how to insert an FY slicer on the workbook Data Model without a PivotTable, find its formula name, and use it in a CUBEVALUE for revenue.

Q2. #NAME? after a tidy-up [L2]

A colleague "tidied" the pack by renaming slicers to "FY Selector" and "BU Selector" in Slicer Settings. Every value now shows #NAME?. Explain what changed, how to repair it with minimal effort, and how to prevent it.

💡 Hint: The caption and the formula name are different settings.

Q3. PY column [L2]

The board pack must show Actual for the selected FY and for the prior year side by side. Compare (a) a [PY] measure with (b) building the prior-year member from text, and write the formula for your preferred approach.

Q4. Robust selection display [L3]

Design the cover-sheet cells that display the selected FY, BU(s) and Region(s), warn on multiple FYs, and show "All BUs" when nothing is selected, using CUBESETCOUNT, CUBERANKEDMEMBER and Excel logic.
