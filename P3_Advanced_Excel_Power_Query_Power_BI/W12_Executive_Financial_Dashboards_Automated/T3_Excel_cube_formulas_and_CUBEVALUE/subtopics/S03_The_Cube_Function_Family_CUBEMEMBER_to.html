Subtopic note

The Cube Function Family: CUBEMEMBER to CUBEMEMBERPROPERTY

Scope: CUBEMEMBER, CUBEVALUE, CUBESET, CUBERANKEDMEMBER, CUBESETCOUNT, CUBEMEMBERPROPERTY

Why it matters

Cube functions are Excel's formula interface to an OLAP or tabular model. They let a board pack be laid out cell by cell — Schedule III lines, variance columns, commentary — while every number is computed by the model's measures. Each of the six functions has a distinct job: identify a member, fetch a value, build a set, pick from a set, count a set, and read a member attribute. Knowing what each returns (a member, a set, or a value) is the key to combining them without #N/A or #VALUE! errors.

Core notes

Common behaviour

  • The first argument is the connection name as text: "ThisWorkbookDataModel" for the workbook Data Model, or the workbook connection name for a Power BI semantic model (Concept c06). Store it in a named cell Conn.
  • Member and set arguments are MDX expressions as text (s04) or references to cells containing CUBEMEMBER/CUBESET results, or slicer names.
  • Results are computed asynchronously: cells show #GETTING_DATA until the model returns.
  • Errors: #N/A for an invalid member or connection, #NAME? for a wrong slicer name, #VALUE! for a wrong argument type (e.g. passing a value cell as a member).

CUBEMEMBER — identify a member or tuple

CUBEMEMBER(connection, member_expression, [caption]) returns a member (or a tuple if the expression is a tuple). The cell displays the member's caption (or your caption), but it holds the member for other formulas.

=CUBEMEMBER(Conn, "[CoA].[FSLine].&[Revenue from operations]", "Revenue from operations")
=CUBEMEMBER(Conn, "[Measures].[Actual]")
=CUBEMEMBER(Conn, "([Date].[FY].&[FY2025-26], [BU].[BusinessUnit].&[Agro])")

Uses: row labels, column headers (measures), and members built from cell text (Concept c02).

CUBEVALUE — fetch an aggregated value

CUBEVALUE(connection, [member_expression1], [member_expression2], …) returns the value at the intersection of the given members (one per hierarchy), with all other hierarchies at their default (usually All). One argument should be a measure; otherwise the model's default measure is used, which is rarely what you want.

=CUBEVALUE(Conn, MsrActual, C$4, Slicer_FY, $A5)

Here MsrActual holds a measure member, C$4 a column member (e.g. a month), Slicer_FY a slicer, and $A5 the row member. Up to 255 member arguments are possible; Excel combines them into one query context.

CUBESET — define a set

CUBESET(connection, set_expression, [caption], [sort_order], [sort_by]) returns a set of members or tuples. The cell shows the caption only. sort_order: 0 none, 1 ascending, 2 descending (both by sort_by), 3 alpha ascending, 4 alpha descending, 5 natural ascending, 6 natural descending. sort_by is required for 1 and 2.

=CUBESET(Conn, "[Vendor].[Name].Children", "Top vendors", 2, "[Measures].[Expense]")
=CUBESET(Conn, "{[Date].[FiscalMonth].&[Apr], [Date].[FiscalMonth].&[May]}", "Q1 to date")

A set can also be passed to CUBEVALUE as a filter: the value aggregates over all members of the set (e.g. a set of three BUs).

CUBERANKEDMEMBER — the n-th member of a set

CUBERANKEDMEMBER(connection, set_expression, rank, [caption]) returns the member at position rank of a set — the building block of Top N lists (s07, Concept c05):

=CUBERANKEDMEMBER(Conn, B$2, ROWS(A$5:A5))

Used with slicers too: =CUBERANKEDMEMBER(Conn, Slicer_FY, 1) returns the first selected FY, handy for titles.

CUBESETCOUNT — size of a set

CUBESETCOUNT(set) takes a cell containing a CUBESET (no connection argument) and returns the number of items. Use it to stop a Top N list from showing #N/A beyond the end of the set, and to show "Showing 10 of 214 vendors".

CUBEMEMBERPROPERTY — a member property

CUBEMEMBERPROPERTY(connection, member_expression, property) returns a property of a member, e.g. a key or a custom member property in a multidimensional (SSAS MD) cube. Tabular models (Power Pivot, Power BI) generally do not expose column attributes as member properties, so this function is of limited use there — to fetch, say, a vendor's MSME status, use a measure ([Vendor MSME] = SELECTEDVALUE(Vendor[MSMEFlag])) and CUBEVALUE it. Learn it because it appears in interviews and legacy SSAS packs.

Return types at a glance

Function Returns Can feed
CUBEMEMBER Member/tuple CUBEVALUE, CUBESET expressions (as reference), CUBEMEMBERPROPERTY
CUBEVALUE Number/text value Excel arithmetic, charts
CUBESET Set CUBERANKEDMEMBER, CUBESETCOUNT, CUBEVALUE

Illustration

Board-pack strip for FY2025-26 (Slicer_FY = FY2025-26):

Cell Formula Displays
B1 =CUBEMEMBER(Conn,"[Measures].[Revenue]") Revenue
A5 =CUBEMEMBER(Conn,"[BU].[BusinessUnit].&[Agro]") Agro
B5 =CUBEVALUE(Conn,B1,A5,Slicer_FY)/1e7 512.3
B2 =CUBESET(Conn,"[BU].[BusinessUnit].Children","All BUs",2,"[Measures].[Revenue]") All BUs
C2 =CUBESETCOUNT(B2) 3
A9 =CUBERANKEDMEMBER(Conn,B2,1) Agro

(Better still, use a [Revenue ₹ Cr] measure rather than dividing in Excel.)

Edge cases & judgement calls

  • Two members from one hierarchy in a CUBEVALUE (e.g. two FS lines) return #N/A or unexpected results; use a set for "either of".
  • Slicer with no selection passes All; with multiple selections passes a set — values aggregate.
  • Text measures can be fetched with CUBEVALUE (dynamic labels), but Excel cannot do arithmetic on them.
  • Captions in CUBEMEMBER/CUBESET are display only; formulas still use the member.
  • Calculation mode manual: cube formulas do not refresh until recalculation; Refresh All plus calculation is needed.
  • Large sets in CUBESET (e.g. 2 lakh customers) are slow to sort; pre-filter with MDX (TopCount, NonEmpty).

Key takeaways

  • CUBEMEMBER identifies, CUBEVALUE fetches, CUBESET groups, CUBERANKEDMEMBER picks, CUBESETCOUNT counts, CUBEMEMBERPROPERTY reads properties.
  • Every value formula should include an explicit measure member.
  • Store the connection, measures and slicers in named cells or names and reference them.
  • CUBESET sort_order 2 with a sort_by measure produces descending ranked sets.
  • In tabular models, fetch attributes with measures rather than CUBEMEMBERPROPERTY.

Practice Questions

Q1. Identify the function [L1]

For each requirement, name the cube function and write the formula: (a) header cell showing the Budget measure; (b) Agro's budget for the slicer-selected FY; (c) a set of all cost centres sorted by Actual descending; (d) the 5th cost centre of that set; (e) how many cost centres are in it.

Q2. Debug the errors [L2]

Explain the likely cause of each: #NAME? in =CUBEVALUE(Conn, MsrActual, Slicer_Fiscal_Year, $A5); #N/A in =CUBEMEMBER(Conn, "[CoA].[FS Line].&[Revenue]") where the column is FSLine; #VALUE! in =CUBEVALUE(Conn, B5, A5) where B5 contains a CUBEVALUE result.

💡 Hint: Match each error type to the kind of argument that is wrong.

Q3. Region set [L2]

Write formulas that return revenue for "North + West" combined, for the slicer-selected FY, without adding two CUBEVALUE results together, and explain why a set is better than two separate member arguments.

Q4. Interview explanation [L3]

In under 150 words, explain to an interviewer how a cube-formula board pack differs from a PivotTable and from SUMIFS on an exported TB, covering source of truth, layout flexibility and refresh.
