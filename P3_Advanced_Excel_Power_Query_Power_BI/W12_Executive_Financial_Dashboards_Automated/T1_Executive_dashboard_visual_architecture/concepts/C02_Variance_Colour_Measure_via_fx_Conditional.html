Key concept

Variance Colour Measure via fx Conditional Formatting

Concept: Var Colour = IF([Variance Fav/Adv] >= 0, "#2E7D32", "#C62828") applied via fx conditional formatting (Field value)

Statement

Var Colour =
IF ( [Variance Fav/Adv] >= 0, "#2E7D32", "#C62828" )
  • [Variance Fav/Adv] is the sign-adjusted variance: positive = favourable to profit or cash, negative = adverse (subtopic s05).
  • "#2E7D32" is a dark green (favourable); "#C62828" is a dark red (adverse). Any valid CSS colour string (hex, or names like "Green") works, but hex codes matched to the theme good/bad colours are standard.
  • The measure returns text. It is bound via fx next to a colour property (font colour, background, bar fill, data label colour, card reference label colour) with Format style = Field value and What field should we base this on? = [Var Colour].

Explanation

Power BI conditional formatting offers three styles: Gradient, Rules and Field value. Gradient and Rules work on the raw numeric value of a field; they cannot know that a positive cost variance is bad unless you write separate rules per line. Field value lets a measure decide the colour with full DAX logic, so the favourable/adverse semantics live in the model and are reused everywhere — cards, matrix cells, diverging bars, waterfall-adjacent tables.

Conditions and refinements:

  • Blank handling. If [Variance Fav/Adv] is BLANK (no budget), BLANK() >= 0 evaluates TRUE in DAX (blank is treated as zero in comparisons), so the cell turns green. Guard it: IF(ISBLANK([Variance Fav/Adv]), "#9E9E9E", IF([Variance Fav/Adv] >= 0, "#2E7D32", "#C62828")).
  • Materiality band. Small variances can be neutral grey: use SWITCH(TRUE(), ABS(v) < 0.5e7, "#9E9E9E", v >= 0, ...) so ₹0.3 Cr noise does not flash red.
  • Context. In a matrix, the measure is evaluated per cell, so subtotal rows get their own colour from their own fav/adv variance. This is why [Variance Fav/Adv] must aggregate correctly across lines with different signs.
  • Where it applies. Bar charts: Columns/Bars > Colors > fx. Matrix: Cell elements > Font colour or Background colour > fx. New Card: Reference labels > Value > Colour > fx. Waterfalls do not accept per-bar field-value colours in the same way; they use sentiment colours.
  • Do not show it. The measure is for formatting only; hide it from report view or put it in a "Formatting" display folder.

Binding the same measure to the Var (₹) column font and to the diverging bar fill gives a consistent signal across Page 1.

Practice Questions

Q1. Three-state colour [L1]

Write [Var Colour 3] returning grey for blank or variances below ₹50 lakh in absolute terms, green for favourable and red for adverse, and state where you would bind it in a matrix.

Q2. Rules vs field value [L2]

A colleague applied Rules formatting to the Var (₹) column: green if value > 0, red if value < 0. Using the illustration table, identify which rows are coloured wrongly and explain why Field value with a measure solves it.

Q3. Colour-blind-safe variant [L2]

Rewrite the colour measure to use a blue/orange palette and add a companion measure returning "▲" or "▼" for use as a text prefix, and explain how this meets accessibility guidance.

💡 Hint: The icon measure should use the same fav/adv sign test as the colour.
