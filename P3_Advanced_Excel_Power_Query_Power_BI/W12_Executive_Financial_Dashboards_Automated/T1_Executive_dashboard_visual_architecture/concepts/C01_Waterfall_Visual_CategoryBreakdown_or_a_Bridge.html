Key concept

Waterfall Visual: Category/Breakdown or a Bridge-Step Table

Concept: Waterfall visual: Category = bridge step, Breakdown = driver; or a disconnected bridge-step table with a SWITCH measure

Statement

Two ways to bind a Power BI waterfall:

Pattern A — native wells. Category = bridge step (for example CoA[FSLine] or a scenario field), Y-axis = a variance or amount measure, optional Breakdown = a driver field. With only Category, each category is one step and the visual appends a Total. With Category = period or scenario and Breakdown = driver, the visual shows how the total moved from one category to the next, split by the top breakdown items (the rest grouped as "Other").

Pattern B — disconnected step table. A table Bridge Steps (StepNo, Step, Kind) not related to the model, placed on Category and sorted by StepNo, plus one measure:

Bridge Value =
VAR s = SELECTEDVALUE ( 'Bridge Steps'[Step] )
RETURN
    SWITCH (
        s,
        "Budget EBITDA",  [Budget EBITDA],
        "Revenue",        [Revenue] - [Revenue Budget],
        "Material",       -( [Material Cost] - [Material Cost Budget] ),
        "Employee",       -( [Employee Cost] - [Employee Cost Budget] ),
        "Power & fuel",   -( [Power Cost] - [Power Cost Budget] ),
        "Other opex",     -( [Other Opex] - [Other Opex Budget] )
    )

Each symbol: [Budget EBITDA] is the start; each driver line is a sign-adjusted variance (favourable positive); the visual's Total bar is the end and must equal [EBITDA]. The identity that must hold is

\[ [\text{EBITDA}] = [\text{Budget EBITDA}] + \sum_{i} \Delta_i \]

Explanation

In Pattern A the visual computes the running total and adds its own Total bar. It is quick and works well for "PY revenue → CY revenue by BU" (Category = FY with two years, Breakdown = BU): the first bar is PY total, the breakdown bars are each BU's change, and the last bar is CY. Limits: step order follows the visual's sort (often by value), the Breakdown shows only the top items (configurable maximum) with "Other", start/end bars are tied to categories, and you cannot insert a subtotal such as "Contribution".

Pattern B treats the bridge as a report object with policy-defined order. One mechanical point matters: the native waterfall always appends its own Total bar (there is no reliable switch to hide it across Desktop versions), and the Total equals the sum of all bars. So the usual convention is to put Start in the step table and let the visual's Total bar represent End (rename the total label to "Actual EBITDA" where the format pane allows). If "Actual EBITDA" were also a step, the Total would double-count it. The Start bar is drawn as an increase from zero; label it clearly ("Budget EBITDA") so readers do not read it as a driver.

The step table can carry a Kind column (Start, Driver, Subtotal) used in a colour measure, and a residual step defined as End − Start − sum of drivers to guarantee closure. Because the table is disconnected, slicers on FY, BU and Region still filter the measures inside SWITCH, so the bridge responds to context.

Illustration

October 2025 YTD, ₹ Cr: Budget EBITDA 122.6; Revenue −22.8; Material +16.1; Employee −1.4; Power & fuel −4.2; Other opex +2.9; result 113.2 — equal to [EBITDA]. Step table:

StepNo Step Kind
1 Budget EBITDA Start
2 Revenue Driver
3 Material Driver
4 Employee Driver
5 Power & fuel Driver
6 Other opex Driver

With the native Total enabled, the visual's Total bar shows 113.2 as Actual EBITDA. A check measure [Bridge Check] = SUMX('Bridge Steps', [Bridge Value]) - [EBITDA] returns 0.

Practice Questions

Q1. PY-to-CY revenue bridge with native wells [L1]

Describe the exact Category, Breakdown and Y-axis bindings and the filters needed to show FY2024-25 revenue → FY2025-26 revenue split by BU using Pattern A.

Q2. Add a subtotal [L2]

Extend the step table and SWITCH measure to show a "Contribution" subtotal bar after Material, coloured differently, while keeping the end value equal to [EBITDA].

💡 Hint: A subtotal step returns a cumulative value, so think about how the visual treats it.

Q3. Choose the pattern [L2]

For each of (a) cash bridge from opening to closing cash with seven fixed steps, (b) top-5 cost centres explaining the opex variance, (c) monthly EBITDA movement from September to October by FS line — choose Pattern A or B and justify.
