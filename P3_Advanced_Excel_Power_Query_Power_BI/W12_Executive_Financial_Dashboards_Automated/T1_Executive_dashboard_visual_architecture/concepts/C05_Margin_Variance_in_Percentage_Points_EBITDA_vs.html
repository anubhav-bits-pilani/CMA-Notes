Key concept

Margin Variance in Percentage Points: EBITDA % vs Budget

Concept: EBITDA % vs Budget = [EBITDA %] - [Budget EBITDA %] with format +0.0 "pp";-0.0 "pp"

Statement

EBITDA % vs Budget = [EBITDA %] - [Budget EBITDA %]
-- Custom format string:  +0.0 "pp";-0.0 "pp"

\[ \Delta m = m_A - m_B = \frac{E_A}{R_A} - \frac{E_B}{R_B} \]

where \(E_A, R_A\) are actual EBITDA and revenue, \(E_B, R_B\) are budget EBITDA and revenue, and \(m\) is the EBITDA margin. Because margins are stored as fractions (0.159), the measure returns a fraction such as −0.008; the format string must therefore multiply by 100 for display. In Power BI/Excel custom formats, a % symbol in the format multiplies by 100, so a literal pp format applied to a raw fraction would show "−0.0 pp". Two working choices:

  1. Multiply in DAX: EBITDA % vs Budget = ([EBITDA %] - [Budget EBITDA %]) * 100 with format +0.0 "pp";-0.0 "pp".
  2. Keep the fraction and use a percent format: +0.0%;-0.0% — but then the label says "%", which readers confuse with a relative change.

The concept's format string implies option 1: the measure value is expressed in points.

Explanation

A percentage-point (pp) difference is the arithmetic difference between two percentages; a percentage change is relative. EBITDA margin moving from 16.7% to 15.9% is −0.8 pp, but a −4.8% relative change. Analysts and boards speak in pp (or basis points: 1 pp = 100 bps) for margins, and mixing the two is a classic interview trap.

The format string has two sections separated by ; — positive and negative — each with an explicit sign, so the variance always shows a leading + or − (a third section after a second ; can define zero, e.g. 0.0 "pp"). The quoted "pp" is a literal suffix.

Rules:

  • Both margins must be recomputed in the same filter context from totals (DIVIDE([EBITDA], [Revenue])), never averaged across months or BUs.
  • If budget revenue is zero for a BU, [Budget EBITDA %] is BLANK and the variance should be BLANK, not equal to the actual margin. Guard: IF(NOT ISBLANK([Budget EBITDA %]), ...).
  • The favourable direction is up for EBITDA % (and down for cost ratios such as employee cost %); colour with a fav/adv measure (Concept c02).
  • For basis points, multiply by 10,000 and use +0 "bps";-0 "bps".

Illustration

October 2025 YTD: Actual EBITDA ₹113.2 Cr on revenue ₹712.4 Cr; Budget EBITDA ₹122.6 Cr on revenue ₹735.2 Cr.

\[ m_A = \frac{113.2}{712.4} = 15.89\%, \qquad m_B = \frac{122.6}{735.2} = 16.68\% \]

\[ \Delta m = 15.89\% - 16.68\% = -0.79 \text{ pp} \;\Rightarrow\; \text{displayed as } -0.8 \text{ pp} \]

The relative change is \(-0.79 / 16.68 = -4.7\%\). The EBITDA % card shows "15.9%" with the reference label "vs Budget −0.8 pp" in red.

Practice Questions

Q1. pp vs % [L1]

PAT margin moved from 7.4% (PY) to 6.6% (CY). Express the change in pp, in bps and as a relative percentage, and write the DAX measure and format string for the pp version.

Q2. Averaging trap [L2]

BU margins for October 2025: Agro 12.0% on revenue ₹48.0 Cr, Pharma 21.0% on ₹30.5 Cr, Polymers 14.0% on ₹23.6 Cr. Budget margins were 13.0%, 20.0% and 15.5% on revenue ₹52.0 Cr, ₹29.0 Cr and ₹24.0 Cr. Compute the company-level pp variance correctly, and show the result you would get by averaging BU variances.

💡 Hint: Rebuild company EBITDA and revenue from the BU figures before dividing.

Q3. Format string sections [L2]

Write custom format strings for: (a) margin variance in pp with one decimal and "0.0 pp" for zero; (b) cost-ratio variance in bps with no decimals; (c) Var % with brackets for negatives. Explain how each behaves for a value of −0.04 if the measure was not multiplied by 100.
