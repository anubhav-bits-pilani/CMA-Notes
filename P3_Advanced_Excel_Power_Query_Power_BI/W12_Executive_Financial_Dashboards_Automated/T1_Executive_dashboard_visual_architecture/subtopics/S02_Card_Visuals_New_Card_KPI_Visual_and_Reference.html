Card Visuals: New Card, KPI Visual and Reference Labels

Scope: Card visuals: the new Card (multi-card), the KPI visual with target and trend axis, reference labels vs Budget/PY

Why it matters

The KPI row is the most-read part of any executive pack, and the card visual decides whether a number carries meaning. "Revenue ₹712 Cr" tells a CFO nothing; "Revenue ₹712 Cr, −3.1% vs Budget, +8.4% vs PY" tells a story. Power BI now offers three ways to build that row — the new Card visual (with multiple cards and reference labels), the KPI visual (value, target and trend axis) and the legacy card/multi-row card. Choosing correctly, and binding the comparison measures properly, is the difference between a decorative card and a decision card.

Core notes

Legacy card and multi-row card

The legacy Card shows one measure with a category label. It cannot show a second value, so comparisons had to be faked with a second card or a text-measure concatenation. The Multi-row card stacks several measures but with limited formatting. Both remain in the visual pane but should not be the default for new executive pages.

The new Card visual (multi-card)

The new Card visual (introduced in preview in late 2023 and now generally available — check your Desktop version) replaced both:

  • Multiple measures in one visual. Drop Revenue, EBITDA %, PAT, Cash and Net Debt into the Value well and the visual renders five cards with shared formatting. Layout settings control cards per row, padding and alignment, so one visual can be the whole KPI row. This keeps sizes, fonts and spacing identical without manual alignment.
  • Per-card formatting. In the format pane you can apply settings to All cards or to a specific series (for example, an accent bar colour per KPI), callout value font and size, label position, and display units.
  • Reference labels. Each card can carry one or more reference labels — secondary values beneath or beside the callout. A reference label has a Title (for example "vs Budget"), a Value (a measure) and an optional Detail (a further measure or text). Reference label values support fx conditional formatting, so variance text can turn green or red.
  • Images and shapes. An optional image or icon per card and accent bars/borders give status signals without extra visuals.
  • Small-multiple style split. A category field can split cards (for example one card per BU), useful on a BU comparison page but usually not on the CFO overview.

Building reference labels vs Budget and PY

Reference labels should use dedicated variance measures from the library rather than ad-hoc DAX:

Revenue vs Budget % = DIVIDE ( [Revenue] - [Revenue Budget], ABS ( [Revenue Budget] ) )
Revenue vs PY %     = DIVIDE ( [Revenue] - [Revenue PY], ABS ( [Revenue PY] ) )
EBITDA % vs Budget  = ( [EBITDA %] - [Budget EBITDA %] ) * 100  -- points; format +0.0 "pp";-0.0 "pp" (c05)
Net Debt vs Budget  = [Net Debt] - [Net Debt Budget]          -- adverse when positive

Set Title = "vs Budget", Value = [Revenue vs Budget %], Detail = [Revenue Budget] formatted in ₹ crore, so the card reads ₹712.4 Cr · vs Budget −3.1% (₹735.2 Cr). Add a second reference label for PY. Colour each value with a sign-aware colour measure (Concept c02): for cost and Net Debt, a positive variance is adverse, so the colour logic must use a favourable/adverse measure, not the raw difference.

The KPI visual

The KPI visual is designed for a value against a target over time. Its wells are:

Well Content Example
Value The indicator measure [EBITDA %]
Target The goal measure [Budget EBITDA %]
Trend axis A date/sequence field 'Date'[MonthEnd] or fiscal month

It shows the indicator value, the goal, the distance to goal and a background area chart of the indicator over the trend axis. Color coding > Direction sets whether high is good (revenue, margin), low is good (Net Debt, DSO) or neutral, which drives green/red automatically.

Two behaviours matter in finance:

  1. The KPI visual displays the value for the last category on the trend axis, not the total over the filtered period. With FY2025-26 selected and month on the trend axis, it shows the latest month's EBITDA %, not YTD. Use a YTD measure as Value if you want YTD, or accept that the KPI represents the latest month and label it so.
  2. If future months exist in the Date table and the measures return values for them (budget does), the "last category" may be a future month. Filter the trend axis to months up to the last actual date, or make the indicator measure blank beyond [Last Actual Date].

The distance-to-goal is computed as a percentage of the goal; for a margin, a "−4.8%" distance from a 16.7% target is confusing. For ratio KPIs, the new Card with a pp reference label usually communicates better.

Choosing between them

Need Best visual
Five headline numbers with Budget and PY comparisons New Card (one visual, five cards, two reference labels each)
One KPI against target with visible trend KPI visual
Sparkline inside a table Table/matrix sparklines (not a card)
Text-only status ("All checks PASS") New Card with a text measure, or a button/shape with fx text

Illustration

Revenue card for October 2025 YTD: Actual ₹712.4 Cr, Budget ₹735.2 Cr, PY ₹657.2 Cr.

\[ \text{vs Budget} = \frac{712.4 - 735.2}{735.2} = -3.1\%, \qquad \text{vs PY} = \frac{712.4 - 657.2}{657.2} = +8.4\% \]

The card shows −3.1% in red (adverse for revenue) and +8.4% in green. For Net Debt, ₹226.9 Cr against a budget of ₹208.5 Cr gives +₹18.4 Cr, shown in red because a higher Net Debt is adverse.

Edge cases & judgement calls

  • Blank budget. If a BU has no budget, the reference label shows blank or a misleading −100%. Use DIVIDE with BLANK and a Detail text such as "No budget".
  • PY for a new BU. A BU started in FY2025-26 has no PY; show "n.a." rather than +∞.
  • Display units. The card's display units (thousands, millions, billions) do not support lakh/crore, so use ₹ crore measures or a dynamic format string (s06).
  • Sign of cost KPIs. If expenses are stored negative (credit-negative convention), a "−5%" variance on cost may be favourable or adverse depending on the measure's sign; define Fav/Adv explicitly.
  • Version drift. The new Card's format-pane labels have changed between monthly releases; document the Desktop version used for the pack.
  • Accessibility. Red/green alone is not enough; add ▲/▼ or "Fav/Adv" text in the reference label.

Key takeaways

  • Use the new Card visual for the KPI row: one visual, multiple cards, consistent formatting.
  • Every card needs at least one reference label (vs Budget) and usually two (vs PY).
  • Reference labels should bind to library variance measures with sign-aware colour measures.
  • The KPI visual shows the last trend-axis value, so control future months and YTD semantics.
  • Ratio KPIs compare in percentage points, not percentages.
  • Avoid legacy cards for new packs except for simple text indicators.

Practice Questions

Q1. Reference label measures [L1]

Write DAX for [PAT vs Budget] (absolute, ₹) and [PAT vs PY %], and specify the Title, Value and Detail you would set on the PAT card's two reference labels.

Q2. KPI visual shows the wrong month [L2]

A KPI visual with Value = [Revenue], Target = [Revenue Budget], Trend axis = 'Date'[MonthEnd] shows ₹0.0 Cr against a target of ₹108.5 Cr when FY2025-26 is selected on 15 November 2025. Actuals exist to 31 October 2025 and the budget covers all twelve months. Explain the behaviour and give two fixes.

💡 Hint: Think about which category the KPI visual treats as "current".

Q3. Sign-aware card colours [L2]

For five cards — Revenue, EBITDA %, PAT, Cash, Net Debt — state for each whether a positive (Actual − Budget) variance is favourable or adverse, and write one measure [KPI Fav Flag] that could be used with a field parameter or SWITCH to return +1/−1 per KPI.

Q4. Pick the visual [L3]

A CFO wants: (a) a headline row with five numbers and Budget/PY comparisons; (b) a single "DSO vs 60-day target" indicator with a 12-month trend; (c) a status message showing whether all controls pass. Choose a visual for each, specify its fields and formatting, and justify why the alternatives are worse.
