Key concept

Multi-Row Header Recipe: Transpose, Fill, Combine, Unpivot, Split

Concept: Multi-row headers: Table.Transpose → Table.FillDown → Table.CombineColumns(..., Combiner.CombineTextByDelimiter("|"), "Hdr") → transpose → promote → unpivot → split on "|"

Statement

Given a table whose first two rows are headers (upper level, e.g. Department, in merged cells; lower level, e.g. Month), the recipe produces a long table with both header levels as columns:

Step Function Purpose
1 Table.Transpose(t) Header rows become the first two columns
2 Table.FillDown(t, {"Column1"}) Fill the merged upper header down (it was "across" before transposing)
3 Table.CombineColumns with Combiner.CombineTextByDelimiter (pipe delimiter), new column "Hdr" One combined header per original column, e.g. Sales, pipe, Apr-25
4 Table.Transpose(t) Back to original orientation
5 Table.PromoteHeaders(t, [PromoteAllScalars=true]) Combined header row becomes column names
6 Table.UnpivotOtherColumns(t, {"Account"}, "Attribute", "Amount") Long shape
7 Table.SplitColumn on "Attribute" with Splitter.SplitTextByEachDelimiter (pipe), into Department and Month Recover both header levels

The exact calls for steps 3 and 7:

Combined = Table.CombineColumns(Filled, {"Column1","Column2"}, Combiner.CombineTextByDelimiter("|"), "Hdr")
Split    = Table.SplitColumn(Long, "Attribute", Splitter.SplitTextByEachDelimiter({"|"}), {"Department","Month"})

Explanation

Why transpose? Merged cells in Excel arrive as a value in the first cell and nulls to its right. Power Query has Fill Down and Fill Up, not Fill Right. Transposing turns the header row into a column so Fill Down can do the job, then transposing back restores the shape.

Combining: Combiner.CombineTextByDelimiter("|") joins the two header cells. It treats nulls by skipping them in current versions, so the identifier column header (null over "Account") becomes "Account"; to be explicit and version-proof, use an added column if [Column1] = null then [Column2] else [Column1] & "|" & [Column2]. Note Table.CombineColumns places the new column at the position of the first combined column and removes the originals — convenient because "Hdr" ends up as the first column, ready to become the header row after transposing back.

Delimiter: choose a character that does not occur in either header level. "|" is standard; "-" is wrong because month labels contain it.

Types: after transposing, each column contains mixed values (header text and numbers), so all typing must wait until after the unpivot. Disable automatic type detection to avoid a Changed Type step after promotion that hard-codes the combined headers.

Preparation steps often needed before step 1: skip report header rows by condition, remove empty spacer columns and rows, and convert empty strings to null in the upper header row (Fill Down fills only nulls).

After step 7: trim Department, convert Month to a month-end date (c02), split Account code/name, add Scenario (c05), type Amount.

Scaling: Table.Transpose materialises the full table; on large sheets build the header list separately (List.Zip of the filled-right upper row and the lower row) and rename columns instead.

Illustration

Input (top): row 1 = null, "Sales", null, "Marketing", null; row 2 = "Account", "Apr-25", "May-25", "Apr-25", "May-25"; data row "610100" with 12,00,000, 12,00,000, 6,00,000, 6,00,000.

After step 3 (transposed), the Hdr column reads: "Account", "Sales|Apr-25", "Sales|May-25", "Marketing|Apr-25", "Marketing|May-25". After steps 4–7, four long rows for 610100: (Sales, Apr-25, 12,00,000), (Sales, May-25, 12,00,000), (Marketing, Apr-25, 6,00,000), (Marketing, May-25, 6,00,000). Total ₹36,00,000 equals the sum of the data row.
