Key concept

The each Keyword and the Underscore Parameter

Concept: each [Amount] > 0 is shorthand for (_) => _[Amount] > 0

Statement

In M, each expression defines an anonymous function of one parameter named _:

\[ \texttt{each}\; E \;\equiv\; (\_) \Rightarrow E \]

Within \(E\), a field access written without a target, [Field], is resolved against _, so [Amount] means _[Amount]. Hence each [Amount] > 0 is exactly (_) => _[Amount] > 0: a function that takes a record (a row) and returns true when its Amount field exceeds zero.

Explanation

Library functions that need a per-row or per-item rule accept a function value. Table.SelectRows(table, condition) calls condition once per row, passing the row as a record; each is just the shortest way to write that function. Knowing the long form unlocks several things:

  1. Readable nesting. In Table.SelectRows(Bank, each List.Contains(BookRefs, [Ref])) the _ is the bank row. If you need an inner each (e.g. inside List.Select), the inner _ shadows the outer one. Write the outer explicitly: (bankRow) => List.AnyTrue(List.Transform(BookAmts, each Number.Abs(_ - bankRow[Amount]) <= 1)).
  2. Typed lambdas. (row as record) as logical => row[Amount] > 0 documents and enforces types.
  3. Non-record contexts. When the function receives a scalar (a cell in Table.TransformColumns, a list item in List.Transform), [Field] makes no sense; use _ itself: each Text.Upper(_), each _ * -1.
  4. Group By. In Table.Group, _ is the sub-table for the group, so each List.Sum([Amount]) works because [Amount] on a table returns a list column; each Table.RowCount(_) counts rows.
  5. Reusable named functions. IsPositive = (r) => r[Amount] > 0 can be passed as Table.SelectRows(t, IsPositive) — useful when the same rule is used in several queries.

Precedence note: each captures the whole expression to its right, so each [Debit] ?? 0 - [Credit] ?? 0 is parsed with arithmetic precedence inside the body — parentheses are still required for correct net amounts (Topic 6).

Illustration

Bank rows: (Ref "UTR001", Amount 25,000), (Ref "CHQ0456", Amount −12,500), (Ref "UTR002", Amount 0).

Expression Evaluates for row 2 to Rows kept
Table.SelectRows(t, each [Amount] > 0) _[Amount] > 0 → −12,500 > 0 → false UTR001
Table.SelectRows(t, (r) => r[Amount] <> 0) true UTR001, CHQ0456
Table.TransformColumns(t, {{"Amount", each _ * -1, type number}}) _ = −12,500 → 12,500 all, signs flipped
Table.AddColumn(t, "IsCheque", each Text.StartsWith([Ref], "CHQ"), type logical) true all, new column

Practice Questions

Q1. Expand the shorthand [L1]

Rewrite each using explicit lambda syntax: (a) each [Debit] > 100000; (b) each Text.Trim(_); (c) each List.Sum([Amount]) inside Table.Group; (d) each fxCleanBank([Content]).

Q2. Nested each [L2]

You want to keep bank rows whose Amount is within ₹1 of any amount in the list BookAmounts. A colleague writes Table.SelectRows(Bank, each List.AnyTrue(List.Transform(BookAmounts, each Number.Abs(_ - [Amount]) <= 1))) and it errors. Explain why and fix it.

💡 Hint: Identify what _ refers to in the innermost function.

Q3. Reusable rule [L2]

Define a named function that flags a ledger row as a "subtotal" when Ledger is null, starts with "Total" or equals "Grand Total", and show how to use it both to remove such rows and to keep them in an exceptions query.
