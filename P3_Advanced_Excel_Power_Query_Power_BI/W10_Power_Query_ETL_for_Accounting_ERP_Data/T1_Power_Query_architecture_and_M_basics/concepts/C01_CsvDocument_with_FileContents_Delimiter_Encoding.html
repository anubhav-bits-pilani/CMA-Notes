Key concept

Csv.Document with File.Contents: Delimiter, Encoding, QuoteStyle

Concept: Csv.Document(File.Contents(FilePath), [Delimiter=",", Encoding=65001, QuoteStyle=QuoteStyle.Csv])

Statement

File.Contents(path) returns the raw binary of a file. Csv.Document(binary, options) parses that binary into a table with columns Column1 … ColumnN, all of type any/text. The options record controls parsing:

Option Meaning Values
Delimiter Field separator ",", "#(tab)", ";" or the pipe character
Columns Fixed number of columns (or a list of names) Omit to let the file decide
Encoding Code page 65001 = UTF-8, 1252 = Windows Western, TextEncoding.Utf16
QuoteStyle Treatment of quotes QuoteStyle.Csv (quoted fields may contain delimiters and line breaks), QuoteStyle.None (quotes are literal characters)
CsvStyle Quote handling at field start CsvStyle.QuoteAfterDelimiter, CsvStyle.QuoteAlways

Explanation

Separating the two functions matters: File.Contents is the only part that touches the file system, so in a folder pipeline you replace it with the [Content] binary from Folder.Files and keep the same Csv.Document call inside a function.

Encoding 65001 (UTF-8) is the safe default for modern bank and ERP exports; it reads ₹, en-dashes and Hindi narrations correctly. Files from older Windows software are often 1252; reading UTF-8 as 1252 produces mojibake such as â‚¹ instead of ₹, which breaks text matching on narration. Check by inspecting a known special character after import.

QuoteStyle.Csv is essential for bank narrations like "NEFT-SBIN0001234-ABC TRADERS, PUNE": with QuoteStyle.None the comma inside the quotes splits the field and shifts every following column by one — amounts land in the balance column, silently. QuoteStyle.Csv also permits line breaks inside quoted fields (common in SAP long texts), which None would treat as new rows.

Columns: the UI writes Columns=7 from the sample; if a later file has 8 columns, the extra one is dropped without error. Omit Columns in recurring pipelines and select columns by name after promoting headers.

Delimiter: SAP downloads via "Unconverted" or spreadsheet export are frequently tab-delimited .txt; use "#(tab)". Some European-format files use semicolons.

Illustration

An HDFC CSV with 18 header lines, then a header row "Date,Narration,Chq./Ref.No.,Value Dt,Withdrawal Amt.,Deposit Amt.,Closing Balance" and lines such as:

02/04/25,"UPI-RAMESH KUMAR-PAYTM, NOIDA",0000412345678901,02/04/25,,25000.00,1245000.00

let
    Source = Csv.Document(File.Contents(FilePath),
                [Delimiter=",", Encoding=65001, QuoteStyle=QuoteStyle.Csv]),
    FromHeader = Table.Skip(Source, each [Column1] <> "Date"),
    Promoted = Table.PromoteHeaders(FromHeader, [PromoteAllScalars=true])
in
    Promoted

With QuoteStyle.Csv, the narration stays one field and "25000.00" sits under Deposit Amt. With QuoteStyle.None, "NOIDA" becomes the Chq./Ref.No. and the deposit shifts into Value Dt.
