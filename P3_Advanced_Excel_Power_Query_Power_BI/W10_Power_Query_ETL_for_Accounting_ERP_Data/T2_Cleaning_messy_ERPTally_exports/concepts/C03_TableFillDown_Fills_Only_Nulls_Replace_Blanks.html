Key concept

Table.FillDown Fills Only Nulls: Replace Blanks First

Concept: Table.FillDown(t, {"CostCentre"}) only fills nulls, so first run Table.ReplaceValue(t, "", null, Replacer.ReplaceValue, {"CostCentre"})

Statement

Table.FillDown(table as table, columns as list) as table replaces each null value in the listed columns with the nearest preceding non-null value, in current row order. An empty string "" is a non-null value, so it is neither filled nor skipped — it becomes the value carried down.

Table.ReplaceValue(table, oldValue, newValue, replacer, columnsToSearch) with Replacer.ReplaceValue replaces cells whose entire value equals oldValue; here every "" in CostCentre becomes null, making the column fillable.

Explanation

Where empty strings come from: CSV parsing returns "" for empty fields between delimiters; Excel cells containing a formula returning "" or a stray space; Tally exports with blank-looking cells containing a space or char 160. In the preview, null shows in italics as null, while "" shows as an empty cell — a visual clue worth learning.

What goes wrong without the replace: suppose rows are Header "Mumbai HO", detail, detail (CostCentre ""), detail (""). Fill Down sees "" as a value: the detail rows keep "" instead of "Mumbai HO". Worse, if some rows are null and some "", fills stop and restart unpredictably.

Replacer.ReplaceValue vs Replacer.ReplaceText: the first replaces whole cell values (correct here — and the only one that can produce null); the second replaces substrings inside text, and replacing "" as a substring is meaningless.

Handling spaces as well as empties:

Blanks = Table.TransformColumns(t, {{"CostCentre", each
           let x = if _ = null then null else Text.Trim(Text.Replace(Text.From(_), Character.FromNumber(160), " "))
           in if x = null or x = "" then null else x, type nullable text}}),
Filled = Table.FillDown(Blanks, {"CostCentre"})

Sequence rules:

  1. Skip report header and promote (c01).
  2. Create the header column (only header rows populated).
  3. Convert blanks to null.
  4. Fill Down — before any sort, merge or filter that changes order.
  5. Remove header-only rows and total rows (c02).

Illustration

Row Particulars CostCentre (raw) After FillDown only After Replace + FillDown
1 Mumbai HO Mumbai HO Mumbai HO Mumbai HO
2 Salaries "" "" Mumbai HO
3 Rent null "" Mumbai HO
4 Pune Plant Pune Plant Pune Plant Pune Plant
5 Power & Fuel "" "" Pune Plant

Without the replace, row 3 inherits "" from row 2 — every detail row ends up with no cost centre and a cost-centre P&L shows everything as "(Blank)".

Connections

Implements s03 (filling down headers). Related to s05 (char 160 and spaces that also defeat the fill), the pitfall on running Fill Down after a sort/filter, and Topic 3 (Fill Down on transposed multi-row headers, where empty strings from Excel merged cells cause the same issue).
