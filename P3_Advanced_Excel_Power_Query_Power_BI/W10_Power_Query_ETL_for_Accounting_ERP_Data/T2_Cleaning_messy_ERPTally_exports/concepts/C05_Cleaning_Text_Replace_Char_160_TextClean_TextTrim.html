Key concept

Cleaning Text: Replace Char 160, Text.Clean, Text.Trim

Concept: Table.TransformColumns(t, {{"Name", each Text.Trim(Text.Clean(Text.Replace(_, Character.FromNumber(160), " "))), type text}})

Statement

Table.TransformColumns(table, transformOperations) applies a function to every value of the named column(s); each operation is {columnName, function, optional newType}. Here the function, applied to each cell value _, is a composition evaluated inside-out:

\[ f(x) = \text{Trim}\big(\text{Clean}\big(\text{Replace}(x,\ \text{char}_{160},\ \text{" "})\big)\big) \]

  1. Text.Replace(_, Character.FromNumber(160), " ") — converts every non-breaking space (U+00A0) to an ordinary space (U+0020).
  2. Text.Clean(...) — removes control (non-printable) characters such as line feed, carriage return and tab.
  3. Text.Trim(...) — removes leading and trailing whitespace.
  4. type text — ascribes the column type so it does not become any.

Explanation

Why this exact order: non-breaking spaces are printable, so Text.Clean leaves them alone; converting them first ensures they are treated as ordinary spaces by the trim and by any later space-collapsing. Cleaning before trimming means that a trailing line feed, once removed, exposes trailing spaces that the trim then removes.

What it does not do:

  • Collapse internal double spaces ("ABC Traders" stays as is) — add a split/select/combine step if needed.
  • Remove zero-width spaces (code 8203) or the byte-order mark (65279) — add Text.Remove.
  • Handle nulls in a strict sense: Text.Replace(null, ...) returns null in current versions, and Text.Clean/Text.Trim propagate null, but numeric values in an untyped column (e.g. a code read as a number) make Text.Replace error. Wrap with Text.From(_) when the column may hold non-text values.
  • Fix case — combine with Text.Upper for keys.

Line breaks inside narrations: Text.Clean deletes them, gluing words together ("NEFTRECEIVED"). For narration columns, replace "#(cr)", "#(lf)" and "#(tab)" with spaces before cleaning.

Applying to several columns with one rule:

fx      = (x) => if x = null then null else Text.Trim(Text.Clean(Text.Replace(Text.From(x), Character.FromNumber(160), " "))),
Cleaned = Table.TransformColumns(t, {{"Name", fx, type text}, {"Narration", fx, type text}, {"PartyGSTIN", fx, type text}})

Table.TransformColumns also has an optional defaultTransformation argument applied to all columns not listed — handy but risky on numeric columns.

Illustration

Vendor master from a GST portal download vs Tally purchase register:

Source Raw value (visible) Length After the expression
GSTR-2B "Shree Ganesh Steels" + char 160 at end 20 "Shree Ganesh Steels" (19)
Tally "Shree Ganesh Steels" + line feed 20 "Shree Ganesh Steels" (19)
Tally " Shree Ganesh Steels" (leading space) 20 "Shree Ganesh Steels" (19)

Before cleaning, a merge on name produced zero matches for this vendor; after cleaning, all three agree. Lengths reveal the hidden characters even when the text looks identical.

Connections

Implements s05. Prerequisite for key normalisation before merges (Topic 5 s04) and for number conversion (s06 — char 160 inside "1,23,456.00" breaks typing). Compare Excel TRIM/CLEAN/SUBSTITUTE(x, CHAR(160), " ") from Week 9.

Practice Questions

Q1. Order of operations [L1]

Explain what result you would get for the value "ABC" + char 160 + line feed if the expression were written Text.Replace(Text.Trim(Text.Clean(_)), Character.FromNumber(160), " "), and why the concept's order is better.

Q2. Extend for keys [L2]

Extend the expression into a function fxPartyKey that also removes zero-width spaces and BOM, collapses internal spaces, upper-cases, and is safe for null and numeric inputs. Apply it to columns Party and GSTIN in one step.

💡 Hint: Use Text.From at the start and a split/select/combine for internal spaces.

Q3. Narration damage [L2]

After cleaning, UTR extraction from SBI narrations fails because "NEFT/SBIN526012345678/ABC" became "NEFTSBIN526012345678ABC" on some rows. Explain which step caused it and how you would restructure the cleaning.
