Subtopic note

Indian FY Attributes: Label, Fiscal Month, Quarter and Sort Key

Scope: Indian FY attributes: FY label (FY2025-26), fiscal month number, fiscal quarter, period sort key

Why it matters

Indian companies report on a financial year running 1 April to 31 March — mandatory under Sec 2(41) of the Companies Act, 2013 (with limited exceptions for certain subsidiaries of foreign companies on Tribunal approval) and the "previous year" basis of the Income-tax Act. Every MIS, budget, board pack and Power BI report slices by FY, quarter and month in that order: April is month 1, Q1 is April–June, and the sequence must sort Apr, May … Mar, not alphabetically or in calendar order. Calendar-based attributes from tools built for January year-ends (Date.QuarterOfYear, default date hierarchies) silently produce the wrong quarter for Indian data. Building correct fiscal attributes at ingestion prevents an entire class of reporting errors.

Core notes

Definitions and conventions

Attribute Definition Example for 15-Feb-2026
FY end year Calendar year in which the FY ends 2026
FY start year FY end year − 1 2025
FY label "FY" + start year + "-" + last two digits of end year FY2025-26
Fiscal month April = 1 … March = 12 11
Fiscal quarter Q1 Apr–Jun, Q2 Jul–Sep, Q3 Oct–Dec, Q4 Jan–Mar Q4
Period sort key FY end year × 100 + fiscal month 202611
Month label "Feb-26" or "Feb 2026" Feb-26

Labels vary by company: "FY2025-26", "FY 25-26", "FY26" (meaning the year ending March 2026), "2025-26". Agree the house convention with management reporting and use exactly that, because labels are used as join and slicer values against budgets and prior-year data.

M implementation

let
    Source   = GL,
    WithDate = Table.TransformColumns(Source, {{"PostingDate", Date.From, type date}}),
    FYEnd    = Table.AddColumn(WithDate, "FYEndYear", each
                   Date.Year([PostingDate]) + (if Date.Month([PostingDate]) >= 4 then 1 else 0), Int64.Type),
    FYLabel  = Table.AddColumn(FYEnd, "FY", each
                   "FY" & Text.From([FYEndYear] - 1) & "-" & Text.End(Text.From([FYEndYear]), 2), type text),
    FMonth   = Table.AddColumn(FYLabel, "FiscalMonth", each
                   Number.Mod(Date.Month([PostingDate]) + 8, 12) + 1, Int64.Type),
    FQtr     = Table.AddColumn(FMonth, "FiscalQuarter", each
                   "Q" & Text.From(Number.IntegerDivide([FiscalMonth] - 1, 3) + 1), type text),
    SortKey  = Table.AddColumn(FQtr, "PeriodKey", each [FYEndYear] * 100 + [FiscalMonth], Int64.Type),
    MonthLbl = Table.AddColumn(SortKey, "MonthLabel", each
                   Date.ToText([PostingDate], [Format = "MMM-yy", Culture = "en-IN"]), type text)
in
    MonthLbl

How the formulas work:

  • FY end year: April–December belong to the FY ending the next calendar year (+1); January–March belong to the FY ending this year (+0).
  • Fiscal month: \(\text{FM} = ((m + 8) \bmod 12) + 1\), where \(m\) is the calendar month. April: \((4 + 8) \bmod 12 = 0\), so FM = 1. March: \((3 + 8) \bmod 12 = 11\), so FM = 12. Equivalent readable form: if m >= 4 then m - 3 else m + 9.
  • Fiscal quarter: \(\text{FQ} = \lfloor (\text{FM} - 1) / 3 \rfloor + 1\). Number.IntegerDivide performs the floor division for positive numbers.
  • Period sort key: an integer that sorts chronologically across years (202601 = April 2025, 202612 = March 2026, 202701 = April 2026). It is also a compact join key to a monthly budget.
  • Month label: a text label for display; never sort by it. In Power BI, set Sort by column of MonthLabel to PeriodKey or FiscalMonth.

Quarter-end dates

Indian fiscal quarters end on 30 June, 30 September, 31 December and 31 March — the same dates as calendar quarter ends. So Date.EndOfQuarter([PostingDate]) gives the correct fiscal quarter-end date, even though Date.QuarterOfYear gives the wrong quarter number (April returns 2). This is useful for SEBI LODR Reg 33 quarterly results periods, where the quarter-end date is what matters.

Where to compute

In a flat Excel output, add the attributes to the fact. In a data model, compute them once in a Calendar dimension (Week 11) and keep only the date in facts. In both cases the M is the same.

The first and last two rows are the boundary tests every implementation should pass.

Edge cases & judgement calls

  • Datetime inputs. Date.Month and Date.Year work on datetimes too, but convert to date first so that the column is a clean date for the model and for joins.
  • Century rollover in labels. Text.End(Text.From(2100), 2) gives "00"; harmless in practice, but string-based labels should be tested if long horizons (lease schedules to 2099) are modelled.
  • Thirteenth period. Some ERPs (SAP special periods 13–16) post year-end adjustments to periods beyond 12 dated 31 March. A date-based fiscal month maps them to 12; if you need to distinguish them, carry the ERP period field as well.
  • Non-standard year-ends. Subsidiaries of foreign groups may report to the parent on a December year-end; keep both calendars and label clearly.
  • Text vs number FY. Storing FY as text is fine for display; store FYEndYear as an integer for arithmetic (prior year = FYEndYear − 1).

Key takeaways

  • FY end year = calendar year + 1 for April–December, + 0 for January–March.
  • Fiscal month = Number.Mod(Date.Month(d) + 8, 12) + 1; fiscal quarter from fiscal month by integer division.
  • Use an integer PeriodKey (FY end year × 100 + fiscal month) for sorting and monthly joins.
  • Calendar quarter-end dates coincide with Indian fiscal quarter ends, but calendar quarter numbers do not.
  • Agree the FY label convention with management reporting and test boundary dates.

Practice Questions

Q1. Compute the attributes [L1]

For 5-Jan-2026, 30-Jun-2025, 1-Oct-2025 and 31-Mar-2025, compute FY end year, FY label (FY2025-26 style), fiscal month, fiscal quarter and PeriodKey.

Q2. Alternate label convention [L2]

Management uses "FY26" for the year ending 31-Mar-2026 and "Q3 FY26" for Oct–Dec 2025. Write M for both labels, typed as text, and a check query that flags any row where your label differs from the label in an imported budget file.

💡 Hint: The two-digit year in "FY26" is the FY end year.

Q3. Sort-order defect [L2]

A Power BI matrix shows months in the order Apr-25, Aug-25, Dec-25, Feb-26, Jan-26, Jul-25… Explain the cause, the Power Query column you would add and the model setting you would change.

Q4. Quarter functions trap [L2]

A colleague uses "Q" & Text.From(Date.QuarterOfYear([Date])) for fiscal quarters. Show the result for 15-May-2025 and 10-Feb-2026, explain the error, and state whether Date.EndOfQuarter has the same problem.
