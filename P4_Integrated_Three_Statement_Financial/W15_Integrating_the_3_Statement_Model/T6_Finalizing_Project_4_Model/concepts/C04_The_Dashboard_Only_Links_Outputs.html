Key concept

The Dashboard Only Links Outputs

Concept: Dashboard only links outputs; no new calculations or pasted values

Statement

Every number on the executive summary dashboard must satisfy:

\[ \text{Dashboard cell} = \text{Reference to an output cell elsewhere in the model} \]

The permitted contents of a dashboard cell are:

  1. A direct link, such as =Outputs!H12 or =FS!H45.
  2. Presentation-only formatting logic that does not create a new metric: INDEX or CHOOSE to pick a year, TEXT for commentary, IF for "n.m." display.

Not permitted: new calculations of metrics (ratios, CAGRs, FCF) that exist nowhere else, typed numbers, and values pasted from another run or file.

Explanation

The rule creates a single source of truth. If ROCE is calculated on the Outputs sheet and again on the dashboard, sooner or later someone changes one definition and not the other, and the two disagree. The reviewer then cannot tell which is right. If a number is pasted, it is correct only for the scenario and inputs at the time of pasting. It does not move when the scenario switch changes, which defeats the purpose of a live model and is a topic pitfall.

Practical architecture:

  • Outputs sheet: a calculation sheet that pulls statement lines and computes every KPI the dashboard needs (margins, EPS, FCF, net debt, ROCE, ROE, CAGRs, conversion, covenant ratios). It has the same timeline as the statements and follows normal formula rules.
  • Dashboard sheet: presentation only. Links to Outputs, selected years via INDEX(Outputs!Row, Year_Pos), charts sourced from dashboard ranges or Outputs, and commentary built with TEXT.

This separation also helps Week 16, because valuation outputs (EV, implied price) are added to Outputs and linked to the dashboard the same way. And it helps a future Power BI build, because the Outputs sheet is effectively a tidy fact table.

Detecting violations:

  • Go To Special → Constants on the dashboard. The only constants allowed are labels and year headers.
  • Formula review: dashboard formulas should be short links. Anything with arithmetic operators (/, *, - between references) is a candidate for moving to Outputs.
  • Scenario toggle: every number and chart must change when you switch from Base to Bear.
  • Inquire: "Formulas with hardcoded values" and "External references" filtered to the dashboard.
  • Chart series: check each series formula (=SERIES(…)). Static arrays such as {280,340,410} mean the data was pasted into the chart.

Commentary text: narrative such as "Revenue CAGR of 11.0%" must be built with formulas, for example ="Revenue CAGR of "&TEXT(Outputs!CAGR_Rev,"0.0%"). Typed commentary goes stale on the first input change.

Exceptions: an explicitly labelled, dated snapshot table (for example, side-by-side scenario outputs produced by a macro) is acceptable if it is marked as a snapshot, sits outside the live dashboard area, and has a staleness check (s03). Even then, a data table is preferable.

Illustration

A reviewer opens the Kaveri Consumer Ltd dashboard in the Bear case. Revenue and EBITDA change, but the "FY30E ROCE" card still shows 27.4% (the Base value). Inspection shows the card formula is =E40/E52, a fresh calculation using EBIT and capital employed rows copied as values onto a hidden helper area of the dashboard. The Outputs sheet's live Bear ROCE is 15.2%. The fix is to delete the helper area and set the card to =INDEX(Outputs!ROCE_Row, MATCH("FY30E", Outputs!Year_Row, 0)). After the fix, toggling scenarios moves the card correctly, and Go To Special shows no constants on the dashboard.

Connections

This rule implements the topic pitfall against hardcoded or pasted dashboard numbers. It applies the Week 13 formula integrity principles and the Topic 4 hardcode-hunting tools (s06 in t4) to the presentation layer. It underpins s01 (dashboard), s02 (charts sourced from live ranges) and s03 (live label and scenario panel). It mirrors the Power BI principle from Phase 3 of one semantic model feeding all visuals, and it prepares the Outputs sheet that Week 16 valuation and the Phase 6 capstone will extend.

Q2. Audit procedure [L2]

Write a 10-minute audit procedure that proves a dashboard contains only links. Cover constants, formulas with arithmetic, chart series, commentary text and scenario toggling, and state the Excel feature used at each step.

💡 Hint: Remember that charts can contain pasted arrays even when every cell is a link.
