Key concept

Goal Seek and Data Tables to Find Breaking Points

Concept: Goal Seek/data tables to find breaking points (growth at which covenant breaches)

Statement

A breaking point is the value of an input \( x \) at which an output metric \( f(x) \) hits a threshold \( k \):

\[ x^{*} \text{ such that } f(x^{*}) = k \]

For example, \( x \) might be revenue growth, \( f \) the FY28E net debt/EBITDA, and \( k \) the covenant maximum of 3.0x. The breaking point is found by:

  • Goal Seek (Data → What-If Analysis → Goal Seek): set cell = a headroom cell \( f(x) - k \), to value = 0, by changing cell = the input \( x \). Excel iterates numerically to a single solution.
  • Data tables (Data → What-If Analysis → Data Table): evaluate \( f(x) \) over a grid of \( x \) values (one-variable) or \( (x, y) \) pairs (two-variable), and read where \( f \) crosses \( k \).

Explanation

Goal Seek gives one precise answer for one input. Practical rules:

  • The "changing cell" must be a hardcoded input, not a formula. Point it at the scenario input or stress shock cell (for example, Growth_Shock), not the live selector.
  • Target a headroom cell (covenant minus ratio) so the goal is always 0 and the sign shows the direction.
  • Goal Seek finds a root, not necessarily the first. If the metric is non-monotonic (net debt/EBITDA can rise and then fall as working capital releases), start from a sensible initial value and confirm with a data table.
  • In circular models Goal Seek runs on top of iteration and may fail to converge or return a stale answer. Run it with the breaker off for a first estimate, then refine with it on. Always check the convergence check afterwards.
  • Goal Seek overwrites the input. Record the original value (or use a copy of the input cell) and restore it.

Data tables give a map across the whole range:

  • One-variable: a column of growth rates and a header row of output formulas (FY28E net debt/EBITDA, minimum DSCR, minimum cash, maximum absolute BS check). The column input cell is the growth input.
  • Two-variable: growth down the side, margin across the top, one output in the corner. This is good for "breach regions."
  • The input cell must be on the same sheet as the data table. Put the table on the inputs sheet or route the input through a cell on the table's sheet.
  • Data tables recalculate the entire model for each cell, which is slow with circularity. Use "Automatic except for data tables" and F9 when needed.
  • Include the BS check as an output column. If any row shows a non-zero check, the model is not scenario-invariant at that input, so the breaking point read from it is invalid (c05).

Interpolation: with a grid in 5% steps, linear interpolation between the two rows that straddle the threshold gives a quick estimate. Goal Seek then confirms it.

\[ x^{*} \approx x_1 + (k - f_1) \times \frac{x_2 - x_1}{f_2 - f_1} \]

where \( (x_1, f_1) \) and \( (x_2, f_2) \) are the grid points either side of \( k \).

Illustration

Bhagirathi Cables Ltd: FY28E net debt/EBITDA by uniform annual revenue growth (FY26E–FY28E), covenant ≤ 3.0x:

Growth FY28E ND/EBITDA Min DSCR Max abs BS check
+10% 1.85x 1.92x 0.000
+5% 2.30x 1.64x 0.000
0% 2.78x 1.38x 0.000
−5% 3.36x 1.15x 0.000
−10% 4.10x 0.94x 0.000

The leverage covenant is breached between 0% and −5%. By interpolation:

\[ x^{*} \approx 0\% + (3.0 - 2.78) \times \frac{-5\% - 0\%}{3.36 - 2.78} = -1.9\% \]

Goal Seek on the headroom cell refines this to −1.8%. The DSCR covenant (≥ 1.20x) breaks slightly later, near −4%. Communicated result: "a sustained revenue decline of about 2% a year breaches the leverage covenant in FY28E, before DSCR becomes binding." The BS check column confirms every row is valid.

Connections

This concept turns s06 covenant flags into management information and is the forerunner of Week 16 (w16_t5) sensitivity grids on valuation. It relies on c05 (scenario invariance), because a breaking point is only meaningful if the model balances at that input, and on the Week 13 scenario and input architecture (inputs as hardcoded cells, one location). In Phase 5 FP&A work, breaking points become "headroom" statements in lender compliance packs and downside planning memos.

Practice Questions

Q1. Set up Goal Seek [L1]

Describe, step by step, how you would use Goal Seek to find the EBITDA margin at which FY27E ICR equals the covenant of 2.5x. Name the set cell, the target value and the changing cell, and list two checks you would perform after Goal Seek finishes.

Q2. Interpolate the breaking point [L2]

A one-variable data table for Sabari Tiles Ltd shows minimum DSCR of 1.34x at revenue growth of −2% and 1.12x at −6%, against a covenant of 1.20x. (a) Estimate the breaking-point growth by linear interpolation. (b) Explain why the true breaking point may differ. (c) Describe how you would confirm it.

💡 Hint: Use the interpolation formula with the two straddling grid points.

Q3. Two-variable breach map [L3]

Design a two-variable data table showing, for growth from −20% to +20% (5% steps) and EBITDA margin from 8% to 20% (2% steps), whether any covenant is breached in any forecast year. Specify the corner formula, the input cells, how you would visualise the breach region with conditional formatting, and how you would guarantee that every cell in the table reflects a balanced model.
