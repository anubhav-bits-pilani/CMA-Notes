Key concept

Treasury Stock Method and Implied-Price Iteration

Concept: TSM: Incremental shares = Σ ITM options × (1 − Strike ÷ Price); iterate if using implied price

Statement

\[ \Delta N_{\text{TSM}} = \sum_{i \,:\, K_i < P} n_i \left(1 - \frac{K_i}{P}\right) \]

where \(n_i\) is the number of options (or RSUs or warrants) in tranche \(i\), \(K_i\) is the exercise price (the unpaid amount for warrants), and \(P\) is the share price used for the test.

When \(P\) is the DCF implied price, \(P = E \div (N + \Delta N_{\text{TSM}}(P))\). This is circular. For the set of ITM tranches \(S\), the fixed point has a closed form:

\[ P^{*} = \frac{E + \sum_{i \in S} n_i K_i}{N + \sum_{i \in S} n_i} \]

valid only if every \(i \in S\) satisfies \(K_i < P^{*}\) and every \(i \notin S\) satisfies \(K_i \ge P^{*}\).

Explanation

The TSM assumes that ITM holders exercise and pay \(n_i K_i\) to the company, and that the company uses these proceeds to buy back \(n_i K_i \div P\) shares at the price \(P\). The net shares issued are \(n_i(1 - K_i/P)\). Out-of-the-money tranches are excluded as anti-dilutive. Ind AS 33.45–47 uses the same logic for diluted EPS, but with the average market price for the period.

Which price?

  • Trading comps: CMP. No circularity.
  • DCF: the implied price, which depends on the share count. This is circular.
  • Some analysts use CMP for DCF dilution for simplicity. That understates dilution when the implied price exceeds CMP. It is acceptable only if the difference is immaterial, and it must be disclosed.

Resolving the circularity:

  1. Closed form. Assume an ITM set \(S\), compute \(P^*\), then verify each tranche's ITM status. If any status flips, update \(S\) and recompute. This converges in a few steps because \(P^*\) is monotonic in \(S\).
  2. Excel iteration. Enable iterative calculation (maximum iterations 100, maximum change 0.0001). Include a circuit-breaker cell that switches the TSM price to CMP when it is set to 0, so errors do not propagate.
  3. Manual fixed-point. Run 3–4 explicit iteration columns (price 1 → shares 1 → price 2 …). This is transparent and needs no iterative setting.

Prefer methods 1 or 3 in models that also run data tables (topic t5, c05), because iterative calculation combined with data tables is slow and can be unstable.

Illustration

Equity value is ₹ 4,800 crore and basic shares are 16.0 crore. The option tranches are:

Tranche Options (crore) Strike (₹)
A 0.40 120
B 0.30 290
C 0.20 320

Iteration 0. \(P_0 = 4{,}800 \div 16.0\) = ₹ 300. Tranches A and B are ITM.

Closed form with \(S = \{A, B\}\). \(P^* = (4{,}800 + 48 + 87) \div 16.70\) = ₹ 295.5. Tranche B's strike of ₹ 290 is still below ₹ 295.5, so B remains ITM. Tranche C's strike of ₹ 320 is above, so C remains OTM. The solution is stable.

\(\Delta N\) = \(0.40(1 - 120/295.5) + 0.30(1 - 290/295.5)\) = 0.238 + 0.006 = 0.244 crore. Diluted shares are 16.244 crore, giving ₹ 4,800 ÷ 16.244 = ₹ 295.5, which matches the closed form.

A spreadsheet that tested ITM status at CMP of ₹ 250 would have excluded tranche B entirely. Here that hardly matters, but it shows why the test price must be the same price you are solving for.

Practice Questions

Q1. Status flip during iteration [L2]

Equity value is ₹ 9,000 crore and basic shares are 30.0 crore. Tranches: 1.0 crore at ₹ 200; 0.8 crore at ₹ 295; 0.5 crore at ₹ 305. Start from \(P_0 = E/N\) and find the stable implied price and ITM set using the closed form. Show each step.

💡 Hint: Start with the set that is ITM at \(P_0\), then re-test after each recomputation.

Q2. Excel design choice [L2]

Your Project 5 model runs two 2D data tables on implied share price. Compare enabling iterative calculation, the closed form with an ITM check, and a 4-column manual iteration as ways to handle TSM circularity. Recommend one, covering speed, auditability and stability.

Q3. Warrants with partial payment [L1]

A preferential issue under SEBI ICDR allotted 0.5 crore warrants at ₹ 400, with 25% received upfront. Your implied price is ₹ 520. Compute the TSM incremental shares. Explain why the upfront amount is excluded from the strike, and where that cash already appears in the bridge.
