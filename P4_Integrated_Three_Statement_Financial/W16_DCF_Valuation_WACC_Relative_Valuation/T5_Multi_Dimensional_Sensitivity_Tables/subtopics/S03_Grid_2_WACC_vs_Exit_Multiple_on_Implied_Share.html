Grid 2: WACC vs Exit Multiple on Implied Share Price

Scope: Grid 2: WACC vs exit multiple on implied share price

Why it matters

Bankers and private-equity investors often think of terminal value as "what will someone pay for this business in year n". That is the exit-multiple method. Grid 2 shows implied share price across a range of WACCs and terminal EV/EBITDA multiples. It complements Grid 1, because the two grids rely on different assumptions: perpetuity economics versus market pricing. If the two grids overlap, the valuation is triangulated. If they diverge sharply, either the implied growth in the exit multiple or the implied multiple in the Gordon TV is unreasonable. The debate is especially live in India, where current consumer and specialty multiples (40–60× EBITDA) are far above mature-state levels.

Core notes

Specification

Element Standard choice Rationale
Output Implied share price (₹) Same output as Grid 1 for comparability
WACC axis Base ±100 bp, 50 bp steps (across) Same axis as Grid 1, so the grids can be read side by side
Multiple axis Base ±2.0× in 1.0× steps (or ±20% of base) Covers the peer interquartile range (topic t6)
Base multiple Mature-state peer median EV/EBITDA, not today's elevated multiple Topic t3, s03
Centre Base WACC × base multiple Proof of wiring

Mechanics

The terminal value under the exit method is:

\[ TV_n = EBITDA_n \times M \]

where \(M\) is the exit EV/EBITDA multiple. It is discounted at the end-year exponent \(s + N\) (topic t3, c05), because a multiple prices the business at a point in time.

WACC affects only the discounting of the TV and of the explicit flows, not the TV itself. Grid 2 is therefore much less sensitive to WACC than Grid 1. Each WACC step moves value modestly, while each 1× multiple step moves it substantially.

Wiring

  1. Create a driver cell for the exit multiple on the DCF sheet. Using offsets, D7 = 0.0× and the model multiple = =Comps!Median_EV_EBITDA_Mature + D7. Alternatively, make it an absolute input documented against the comps.
  2. Use the same WACC driver D5 as Grid 1.
  3. Make sure the TV toggle (Gordon vs exit) feeds the price cell used in Grid 2. Either have a separate output cell Implied_Price_Exit, or set the TV method switch inside the table's corner formula. The cleaner approach is two parallel TV and price calculations, so that both grids can run without toggling.
  4. Set up the headers: WACC offsets across, multiple offsets (−2×, −1×, 0, +1×, +2×) down.
  5. Run the Data Table with row input $D$5 and column input $D$7.

Shakti Auto Components has FY31 EBITDA of ₹ 1,700 crore and a base exit multiple of 10.0×. Values are ₹ per share, holding diluted shares constant.

8.0× 476 467 458 449 441
9.0× 523 513 504 494 485
10.0× 571 560 549 539 529
11.0× 618 607 595 584 573
12.0× 666 653 641 628 616

The grid supports several observations:

  • Each 1× multiple step moves price by about ₹ 46, roughly 8%. Each 50 bp WACC step moves it by only about ₹ 10.
  • The centre (₹ 549) is close to the Gordon centre (₹ 550). The base growth of 5.5% and the base multiple of 10.0× are therefore mutually consistent, which is the triangulation outcome you want.
  • A user who instead picked today's peer multiple of, say, 16× would get a price far above the Gordon grid. That signals an implied perpetual growth rate above the cap (topic t3, s04).

Supplementary rows

Add a row showing the implied perpetuity growth for each multiple at base WACC:

\[ g_{\text{implied}} = \frac{TV \times WACC - FCFF_n}{TV + FCFF_n} \]

This uses the end-year form consistent with the TV timing (topic t3, c04). Flag any cell where \(g_{\text{implied}} > R_f\) or exceeds long-run nominal GDP growth.

Also add a row for TV % of EV. Exit-multiple TVs often push this above 80%.

Choosing the multiple range

  • Anchor on mature-state multiples. Use the comps' interquartile range for slower-growth peers, the company's own long-term average, or precedent transactions adjusted for control premium.
  • Do not anchor on today's multiple for high-growth names, because the terminal year represents a mature business.
  • Use the same basis as terminal EBITDA. A post-116 EBITDA needs a post-116 multiple (topic t6, s05).
  • LTM vs forward multiple. A terminal multiple applied to year-n EBITDA is effectively an LTM multiple at the end of year n. If the comps median is forward (FY+1), either apply it to \(EBITDA_{n+1}\) or convert it.

Edge cases & judgement calls

  • Cyclical businesses (steel, chemicals). Apply the multiple to mid-cycle EBITDA, not the terminal year's forecast if that is a peak or trough.
  • Capex-heavy vs asset-light peers. EV/EBITDA ignores capex intensity. Consider an EV/EBIT grid if peers' D&A ratios differ widely.
  • Holding the multiple fixed while WACC changes is logically inconsistent in theory (a higher WACC should lower market multiples), but it is the market convention. Note this in the footnote.
  • Mixed TV presentations. If the published price blends Gordon and exit TVs, run a grid on the blended price as well, or present both grids with their weights.
  • Negative terminal EBITDA (turnaround cases). The exit multiple is meaningless, so use Gordon only.

Key takeaways

  • Grid 2 flexes WACC and the exit multiple on implied price. The multiple axis dominates.
  • Base the multiple on mature-state comps on a consistent Ind AS 116 basis, not on today's elevated multiples.
  • Discount the exit TV at the end-year exponent and show implied g and TV % rows.
  • Overlap between the Grid 1 and Grid 2 centres is the triangulation test. Explain any divergence.
  • Use the same WACC driver and axis as Grid 1 so the two grids read side by side.

Q2. Divergent grids [L3]

Q3. LTM vs forward multiple mismatch [L1]
