Key concept

Data Table Input Cells Must Be on the Same Sheet

Concept: Input cells must sit on the same sheet as the table; put WACC/g/multiple drivers on the DCF sheet

Statement

The Row and Column input cells of a data table must be on the same worksheet as the table. If you select an input cell on another sheet, Excel returns "Input cell reference is not valid".

Design rule: on the sheet that hosts the sensitivity grids (normally the DCF sheet), create one driver cell per sensitised variable:

  • WACC, or a WACC offset
  • terminal growth g, or a g offset
  • exit multiple, or a multiple offset
  • revenue-growth and margin deltas

Every model formula that uses the variable must reference that driver, directly or indirectly.

Explanation

Integrated models usually calculate WACC on a WACC tab, hold g in an inputs sheet, and source exit multiples from a comps sheet. The data table cannot point at those cells. There are three design patterns.

Pattern How Pros Cons
Offset drivers on the DCF sheet (recommended) DCF!D5 = 0 (WACC offset). Model WACC = WACC!C25 + DCF!D5 WACC tab stays live; grid auto-centres; scenario-proof Readers need a display row showing absolute values
Absolute drivers on the DCF sheet DCF!D5 = 12.0% (hardcoded or a "selected WACC"). WACC tab result shown alongside for reference Simple to read Hardcoding breaks the live link. A link formula in the input cell is not a clean input
Tables on the inputs sheet Place grids where the drivers already live No new drivers Clutters the input sheet. Breaks the inputs/calcs/outputs separation

Cross-sheet dependents are fine. The restriction applies only to the input cell's location. The assumptions sheet can reference DCF!$D$8 (for example, a revenue-growth delta), and the table on the DCF sheet still flexes it (topic t5, s04). Model chains running through any number of sheets recalculate correctly during table substitution.

All uses must route through the driver. The table substitutes values into the driver cell only. If the TV formula references WACC!C25 directly while the discount factors reference the DCF-sheet WACC, the grid flexes discounting but not the TV. That gives wrong values with no error message. Use Trace Dependents on the driver cell, or search with Find (Ctrl+F, "Look in: Formulas") for direct references to WACC!C25. Every hit outside the driver formula is a leak.

Hardcoded constants inside formulas. For example =E20/(1.12)^E12, or a 0.055 typed inside the TV formula. These are the same leak in another form, and correspond to the topic pitfall "WACC hardcoded inside discount formulas".

Illustration

Here is the DCF-sheet driver block for Project 5.

Cell Label Value Used by
D5 WACC offset 0.00% WACC_used = WACC!C25 + D5
D6 g offset 0.00% g_used = Inputs!C40 + D6
D7 Exit multiple offset 0.0× Mult_used = Comps!K30 + D7
D8 Revenue growth delta 0.0 pp Assumptions growth rows: +DCF!$D$8
D9 EBITDA margin delta 0 bp Assumptions margin rows: +DCF!$D$9
D11 Check: all offsets zero TRUE =AND(D5=0,D6=0,D7=0,D8=0,D9=0)

The D11 check matters. If a user types a non-zero offset to test something and forgets to reset it, the base case is silently changed. Wire D11 into the master check.

Connections

  • This concept is the build rule behind subtopics s01–s04.
  • It prevents the topic pitfall on hardcoded WACC.
  • It supports the exercise requirement that grids stay live to the Project 4 scenario switch, because the offsets apply around whatever the scenario produces.
  • It links to Phase 3 model-design principles: inputs, calculations and outputs separation, and single-point-of-entry drivers.

Practice Questions

Q1. Leak hunt [L2]

A DCF sheet's WACC driver is DCF!E4. Searching formulas for WACC! returns: E4 (=WACC!H30 + E5), the TV formula =K20*(1+g)/(WACC!H30-g), and the mid-year factor row =1/(1+$E$4)^F14. Identify each leak. Write the corrected formulas. Describe the grid symptom the leak would have produced.

💡 Hint: Ask which formulas would respond when Excel substitutes values into E4.

Q2. Design for a separate sensitivity sheet [L2]

Your firm's template requires all grids on a "Sensitivities" sheet. Design the driver cells and links so that Grids 1–3 work there, while the DCF and WACC tabs remain the calculation sheets. Explain how the inputs/calcs/outputs separation is preserved.

Q3. Offset reset control [L1]

Write the check formula and conditional format that flag when any sensitivity offset is non-zero. Explain why this check belongs in the model's master check rather than only next to the grids.
