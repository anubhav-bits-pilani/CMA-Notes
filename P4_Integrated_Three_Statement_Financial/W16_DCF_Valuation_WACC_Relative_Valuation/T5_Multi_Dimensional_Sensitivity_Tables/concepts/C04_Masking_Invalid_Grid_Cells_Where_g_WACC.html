Key concept

Masking Invalid Grid Cells Where g ≥ WACC

Concept: Mask invalid cells where g ≥ WACC with an adjacent =IF(g>=WACC,"n.m.",…) presentation grid

Statement

The Gordon terminal value is

\[ TV = \frac{FCFF_n (1+g)}{WACC - g} \]

It is defined and economically meaningful only when \(WACC - g > 0\), and in practice only when the spread is comfortably positive. For any grid cell with \(g_i \ge WACC_j\), the value is undefined (division by zero) or negative.

The raw TABLE() body cannot be edited, so build an adjacent presentation grid that mirrors it:

=IF($H21>=I$20, "n.m.", I21)

Here $H21 is the g header, I$20 is the WACC header, and I21 is the raw table cell. With offset axes, compare the absolute values instead, for example =IF(gBase+$H21>=WACCBase+I$20,"n.m.",I21).

Explanation

Why not fix it inside the model? You can wrap the TV in =IF(WACC<=g, NA(), …) so the raw table returns #N/A. That still leaves error values, or a misleading zero if you use IFERROR(…,0), in a client-facing grid. The robust design is:

  1. Raw table, hidden or placed off-print. It contains the TABLE() array and may show errors.
  2. Presentation grid, placed visibly. It contains the IF masking and number formats, and is the only grid that is printed.

Extend the mask beyond the strict boundary. A spread of only 50–100 bp produces absurd TVs (implied multiples above 50×) even when the value is technically valid. A practical rule masks or flags cells where \(WACC - g < \text{min spread}\), for example 2.0%, or where the implied g exceeds Rf (topic t3, s02):

=IF((WACC_j - g_i) < Min_Spread, "n.m.", IF(ISERROR(I21), "err", I21))

Exit-multiple grids rarely need masking, but negative terminal EBITDA or negative equity value in the bridge should show "n.m." rather than a negative price. Use =IF(I21<=0,"n.m.",I21).

Colour scales ignore text cells. Masked cells drop out of the heat map automatically. Grey them with a text-based rule (topic t5, s05).

Statistics on grids. When summarising a range for the football field (min and max of the grid), use =MIN(...) and =MAX(...) on the presentation grid, which ignore text. Alternatively use AGGREGATE(15,6,range,1) on the raw grid to ignore errors.

Illustration

A regulated utility has base WACC 9.0% and base g 6.0%. The grid has WACC from 8.0% to 10.0% across and g from 5.0% to 7.0% down, with a minimum spread of 2.5% (chosen for this low-WACC utility).

g ↓ / WACC → 8.0% 8.5% 9.0% 9.5% 10.0%
5.0% 412 357 316 284 258
5.5% 488 405 350 310 279
6.0% n.m. 474 396 343 305
6.5% n.m. n.m. 465 389 337
7.0% n.m. n.m. n.m. 459 381

Values are ₹ per share and illustrative. Cells with a spread below 2.5% are masked.

Without masking, the 7.0%/8.0% cell (spread 1.0%) would show a TV around 107× terminal FCFF. A reader might quote it as a "bull case". Masking prevents a meaningless number being presented as a valuation.

Connections

  • This concept builds on topic t3, s02 (g caps) and c01 (the Gordon formula).
  • It feeds the football-field DCF bar (topic t6, s08), where min and max should come from the masked grid.
  • It relates to s05 (formatting n.m. cells) and c02. The centre cell is never masked, and if it were, the base case itself would be invalid.
  • In practice, consumer and utility DCFs with low WACCs and high g are the usual candidates for masking.

Practice Questions

Q1. Write the masking formulas [L1]

A raw grid has its body in I21:M25, absolute WACC headers in I20:M20, and g headers in H21:H25. Write the presentation-grid formula for cell I31 (mirroring I21). It should show "n.m." if \(WACC - g < 2\%\), "err" if the raw cell is an error, and the value otherwise.

Q2. Spread threshold judgement [L2]

For a consumer-staples DCF with a base WACC of 10.5% and g of 6.0%, argue for a minimum spread threshold (1.5%, 2.0% or 3.0%). Explain how the choice affects the football-field DCF range. Explain how you would document it.

💡 Hint: Translate each spread into an implied terminal EV/EBITDA using a plausible FCFF/EBITDA conversion.

Q3. Football-field range from a masked grid [L2]

Explain why using MIN and MAX on the raw table (with errors or negative values) for the football-field DCF bar is wrong. Write the correct formulas using either the presentation grid or AGGREGATE.
