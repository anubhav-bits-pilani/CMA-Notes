Key concept

Football Field Chart Mechanics: Stacked Bar with Invisible Low

Concept: Football field: stacked bar with invisible "Low" series plus visible "High − Low" series and CMP line

Statement

For each valuation method \(i\) with range \([L_i, H_i]\) in ₹ per share, the football field plots a horizontal stacked bar made of two series:

\[ \text{Series 1 (invisible)} = L_i, \qquad \text{Series 2 (visible)} = H_i - L_i \]

The visible segment therefore starts at \(L_i\) and ends at \(H_i\). A vertical reference line at \(x = \text{CMP}\) (and, optionally, at the offer price or blended point estimate) is overlaid using a scatter series on secondary axes, with points \((\text{CMP}, 0)\) and \((\text{CMP}, 1)\).

Explanation

Excel has no native "floating bar" chart type. The stacked-bar trick creates one:

  • Invisible Low series. Format it with No fill and No line. It pushes the visible bar out to the right by the low value.
  • Visible Spread series. Format it with a fill. Its length equals the range width.
  • Category axis. Each method is a category. Set "Categories in reverse order" so the first row of the data appears at the top.
  • Value axis. Fix the minimum and maximum (for example ₹ 300 and ₹ 800). Starting at zero would compress the bars. Excel's native chart axes cannot link to cells, so update them manually or with a small macro when ranges move a lot.
  • CMP line. Add a new series and change its chart type to "Scatter with Straight Lines". Use X values ={405,405} and Y values ={0,1}, plot it on the secondary axes, set the secondary vertical axis to 0–1, and hide it. Make sure the secondary horizontal axis matches the primary value axis (or delete it, so the scatter uses the primary X scale). Label the line "CMP ₹ 405 (30-Sep-26)".
  • Labels.
  • Low label: add data labels to the invisible series, positioned "Inside End" (this shows \(L_i\) next to where the visible bar starts).
  • High label: on the visible series, use "Value From Cells" pointing to the \(H_i\) column, positioned "Inside End" or "Outside End".
  • Alternatives:
  • error bars (custom plus and minus values) on a scatter or bar series can draw ranges
  • Excel 365's floating-bar workaround with the up/down bars of a line chart
  • in Power BI, a stacked bar visual with a transparent first series, or a custom visual

Live linking. The chart data block references the model:

  • Low: =MIN(DCF!Grid1_Inner)
  • High: =MAX(DCF!Grid1_Inner)
  • Spread: =High-Low

The chart updates after F9 when the scenario changes (topic t5, s06).

The CMP line uses X = {405, 405} and Y = {0, 1}.

To build it:

  1. Select A1:C7.
  2. Insert → Bar → Stacked Bar.
  3. Format the Low series with no fill.
  4. Colour the Spread series: dark blue for the DCF bars, teal for comps, grey for precedents and 52-week.
  5. Reverse the categories.
  6. Set the value axis to 300–800.
  7. Add the CMP scatter line and the labels.
