Key concept

Copy-Paste Macro for Solving Interest Without Circularity

Concept: Copy-paste macro: paste interest values to a helper row, recalculate, loop until |Δ| < tolerance

Statement

Let \(I^{(k)}_t\) be the interest values pasted into a helper row at macro pass \(k\), and \(\hat{I}^{(k)}_t\) the live interest calculated by the model when it uses those pasted values. The macro repeats

\[ I^{(k+1)}_t = \hat{I}^{(k)}_t \quad \text{for all } t \]

until

\[ \max_t \left\lvert \hat{I}^{(k)}_t - I^{(k)}_t \right\rvert < \varepsilon \]

or a maximum pass count \(K\) is reached, where \(\varepsilon\) is the tolerance (for example ₹0.0001 crore), and \(t\) runs over all forecast periods.

Explanation

The model's P&L uses the helper row (values) as interest. The live row calculates what interest would be given the resulting closing debt, e.g. =Rate*AVERAGE(Open_Debt,Close_Debt). Because the P&L reads values, not the live row, there is no formula loop — the circularity is moved out of the worksheet into the macro. Each pass is one manual iteration; the macro is simply a scripted version of what Excel's iteration engine does.

Typical structure:

  1. Rows: Interest_Live (formula), Interest_Paste (values), Interest_Diff (= live − paste), and a status cell.
  2. Macro: set calculation to manual; loop — copy Interest_Live values into Interest_Paste; Application.Calculate; test MAX(ABS(Interest_Diff)) against tolerance; exit when below; restore automatic calculation; write status ("Converged in 4 passes" or "NOT converged").
  3. Worksheet check: a cell =MAX(ABS(Interest_Diff))>Tol that turns red when inputs change after the last macro run — the stale flag.

Note the |Δ| uses absolute value because the difference may be positive or negative; in a worksheet use =MAX(ABS(range)) entered as a dynamic-array formula (Microsoft 365) or =SUMPRODUCT(ABS(range)) as a total-change metric.

Why use it: no circular references (FAST-friendly, s06); errors cannot be trapped because pasted values replace any error on the next good pass; iteration can stay off application-wide (c03), so unintended circularities remain visible. Costs: requires .xlsm and macro permissions; results are stale until rerun; the Undo stack is cleared by macro execution; Data tables cannot run the macro per cell, so sensitivities need a scenario macro that calls the solver inside its own loop.

Paste interest or paste debt? Either works. Pasting closing debt and computing interest live from it is equivalent. Pasting interest is usually simpler because there is one row per tranche and the diff check is directly in rupees of P&L impact.

Illustration

Revolver: opening ₹90 crore; pre-interest funding need ₹40 crore; rate 10%; tax 25.168%. Helper row starts at zero.

Pass Pasted interest (₹ cr) Closing revolver Live interest |Δ|
0 0.000 130.000 11.000 11.000
1 11.000 138.232 11.412 0.412
2 11.412 138.540 11.427 0.015
3 11.427 138.551 11.428 0.001
4 11.428 138.552 11.428 < 0.0001

The macro stops after pass 4 with interest of ₹11.428 crore — the same fixed point Excel's iteration would reach.

Q2. Manual passes [L2]

Opening revolver ₹150 crore; funding need ₹–30 crore (a surplus used to repay); rate 9.75%; tax 25.168%. Starting with pasted interest equal to opening-balance interest, perform three macro passes by hand and report the absolute change at each pass.

💡 Hint: A surplus reduces the revolver; post-tax interest still adds to the funding need.
