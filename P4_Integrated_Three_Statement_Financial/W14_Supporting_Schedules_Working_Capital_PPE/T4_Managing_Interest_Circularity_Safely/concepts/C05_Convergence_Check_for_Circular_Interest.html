Key concept

Convergence Check for Circular Interest

Concept: Convergence check: compare interest on two successive iterations or vs paste-values row

Statement

A circular model has converged when interest (and every other loop-closing value) no longer changes between successive iterations:

\[ \max_{t,\,j} \left\lvert I^{(k)}_{t,j} - I^{(k-1)}_{t,j} \right\rvert < \varepsilon \]

where \(I^{(k)}_{t,j}\) is interest on tranche \(j\) in period \(t\) after iteration \(k\), and \(\varepsilon\) is the tolerance (e.g., ₹0.001 crore). In practice the test is implemented either as (a) successive-iteration comparison — store the previous iteration's value and compare with the current; or (b) paste-values comparison — compare live interest with a pasted snapshot (as in the copy-paste macro, c02). The check result is a 0/1 flag feeding the master check.

Explanation

Excel does not report when iteration stops because the maximum-iterations cap was hit rather than because the maximum-change criterion was met (s03). A model can therefore show plausible numbers that have not converged — particularly when MIN/MAX regime switches cause oscillation (revolver flipping between draw and repay, sweep cap binding then not binding). The convergence check turns "it looks fine" into evidence.

Method (a): successive-iteration comparison. The simplest form is manual: note total interest, press F9 once more, and compare. Automated versions use a "lag" cell placed so that it is evaluated before the live total within each iteration and therefore holds the previous pass's value; the check is then =ABS(Total_Int-Lag_Int)>Tol. Because it depends on Excel's internal calculation order and works only with iteration on, it is fragile; many modellers prefer method (b) or the manual tests below.

Method (b): paste-values row. Keep a row Int_Snapshot of pasted values from the last confirmed run. Check:

=IF(MAX(ABS(Int_Live-Int_Snapshot))>Tol, 1, 0)

(entered as a dynamic-array formula in Microsoft 365, or with SUMPRODUCT of absolute differences in older versions). After any change, press F9 twice and repaste; if the second F9 moves results beyond tolerance, the model is still moving.

Manual tests every reviewer can run:

  1. Press F9 several times — outputs must not change.
  2. Temporarily set Maximum Iterations to 1 and press F9 repeatedly, watching interest converge; the number of presses needed indicates loop speed.
  3. Compare with the closed-form result for a simple year (s05).
  4. Switch breaker 1 → 2 → 1 and confirm outputs return exactly to the original values (path independence). If they return to different values, the loop has multiple fixed points or is oscillating — a regime-switch problem.

What to check besides interest. Closing debt per tranche, closing cash, revolver draw and sweep amounts. Interest can be converged while a revolver oscillates between two equal-interest states only by coincidence, but checking balances is cheap.

Illustration

FY29E revolver near zero: iteration 98 shows revolver closing ₹4.2 crore and interest ₹12.611 crore; iteration 99 shows closing ₹0.0 crore and interest ₹12.402 crore; iteration 100 shows ₹4.2 crore and ₹12.611 crore. Excel stops at the cap. The displayed FY29E interest depends on whether the final iteration was even or odd. The paste-values check shows a difference of ₹0.209 crore (above the ₹0.001 tolerance) and flags 1. Root cause: the sweep uses cash before revolver repayment, so when the revolver is repaid the sweep increases, cash falls, and the revolver redraws. Fix: sequence the waterfall so the revolver is repaid first and the sweep uses cash after revolver (t3 c04), then re-check — difference ₹0.000 crore, flag 0.

Practice Questions

Q1. Build the check row [L1]

Write the worksheet formulas for a paste-values convergence check across five forecast years and three tranches, with a tolerance input of ₹0.001 crore, returning 1 if any cell fails. Explain how the flag feeds the master check.

Q2. Diagnose oscillation [L3]

In a model with a revolver and a 75% cash sweep, FY30E interest alternates between ₹18.44 crore and ₹18.97 crore on successive F9 presses. Explain two waterfall-design causes of such oscillation, how you would confirm the cause, and how you would redesign the logic.

💡 Hint: Look at whether the sweep and revolver use the same cash line and in what order.

Q3. Path-independence test [L2]

Describe the breaker 1 → 2 → 1 test, what result you expect for a well-behaved model, and what it means if FY28E closing debt returns as ₹412.6 crore instead of the original ₹409.8 crore.
