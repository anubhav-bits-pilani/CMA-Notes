Key concept

Circuit-Breaker Interest Formula

Concept: Breaker: =IF(Circ=1,Rate*AVERAGE(Open_Debt,Close_Debt),Rate*Open_Debt) or zero when off

Statement

Interest for each tranche in period \(t\) is computed through a switch \(C\):

\[ I_t = \begin{cases} r_t \times \dfrac{D_{t-1} + D_t}{2} & \text{if } C = 1 \ (\text{circular}) \\[4pt] r_t \times D_{t-1} & \text{if } C = 2 \ (\text{opening balance}) \\[4pt] 0 & \text{if } C = 0 \ (\text{off}) \end{cases} \]

where \(I_t\) is interest expense, \(r_t\) the period interest rate, \(D_{t-1}\) opening debt (prior closing), \(D_t\) closing debt and \(C\) the breaker switch cell. In Excel the two-state version is

=IF(Circ=1, Rate*AVERAGE(Open_Debt,Close_Debt), Rate*Open_Debt)

and the zero-when-off version replaces the false branch with 0.

Explanation

The switch converts the loop into a choice. When \(C = 1\), interest depends on closing debt, which depends on cash after interest — the loop is live and iteration must be enabled. When \(C\) is anything else, interest depends only on opening debt (known before the period) or on nothing at all, so the model is a straight dependency chain that Excel calculates in one pass.

Which "off" state to use. The roadmap allows either opening-balance or zero as the off state:

  • Opening-balance off-state keeps outputs realistic (understatement or overstatement ≈ Rate × ΔDebt ÷ 2, see c04). It is best for data tables and for users who cannot enable iteration.
  • Zero off-state guarantees the loop and any error in it are completely flushed, and isolates financing from operating issues when debugging imbalances. It must never be the presented state.

A three-state switch supports both, as shown in the Statement.

Implementation rules:

  • One named cell (Circ), on Cover or Inputs, with data validation restricting it to the allowed values.
  • Every loop-closing formula references it: interest on revolver and swept tranches, commitment fees, interest income on cash.
  • Ratios that use interest and sit inside the loop must be guarded against the zero state (IF(Interest=0,…)).
  • A status label and conditional formatting showing the current mode.

Why AVERAGE rather than (Open+Close)/2: functionally equivalent for two numbers; AVERAGE reads more clearly. Note that AVERAGE ignores blank cells — if Close_Debt were ever blank, AVERAGE would return opening debt silently, whereas (Open+Close)/2 would return half of opening. Neither is a substitute for proper links; check for blanks.

Illustration

Term loan B: opening ₹640 crore; mandatory repayment ₹80 crore; cash sweep ₹65 crore (converged); closing ₹495 crore; rate 9.4%.

Circ Formula branch Interest (₹ crore)
1 9.4% × (640 + 495) ÷ 2 53.35
2 9.4% × 640 60.16
0 0 0.00

Switching from 1 to 2 raises FY27E interest by ₹6.81 crore and cuts PAT by about ₹5.10 crore at the 25.168% rate — before second-round effects on the sweep. (With the switch on 2, the sweep itself would be smaller because more cash goes to interest, so the closing balance would also change.)

Practice Questions

Q1. Write the formula family [L1]

Using Circ, Rate_TLA, TLA_Open, TLA_Close, write the three-state interest formula with IF and with CHOOSE. State one advantage of each.

Q2. Off-state choice [L2]

Revolver: opening ₹25 crore, converged closing ₹110 crore, rate 10.0%. Compute interest in each of the three switch states, the PAT difference between states 1 and 2 at 25.168% tax, and say which off-state you would use for a 9 × 9 WACC/terminal-growth data table, with reasons.

Q3. Blank-cell behaviour [L2]

The closing-debt cell for FY31E is accidentally blank. Compare what =Rate*AVERAGE(Open,Close) and =Rate*(Open+Close)/2 return with opening ₹300 crore and rate 9%, and propose a check that would catch the blank.
