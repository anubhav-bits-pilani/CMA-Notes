Excel Iterative Calculation Settings for Circular Models

Scope: Excel iteration settings: File → Options → Formulas → Enable iterative calculation, 100 iterations, max change 0.001

Why it matters

A circular model will not calculate at all until iteration is enabled — Excel shows a circular-reference warning and returns zero or the last value in the looped cells. Once iteration is enabled, the two parameters (maximum iterations and maximum change) decide how far Excel goes before stopping and whether it stops at a converged answer. Getting the settings wrong produces models that look fine but carry unconverged numbers, or models that take a minute to recalculate. In a modelling test or interview, being able to state the path and sensible values without hesitation signals that you have actually built circular models.

Core notes

Where the setting lives

  • Windows Excel (Microsoft 365, 2019, 2016): File → Options → Formulas → Calculation options → tick Enable iterative calculation → set Maximum Iterations and Maximum Change → OK.
  • Mac Excel: Excel → Preferences (Settings) → Calculation → tick Use iterative calculation → set Maximum iterations and Maximum change.
  • Excel for the web: File → Options → Formulas (availability depends on version and tenancy settings); test before relying on it for client delivery.
  • VBA: Application.Iteration = True, Application.MaxIterations = 100, Application.MaxChange = 0.001.

What the two parameters mean

Parameter Default Meaning Recommended
Maximum Iterations 100 Upper bound on loop recalculations per recalc event 100 (enough for a damped loop; raising it hides problems)
Maximum Change 0.001 Excel stops early when no cell in the loop changes by more than this between iterations 0.001 in the model's units; tighten to 0.0001 if units are ₹ crore and precision matters

Excel stops when either condition is met: the maximum change across looped cells falls below the threshold, or the iteration count is reached. Excel gives no warning when it stops because of the iteration cap without having converged — which is why the convergence check (c05) is mandatory.

Units matter for maximum change

Maximum change is an absolute number, not a percentage. In a model in ₹ crore, 0.001 means ₹1 lakh — adequate. In a model in ₹ (rupees), 0.001 means one-tenth of a paisa — Excel may hit the iteration limit chasing meaningless precision on large balances, though for a damped loop it will still converge. In a model in ₹ lakh, 0.001 = ₹100. Choose the threshold with the units on the Cover tab in mind.

Calculation mode interaction

  • Automatic: each edit triggers a recalc, which runs the loop up to the cap. Normal setting for most models.
  • Automatic except for data tables: recommended for models with large sensitivity tables; press F9 to refresh the tables.
  • Manual: each F9 runs the loop once up to the cap. If the cap is reached without convergence, pressing F9 again continues from where it stopped — values drift towards convergence with each press, which can mislead a reviewer comparing printouts.

Why 100 iterations and not 1,000 or 10

A well-built damped loop converges in fewer than 10 iterations (s01 multiplier analysis). Setting 100 gives headroom for multi-tranche models with several interacting MIN/MAX regimes. Setting 1,000 or 32,767 (the maximum) does not improve accuracy for a converging loop; it only lengthens recalculation when the loop fails to converge, masking the failure as slowness. Setting 1 iteration turns each recalculation into one step of the loop — sometimes used deliberately with manual calculation to watch convergence, but never as a delivery setting.

Deliberate settings checklist for a circular model

  1. Build the model with iteration off and the breaker set to opening-balance mode — catch unintended circularity while building.
  2. When the debt schedule is complete, enable iteration (100, 0.001) and switch the breaker on.
  3. Confirm convergence with the check row (c05).
  4. Record the settings on the Cover: "This model contains an intended circular reference (interest on average debt and cash). Iterative calculation must be enabled: 100 iterations, maximum change 0.001. Breaker cell: Cover!F12."
  5. Optionally add a Workbook_Open macro that sets the parameters and warns if iteration is off — remembering the application-level issue (c03).

Visual cue in the workbook

Add a cell on the Cover that reports whether iteration is active. There is no worksheet function that reads the setting directly, but a tiny intentional test loop can reveal it, or a VBA user-defined function returning Application.Iteration can be used in macro-enabled files. Many teams simply display the breaker state and a text instruction.

Illustration

A ₹ crore model with a revolver loop; true FY28E interest at convergence ₹42.3765 crore. With max change 0.001, Excel stops when successive interest values differ by less than ₹0.001 crore; at a multiplier of 0.035 per iteration starting from opening-balance interest of ₹38.0 crore, iterations go 38.0 → 42.22 → 42.371 → 42.3763 → 42.3765, stopping by the fifth pass. If units were rupees (₹423,765,000), the same threshold requires roughly four further passes — still trivial for a damped loop.

Edge cases & judgement calls

  • Settings shared with other workbooks: iteration is application-level (c03); opening a client file first may override your settings. Check after opening.
  • Excel Online/co-authoring: iterative behaviour in co-authoring sessions can differ; deliver circular models as desktop files with explicit instructions.
  • Power Query/Power Pivot loads: a refresh triggers recalculation of the whole loop; large models slow noticeably.
  • Google Sheets: has its own iterative-calculation setting (File → Settings → Calculation), with different defaults; models converted to Sheets need re-checking.
  • Precision and floating point: even converged values may show tiny differences at the 10th decimal; checks should use a tolerance, not equality.
  • Changing settings mid-review: a reviewer who tightens max change to 0.000001 and sees numbers move by more than tolerance has found an unconverged model.

Key takeaways

  • Path: File → Options → Formulas → Enable iterative calculation; Mac: Preferences → Calculation.
  • Use 100 iterations and maximum change 0.001 (in model units); higher caps hide non-convergence.
  • Excel stops silently at the iteration cap — always build a convergence check.
  • Maximum change is absolute, so interpret it in the model's units (₹ crore vs ₹).
  • Build with iteration off and the breaker on opening mode; switch on only when the debt schedule is finished.
  • Document the required settings and breaker location on the Cover tab.

Practice Questions

Q1. Settings from memory [L1]

Write the exact menu path to enable iterative calculation on Windows and Mac Excel, and state the default values of the two parameters. Write the three-line VBA equivalent.

Q2. Units and tolerance [L2]

A model is in ₹ lakh. The revolver loop has a multiplier of 0.04 per iteration; the starting error (opening vs converged interest) is ₹350 lakh. Determine how many iterations Excel will run before stopping with maximum change 0.001, and comment on whether 100 iterations is sufficient. Repeat if the multiplier were 0.95.

💡 Hint: The change after k iterations is roughly the starting error times the multiplier to the power k.

Q3. Manual calculation trap [L2]

A colleague sets calculation to manual, iteration to 5 and maximum change to 0.001, then prints the FY27E–FY31E P&L after one F9. You print it after three F9 presses. Explain why the interest lines differ and what settings you would agree for the final version.

Q4. Cover-tab documentation [L1]

Draft the Cover-tab note (maximum 80 words) for a circular LBO model, covering the settings, breaker location, its states and what a user must do if errors appear.
