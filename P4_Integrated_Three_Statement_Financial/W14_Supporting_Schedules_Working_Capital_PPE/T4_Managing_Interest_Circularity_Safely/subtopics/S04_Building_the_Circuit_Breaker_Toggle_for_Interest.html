Building the Circuit-Breaker Toggle for Interest

Scope: Circuit-breaker toggle to zero or opening-balance interest to flush errors

Why it matters

A circular model without a breaker is fragile: one error value that enters the loop feeds back into itself every iteration and never clears, even after the cause is fixed. The breaker is a single switch cell that cuts the loop by replacing average-balance interest with a non-circular alternative — zero interest or opening-balance interest — so the model recalculates in a single pass, the error is flushed out, and the loop can then be reconnected. Model auditors, lenders' technical advisors and interviewers all look for it. In live deal work it is also the tool you reach for before running data tables, before debugging a balance-sheet imbalance and before handing a file to someone whose Excel may have iteration disabled.

Core notes

Design of the switch cell

  • Location: one cell, on the Cover or Inputs tab, clearly labelled, formatted as an input (blue font / yellow fill per your colour convention), with a named range such as Circ.
  • States: at minimum 1 = circular (average-balance), 0 = off. Better practice uses three states:
Value Mode Interest formula behaviour Use
1 Circular Rate × average(opening, closing) Normal delivery mode
2 Opening balance Rate × opening Data tables, quick checks, users without iteration
0 Zero 0 Flushing trapped errors; isolating linking errors
  • Data validation: restrict to the list 0, 1, 2 (Data → Data Validation → List) so typos cannot create an undefined state.
  • Status display: a formula next to the cell such as =CHOOSE(Circ+1,"OFF – zero interest","ON – average balance","OFF – opening balance") and conditional formatting (red when not 1) so no one delivers a file with the breaker off by accident.

Where the breaker must be applied

Every cell that closes a loop must pass through the switch:

  • Interest expense on each tranche that uses closing balance (revolver, swept loans, NCDs with sweep).
  • Commitment fee on the average undrawn revolver.
  • Interest income on average cash (s02).
  • Any other formula referencing a balance that depends on post-interest cash — e.g., a DSCR-driven cash trap, an interest-cover-based dividend lock-up.

A common error is applying the switch to the revolver only. With Circ = 0 the model then remains circular through interest income; with iteration disabled Excel will still warn. The test of a complete breaker: set Circ = 0 or 2, disable iteration, recalculate — there must be no circular-reference warning.

Why zero and opening-balance modes are both useful

Opening-balance mode keeps the P&L economically sensible: interest is understated or overstated only by \(\text{Rate} \times \Delta\text{Debt} \div 2\) (c04). Use it for sensitivity tables and for sharing with users who cannot enable iteration.

Zero mode is the cleanest for error flushing: no interest cell depends on any debt balance, so the error cannot persist in interest; it also isolates whether a balance-sheet imbalance is linked to the financing block. It distorts PAT heavily, so never present outputs in zero mode.

Flushing procedure (the reason the breaker exists)

  1. Fix the underlying cause (restore the deleted reference, guard the zero denominator).
  2. Set Circ = 0 (or 2). The loop is cut; every cell recalculates in one pass from clean inputs. The trapped error disappears.
  3. Confirm all checks pass in the non-circular state.
  4. Set Circ = 1. The loop restarts from a clean seed and converges.
  5. Run the convergence check.

The full recovery routine including the case where you cannot find the cause is in s07.

Formula pattern

With three states:

=IF(Circ=1, Rate*AVERAGE(Open_Debt,Close_Debt), IF(Circ=2, Rate*Open_Debt, 0))

Or with CHOOSE (index must start at 1):

=CHOOSE(Circ+1, 0, Rate*AVERAGE(Open_Debt,Close_Debt), Rate*Open_Debt)

The IF version is more readable for reviewers. See c01 for the exact concept formula and naming discussion.

Automatic error-triggered breaker

Some models add an automatic trip: the effective switch is the user switch multiplied by an error test.

Circ_Eff: =IF(ISERROR(SUM(Debt_Block_Totals)), 0, Circ)

Interest formulas then reference Circ_Eff. If an error appears in the financing block, interest drops to zero for one calculation, which flushes the loop; on the next pass, if the error has cleared, interest reconnects. This self-heals transient errors but can hide persistent ones (the model silently runs at zero interest). If used, display Circ_Eff prominently and fail a check whenever it differs from Circ. Many reviewers prefer a purely manual switch for this reason.

Illustration

FY27E: opening revolver ₹120 crore, closing (converged) ₹146 crore, rate 9.5%; opening term loan ₹500 crore, closing ₹420 crore (scheduled), rate 8.75%.

Mode Revolver interest (₹ cr) Term-loan interest (₹ cr) Total
1 Circular 9.5% × 133 = 12.64 8.75% × 460 = 40.25 52.89
2 Opening 9.5% × 120 = 11.40 8.75% × 500 = 43.75 55.15
0 Zero 0 0 0

The term loan has a known closing balance, so its average-balance interest need not pass through the breaker — but many modellers route all tranches through the switch for a consistent opening-mode output. Whichever choice, document it. (In mode 2 the revolver closing would itself change; the table holds it constant for simplicity.)

Edge cases & judgement calls

  • Breaker in a scenario manager: if scenarios are run via a macro, force Circ = 1 at the end of the macro, otherwise the last scenario run may leave the file in opening mode.
  • Multiple breakers: avoid separate switches for each tranche; a single master switch (with optional tranche overrides) prevents half-circular states.
  • Opening-mode fidelity: for a model with heavy intra-year repayment (e.g., a bullet repaid in month 2), opening mode overstates interest materially; consider a timing factor input rather than the breaker.
  • Deliverable state: decide and document whether the delivered file is in mode 1 or 2. Investment-banking deliverables are usually mode 1; files sent to clients' finance teams without modelling experience are often mode 2 with a note.
  • Error inside the breaker formula itself: if Rate or Open_Debt is the erroring cell, the breaker will not help — the error is upstream of the switch and is not a loop issue.

Key takeaways

  • One named, validated switch cell with clear states (1 circular, 2 opening, 0 zero) and a visible status flag.
  • Route every loop-closing formula — interest expense, commitment fees, interest income, cash traps — through the same switch.
  • Test completeness: breaker off + iteration off must produce no circular-reference warning.
  • Zero mode flushes errors; opening mode keeps outputs sensible for data tables and non-iterating users.
  • Automatic error-trip breakers self-heal but can hide persistent errors; flag any difference from the user switch.
  • Never deliver a file with the breaker in an undocumented state.

Q1. Write the three-state breaker [L1]

Q2. Incomplete breaker diagnosis [L2]

With Circ = 0 and iteration disabled, Excel still warns of a circular reference in a model with a revolver, a cash sweep on the term loan, interest income on cash and a commitment fee. Q3. Mode comparison [L2]

FY28E: opening revolver ₹60 crore, converged closing ₹15 crore, rate 10.25%; commitment fee 0.40% on average undrawn amount of a ₹200 crore limit; opening cash ₹40 crore, closing ₹40 crore, yield 6.5%. Compute revolver interest, commitment fee and interest income under modes 1, 2 and 0, holding closing balances constant, and the net finance cost in each mode.

Q4. Auto-trip design review [L3]

A model uses Circ_Eff = IF(ISERROR(Total_Debt_Close),0,Circ). A reviewer finds the FY30E P&L shows zero interest while the switch reads 1. Explain how this could happen, why it is dangerous, and what check and display you would add.
