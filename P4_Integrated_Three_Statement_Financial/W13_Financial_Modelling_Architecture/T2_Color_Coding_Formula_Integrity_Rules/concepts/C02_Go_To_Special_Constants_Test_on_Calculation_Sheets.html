Key concept

Go To Special Constants Test on Calculation Sheets

Concept: Go To Special → Constants (Numbers) on a calc sheet should select only intended blue inputs

Statement

For any calculation sheet \( S \), let \( K(S) \) be the set of cells selected by Go To Special → Constants → Numbers, and \( B(S) \) the set of cells intentionally designated as inputs (blue font, input style). The integrity condition is:

\[ K(S) = B(S) \]

On a well-built model where all inputs live on the Inputs tab and historicals on the Historicals tab, \( B(S) = \varnothing \) for every calc sheet, so the test should select nothing in the calc area (other than labels' numeric constants such as a year in a header, if typed — which should themselves be formulas from the timeline).

Explanation

The test is a fast census of typed numbers. Steps:

  1. Select the calc area of the sheet (or the whole sheet).
  2. F5 → Special → Constants, tick only Numbers (untick Text, Logicals, Errors) → OK.
  3. Inspect the selection. Use Tab/Enter to cycle through selected cells, or apply a temporary fill.

Interpretation:

Selected cell Meaning Action
Blue, labelled input on a calc sheet (if house style allows) Intended Confirm source; consider moving to Inputs
Black or green typed number Former formula pasted as value, or override Restore formula or create flagged override row
Typed year in header Timeline not linked Link to master timeline
Number in a constant column (useful life) Intended if blue Confirm style
Historical actual typed in calc sheet Should be a link to Historicals Replace with link

Limitations — the test does not find:

  • Constants embedded in formulas (=L40*1.12) — see s05 techniques.
  • Numbers stored as text (select Constants → Text to find them).
  • Values in hidden rows if you select visible cells only.

Pair it with the reverse test on the Inputs tab: Go To Special → Formulas should select only input-side aids (totals of input tables, links to the timeline).

This is the first step of the Saturday audit: running it on every calc tab and documenting a screenshot of the empty selection ("No cells were found") is direct evidence of zero hardcodes in calc cells.

Illustration

Running Constants → Numbers on the Pidilite Opex tab (M10:Q150) selects:

Cell Value Font Diagnosis
O48 612.0 Black A&P FY28E pasted as value; formula was =O40*O47
E62 30 Blue Useful life of IT assets in constant column — intended
Q90 0 Black Placeholder zero for FY30E royalty — should be formula or input

O48: with FY28E revenue ₹17,300 crore and A&P 11.5%, the formula would give ₹1,989.5 crore — the pasted ₹612.0 crore is clearly a quarter-level number pasted from another file. One cycle of the test caught a ₹1,377.5 crore understatement of opex.

Connections

Part of the s07 toolkit (Go To Special) and the colour convention of s01 and s02 (blue = input). Complements c01 (R1C1 consistency) and s05 (embedded constants). Supports topic t1 s02's separation of inputs and calculations and the Saturday assessment.
