Key concept

Targeted Error Guards Instead of Blanket IFERROR

Concept: Targeted error guards over IFERROR: =IF(Denominator=0,0,Numerator/Denominator)

Statement

Where a formula has a known, legitimate error condition, guard against that condition only:

=IF(Denominator=0, 0, Numerator/Denominator)

rather than suppressing all errors:

=IFERROR(Numerator/Denominator, 0)

Formally, a targeted guard returns a defined value \( v \) only when a specific condition \( c \) holds, and otherwise lets the formula's result — including any unexpected error — propagate:

\[ \text{Result} = \begin{cases} v & \text{if } c \\ f(x) & \text{otherwise (errors propagate)} \end{cases} \]

Explanation

Why IFERROR is dangerous. IFERROR catches #DIV/0!, but also #REF! (deleted rows or broken links), #NAME? (misspelt names), #VALUE! (text in a number cell) and #N/A (failed lookups). Each of those signals a defect. Wrapping in IFERROR converts a defect into a plausible zero that flows into the statements and may even let the balance check pass (if the zero enters both sides). This is a listed pitfall of this topic.

Choosing the guard.

Situation Targeted guard
Ratio with possibly zero denominator (margin when revenue 0) =IF(M40=0,0,M60/M40)
Growth rate with zero prior value =IF(L40=0,0,M40/L40-1)
Days ratio with zero sales =IF(M40=0,0,M41/M40*Days_in_Year)
Lookup that may legitimately not find a match =IFNA(XLOOKUP(…),0) or XLOOKUP's if_not_found argument — catches only #N/A
Negative under square root / log =IF(M50<=0,0,LN(M50))
Iterative circularity blow-ups Circuit breaker switch (topic t1, s06), not IFERROR

What value to return. Zero is common for ratios, but sometimes a blank-looking result ("") is used on output pages; avoid "" in calc sheets because text in a numeric row breaks downstream arithmetic (#VALUE!) and SUM ignores it silently. For growth rates on zero bases, consider returning 0 and flagging in a note.

Excel's DIVIDE equivalent. In Power BI DAX, DIVIDE(Numerator, Denominator, 0) is the built-in targeted guard — it handles only division by zero.

Where IFERROR is acceptable. On presentation outputs where the error cause is fully understood (e.g., a chart helper), or in a raw-data parsing step — never in core calculation rows, and never wrapped around cross-sheet links.

Illustration

WC tab, DIO in FY26E for a new segment with no inventory yet:

Bad:   =IFERROR(M45/M41*365,0)
Good:  =IF(M41=0,0,M45/M41*Days_in_Year)

Now suppose a row deletion on the Revenue tab breaks M41's link (=#REF!). The bad formula returns 0 DIO and inventory of ₹0 crore in the forecast — the model continues to balance, and a ₹380 crore inventory build vanishes from NWC, overstating FCFF by that amount in FY26E. The good formula returns #REF!, which propagates to the BS, trips the master check via SUMPRODUCT (topic t1, c04), and the error is fixed within minutes.

Connections

Supports s06 (Error Checking, Trace Error) and s07 (Go To Special → Formulas → Errors) — targeted guards keep errors visible for these tools. Relates to topic t1's master check design (no IFERROR around checks) and to Week 15 debugging. Phase 3 DAX DIVIDE is the reporting analogue.

Practice Questions

Q1. Rewrite the guards [L1]

Rewrite each formula with a targeted guard: (a) =IFERROR(M60/M40,0) (EBITDA margin); (b) =IFERROR(M40/L40-1,0) (growth); (c) =IFERROR(VLOOKUP(B5,Map,2,FALSE),"Other") (mapping an XBRL tag to model line).

Q2. Hidden broken link [L2]

A Trent model's Debt tab uses =IFERROR(Inputs!M60*M52,0) for interest. After an analyst deletes a row on Inputs, FY26E–FY30E interest becomes zero but the master check stays green. Explain why, quantify the PAT effect if average debt is ₹1,200 crore at 8.5% and tax 25.168%, and describe the redesign.

💡 Hint: Consider why the balance sheet still balances when interest is zero in every year.

Q3. Mapping fallback [L2]

When mapping XBRL tags to the model chart of accounts via XLOOKUP, some tags legitimately do not map. Design the formula and a check that ensures unmapped tags are visible and their total is reconciled, rather than silently dropped.
