Subtopic note

Absolute and Mixed References for Constants and Flags

Scope: Absolute/mixed referencing ($C5, C$5) for constant-column drivers and timeline flags

Why it matters

One formula per row (s03) is only achievable if the formula can be written once in the first forecast column and copied to the last without editing. That depends on anchoring references correctly: a driver held in the constant column must stay in that column as the formula moves right, and a timeline flag in row 4 must stay in row 4 as the formula is copied down to other rows. Mixed references ($E20, M$4) are the mechanism. Getting them wrong produces the most common copying errors in modelling tests — a tax rate that drifts to an empty cell, a flag that drifts into a revenue row.

Core notes

The four reference types

Reference Column Row Behaviour when copied right When copied down Typical use
E20 Relative Relative Becomes F20 Becomes E21 Same-period values on the same row structure
$E20 Absolute Relative Stays E20 Becomes E21 Constant column driver for each row
E$20 / M$4 Relative Absolute Becomes F$20 / N$4 Stays row 20 / row 4 Timeline rows and flags
$E$20 Absolute Absolute Stays Stays Single scalar (better: a named range)

F4 cycles through the four forms while editing a reference.

Constant-column drivers: $E5

In the standard column layout (topic t1, s04), column E holds a per-row constant: useful life, a cap, a base-year value or a scalar linked from Inputs. A depreciation block:

Row Label Units E (const) M (FY26E)
30 Capex – stores ₹ crore =Inputs!M50
31 Useful life – stores years 10
32 Depreciation on FY26E additions ₹ crore =M30/$E31

$E31 keeps the column fixed as the formula copies across FY27E–FY30E, while the row stays relative — so if the block is copied down for "Capex – warehouses" with its own life in E35, the formula picks up E35 automatically.

Timeline flags: M$4

Flags live in fixed rows at the top of every sheet (topic t1, s03): row 4 actual flag, row 5 forecast flag, row 7 counter. A formula referencing them must anchor the row:

=M$4*Hist!M40 + M$5*(L41*(1+M42))

Copying this formula down to another line item keeps the flag references in rows 4 and 5, while the line-specific references (L41, M42) shift. Without $ on the row, the copied formula would reference row 5 and 6 and treat a forecast flag as an actual flag.

Combining both: inflation index example

A cost index compounding from a base year:

Row 7 (counter): 1, 2, 3, 4, 5 for FY26E–FY30E
Row 60 (inflation, const in E60): 6.0%
Row 61 (index):  =(1+$E60)^M$7
Row 62 (cost):   =Base_Cost*M61

$E60 fixes the constant column; M$7 fixes the counter row. FY28E index = 1.06³ = 1.1910.

Absolute references vs named ranges

For workbook-wide scalars (tax rate, scenario, circularity switch), named ranges are clearer than $E$12 (topic t1, s07). Use $E5-style mixed references for row-specific constants that differ by line item; use names for global constants.

Common errors and how they show up

Error Symptom Detection
Relative reference to a constant (E31 instead of $E31) FY27E refers to F31 (blank) → depreciation 0 or #DIV/0! Row of zeros or errors after the first year
Absolute row missing on a flag (M4 instead of M$4) Copied rows reference wrong flags Row differences scan; R1C1 shows R[-36]C instead of R4C
Fully absolute where relative needed ($M$40) All years use FY26E revenue Flat row; R1C1 shows R40C13 across row
Mixed in wrong direction (E$31) Copying right drifts to F$31 Same as relative case

R1C1 view (c01) makes anchoring visible: $E31 appears as R[0]C5 (or RC5) and M$4 as R4C.

Illustration

Employee cost per store for Trent with store-level CTC inflation in constant column E:

Row Label E M (FY26E) N (FY27E)
70 Average stores 1,050 1,250
71 Staff per store 18
72 CTC per staff, ₹ lakh 3.00 =M72*(1+$E73)
73 Increment 9.0%
74 Store staff cost, ₹ crore =M70*$E71*M72/100 =N70*$E71*N72/100

FY26E = 1,050 × 18 × 3.00 / 100 = ₹567.0 crore; FY27E CTC = 3.27, cost = 1,250 × 18 × 3.27 / 100 = ₹735.8 crore. The FY27E formula is the FY26E formula copied right, unchanged in structure.

Edge cases & judgement calls

  • Constant that becomes time-varying. If increments differ by year, move from $E73 to a timeline row; do not mix constants in E with yearly overrides in the row.
  • Copying blocks between sheets. Mixed references survive copying if both sheets share the column layout; otherwise they misalign — another reason for identical layouts.
  • Structured references in tables follow different rules ([@Revenue]); avoid mixing tables and timeline rows in calc sheets.
  • Dynamic arrays. Spilled formulas (=M30:Q30/$E31) produce one formula for the row; useful but less familiar to reviewers and harder to override per cell. Many house styles still prefer copied formulas.
  • Pre-timeline column G for corkscrews is referenced relatively (L90 from M) — not anchored.

Key takeaways

  • $E5 anchors the constant column; M$4 anchors the flag row; $E$5 is a scalar better replaced by a name.
  • Write the formula once in the first forecast column with correct anchoring, then copy across and down.
  • R1C1 view reveals anchoring errors immediately.
  • Row-specific constants live in the constant column; global constants are named ranges.
  • Errors show up as zeros, flat rows or #DIV/0! after the first forecast year — scan for them.

Practice Questions

Q1. Anchor the formula [L1]

Write the FY26E formula (column M) for FY26E–FY30E depreciation on opening net block at a WDV rate held in column E of row 25, with opening net block in row 24, so that it can be copied across and down to three asset classes without editing.

Q2. Debug copied formulas [L2]

After copying, a row shows FY26E ₹120.0, FY27E ₹0.0, FY28E #DIV/0!, FY29E ₹0.0, FY30E ₹0.0. The FY26E formula is =M30/E31. Explain the failure, write the corrected formula and describe how R1C1 view would have revealed it.

💡 Hint: Ask what column E31 becomes in each subsequent column.

Q3. Flags in a copied block [L2]

You copy a five-row block (revenue, COGS, gross profit, A&P, EBITDA) from row 40 to row 140 on the same sheet. The block's formulas use M4 and M5 for the actual/forecast flags. Explain what breaks, how to fix the block before copying, and how to test the copy.

Q4. Inflation index design [L3]

Design a reusable opex block for four cost lines (power, freight, store maintenance, corporate overheads), each with its own inflation rate in the constant column and a base FY25A cost, such that the same formula works for all lines and years. Base costs: ₹420, ₹610, ₹280, ₹350 crore; inflation 5%, 6%, 7%, 8%. State the FY27E value for one line as a check of your layout.
