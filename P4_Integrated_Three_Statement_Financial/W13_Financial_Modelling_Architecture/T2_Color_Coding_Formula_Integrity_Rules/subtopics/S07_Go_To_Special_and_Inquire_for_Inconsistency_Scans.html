Subtopic note

Go To Special and Inquire for Inconsistency Scans

Scope: Go To Special (Constants, Formulas, Row differences) and Inquire/Spreadsheet Compare for inconsistency scans

Why it matters

Cell-by-cell review does not scale: a 15-tab model with 10 forecast years and 300 rows per tab has tens of thousands of formula cells. Go To Special and Microsoft's Inquire add-in let you scan for whole classes of defects at once — every constant on a calc sheet, every formula on an input sheet, every cell whose formula differs from its row, every change between two versions. These are the tools a Big 4 model reviewer uses first, and they are exactly what this week's Saturday audit asks you to apply to your own model.

Core notes

Go To Special (F5 → Special, or Home → Find & Select → Go To Special; Ctrl+G → Special)

Option Selects Use in review
Constants → Numbers Cells containing typed numbers On a calc sheet, should select only intended inputs (ideally none); on Historicals, the loaded actuals
Constants → Text Typed text Find numbers stored as text (e.g., pasted "1,234")
Formulas → Numbers / Text / Logicals / Errors Formula cells by result type Formulas → Errors finds every #REF!, #N/A, #DIV/0! at once
Row differences Cells in each row of the selection whose formula differs from the active cell's column comparison cell Finds breaks in one-formula-per-row
Column differences Same, by column Useful in tables with years in rows
Precedents / Dependents (direct / all levels) Like Ctrl+[ and Ctrl+] Bulk selection
Blanks Empty cells Find gaps in a forecast row
Last cell Bottom-right used cell Detect bloated used ranges
Visible cells only Excludes hidden rows/columns Compare with full selection to detect hidden content
Conditional formats / Data validation Cells with those features Check that inputs carry validation

Constants scan workflow

  1. On a calc sheet, select the forecast range (e.g., M10:Q300).
  2. F5 → Special → Constants → Numbers only → OK.
  3. Apply a temporary bright fill (or note the selection). Every selected cell must be an intended input (blue) — usually none on calc sheets.
  4. Repeat for Formulas on the Inputs tab: any formula there should be an input-side aid, not a hidden calculation.

Remember that Constants does not find numbers embedded in formulas (=L40*1.12) — combine with the s05 techniques.

Row differences in detail

Select the row range starting from the first forecast cell (the active cell, white within the selection, sets the comparison column), e.g., select M40:Q120 with M40 active. Go To Special → Row differences selects every cell in each row whose formula is not the same relative formula as the cell in the active cell's column for that row. Selected cells are breaks: overrides, partial copy-across, typed values. Excel compares in R1C1 terms, so properly copied formulas are not flagged.

Caveat: if the first forecast column itself is wrong, the scan flags the correct cells instead. Interpret selections, don't just overwrite them.

Inquire add-in

Inquire is included with Microsoft 365 Apps for enterprise / Office Professional Plus on Windows (enable via File → Options → Add-ins → COM Add-ins → Inquire). It provides:

Feature What it gives
Workbook Analysis Report of formulas (with errors, with constants, unique formulas), hidden sheets/rows/columns, external links, named ranges, data connections, cells with warnings; exportable to Excel
Workbook Relationship / Worksheet Relationship Diagrams of links between files and between sheets — reveals backward and daisy-chained links
Cell Relationship Diagram of precedents/dependents of a cell across sheets and files
Compare Files (Spreadsheet Compare) Cell-by-cell comparison of two workbooks: entered values, formulas, names, macros, formatting — colour-coded by change type
Clean Excess Cell Formatting Removes formatting beyond the used range, reducing file size
Workbook Passwords Stores passwords for analysing protected files

Spreadsheet Compare for version control

Before issuing v1.4, compare v1.3 and v1.4: the report lists each changed formula and value by sheet and cell. Expected changes (those in the change log) should match; anything else is an unintended edit. This is the strongest evidence in a version dispute (topic t1, s08) and a standard step in model assurance.

Illustration

Running Row differences on the Trent Opex tab M40:Q90 selects:

Cell Content Diagnosis
O52 1,940 Typed override in FY28E employee cost
P61 =P58*0.065 Constant rate replacing link to Inputs
Q70 =Q66*Q67/100+15 One-off ₹15 crore in FY30E

Workbook Analysis additionally reports 3 external links to "Trent_FY24_old.xlsx" and 2 hidden rows on Inputs. Each becomes a review finding with a fix: override row with flag, linked input, labelled adjustment row, link breaking and unhiding.

Edge cases & judgement calls

  • Mac Excel does not include Inquire; Spreadsheet Compare is Windows-only. Alternatives: third-party tools (xltrail, PerfectXL) or manual FORMULATEXT comparisons.
  • Design A split rows (s03): Row differences on a selection that spans both actual and forecast columns flags all actual cells. Select forecast columns only.
  • Spilled dynamic arrays appear as one formula; Row differences treats spilled cells specially — review the anchor formula.
  • Large workbooks: Workbook Analysis may be slow; run on a copy and limit categories.
  • Protected sheets: Go To Special works on locked cells only if selection of locked cells is permitted.

Key takeaways

  • Constants → Numbers on a calc sheet should select only intended inputs; Formulas on the Inputs tab should select only input aids.
  • Formulas → Errors finds every error value in one action.
  • Row differences, anchored on the first forecast cell, finds breaks in row consistency.
  • Inquire's Workbook Analysis reports hidden content, external links, constants in formulas and names.
  • Spreadsheet Compare between versions proves which changes were made.

Q1. Match tool to defect [L1]

Match each defect to the Go To Special or Inquire feature that finds it fastest: (a) a typed number in a FY29E forecast cell; (b) #REF! after a row deletion; (c) a link to an old workbook; (d) a hidden row on Inputs; (e) an undocumented change between v2.1 and v2.2; (f) numbers pasted as text on Historicals.

Q2. Row differences pitfalls [L2]

A reviewer selects H40:Q120 (FY21A–FY30E) on the Revenue tab and runs Row differences with H40 active. Hundreds of cells are selected. Explain why, and specify the correct selection and active cell for a design A model with FY26E in column M.

💡 Hint: The comparison is driven by the active cell's column.

Q3. Spreadsheet Compare evidence [L2]

Describe how you would use Spreadsheet Compare to support a change-log entry "v2.3 → v2.4: updated FY26E store additions and corrected DPO link", and what you would do if the report shows 42 changed cells on the Tax tab.

Q4. Saturday self-audit plan [L3]
