Key concept

Scenario Summary via a One-Variable Data Table on the Switch

Concept: Scenario summary: 1D data table with Scenario as column input returning EV, price, EBITDA, net debt

Statement

A one-variable (1D) data table with the scenario codes down a column and output links across the top row, built with What-If Analysis → Data Table and Column input cell = Scenario, returns for each code \(s\):

\[ \text{Table}(s, j) = f_j(\text{Model} \mid \text{Scenario} = s) \]

where \(f_j\) is the \(j\)-th linked output — typically enterprise value (EV), equity value per share (price), EBITDA for key years and net debt. Excel fills the grid with {=TABLE(,Scenario)}; the table must be on the same sheet as the Scenario input cell.

Explanation

The data table recalculates the whole model for each code in turn, without changing the live selector, and stores the results in the table. It is the cleanest way to show all cases side by side while keeping them live.

Mechanics and conditions:

  • Layout. Codes 1, 2, 3 in a column (say B11:B13); output links in the row above, starting one column to the right (C10 =EV, D10 =Price, E10 =EBITDA_FY27, F10 =Net_Debt_FY27). Select B10:F13, then Data Table with Column input cell = the Scenario cell; Row input cell blank.
  • Same-sheet rule. Excel only accepts an input cell on the table's own sheet. If Scenario lives on the Cover, the table must be on the Cover; if it lives on Inputs, the table goes on Inputs. A cross-sheet design is the topic pitfall.
  • Recalculation. Each row recalculates the full model; with "Automatic except for data tables", press F9 to refresh and show a "Press F9" warning on the Cover.
  • Circularity. Iterative calculations inside data tables can give unstable results; use the circularity breaker or a static snapshot for circular models (Week 15).
  • Labels. Display scenario names beside the codes with =INDEX(Scenario_Names, B11) outside the table range.
  • Output choice. Include valuation (EV, price, implied multiples), operating (revenue, EBITDA, margin), and credit outputs (net debt, net debt ÷ EBITDA, minimum DSCR) so the table answers both equity and lender questions.
