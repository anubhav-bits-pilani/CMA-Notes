Subtopic note

Checks Sheet and the Master Integrity Flag

Scope: Checks sheet: balance check, cash check, revolver limit, circularity status, rolled up into one master flag on the Cover

Why it matters

A model with no checks is only as reliable as the last time someone looked at every cell. Checks turn integrity into a single, visible number: if the master flag on the Cover is green, the balance sheet balances, the cash flow reconciles, financing limits are respected and the circular calculation has converged — in every period and every scenario. Reviewers, lenders' technical advisers and interviewers look for the checks sheet first. In FP&A, where budgets are re-run monthly by different people, the master flag is what lets a finance controller trust a revised forecast without re-auditing it.

Core notes

Design principles

  1. Each check is computed where the data lives (e.g., the balance check row sits on the BS block of the 3-Statement tab) and linked to the Checks sheet. This lets the builder see errors locally while the Checks sheet aggregates.
  2. Each check returns a difference, not TRUE/FALSE, so magnitude is visible; a separate flag converts it using a tolerance (e.g., 0.001 ₹ crore).
  3. Every check row spans the full timeline, so an error in FY29E alone still shows.
  4. One master flag sums all absolute differences or flags and is displayed on the Cover (c04).

Core checks

Opening = prior closing CFS opening cash − prior CFS closing cash 0.001 Catches broken corkscrews

Minimum cash MAX(0, Minimum cash − Cash balance) 0 Optional; flags a sweep error
Circularity status Circ switch = 1 and iteration converged (difference between two passes) 0.001 Or simply reports switch state

Example formulas on the Checks sheet (columns H:Q aligned with the master timeline):

Balance diff (row 10):   ='3-Statement'!H120-'3-Statement'!H160
Cash diff (row 11):      ='3-Statement'!H210-'3-Statement'!H85
Revolver breach (row 12):=MAX(0,Debt!H40-Inputs!$E$55)
Row flag (column F):     =--(SUMPRODUCT(ABS(H10:Q10))>Tolerance)
Master flag:             =--(SUM(F10:F25)>0)

Circularity status

Interest on average debt or average cash creates a loop: interest → PAT → cash → revolver → interest. Best practice:

  • A named switch Circ (1 = on, 0 = off) on Inputs. Interest formulas use =IF(Circ=1, Average_Balance, Opening_Balance) × Rate — this is the one place an IF on a switch is accepted.
  • A circuit breaker: setting Circ to 0 breaks the loop if the model blows up into #VALUE! or #NUM! errors that propagate around the loop.
  • A convergence check: a copy of interest calculated with opening balances is compared to the live figure; or the Checks sheet displays "Circularity ON — iterative calculation enabled (File → Options → Formulas)".
  • The Cover displays the status so a reviewer knows why Excel shows iteration.

Revolver limit

The revolver (cash credit / working capital demand loan in Indian banking) is drawn to keep cash at a minimum. The draw formula typically caps the revolver at the sanctioned limit. If the cap binds, cash may fall below minimum — the model must then flag it rather than silently borrow beyond the limit. The check is MAX(0, Required_draw − Available_limit).

Both balance and cash checks fail by ₹12.4 crore in FY28E only — a strong hint that a FY28E-only item (e.g., a one-year capex override) was added to the BS but not to the CFS. The pattern of failures is diagnostic: a constant difference from the first forecast year suggests an opening balance mismatch; a growing difference suggests a missing flow item in the CFS.

Conditional formatting and visibility

  • Each check row: red fill where the absolute value exceeds tolerance.
  • Master flag on the Cover: big cell, green "OK" / red "ERROR", formula =IF(Master_Check=0,"ALL CHECKS OK","CHECK ERRORS: "&SUM(Checks!F10:F25)).
  • A link from each sheet's title bar to the master flag (some builders show the master flag in cell A1 of every sheet).

Edge cases & judgement calls

  • Tolerance. Use a small absolute tolerance (₹0.001 crore = ₹10,000). Rounding to display precision should never be used as the test; percentage tolerances can hide large errors in big models.
  • Historical balance failures. Reported statements sometimes do not foot due to rounding in ₹ crore; show an explicit rounding line in Historicals (topic t3, c06), not a tolerance increase.
  • Scenario-specific failures. A check may pass in Base but fail in Bear (e.g., revolver breach). Run all scenarios through a data table on the master flag before sign-off.
  • Checks that can never fail. A check like "Assets − Assets" proves nothing; each check must compare two independently derived numbers.
  • Disabling checks. Never zero out a check to "get green". If a check is not applicable (e.g., no revolver), show N/A and exclude it explicitly with a documented reason.

Key takeaways

  • Compute each check where the data lives, link it to a Checks sheet, and roll everything into one master flag on the Cover.
  • Checks should return differences across the full timeline, converted to flags with a small absolute tolerance.
  • Core checks: balance, cash, revolver limit, circularity status; add timeline alignment and historical tie-outs.
  • Circularity needs a switch, a circuit breaker and a visible status.
  • Read the pattern of failures — first-year constant vs growing vs single-year — to locate errors quickly.
  • Run the master flag across all scenarios before circulating.

Practice Questions

Q1. Build the Checks sheet [L1]

List the rows you would place on the Checks sheet of a Trent Ltd 3-statement model with a revolver and Ind AS 116 lease liabilities, writing the formula logic and tolerance for each and the master flag formula.

Q2. Diagnose from the pattern [L2]

A model's balance check shows: FY26E 35.0, FY27E 35.0, FY28E 35.0, FY29E 35.0, FY30E 35.0 (₹ crore), while the cash check is zero throughout. Explain what kind of error this pattern indicates, which three places you would look first, and why the cash check did not catch it.

💡 Hint: A constant difference that starts in the first forecast year usually originates at the actual/forecast boundary.

Q3. Revolver logic [L2]

Minimum cash is ₹200 crore, revolver limit ₹500 crore. In FY27E the pre-revolver cash balance is –₹480 crore and opening revolver is ₹100 crore. Write the revolver draw formula with the limit, state the resulting revolver balance and cash, and specify the check that should fire.

Q4. Circularity governance [L3]

Your model uses average-balance interest with iterative calculation enabled. During a review, the model shows #NUM! across the P&L after an analyst typed a negative interest rate. Describe the circuit-breaker design, the recovery steps, and how the Cover and Checks sheet should communicate circularity status to the next user.
