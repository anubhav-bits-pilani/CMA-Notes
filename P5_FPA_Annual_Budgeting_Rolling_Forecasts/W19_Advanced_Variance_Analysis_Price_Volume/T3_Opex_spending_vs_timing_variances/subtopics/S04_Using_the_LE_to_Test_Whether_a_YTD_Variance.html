Subtopic note

Using the LE to Test Whether a YTD Variance Reverses

Scope: Using LE/full-year forecast to test whether a YTD variance reverses

Why it matters

The question behind every YTD opex variance is "will it still be there in March?". The full-year latest estimate (LE) — YTD actuals plus the forecast for the remaining months (Week 18: 3+9, 6+6, 9+3) — is the only disciplined way to answer it. If the YTD underspend is not reflected as a lower full-year number in the LE, the business owner is implicitly saying the money will still be spent; if the LE shows the full-year number lower, the saving is permanent. Using the LE this way converts a backward-looking variance into a forward-looking commitment and exposes inconsistencies between what budget owners say in variance meetings and what they submit in the forecast.

Core notes

The identity

For a cost line (positive = favourable):

\[ \text{YTD variance} = B_{YTD} - A_{YTD} \]

\[ \text{Permanent variance} = B_{FY} - LE_{FY}, \qquad LE_{FY} = A_{YTD} + F_{ROY} \]

\[ \text{Timing variance} = \text{YTD variance} - \text{Permanent variance} \]

where \(F_{ROY}\) is the rest-of-year forecast. Substituting, timing variance \(= (B_{YTD} - A_{YTD}) - (B_{FY} - A_{YTD} - F_{ROY}) = F_{ROY} - B_{ROY}\): the timing component is exactly the amount by which the rest-of-year forecast exceeds the rest-of-year budget — the catch-up spend. This gives an intuitive check: timing = what is forecast to be spent in the remaining months over and above the remaining budget.

Worked illustration

Marketing, ₹ crore, at 30 September (6+6 LE).

Item Amount
FY budget \(B_{FY}\) 12.00
YTD budget \(B_{YTD}\) 6.00
YTD actual \(A_{YTD}\) 4.50
Rest-of-year forecast \(F_{ROY}\) 7.10
FY LE \(= 4.50 + 7.10\) 11.60
YTD variance \(= 6.00 - 4.50\) +1.50
Permanent \(= 12.00 - 11.60\) +0.40
Timing \(= 1.50 - 0.40\) +1.10
Check: \(F_{ROY} - B_{ROY} = 7.10 - 6.00\) +1.10

Interpretation: of the ₹1.5 crore YTD underspend, ₹1.1 crore will be spent in H2 over and above the H2 budget (catch-up), and ₹0.4 crore is a real saving.

Testing the quality of the LE itself

The identity is only as good as the LE. Tests to apply:

  1. Catch-up feasibility: is it realistic to spend \(F_{ROY}\)? A rest-of-year run rate far above the YTD run rate (e.g., ₹1.18 crore/month vs ₹0.75 crore/month) needs evidence — booked media, signed contracts, open POs (s05).
  2. Run-rate test: compare \(F_{ROY}\) with YTD average monthly actual × remaining months, adjusted for known seasonality. Large gaps need an explanation.
  3. Consistency with the operational plan: hiring forecast joined to the recruitment pipeline; campaign spend joined to the media plan; freight forecast joined to the volume forecast.
  4. Stale LE: if \(F_{ROY}\) was simply copied from the remaining budget (\(F_{ROY} = B_{ROY}\)), then permanent = YTD variance and timing = 0 by construction — a common shortcut that labels every YTD variance as permanent. The opposite shortcut, \(LE_{FY} = B_{FY}\) ("we'll spend it all"), labels every variance as timing. Flag lines where LE equals budget to the rupee.
  5. History: track how much of last year's "timing" actually reversed by March. A business unit whose timing never reverses should have its LE challenged (forecast accuracy — Week 18/20).

Monthly progression

A well-behaved timing variance grows while the activity is delayed and falls back to zero when it happens. Plotting YTD variance, permanent variance and timing variance by month gives a clear picture:

Month-end YTD var FY LE Permanent Timing
June +0.80 11.80 +0.20 +0.60
September +1.50 11.60 +0.40 +1.10
November +0.30 11.60 +0.40 −0.10
March (actual) +0.40 11.60 +0.40 0.00

At year-end timing is zero by definition (YTD = FY). A negative timing balance in November means YTD spend has run ahead of budget phasing — fine if the remaining months are forecast below budget.

Presentation

The opex variance table in the management pack should have, per line: YTD budget, YTD actual, YTD variance, FY budget, FY LE, permanent, timing, class tags (volume/one-off), and a commentary column. Executives can then read the FY implication directly. In the EBITDA bridge for actual vs budget YTD, timing and permanent opex can be shown as two bars to prevent over-celebration of YTD savings (Topic 4).

Excel implementation

YTD_Var    = YTD_Bud - YTD_Act
Permanent  = FY_Bud - FY_LE
Timing     = YTD_Var - Permanent
Check      = Timing - ((FY_LE - YTD_Act) - (FY_Bud - YTD_Bud))
Stale_flag = IF(ABS(FY_LE-FY_Bud)<0.005*FY_Bud,"LE = Budget?","")

The check must be zero; the stale flag prompts review.

Edge cases & judgement calls

  • Variable lines: apply the test to spending variance against the flexed budget; flex the FY budget at LE volume first (s02, c03, c04).
  • Timing across fiscal years: spend shifted from March into April of next year is a permanent saving for this FY but a timing issue for the company; commentary should say so, and next year's budget should not be double-counted.
  • LE updated quarterly, actuals monthly: in non-LE months, use the latest LE plus known changes, or note that the classification is as of the last LE.
  • One-offs: an already-incurred one-off is permanent; it must appear in the LE.
  • Sandbagging: owners may keep the LE high to protect budget; the run-rate and history tests counter this.

Key takeaways

  • Permanent = FY budget − FY LE; timing = YTD variance − permanent = rest-of-year forecast − rest-of-year budget.
  • The test is only as good as the LE: check feasibility, run rate, operational consistency and staleness.
  • An LE equal to budget labels every variance as timing; an LE equal to YTD actual plus remaining budget labels every variance as permanent.
  • Timing variances should trend to zero by year-end; track reversal history by business unit.
  • Show FY LE, permanent and timing columns in every opex variance table.

Practice Questions

Q1. Compute permanent and timing [L1]

IT costs: FY budget ₹18 crore; YTD December budget ₹13.5 crore; YTD actual ₹11.2 crore; Q4 forecast ₹5.6 crore. Compute the YTD variance, FY LE, permanent and timing variances, and verify timing using the rest-of-year identity.

Q2. Stale LE detection [L2]

Five cost centres submitted 6+6 LEs. For each, FY budget and FY LE (₹ lakh) are: CC1 240/240, CC2 180/164, CC3 95/95, CC4 310/322, CC5 150/150; YTD variances are +36, +20, −12, −9, +28 respectively. Identify which LEs are suspect, explain the classification error each would produce, and draft the challenge question you would send to each owner.

💡 Hint: Compare what the LE implies for the remaining months with the YTD pattern.

Q3. Feasibility of catch-up [L2]

Marketing YTD September actual is ₹21 crore against a YTD budget of ₹30 crore; FY budget is ₹60 crore; the LE is ₹59 crore. Booked media and signed agency estimates for October–March total ₹26 crore. Assess whether the ₹8 crore timing classification is credible, compute the implied rest-of-year run rate, and propose a revised classification with justification.

Q4. Year-end cross-over [L3]

A ₹2.5 crore brand campaign budgeted for February is moved to May of the next fiscal year. Explain how it is classified in this year's YTD and FY variance analysis, how it should be treated in next year's AOP, and how you would present it to the board so that neither year's numbers mislead.
