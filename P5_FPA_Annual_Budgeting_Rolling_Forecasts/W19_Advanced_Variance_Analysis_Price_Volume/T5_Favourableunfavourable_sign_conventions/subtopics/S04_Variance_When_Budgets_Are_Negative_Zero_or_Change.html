Variance % When Budgets Are Negative, Zero or Change Sign

Scope: Variance % calculation with negative or zero budgets

Why it matters

Variance % is the column executives scan first, because it normalises for size: a ₹2 crore miss on a ₹10 crore line matters more than on a ₹500 crore line. But percentages break on exactly the lines that matter most for commentary — loss-making segments, start-up businesses, lines budgeted at zero, net finance cost that flips to net income, forex gains budgeted as losses. A naive =Var/Budget produces −50% for an improving loss, #DIV/0! for unbudgeted spend, and +400% for a swing from a small loss to a small profit. Each misleads, and each is easy to catch with a standard rule.

Core notes

The basic formula

With the variance already expressed as Fav/(Adv) (positive = favourable):

\[ \text{Variance \%} = \frac{\text{Variance}_{\text{Fav/(Adv)}}}{\left\lvert \text{Budget} \right\rvert} \]

Dividing by the absolute value of the budget ensures that the sign of the percentage always matches the sign of the ₹ variance. The percentage then reads as "how far better or worse than budget, as a share of the size of the budget".

Case 1: Positive budget (normal case)

Revenue budget ₹4,200 lakh, actual ₹4,350 lakh: variance +150, % = 150 ÷ 4,200 = +3.6%. Cost budget ₹2,940 lakh, actual ₹3,120 lakh: variance (180), % = −180 ÷ 2,940 = (6.1%). No issue.

Case 2: Negative budget, same-sign actual

A new D2C business budgets EBITDA of −₹10 crore; actual is −₹6 crore.

  • Variance = Actual − Budget = −6 − (−10) = +4 (favourable — the loss is smaller).
  • Naive % = 4 ÷ (−10) = −40% → wrongly signals adverse.
  • Correct % = 4 ÷ ABS(−10) = +40% → "40% better than budget".

The same applies to lines whose natural presentation is negative in a signed model (costs stored as negatives): if the cost budget is −₹500 lakh and actual −₹550 lakh, variance = −550 − (−500) = −50 (adverse); % = −50 ÷ 500 = (10.0%). With ABS in the denominator, the profit-effect sign model and the unsigned model give the same percentage.

Case 3: Sign flip between budget and actual

Segment EBITDA budget +₹2 crore, actual −₹3 crore. Variance = (5). Percentage: −5 ÷ 2 = (250%). Arithmetically defined, but what does "250% worse" mean for a line that has moved from profit to loss? Readers anchor on the number and it implies precision about a meaningless ratio. Similarly, budget −₹1 crore and actual +₹4 crore gives +500%. The convention is to show "n.m." (not meaningful) whenever budget and actual have opposite signs, and to let the ₹ variance and the commentary ("swung from budgeted profit of ₹2 cr to a loss of ₹3 cr") carry the message.

Case 4: Zero budget

An unbudgeted consultancy cost: budget 0, actual ₹12 lakh. Variance (12); % undefined (#DIV/0!). Show "n.m." (or "n.b." — not budgeted — if the pack distinguishes). Equally, a budgeted cost with zero actual (budget ₹8 lakh, actual 0) is +100%, which is meaningful (the whole budget was saved or deferred) and should be shown.

Case 5: Tiny budgets

Budget ₹0.5 lakh, actual ₹6 lakh: (1,100%). Technically correct, practically noise. Common rules: show "n.m." if ABS(Budget) is below a floor (e.g., ₹5 lakh, or 0.1% of revenue), or cap display at ">100%" / "<(100%)". The materiality rule for commentary (topic 3, concept c05) usually requires both an absolute and a percentage threshold, so these lines are flagged by ₹ size, not by %.

The Excel implementation

With variance in F8, budget in C8, actual in D8, and a floor in a named cell PctFloor:

=IF(OR(C8=0,ABS(C8)<PctFloor,SIGN(C8)*SIGN(D8)<0),"n.m.",F8/ABS(C8))

Format the cell with 0.0%;(0.0%);"-" and right-align "n.m." text with the numbers. Note that SIGN(C8)*SIGN(D8)<0 is true only when budget and actual have strictly opposite signs; if actual is exactly zero, the percentage (e.g., −100% for revenue, +100% for cost) is meaningful and is shown.

In DAX:

Var % =
VAR b = [Budget]
VAR a = [Actual]
RETURN
    IF (
        b = 0 || ABS ( b ) < [Pct Floor] || SIGN ( a ) * SIGN ( b ) < 0,
        BLANK (),
        DIVIDE ( [Variance FA], ABS ( b ) )
    )

returning BLANK() and using a format string or a separate text measure to display "n.m.".

Margin-type lines

For lines already expressed as percentages (gross margin %, EBITDA margin %, attrition %), the variance is shown in percentage points or bps, not as a percentage of a percentage: GM% budget 38.0%, actual 37.2% → (80) bps, not (2.1%). Mixing "% change" and "pp change" is a frequent source of confusion in board packs.

Growth % vs prior year

The same rules apply to YoY growth: growth % = (Current − PY) ÷ ABS(PY), with "n.m." for sign changes and zero bases. Investor presentations of Indian listed companies often show "n.m." or "—" for PAT growth when the prior year was a loss — consistent with this rule.

Edge cases & judgement calls

  • Aggregates of mixed-sign lines. A "Net other income/(expense)" line may be +3 budget, −1 actual. Use n.m. and explain components.
  • YTD vs month. A line may have opposite signs in the month but the same sign YTD; apply the rule independently per column.
  • Floors and consistency. If you introduce a floor, apply it in Excel and Power BI identically; otherwise the same line shows "n.m." in one and 1,100% in the other.
  • Sorting by variance %. "n.m." text cells break numeric sorts and top-N rankings. Keep a hidden numeric column (e.g., blank or a sentinel) and sort by ₹ variance for exception lists.
  • Do not use ABS(Actual) as denominator. It changes the meaning (variance relative to outcome rather than plan) and makes percentages non-comparable across months.

Key takeaways

  • Variance % = Variance ÷ ABS(Budget), so the % sign always matches the ₹ variance sign.
  • Show "n.m." when the budget is zero, below a floor, or opposite in sign to actual.
  • A zero actual against a non-zero budget gives a meaningful ±100%.
  • Express variances of percentage lines in bps or percentage points, not as % of %.
  • Implement the same rule in Excel and DAX, and let the ₹ variance drive exception reporting.

Practice Questions

Q1. Apply the rule [L1]

Compute the Fav/(Adv) variance and the displayed variance % for each (₹ lakh): (a) Revenue budget 800, actual 760; (b) EBITDA budget −120, actual −150; (c) Net finance cost (expense) budget 40, actual −5 (net finance income); (d) Marketing budget 0, actual 18; (e) Freight budget 65, actual 0.

Q2. Signed model check [L2]

In a profit-effect signed model (costs negative), employee cost budget is −₹410 lakh and actual −₹395 lakh. Compute variance and variance % using =Act-Bud and /ABS(Bud). Then compute the same line in an unsigned model using Budget − Actual. Confirm the two approaches agree and explain why the naive Var/Bud would disagree in the signed model.

💡 Hint: Watch the sign of the denominator in the signed model.

Q3. Floor setting [L2]

Your pack has 220 cost lines; 35 have budgets under ₹2 lakh and frequently show variances above 300%. Propose a floor rule and an exception-reporting rule that together keep the variance % column readable without hiding real issues, and write the Excel formula.

Q4. Board-pack wording [L3]

A segment swung from budgeted EBITDA of ₹4.5 crore to an actual loss of ₹1.2 crore, while group EBITDA margin fell from 16.2% to 15.1%. A draft board slide says "Segment EBITDA (127%) vs budget; group margin (6.8%)". Rewrite the slide's variance statements correctly, explaining each change.
