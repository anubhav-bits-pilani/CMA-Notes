Key concept

Variable Overhead Spending and Efficiency Variances

Concept: Variable OH spending = (Standard rate − Actual rate) × Actual hours; efficiency = (Standard hours for actual output − Actual hours) × Standard rate

Statement

\[ \text{VOH spending} = (\text{SR} - \text{AR}) \times \text{AH} \]

\[ \text{VOH efficiency} = (\text{SH} - \text{AH}) \times \text{SR} \]

\[ \text{Total VOH variance} = \text{SH} \times \text{SR} - \text{AH} \times \text{AR} \]

where SR is the standard (budgeted) variable overhead rate per unit of the activity base (₹ per machine hour or labour hour), AR the actual variable overhead rate (actual variable overhead ÷ AH), AH actual hours worked, and SH standard hours allowed for actual output (actual units × standard hours per unit). Positive values are favourable.

Explanation

Variable overheads (power, fuel, consumables, lubricants, indirect materials) are not traced per unit; they are flexed on an activity base assumed to drive them. Two questions follow:

  • Spending: given the hours actually worked, did we spend more or less per hour than the standard rate? Causes: tariff or price changes, wastage of consumables, inefficient use of power per hour (idle running, compressed air leaks). It mixes price and "usage per hour" of overhead resources.
  • Efficiency: did we use more or fewer hours than standard for the output achieved? Since variable overhead is assumed to follow hours, extra hours imply extra overhead. This variance has the same cause as the labour or machine efficiency variance — it measures the efficiency of the base, not of overhead purchasing.

Conditions: the activity base must genuinely drive the overhead; if overheads follow batches or changeovers rather than hours, efficiency variances are misleading (use activity-based flexing, s06). The rate SR must be computed on the same base used for flexing.

Illustration

Standard: 0.4 machine hours per unit; SR ₹650 per machine hour. Actual output 30,000 units; AH 12,600; actual variable overhead ₹80.64 lakh.

  • SH = 30,000 × 0.4 = 12,000 h; AR = 80,64,000 ÷ 12,600 = ₹640/h.
  • Spending = (650 − 640) × 12,600 = ₹1.26 lakh F.
  • Efficiency = (12,000 − 12,600) × 650 = ₹3.90 lakh A.
  • Total = 12,000 × 650 − 80.64 lakh = 78.00 − 80.64 = ₹2.64 lakh A.

Interpretation: per hour, overheads were cheaper than standard (perhaps lower power tariff), but 600 extra machine hours (5% over standard — slower line speeds or more downtime counted as run time) cost ₹3.9 lakh.

Spending   =(SR - ActVOH/AH) * AH
Efficiency =(ActUnits*SHperUnit - AH) * SR

Practice Questions

Q1. Compute VOH variances [L1]

Standard 1.2 labour hours per unit at a variable overhead rate of ₹180 per labour hour. Actual output 8,500 units; actual hours 10,050; actual variable overhead ₹18.6 lakh. Compute VOH spending, efficiency and total variances.

Q2. Diagnosing causes [L2]

A plant reports VOH spending ₹2.1 lakh A and efficiency ₹0.4 lakh F in a month with a 9% electricity tariff hike and a new line-speed improvement. Explain how each event affects each variance, and how you would separate the tariff effect from consumption per hour in the spending variance.

💡 Hint: Split spending into tariff (price) × actual kWh and kWh-per-hour (usage) × standard tariff.

Q3. Wrong base [L2]

Variable overheads in a bottling plant are mainly CIP cleaning and changeover power. In a month with 30% more changeovers but the same machine hours per unit, explain what the machine-hour-based VOH variances will show and how an activity-based base would change the analysis.
