Key concept

Executive Deck Structure: Summary, Core Slides, Appendix

Concept: Deck structure: 1-page executive summary, 5–8 core slides, appendix

Statement

An executive deck has three tiers:

\[ \text{Deck} = \underbrace{1 \ \text{summary page}}_{\text{the answer}} + \underbrace{5 \text{ to } 8 \ \text{core slides}}_{\text{the argument}} + \underbrace{\text{Appendix}}_{\text{the evidence}} \]

The summary states the conclusion, headline numbers and decisions required; the core slides each carry one message that supports the summary; the appendix holds detailed schedules, definitions and methodology referenced from the core slides.

Explanation

The structure reflects how senior audiences consume information: they read page 1, skim titles, and dive into detail only where they question something. Limiting core slides to 5–8 forces prioritisation — each slide must earn its place by supporting a key message or a decision. A typical Project 6 core set: performance (AvBvPY), EBITDA bridge, segment highlights, KPI scorecard, cash and working capital, outlook (LE vs AOP/guidance), risks and opportunities, decisions.

Conditions for the structure to work:

  • Summary stands alone: someone who reads only page 1 knows the result, the cause, the outlook and what is being asked.
  • One message per slide expressed in an action title; supporting chart or table with no more than the data needed.
  • Consistent order every month (link to t1 c05) so the audience knows where to look.
  • Appendix referenced, not dumped: each appendix page is cited from a core slide ("see A3") or the methodology.
  • Numbers tie: every number on summary and core slides traces to the model (s02 deck tie-out check).

Variations: a board deck may add governance pages (compliance, related-party transactions for Audit Committee, SEBI LODR results calendar) but keeps the same tiering; a pre-read may have more text than a presented deck.

Practice Questions

Q1. Cut the deck [L2]

A colleague's MBR deck has 26 slides, with the summary on slide 4 and twelve tables of departmental opex. Propose a restructured deck with a summary, up to eight core slides and an appendix, and explain what moves where.

💡 Hint: Start by writing the three to five key messages; each core slide must support one of them.

Q2. Summary page test [L1]

List the elements that must appear on a stand-alone executive summary page, and write a sample headline for a month in which revenue beat AOP by 4% but EBITDA missed by 6%.

Q3. Board adaptation [L3]

Explain how you would adapt the eight-slide MBR deck into a quarterly board pack for an NSE-listed company, including which slides you would add for the Audit Committee and which numbers must reconcile to the published quarterly results.
