Key concept

Example RAG Rule: Green ≥ 100%, Amber 95–<100%, Red < 95%

Concept: Example RAG: Green ≥ 100%, Amber 95–<100%, Red < 95% of target; =IF(Att>=1,"G",IF(Att>=0.95,"A","R"))

Statement

Given direction-aware attainment \(\text{Att}\) (c01):

\[ \text{Status} = \begin{cases} \text{Green} & \text{Att} \geq 100\% \\ \text{Amber} & 95\% \leq \text{Att} < 100\% \\ \text{Red} & \text{Att} < 95\% \end{cases} \]

Excel implementation, where Att is the attainment cell or name:

=IF(Att>=1,"G",IF(Att>=0.95,"A","R"))

Explanation

This is the default three-band traffic-light rule: Green means at or better than target, Amber means slightly below (within a 5% tolerance) and Red means materially below. The nested IF tests the Green condition first, then Amber; anything else falls to Red. Because attainment is already direction-aware, the same formula works for both higher-is-better and lower-is-better KPIs.

Points to get right:

  • Boundary inclusion: exactly 100% is Green; exactly 95% is Amber. State this in the definition sheet so nobody argues over 94.99% vs 95.00%.
  • Display rounding: 94.96% displays as 95.0% at one decimal but is Red; either round attainment before testing (ROUND(Att,3)) or display enough decimals.
  • Errors and blanks: if attainment is an error (target zero) or blank (no data), the nested IF returns an error or "R"; wrap with an explicit test, e.g. =IF(ISNUMBER(Att), IF(Att>=1,"G",IF(Att>=0.95,"A","R")), "n/a").
  • KPI-specific thresholds: 95% is an example, not a universal rule. Replace hard-coded 1 and 0.95 with references to the KPI's parameter row ([@GreenThr], [@AmberThr]), so volatile KPIs can have wider bands and critical ones tighter (see s03 and the topic pitfall on uniform thresholds).
  • Excel 365 alternative: =IFS(Att>=1,"G",Att>=0.95,"A",TRUE,"R") reads more clearly; for KPI-specific thresholds XLOOKUP with match mode −1 against a sorted threshold table also works.

Illustration

Shakti October, default rule:

KPI Attainment Status
Fill rate (93% vs 97%) 95.9% A
OTIF (88% vs 95%) 92.6% R
NPS (41 vs 45) 91.1% R
GM % (33.6% vs 34.0%) — hypothetical month 98.8% A
Net debt/EBITDA (1.28× vs ≤ 1.50×) 117.2% G

Note that NPS is Red under the default rule but Amber under the volatility-based band of s03 (Amber ≥ 39), and GM% at 40 bps below target is only Amber under the ratio rule though it is worth about ₹4.7 crore of annual gross margin on ₹1,170 crore revenue — showing why KPI-specific bands matter.

Connections

The rule consumes attainment (c01), is customised by tolerance bands (s03), automated through conditional formatting and DAX status measures (s04) and documented in the definition sheet (s05). In Power BI the equivalent status measure returns 3/2/1 and a colour hex code for field-value formatting (Week 11).

Practice Questions

Q1. Apply and extend the formula [L1]

Write the Excel formula that returns "G", "A", "R" or "n/a" using KPI-specific thresholds in columns F (Green) and G (Amber) for attainment in E5, and test it on: 1.000, 0.9499, 0.95, blank, #DIV/0!.

Q2. Four-band design [L2]

Shakti's CFO wants a fourth status "Blue" for attainment above 110% to prompt review of soft targets or data errors. Write the formula, the conditional formatting rules, and identify which of these October KPIs would turn Blue: Net debt/EBITDA (117.2%), distributor salesmen trained (260 vs 233), A&P spend (₹33 crore vs ₹35 crore budget, lower-is-better).

💡 Hint: Consider whether "Blue" is desirable for a cost KPI that is under-spent because activity was deferred.

Q3. Threshold sensitivity [L2]

With the default rule, how many of these attainments change colour if the Amber threshold moves from 95% to 90%: 92.6%, 88.2%, 91.5%, 75.0%, 95.9%, 91.1%? Discuss whether the change improves or weakens the scorecard's information value.
