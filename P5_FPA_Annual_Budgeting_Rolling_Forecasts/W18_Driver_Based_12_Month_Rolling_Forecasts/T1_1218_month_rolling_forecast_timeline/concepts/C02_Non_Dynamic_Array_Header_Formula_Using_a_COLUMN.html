Key concept

Non-Dynamic-Array Header Formula Using a COLUMN Offset

Concept: Non-dynamic-array header: =EOMONTH($B$1,COLUMN()-COLUMN($C$1)+1) copied across

Statement

Where dynamic arrays are unavailable or undesirable, put the cutoff in $B$1 and enter in the first header cell (column C), then copy across:

=EOMONTH($B$1,COLUMN()-COLUMN($C$1)+1)

For the header in column \( j \):

\[ k_j = \text{COLUMN}(j) - \text{COLUMN}(C) + 1, \qquad H_j = \text{EOMONTH}(\text{Cutoff}, k_j) \]

where \( \text{COLUMN}(j) \) is the column number of the cell containing the formula, \( \text{COLUMN}(C) \) is the column number of the anchor (the first header column, here 3), and \( k_j \) is the month offset (1 in column C, 2 in column D, … 12 in column N).

Explanation

COLUMN() with no argument returns the column number of the cell the formula sits in. Subtracting the anchor column (absolute $C$1, so the reference does not move when copied) produces a counter starting at 0 in column C; adding 1 makes the first header the month after the cutoff. Because the cutoff reference $B$1 is absolute, each copied cell reads the same cutoff and only the counter changes.

Why use it:

  • Compatibility: works in every Excel version and in Google Sheets; dynamic arrays from Excel 365 appear as legacy array formulas or errors in Excel 2016/2019.
  • Cell-level formulas: each header is its own formula, which some audit and model-review tools handle better than spill ranges; individual columns can be formatted or grouped independently.
  • No spill collisions: nothing can block a spill.

Robustness considerations:

  • Anchoring with COLUMN($C$1) rather than a hard-coded 3 keeps the formula correct if columns are inserted before column C (both references shift). A literal COLUMN()-2 breaks on insertion.
  • Inserting a column inside the header range shifts subsequent counters correctly, but the inserted column is blank until the formula is copied into it — check for blanks.
  • Prefer a named cutoff (Cutoff) over $B$1 for readability; the logic is the same.
  • An even more robust alternative chains each header to the previous: D4: =EOMONTH(C4,1), with C4: =EOMONTH(Cutoff,1). Chaining tolerates any column position but propagates an error from one cell to all following.
  • For vertical timelines, use ROW()-ROW($A$5)+1.

Illustration

B1 = 30-Sep-2025. Header formulas in C4:N4.

Cell Counter COLUMN()-COLUMN($C$1)+1 Result
C4 3 − 3 + 1 = 1 31-Oct-2025
D4 4 − 3 + 1 = 2 30-Nov-2025
H4 8 − 3 + 1 = 6 31-Mar-2026
N4 14 − 3 + 1 = 12 30-Sep-2026

A user inserts a new column before column C to add a "Description" column. Headers now sit in D4:O4; the anchor $C$1 becomes $D$1, counters still start at 1, and all headers remain correct. Had the formula used COLUMN()-2, D4 would now return EOMONTH(Cutoff, 2) = 30-Nov-2025 — every header shifted one month, silently misaligning all SUMIFS.

Connections

This is the legacy twin of c01 and supports s03 (dynamic headers). It ties to c05: COLUMN() is non-volatile, unlike OFFSET/INDIRECT, so this approach keeps recalculation fast. In Phase 4 model-build tests, timeline headers are frequently required in this copy-across form because test environments may run older Excel. The same counter idea underlies period-number rows used in DCF discounting (period \( t \) in \( 1/(1+r)^t \)).

Practice Questions

Q1. Counter arithmetic [L1]

The first header is in cell F6 and the cutoff is named Cutoff = 31-Jan-2026. Write the copy-across header formula, and state the values in F6, K6 and Q6.

Q2. Insertion stress test [L2]

A model uses =EOMONTH($B$1,COLUMN()-3) in C4:N4. A reviewer inserts two columns before C and one column between G and H. Describe what each header now shows and rewrite the formula to be robust to both insertions.

Q3. Chained vs counter headers [L2]

Compare the chained approach (=EOMONTH(C4,1)) with the counter approach for a 60-month model used in a lender case. Discuss error propagation, auditability, flexibility for a quarterly section after month 24, and which you would choose.

💡 Hint: Think about what happens when the timeline must switch from monthly to quarterly steps partway along.
