Key concept

Prefer INDEX/XLOOKUP over Volatile OFFSET/INDIRECT

Concept: Prefer INDEX / XLOOKUP over volatile OFFSET/INDIRECT for dynamic windows

Statement

To build ranges or lookups that move with the cutoff, use non-volatile functions — INDEX, XLOOKUP, XMATCH, SUMIFS, FILTER, TAKE, DROP, CHOOSECOLS — rather than the volatile OFFSET and INDIRECT.

A dynamic window of the last \( n \) actual months ending at the cutoff column position \( p \) can be written:

\[ \text{Range} = \text{INDEX}(R, p - n + 1) : \text{INDEX}(R, p) \]

where \( R \) is the full row of monthly values, \( p = \text{XMATCH}(\text{Cutoff}, \text{Headers}) \) the position of the cutoff month, and \( n \) the window length.

Explanation

Volatility. A volatile function recalculates whenever anything in the workbook changes, and forces every dependent formula to recalculate too. OFFSET, INDIRECT, TODAY, NOW, RAND and CELL/INFO (in some forms) are volatile. In a forecast model with tens of thousands of SUMIFS, a few hundred OFFSET calls make every edit trigger a full recalculation — seconds per keystroke.

Auditability. OFFSET(C5,0,0,1,12) hides which cells are actually summed; Trace Precedents shows only the anchor. INDIRECT("'"&Sheet&"'!C5") builds references from text: precedents are invisible, renaming a sheet breaks it silently (it returns #REF! only when evaluated), and model-audit tools such as Inquire cannot follow it.

Equivalent non-volatile patterns:

Purpose Volatile (avoid) Non-volatile (prefer)
Sum last 3 actual months =SUM(OFFSET(C5,0,p-3,1,3)) =SUM(INDEX(C5:N5,p-2):INDEX(C5:N5,p))
YTD to cutoff =SUM(OFFSET(C5,0,0,1,p)) =SUMIFS(C5:N5,C$4:N$4,"<="&Cutoff)
Value at cutoff month =OFFSET(C5,0,p-1) =XLOOKUP(Cutoff,C$4:N$4,C5:N5)
Choose scenario sheet =INDIRECT(Scen&"!C5") =CHOOSE(ScenNo,Base!C5,Up!C5,Down!C5) or a long table with a scenario column
Last 3 of a spill OFFSET on spill =TAKE(FILTER(Vals,Hdrs<=Cutoff),,-3)

INDEX returning a reference (the INDEX(...):INDEX(...) construction) is non-volatile in modern Excel and fully traceable.

Exceptions. OFFSET is acceptable in a few named ranges for chart series or data-validation lists in small models, and INDIRECT is sometimes unavoidable when referencing closed external workbooks — but those should be rare and documented. TODAY() must never drive the cutoff: the model would roll on its own without a close.

Illustration

Row 5 holds FY26 monthly revenue in C5:N5 (Apr–Mar); cutoff 30-Sep-2025, so \( p \) = 6. Last-3-month run-rate:

=AVERAGE(INDEX(C5:N5,XMATCH(Cutoff,C4:N4)-2):INDEX(C5:N5,XMATCH(Cutoff,C4:N4)))

averages July–September. With LET:

=LET(p,XMATCH(Cutoff,C4:N4), AVERAGE(INDEX(C5:N5,p-2):INDEX(C5:N5,p)))

A 300-line model replacing 3,600 OFFSET formulas with this pattern typically recalculates noticeably faster and passes Inquire's precedent analysis.

Connections

Q2. Trailing-3 average in a rolling grid [L2]
