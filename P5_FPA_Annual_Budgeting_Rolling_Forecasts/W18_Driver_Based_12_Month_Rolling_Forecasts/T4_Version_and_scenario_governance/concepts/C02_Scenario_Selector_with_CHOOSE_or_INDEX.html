Key concept

Scenario Selector with CHOOSE or INDEX

Concept: Scenario selector: =CHOOSE(ScenarioNo,Base,Upside,Downside) or =INDEX(ScenRange,,ScenarioNo)

Statement

A scenario selector returns the active scenario's value for an assumption from a set of alternatives, driven by a single integer ScenarioNo:

=CHOOSE(ScenarioNo, Base, Upside, Downside)
=INDEX(ScenRange, , ScenarioNo)
  • ScenarioNo — named input cell holding 1, 2 or 3 (validated).
  • Base, Upside, Downside — references (cells or named ranges) holding each scenario's value.
  • ScenRange — a contiguous block with one column per scenario (rows = drivers or months). The omitted row argument in INDEX(ScenRange,,ScenarioNo) returns the entire column, which spills as a dynamic array in Excel 365 or can be used row by row as INDEX($E7:$G7,,ScenarioNo).

Formally, for assumption \(d\) with scenario values \(x_{d,1}, x_{d,2}, x_{d,3}\):

\[ \text{Live}_d = x_{d,k}, \quad k = \text{ScenarioNo} \in \{1, 2, 3\} \]

Explanation

CHOOSE takes an index and a list of up to 254 values or references and returns the k-th. It is readable ("1 = Base, 2 = Upside, 3 = Downside") and works with non-contiguous references. Its weaknesses: every argument is a separate reference, so formulas on different rows can silently point to the wrong column; adding a fourth scenario requires editing every formula; and it returns #VALUE! if the index is outside 1…n.

INDEX with a column number selects from a contiguous range. One consistent formula works down an entire assumption block; adding a scenario column only requires widening ScenRange. It is non-volatile and easy to trace. If the index exceeds the number of columns it returns #REF! — a useful loud failure.

Choosing between them:

Criterion CHOOSE INDEX
Number of scenarios Small, fixed Any; extensible
Layout Non-contiguous allowed Contiguous block needed
Consistency risk Higher (per-row references) Lower (one range)
Returning whole arrays Possible but clumsy Natural (INDEX(rng,,k))
Readability for reviewers High for 2–3 cases High with labelled headers

Both should be paired with data validation on ScenarioNo (whole number between 1 and the count of scenarios, or a drop-down of names with MATCH converting to a number) and an on-page label showing the active scenario. Prefer either over nested IF chains and over volatile OFFSET/INDIRECT (Topic 1, c05). When selecting by name rather than number, XLOOKUP(SelScen, Hdr, Row) is an equally good third option (s03).

Illustration

Assumption block on the Inputs sheet (columns E:G = Base, Upside, Downside):

Row Driver E Base F Upside G Downside
7 H2 volume growth 8% 12% 2%
8 Realisation ₹/kg 182 186 176
9 Debtor days 42 40 50

With ScenarioNo = 3: =CHOOSE(ScenarioNo,E8,F8,G8) and =INDEX($E8:$G8,,ScenarioNo) both return ₹176/kg. =INDEX($E$7:$G$9,,ScenarioNo) spills {2%; 176; 50} for the full Downside column.

Now suppose the analyst inserts a new "Stress" scenario in column H. The INDEX formulas need only $E8:$H8; with ScenarioNo = 4 they return the stress values. The CHOOSE formulas must each be edited to add H8; any row missed returns #VALUE! for ScenarioNo = 4, which at least fails loudly, but a row where someone typed CHOOSE(ScenarioNo,E8,G8,F8) returns the Upside value under Downside without any error.

Connections

This concept implements s03 (scenario switching) and complements c01, which retrieves stored scenario results from the long table by a Scenario criterion. The distinction between what the selector changes (a coherent set of linked assumptions) and a one-variable flex is c05. In Phase 4 three-statement and DCF models the same selector drives revenue, margins, capex and working capital; in Power BI the equivalent is a disconnected Scenario table with SELECTEDVALUE.

Practice Questions

Q1. Write and extend a selector [L1]

An assumption block in Inputs!D10:F25 holds Base, Upside and Downside for 16 drivers. (a) Write the CHOOSE and the INDEX selector for row 14. (b) A fourth "Stress" column is added in G. Describe the edits needed under each approach. (c) Write a data-validation rule for ScenarioNo that remains correct when scenarios are added.

Q2. Error behaviour [L2]

For ScenarioNo values of 0, 2.6, 4 and blank, state what =CHOOSE(ScenarioNo,E8,F8,G8) and =INDEX($E8:$G8,,ScenarioNo) return, and explain which behaviours are dangerous in a Board model.

💡 Hint: Test how each function truncates non-integers and treats a blank index before answering.

Q3. Monthly scenario drivers [L2]

Volume growth assumptions vary by month (12 months × 3 scenarios) and are stored on a sheet as three stacked 1 × 12 blocks in rows 20, 21 and 22, columns D:O. Write one formula, fillable across D:O on the calculation sheet, that returns the active scenario's monthly growth, and explain why this is safer than a CHOOSE across three rows.
