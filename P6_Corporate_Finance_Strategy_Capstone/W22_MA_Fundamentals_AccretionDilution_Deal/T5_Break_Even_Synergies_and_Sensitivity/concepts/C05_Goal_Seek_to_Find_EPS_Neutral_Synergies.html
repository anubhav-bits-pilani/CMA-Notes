Key concept

Goal Seek to Find EPS-Neutral Synergies

Concept: Goal Seek: set pro-forma EPS − standalone EPS = 0 by changing synergies input

Statement

Goal Seek (Data → What-If Analysis → Goal Seek) iteratively changes one input cell until a formula cell reaches a target value. For break-even synergies:

Goal Seek field Entry
Set cell Difference cell: =PF_EPS - SA_EPS for the year
To value 0
By changing cell The pre-tax synergy input for that year

At convergence, the synergy input holds the break-even \(S^{*}\) such that

\[ \text{EPS}_{PF}(S^{*}) - \text{EPS}_{A} = 0 \]

Explanation

Goal Seek is a numerical root-finder (secant/Newton-type iteration). It is useful when:

  • the model is non-linear in synergies — e.g. ratings-linked margin ratchets that depend on leverage, which depends on synergies; tax-deductibility caps; synergy-linked working capital; or NCI whose share depends on where synergies land;
  • you want to verify the closed-form formula (c01/c02);
  • you need a one-off answer for a different target (e.g. maximum offer price: set the same difference cell to 0 by changing the offer premium input — topic 5 s04).

Limitations and good practice:

  • It writes a constant into the input cell. The result does not update when other inputs change — never present a Goal Seek result as a live output (topic pitfall on hard-coding). Restore the synergy input after the check, or keep a dedicated "Goal Seek scratch" input that feeds only a test copy of the calculation.
  • Set a difference cell, not EPS itself, so the target is always 0 even when standalone EPS changes.
  • Precision: Goal Seek stops at a tolerance (File → Options → Formulas → Maximum Change, default 0.001, with Maximum Iterations); with EPS in rupees, a tolerance of 0.001 means ₹0.001 per share — adequate, but check the residual.
  • Circularity: with iterative calculation enabled, Goal Seek can converge erratically; switch to opening-balance interest temporarily.
  • One year at a time. Run separately for Year 1 and Year 2. For repeated use, a short VBA macro can loop over years and paste results into an audit table with a timestamp.
  • Multiple roots / no root: if the deal is accretive at zero synergies, Goal Seek may return a negative synergy — interpret as nil break-even.

Illustration

Bharat Polymers / Deccan Packaging, 60/40 deal, Year 1. Inputs: synergies cell Inputs!D20 = 100; difference cell Outputs!F30 = =PF_EPS_Y1 - SA_EPS_Y1 = 19.989 − 20.000 = −0.011.

Goal Seek: Set cell F30, To value 0, By changing D20. Result: D20 = 100.87, F30 ≈ 0.0000. This matches the closed-form \(S^{*} = (20 \times 60 - 1{,}124.35) \div 0.75 = 100.87\).

Now add a ratings ratchet: if Net Debt/EBITDA exceeds 1.70x, the margin on the ₹1,620 crore loan rises by 25 bps. With synergies near ₹100 crore, leverage is ≈1.71x, so the ratchet applies; break-even becomes non-linear around the threshold. Goal Seek finds \(S^{*}\) ≈ ₹104.9 crore — about ₹4 crore above the closed-form answer, since 1,620 × 0.25% = ₹4.05 crore of extra pre-tax interest must also be covered. The closed-form formula would still be correct if the ratchet were included in \(\text{PAT}_{PF}^{\text{ex-}S}\), but because the ratchet depends on \(S\), only an iterative solve handles it cleanly.

Simple VBA loop for multiple years:

Sub BreakEvenSynergies()
    Dim y As Integer
    For y = 1 To 2
        Range("Diff_Y" & y).GoalSeek Goal:=0, ChangingCell:=Range("Syn_Y" & y)
        Range("BE_Audit").Offset(y, 0).Value = Range("Syn_Y" & y).Value
    Next y
End Sub
