Key concept

Excel Data Tables for Accretion Sensitivity

Concept: Excel data table: {=TABLE(row_input, col_input)} via What-If Analysis; inputs must be on the same sheet as the table

Statement

An Excel data table is an array that recalculates a model output for each combination of input values listed on its axes. It is created via Data → What-If Analysis → Data Table and appears in every result cell as

{=TABLE(row_input_cell, column_input_cell)}

For a two-variable table, the top-left cell holds a link to the output (e.g. =Accretion_Y1), the top row holds values for the row input cell, the left column holds values for the column input cell. Excel substitutes each pair into the input cells, recalculates the workbook, and records the output. The row and column input cells must be on the same worksheet as the data table.

Explanation

Mechanics and rules:

  • One-variable table: values in a column (or row); one input cell; one or more outputs across the top. Useful for scenario numbers (topic 5 s05).
  • Two-variable table: one output only, in the corner cell.
  • "Row input cell" is the cell the top-row values feed; "Column input cell" is the cell the left-column values feed — reversing them is the commonest error, producing a transposed or nonsensical grid.
  • Same-sheet constraint: if the model's inputs live on an Inputs sheet, create driver cells on the table's sheet and make the model inputs reference them (e.g. Inputs!C8 =Outputs!$C$4), or place the table on the Inputs sheet. Never point the input cell to a cell that itself contains a formula linking elsewhere — the input cell must be a hard-coded input that the model depends on.
  • The array cannot be edited cell by cell; delete the whole result range to rebuild.
  • Calculation mode: File → Options → Formulas. "Automatic except for data tables" speeds large models but leaves tables stale until F9. Add a check: base-case cell of the table minus live output = 0.
  • Circularity: tables in models with iterative calculation (interest circularity) can produce unstable results; use a circuit-breaker or opening-balance interest when running tables.
  • Performance: each cell is a full recalculation; a 10 × 10 table means 100 recalcs. Keep tables few and lean.
  • No Goal Seek inside a table. If the output is a break-even, compute it algebraically (c01) so the table can recalculate it.

Illustration

Layout on the Outputs sheet for a synergies × interest rate table (topic 5 s03, Table 2):

Cell Content

C4 Driver: debt rate (input, e.g. 9.0%) — Inputs!D21 references =Outputs!$C$4
E6 =Accretion_Y1

E7:E11 50, 75, 100, 125, 150 (synergies)
F7:J11 Data Table with Row input cell = C4, Column input cell = C3

Base cell H9 (100, 9.0%) should equal the live output (−0.1%); check cell =ROUND(H9 - Accretion_Y1, 6) must return 0.
