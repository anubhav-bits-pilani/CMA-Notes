Subtopic note

Sensitivity Tables for Accretion and Break-Even Synergies

Scope: Sensitivity tables: offer premium × funding mix, synergy level × interest rate, target growth × integration cost

Why it matters

Negotiations move three or four variables at once. The seller pushes the premium up; the treasury team's financing options change the mix of debt, cash and stock; the rate environment shifts between signing and closing; the integration team revises synergy and cost-to-achieve estimates. A single-point accretion figure cannot support those discussions. Two-variable sensitivity tables show the board the whole landscape: where the deal is accretive, where it turns dilutive, and how sensitive the answer is to each pair of drivers. In Indian board packs and fairness opinions, the three grids named in the scope are the standard set.

Core notes

Design principles

  1. Pick the output. Accretion % for a given year is the default; break-even synergies and pro-forma Net Debt/EBITDA are common alternatives. One output per table.
  2. Pick paired drivers that interact. Premium and funding mix interact (premium raises the amount funded); synergies and interest rate offset each other; target growth and integration cost trade off in Year 2.
  3. Centre on the base case. Put the base case in the middle of each axis so the reader sees symmetric up/down moves; highlight the base cell.
  4. Sensible steps. Premium 0–40% in 10% steps; stock % 0–100% in 25% steps; synergies ±50% of guidance; rate ±100 bps in 25–50 bps steps.
  5. Link, do not hard-code. Every table must be a live Excel data table (concept c04) or a formula grid; the base cell must equal the live model output (add a check).
  6. State fixed assumptions under each table (other drivers held at base, year, EPS basis).

Break-even synergy tables

The same grids can output break-even synergies instead of accretion; for example, break-even synergies by premium × stock % lets the board read "at a 30% premium and 50% stock we need ₹X crore". Because break-even is computed by a closed-form formula (c01), a data table on it is straightforward. A data table cannot run Goal Seek inside each cell — another reason to use the algebraic formula.

Building in Excel

  • Inputs used as row/column drivers must be on the same sheet as the data table (Excel restriction, concept c04). Create local "sensitivity driver" cells on the Outputs sheet and have the model's input cells reference them (or put the table on the Inputs sheet).
  • Top-left cell of the table links to the output (e.g. =Accretion_Y1); row and column headers are typed values; select the range and use What-If Analysis → Data Table.
  • Calculation: if set to "Automatic except for data tables", press F9 before reading results.
  • Format with a three-colour scale centred on 0 (see s06) and a custom number format 0.0%;(0.0%);0.0%.
  • For a formula-based alternative (faster, but requires the model to be expressible in one formula), compute accretion directly in each grid cell using the closed-form pro-forma.

Power BI alternative

Create what-if parameters (GENERATESERIES) for premium and synergies; write the pro-forma PAT and EPS as DAX measures using SELECTEDVALUE; place them in a matrix visual with conditional formatting. This gives management an interactive version for the deal committee, but the Excel model remains the source of truth.

Edge cases & judgement calls

  • PPA moving with premium. A higher premium increases identifiable intangibles (and their amortisation) as well as goodwill; holding PPA constant overstates accretion at high premiums. Model intangibles as a % of purchase price over book value if a full PPA is not available.
  • Debt capacity constraints. Cells with leverage above covenant or rating thresholds should be shaded or marked "n.a." rather than shown as accretive.
  • Non-linear effects. Rating ratchets, NCI acceptance levels and tax-deductibility limits create kinks; check a few cells by hand.
  • Too many tables. Dozens of data tables slow large models dramatically; keep 3–5 key grids and use scenario switches for the rest.
  • Spurious precision. Show accretion to one decimal of a percent; synergy figures to the nearest ₹ crore.

Key takeaways

  • Use three standard grids: premium × funding mix, synergies × interest rate, target growth × integration cost.
  • Centre axes on the base case, use sensible steps, one output per table, and a check that the base cell equals the live model.
  • Data-table drivers must sit on the same sheet as the table; recalculate before reading if tables are excluded from automatic calculation.
  • Break-even synergy grids rely on the closed-form formula, not Goal Seek.
  • Flag infeasible cells (covenant breach, insufficient cash) instead of presenting them as valid outcomes.

Debt at 8.9%, tax 25.168%, synergies ₹90 crore pre-tax, after-tax PPA amortisation = 20% of the premium in rupees ÷ 10 years × (1 − t). Specify the Excel layout and formulas for a data table of Year 1 accretion with premiums 15–45% (rows) and stock 0–100% (columns, balance debt), and compute the four corner cells by hand.

Q2. Interpreting the synergy × rate grid [L2]
