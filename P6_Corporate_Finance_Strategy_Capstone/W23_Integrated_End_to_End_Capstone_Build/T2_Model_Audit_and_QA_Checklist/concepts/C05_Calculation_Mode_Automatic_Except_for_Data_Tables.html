Key concept

Calculation Mode: Automatic Except for Data Tables

Concept: Calculation option "Automatic except for data tables" speeds large models; press F9 before reading sensitivities

Statement

Excel offers three workbook calculation modes (Formulas → Calculation Options, or File → Options → Formulas):

Mode Behaviour
Automatic Every change recalculates all dependent formulas, including every data table
Automatic except for data tables Every change recalculates the model; data tables recalculate only on F9 (Calculate Now) or Shift+F9 (Calculate Sheet)
Manual Nothing recalculates until F9; optional "recalculate before save"

With \(N\) data tables of \(r_k \times c_k\) cells, one change under Automatic triggers approximately

\[ R = 1 + \sum_{k=1}^{N} r_k \times c_k \]

full-model recalculations, where each table cell requires the model to recalculate with substituted inputs. Under "Automatic except for data tables", \(R = 1\) until F9 is pressed.

Explanation

Data tables are powerful but expensive. Three 5 × 5 tables and one 1 × 3 scenario table mean about 79 full recalculations per keystroke. In a 20-sheet model with iterative interest, that can be several seconds per edit, which makes building and debugging painful. "Automatic except for data tables" keeps the main model live while deferring the tables.

The cost is staleness: until you press F9, tables show the results of the last full calculation, which may predate your latest changes. Hence the rule in the concept: press F9 before reading, copying or presenting sensitivities. Supporting controls:

  • A sensitivity centre check (s05): the centre cell of each table must equal the live base output. If it does not, the table is stale (or mis-wired), and the master check flags it.
  • The status bar shows "Calculate" when there are pending recalculations.
  • A Cover note stating the calculation mode, and a "last full recalculation" timestamp entered at freeze.
  • Before saving a final version, press F9, confirm the master check, and save.

Important behaviours:

  • The calculation mode is an application-level setting. The first workbook opened in an Excel session sets it, and it then applies to all open workbooks. If a colleague's model was saved in Manual mode and you open it first, your own model will also be in Manual mode. Always check the mode when opening files.
  • Manual mode should never be the state of a shared model. Users will read stale numbers everywhere, not just in tables.
  • Iterative calculation settings (enabled, iterations, maximum change) are also stored with the workbook and interact with the calculation mode. Document both.
  • F9 versus Shift+F9 versus Ctrl+Alt+F9: F9 recalculates all open workbooks (including tables in this mode), Shift+F9 the active sheet only, and Ctrl+Alt+F9 forces a full recalculation of all formulas, which is useful if something seems stuck.

Illustration

A capstone model has four tables: WACC × g (7 × 7), WACC × exit multiple (7 × 7), volume × realisation (5 × 5) and a scenario table (1 × 3). Under Automatic, each edit triggers \(1 + 49 + 49 + 25 + 3 = 127\) recalculations, taking about 6 seconds. Switching to "Automatic except for data tables" makes edits instant. At 5:15 p.m. on Day 2 you change the FY28 capex phasing, and the DCF value moves from ₹612 to ₹596. The WACC × g table centre still shows ₹612 and the master check shows ERROR (sensitivity centre check). You press F9, the centre updates to ₹596, and the check returns OK. You then paste the table into the deck appendix.

Connections

This concept underpins sensitivity integrity (s05) and the F9 step in the PDF export and print routine (s07). The sensitivity centre check feeds the master check (c01). The Cover (s08) records the mode. The Week 23 t1 time plan puts sensitivity work late on Day 2 (s07) precisely because tables slow the model. In the t4 deck, every pasted heat map must come from a freshly recalculated table.

Practice Questions

Q1. Recalculation count [L1]

A model has a 9 × 9 WACC × g table, a 5 × 7 volume × price table and a 1 × 4 scenario table. Compute the number of full-model recalculations per edit under Automatic and under "Automatic except for data tables", and estimate the time per edit if one full recalculation takes 0.08 seconds.

💡 Hint: Count table cells, not tables.

Q2. Stale numbers in the deck [L2]

After the deck was sent, the CFO notices that the sensitivity heat map's centre cell (₹588) does not match the headline value (₹601). Explain the likely sequence of events, the controls that should have prevented it and the fix to the process.

Q3. Application-level setting [L2]

You open a colleague's budget model (saved in Manual mode), then your capstone model. Explain what happens to your capstone's calculation, the risks, and a routine that prevents this from causing errors.
