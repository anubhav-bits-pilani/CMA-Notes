Key concept

The Master Check: Aggregating Every Integrity Test

Concept: Master check = sum of absolute values of all individual check rows; =IF(ROUND(SUMPRODUCT(ABS(range)),2)=0,"OK","ERROR")

Statement

\[ \text{Master check} = \sum_{k=1}^{K} \sum_{t=1}^{T} \left\lvert c_{k,t} \right\rvert, \qquad \text{Status} = \begin{cases} \text{OK} & \text{if } \operatorname{round}(\text{Master check}, 2) = 0 \\ \text{ERROR} & \text{otherwise} \end{cases} \]

where \(c_{k,t}\) is the value of check \(k\) (balance, cash, RE, PPE, debt, lease roll-forward, sign count, error count, and so on) in period \(t\), each defined to equal zero when passing. In Excel, with all check rows in Checks!E8:S30:

=IF(ROUND(SUMPRODUCT(ABS(Checks!E8:S30)),2)=0,"OK","ERROR")

Explanation

A model has dozens of checks across many periods, and nobody reads them all. The master check compresses them into one status that can be shown on the Cover, in every sheet header and in the file's version log.

Why each element of the formula matters:

  • Absolute values: without ABS, a +5 error in FY28 and a −5 error in FY29 cancel to zero and the model shows "OK". Summing absolute values makes any non-zero check count.
  • SUMPRODUCT: evaluates ABS over the whole range without array entry in older Excel versions. In Microsoft 365, =SUM(ABS(range)) also works with dynamic arrays.
  • ROUND(…,2): floating-point arithmetic leaves residues like 1.4E-13 even when the logic is correct. Rounding to 2 decimals (₹0.01 crore = ₹1 lakh) sets the tolerance. Choose the precision deliberately. In a model in ₹ crore, 2 or 3 decimals is appropriate. In a model in ₹, 0 decimals.
  • Text output on the Cover. Keep the numeric sum visible too, since it tells you the size of the problem.

Design rules:

  • Every check row must be numeric and zero when passing. Convert logical checks (WACC > g, switch in range) to 1/0 flags: =--(WACC<=g).
  • Errors inside checks. If any check cell is #REF!, SUMPRODUCT returns an error and the IF returns an error, which is good because it is visible. Do not wrap the master check in IFERROR. That would turn the most important error into "OK" or blank (topic pitfall 1).
  • Weighting. Mixing ₹ crore differences with counts (sign violations) in one sum is fine, because any non-zero value fails. Show sub-totals by group on the Cover so the reader can see which group failed (s08).
  • Coverage. The master check is only as good as the checks feeding it. Include historical tie-outs, all roll-forwards, error counts and sensitivity centre checks (s02, s03, s05).
  • Propagation. Show the master status in a header cell on every sheet (=Checks!$D$3) so a failure is seen wherever you are working. Conditional formatting turns it red.

Illustration

Checks tab extract (₹ crore):

Check FY27 FY28 FY29 FY30
Balance 0.000 0.000 0.000 0.000
Cash 0.000 0.000 0.000 0.000
RE roll-forward 0.000 4.200 0.000 0.000
PPE roll-forward 0.000 0.000 0.000 −4.200
Sign count (capex) 0 0 0 0

The plain sum is 0.000 (4.2 and −4.2 cancel), so a SUM-based master check would show "OK". The absolute-value sum is 8.400, so the status is ERROR. Investigation: a dividend was charged in FY28 RE but the PPE schedule in FY30 had an offsetting typo. Two unrelated errors cancelled, which is exactly the case ABS is designed to catch.

Connections

The master check aggregates the integrity checks of s02 (including c03), the error counts of s03 and the sensitivity centre check of s05, and it is displayed on the Cover (s08). The Week 23 t1 balance and cash checks (c05) are its two most important inputs, and the week's cross-cutting exercise requires the master check status on the Cover at freeze. Practice Questions

Q1. Write the master check [L1]

Check rows are in Checks!E10:S24, with sign-count rows in E26:S28 and a WACC>g flag in D30. Write a master check formula that covers all of them and returns "OK" or "ERROR" with a ₹0.001 crore tolerance.

💡 Hint: You can add several SUMPRODUCT(ABS()) terms inside one ROUND.

Q2. Why not IFERROR [L2]

A colleague wraps the master check in IFERROR(…,"OK") "so the Cover always looks clean". Explain, with an example, the specific failure this creates and what the Cover would show for a deleted row in the BS.

Q3. Tolerance setting [L2]

Your model is in ₹ crore with three decimals. Historical tie-outs show differences of up to 0.08 because the annual report rounds to one decimal. Design the master check so that historical rounding does not trigger ERROR while forecast tolerance stays at 0.001.
