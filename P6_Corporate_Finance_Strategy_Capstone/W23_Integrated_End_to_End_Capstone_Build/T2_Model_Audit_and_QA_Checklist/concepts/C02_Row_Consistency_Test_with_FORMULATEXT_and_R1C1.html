Key concept

Row Consistency Test with FORMULATEXT and R1C1 View

Concept: Row consistency test: formula in column F should equal column E structurally (compare via FORMULATEXT or R1C1 view)

Statement

For each calculation row \(r\) and adjacent forecast columns \(j-1\) and \(j\):

\[ \text{Consistent}_{r,j} = \left[\, \text{R1C1}(r, j) = \text{R1C1}(r, j-1) \,\right] \]

where \(\text{R1C1}(r, j)\) is the formula in row \(r\), column \(j\) written in relative R1C1 notation. Two cells are structurally identical if their R1C1 formulas are the same text. In A1 notation, =E20*(1+F$12) in F20 and =F20*(1+G$12) in G20 differ as text but both read =RC[-1]*(1+R12C) in R1C1.

Explanation

The one formula per row rule (s01) is only valuable if it is tested. A row where nine cells share a formula and the tenth is different (a typed override, a pasted-over formula, an edited cell) is the most common source of silent errors in forecasts. The tenth cell usually looks plausible.

Three ways to test:

  1. R1C1 view. File → Options → Formulas → R1C1 reference style. Click across the row: the formula bar should show identical text. With Ctrl+` (show formulas) in R1C1 mode, a whole row can be scanned visually. Turn R1C1 off afterwards, because collaborators expect A1.
  2. FORMULATEXT comparison. FORMULATEXT returns A1 text, which differs column by column. Compare neighbouring cells by converting to a relative form, or more simply compare each cell with what the copied formula should be. A practical approach in a shadow sheet:
=IF(FORMULATEXT(IS!F20)=SUBSTITUTE(SUBSTITUTE(FORMULATEXT(IS!E20),"D20","E20"),"E$12","F$12"),"","DIFF")

This works for simple rows but becomes fragile with many references. For a general test, use Go To Special → Row differences (select the row block with the comparison cell active), which compares structure the way R1C1 does, or the Inquire Workbook Analysis. 3. Excel's inconsistency flag. Background error checking marks "Formula inconsistent with other formulas in the region" with a green triangle. It is useful but not exhaustive.

Legitimate differences that are not errors:

  • The actual/forecast boundary: the last historical column and the first forecast column use different logic. Test consistency within blocks.
  • The first forecast column linking an opening balance. Better design: a flag-driven single formula (s01).
  • Terminal columns in the DCF.

Each legitimate break should be visually marked (a border, a note) so the reviewer does not need to ask.

Illustration

Revenue row 20 on the IS, forecast columns J to S (FY27–FY36). R1C1 view shows:

Column R1C1 formula
J–N =RC[-1]*(1+R12C)
O =RC[-1]*(1+R12C)+40
P–S =RC[-1]*(1+R12C)

Column O (FY32) carries a typed +₹40 crore, perhaps a one-off the modeller added while testing. Because revenue compounds, every later year is ₹40 crore × growth factor higher. With g = 8% to FY36 and an 11% EBITDA margin, the TV-year EBITDA is overstated by about ₹6 crore, and at a 14× exit multiple that is about ₹84 crore of EV. Fix: remove the +40, and if a one-off is genuinely needed, add a blue input row (R13) and change the whole row to =RC[-1]*(1+R12C)+R13C.

Connections

The test enforces the standards in s01 and uses the tools in s04 (FORMULATEXT, Go To Special, Inquire). It is one block of the one-hour audit routine in s03 and part of the week checklist item on auditing hard-codes and inconsistent formulas. Weeks 9–10 introduced R1C1 and dynamic arrays (topic related item). Consistent column structure (Week 23 t1 s04) is a precondition, since the test is meaningless if years sit in different columns on different sheets.

Practice Questions

Q1. Read R1C1 [L1]

Translate these R1C1 formulas into A1 notation for a cell in K25, and state whether they are consistent with a cell in J25 containing =I25+J$40-J$41: (a) =RC[-1]+R40C-R41C; (b) =RC[-1]+R40C[-1]-R41C; (c) =R25C10+R40C-R41C.

💡 Hint: In R1C1, a bracketed number is relative and an unbracketed number is absolute.

Q2. Build a consistency map [L2]

Describe how to build a shadow sheet that shows, for every cell of the BS forecast block, whether its formula structure matches its left-hand neighbour, using Go To Special or FORMULATEXT, and how to present the result as a heat map.

Q3. Value impact of an override [L2]

In a 10-year model, the FY30 EBITDA margin cell is typed as 18.5% while the row formula would give 16.0%, and later years compound from FY30 EBITDA. FY30 revenue is ₹3,400 crore. Explain how to estimate the value impact under an exit multiple of 13× applied to FY36 EBITDA, and how a row consistency test would have caught it.
