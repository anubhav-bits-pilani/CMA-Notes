Subtopic note

Excel Audit Toolkit: Tracing, Evaluate, Go To Special, Inquire

Scope: Excel audit tools: Trace Precedents/Dependents, Evaluate Formula, Go To Special (constants, formulas), Inquire add-in, FORMULATEXT, ISFORMULA

Why it matters

Reviewing a model by clicking cell by cell does not scale beyond a few hundred formulas. A capstone model has several thousand. Excel's built-in audit tools let you answer the reviewer's three questions quickly: where does this number come from (precedents), what does it affect (dependents), and what in this range is not a formula when it should be (constants). Fluency with these tools is a practical interview skill. Modelling tests sometimes include "find the errors in this model" sections, and an FP&A analyst inheriting a budget model spends the first week doing exactly this.

Core notes

Trace Precedents and Trace Dependents

Formulas → Formula Auditing → Trace Precedents draws arrows from the cells a formula uses, and Trace Dependents draws arrows to cells that use the active cell. A dashed arrow with a worksheet icon indicates a reference on another sheet. Double-click the arrow to open the Go To list and jump there. Remove Arrows clears them.

Keyboard equivalents are faster:

Shortcut Action
Ctrl+[ Select direct precedents (jumps to other sheet if needed)
Ctrl+Shift+[ Select all precedents (direct and indirect) on the sheet
Ctrl+] Select direct dependents on the sheet
Ctrl+Shift+] Select all dependents on the sheet
F5 then Enter Return to the previous location after Ctrl+[
Ctrl+` Toggle Show Formulas view

Use cases: before deleting a row (any dependents?), verifying that the DCF EBIT comes from the IS and not a stale copy, and finding which inputs drive a suspicious output. Limitation: Ctrl+] does not follow dependents on other sheets. Use Trace Dependents arrows or Inquire's Cell Relationship diagram for that.

Evaluate Formula

Formulas → Evaluate Formula steps through a formula's calculation one operation at a time, showing intermediate results. It is ideal for long nested IF/INDEX/MATCH formulas or when a formula returns a surprising value. Step In follows a reference into its own formula. A faster alternative inside the formula bar: select part of the formula and press F9 to see its value (then Esc, not Enter, or the part is replaced by the value).

Go To Special

Home → Find & Select → Go To Special (or F5 → Special). Key options for audit:

Option Audit use
Constants (Numbers) Selects hard-coded numbers. Run on forecast blocks of calc sheets, where the result should be empty or only labelled input rows
Formulas (Errors) Selects all error cells
Formulas (Numbers/Text/Logicals) Selects formulas by result type, e.g. text results in numeric areas
Row differences Selects cells in a row whose formula differs from the comparison cell. A fast row consistency test (c02)
Column differences Same for columns
Precedents / Dependents Direct or all levels, as a selection rather than arrows
Blanks Finds gaps in a series that should be continuous
Visible cells only Copying grouped/filtered ranges without hidden rows
Last cell Reveals the used range. Stray content far below the model inflates file size and print areas

Combine with a fill colour: Go To Special → Constants → apply a temporary yellow fill → inspect → undo.

Inquire add-in

Available in Microsoft 365 Apps for enterprise and Office Professional Plus editions on Windows (enable via File → Options → Add-ins → COM Add-ins → Inquire). Not all consumer editions, or Excel for Mac, include it. Features:

  • Workbook Analysis: an inventory report of formulas, constants, errors, hidden sheets, external links, formulas with hard-coded values, and circular references, exportable to Excel.
  • Workbook Relationship and Worksheet Relationship diagrams: show links between files and between sheets. Useful for confirming one-direction flow (t1 s04).
  • Cell Relationship: a precedent/dependent diagram across sheets for a selected cell, with multiple levels.
  • Compare Files (Spreadsheet Compare): cell-by-cell differences between two versions, including formulas. Essential for version control and for reviewing "what changed since v1.2" (topic related item).
  • Clean Excess Cell Formatting: reduces file bloat.

If Inquire is not available, use the free alternatives: FORMULATEXT comparisons, Go To Special, and manual version comparison with a difference sheet (=IF(v2!E8<>v1!E8,"DIFF","")).

FORMULATEXT and ISFORMULA

FORMULATEXT(ref) returns the formula in a cell as text (#N/A if the cell has no formula). ISFORMULA(ref) returns TRUE if the cell contains a formula. Both are available from Excel 2013 onwards.

Audit applications:

=FORMULATEXT(J20)
=ISFORMULA(J20)
=IF(ISFORMULA(J20),"","HARDCODE")
=SUMPRODUCT(--NOT(ISFORMULA(J20:S120)))
  • Shadow audit sheet: on a copy, place =FORMULATEXT(IS!J20) across a grid that mirrors the IS, then compare adjacent columns (c02).
  • Conditional formatting rule on forecast blocks: formula =NOT(ISFORMULA(J20)) with a red fill, so any hard-code turns red as soon as it is typed.
  • Hard-code count on Checks: the SUMPRODUCT(--NOT(ISFORMULA(...))) count on calc ranges (excluding input rows) feeds the master check or a separate "structure" check.

Note that ISFORMULA over a range inside SUMPRODUCT works in current Excel versions, but test it in your build. Older versions may need array entry.

Supporting tools

  • Watch Window (Formulas → Watch Window): pin the master check, value per share and balance check while you edit elsewhere.
  • Error Checking (Formulas → Error Checking): steps through flagged cells, including "inconsistent formula" green triangles, a built-in row consistency hint.
  • Name Manager: filter for names with errors or external references.
  • R1C1 reference style (File → Options → Formulas): makes copied formulas read identically across a row.

Edge cases & judgement calls

  • Input rows inside calc blocks (e.g. a one-off adjustment row) will show up as constants. Colour them blue and exclude them from the hard-code count by range design.
  • Ctrl+[ to another workbook opens the source file if it is available. That is a sign of an external link to remove (s03).
  • Inquire on protected workbooks needs the password for full analysis, so unprotect for audit.
  • Green triangle noise. Excel flags "formula omits adjacent cells" for legitimate ranges. Do not disable error checking globally. Review and ignore individually.
  • Mac users. Without Inquire, rely on FORMULATEXT, Go To Special (available on Mac) and a manual version-difference sheet.

Key takeaways

  • Ctrl+[ and Ctrl+] trace precedents and dependents fastest. Arrows and Inquire's Cell Relationship cover cross-sheet chains.
  • Evaluate Formula and F9 in the formula bar show how a complex formula arrives at its result.
  • Go To Special → Constants finds hard-codes, Formulas → Errors finds errors, and Row differences tests row consistency.
  • Inquire provides workbook analysis, relationship diagrams and version comparison, but it is edition-dependent.
  • FORMULATEXT and ISFORMULA turn audit tests into live checks and conditional formatting.

Practice Questions

Q1. Tool selection [L1]

For each audit question, name the fastest tool and the exact steps: (a) Is any forecast cell on the BS hard-coded? (b) Which cells on other sheets use the WACC cell? (c) Why does this 180-character formula return 0? (d) What changed between Model_v1.2 and Model_v1.3? (e) Is there content beyond row 400 on the Debt sheet?

💡 Hint: Consider whether each question concerns one cell, one sheet or two files.

Q2. Live hard-code flag [L2]

Write the conditional formatting rule and a Checks-tab count formula that together flag any non-formula cell in the IS forecast range J8:S60 except rows 15 and 32, which are blue input adjustment rows.

Q3. Inquire workbook analysis [L2]

Inquire's Workbook Analysis reports 37 formulas with hard-coded values, 2 external links, 1 hidden sheet and 0 circular references, although you know the model uses iterative interest. Explain how each result should be followed up and why the circularity count may read zero.

Q4. Audit without Inquire [L3]

You use Excel for Mac. Design a substitute audit kit using only FORMULATEXT, ISFORMULA, Go To Special and a comparison sheet, covering hard-codes, row consistency, version differences and error detection.
