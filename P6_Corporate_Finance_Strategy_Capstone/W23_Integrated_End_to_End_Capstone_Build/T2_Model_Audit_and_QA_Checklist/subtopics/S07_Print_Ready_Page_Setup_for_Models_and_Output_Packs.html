Subtopic note

Print-Ready Page Setup for Models and Output Packs

Scope: Print setup: print areas, fit to 1 page wide, repeat title rows, headers/footers with file name and date, page breaks

Why it matters

Models are still read on paper and, more often, as PDFs: board and investment committee packs, lender submissions, audit working papers, and the PDF exports in your portfolio (Week 23 t3). A model that prints as 47 pages of half-columns with no year headers is unusable, and a PDF without a file name and date cannot be traced to a version. Print setup is also part of the roadmap's QA definition ("print-ready page setups"), and the portfolio audit treats it as Visual Clarity evidence. Done properly, it takes 15–20 minutes for a whole model.

Core notes

Print areas

Page Layout → Print Area → Set Print Area defines what prints on each sheet. Excel stores it as a defined name Print_Area scoped to the sheet (visible in Name Manager).

  • Set a print area on every sheet intended for printing: Cover, IS, BS, CFS, DCF, Sensitivity, Checks, and key schedules. Exclude scratch areas and helper columns to the right.
  • Include the label, unit and period columns through the last forecast year. Consider excluding historical columns for an output pack, or printing them as a separate area.
  • For multiple blocks on one sheet, select the ranges with Ctrl and set the print area. Each block prints on a separate page.
  • After adding rows, check that the print area expanded. Inserting rows inside it expands it, while appending below it does not.

Fit to 1 page wide

Page Layout → Page Setup → Page tab → Fit to: 1 page(s) wide by [blank] tall. Clear the "tall" box, so that rows flow onto as many pages as needed while all columns fit on one page width.

  • Use landscape orientation for time-series sheets (15 period columns) and portrait for the Cover.
  • Check the resulting scale (shown in the Scale box after setting). Below about 55–60%, text becomes unreadable. Then reduce columns (group historical years, narrow widths) or split into two print areas (FY22–FY31 and FY32–FY36), rather than shrinking further.
  • Paper size: A4 in India. Set margins to Narrow and centre horizontally.

Repeat title rows (and columns)

Page Setup → Sheet tab → Rows to repeat at top: e.g. $1:$6 (title, units, timeline) so every printed page shows the company name, units and year headers. Columns to repeat at left: $A:$C if a sheet is split across pages horizontally (labels and units on every page). Stored as the defined name Print_Titles.

Headers and footers with file name and date

Page Setup → Header/Footer → Custom. Useful codes:

Code Prints
&[File] Workbook file name
&[Path]&[File] Full path and file name
&[Tab] Sheet name
&[Date] Print date
&[Time] Print time
&[Page] of &[Pages] Page numbering

A standard model footer: left &[File], centre &[Tab], right Page &[Page] of &[Pages]. Header right: Printed &[Date] &[Time], header left: "Kaveri Building Products — Capstone Model — Draft/Final". These codes make every printed page traceable to a file version (topic related item on version control). Note that &[Date] is the print date, not the model date. Show the model's valuation date and version on the Cover itself.

To apply the same setup to many sheets, group-select the sheets (Ctrl+click tabs) and set the header/footer once, then ungroup immediately. Editing while sheets are grouped changes all of them, which is a classic accident.

Page breaks

View → Page Break Preview shows blue lines for page boundaries (dashed automatic, solid manual). Drag them to control where pages split:

  • Break between logical sections (e.g. Revenue build segment A on one page, segment B on the next), never through the middle of a schedule.
  • Insert manual breaks with Page Layout → Breaks → Insert Page Break above the selected row.
  • With "Fit to 1 page wide", horizontal breaks are what you manage. Vertical breaks are removed by the fit setting.
  • Reset All Page Breaks to start again if the layout gets messy.

Exporting to PDF

File → Export → Create PDF/XPS (or Save As PDF), with Options → "Entire workbook" or selected sheets. Before export:

  1. Press F9 (data tables, c05) and confirm the master check is OK and the scenario is base.
  2. Hide gridlines for printing (Page Setup → Sheet → uncheck Gridlines) and keep row/column headings off.
  3. Check print preview for each sheet: correct area, readable scale, titles repeating, footer present.
  4. Name the PDF consistently with the model version (e.g. P4_Capstone_KBPL_v1.0_Outputs.pdf, matching the dossier naming convention in t3).

Edge cases & judgement calls

  • Very wide sensitivity outputs may need their own landscape print area at a different scale. Do not force them into the 1-page-wide setting of the calc sheets.
  • Grouped columns collapsed at print time print as collapsed. Expand or collapse deliberately before printing.
  • Printing hidden or very hidden sheets. These do not print. That is another reason not to hide logic.
  • Different printer drivers change page breaks slightly. PDFs fix the layout, so share PDFs rather than relying on recipients to print the workbook.
  • Confidential drafts. Add "DRAFT — for discussion" in the header until the model is frozen. Remove it at v1.0.

Key takeaways

  • Set print areas on every output sheet and exclude helper columns.
  • Fit to 1 page wide with height blank, in landscape. If scale falls below about 60%, split the area instead.
  • Repeat title rows (title, units, timeline) and, where needed, label columns.
  • Footers and headers carry file name, sheet, page x of y and print date, so pages trace to versions.
  • Manage page breaks at section boundaries, and export PDFs only after F9, checks OK and base scenario.

Practice Questions

Q1. Configure an IS printout [L1]

The IS sheet has labels in A:C, history in E:I, forecasts in J:S and a scratch area in U:Z, with title and timeline in rows 1–6 and content to row 74. Specify every page setup setting to produce a readable A4 landscape printout with traceable headers and footers.

💡 Hint: Think about what must appear on page 2 that would otherwise only be on page 1.

Q2. Unreadable scale [L2]

Fit to 1 page wide produces a 41% scale on the Debt sheet, which has 10 tranches and 20 period columns. Propose two alternative print designs and state the trade-offs of each.

Q3. Grouped-sheet accident [L2]

After applying footers to 12 grouped sheets, you typed a new WACC on the DCF sheet without ungrouping. Explain what happened, how to detect the damage and how to recover.

Q4. PDF output pack specification [L3]

Specify the contents, order, print settings and file naming for a 10–12 page PDF output pack from your capstone model to be attached to the portfolio dossier, including the pre-export checks.
