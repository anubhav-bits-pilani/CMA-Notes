Building the Six-Project Portfolio Section with Links

Scope: Portfolio section: six projects with one-line outcomes and links (GitHub/Drive/LinkedIn Featured)

Why it matters

For a career switcher, the portfolio is the bridge between "I understand Ind AS and modelling" and "here is proof". Hiring managers in FP&A, valuation KPOs and FAAS increasingly ask candidates to share work samples or will open a link in the CV before a screening call. A well-built portfolio section also shortens interviews: instead of abstract questions, the interviewer asks about your model, where you are strongest. The six projects from this curriculum map to the core role families, so the section doubles as evidence of breadth.

Core notes

The six projects

The curriculum produces six portfolio deliverables. A typical mapping:

# Project Built in Primary role signal
1 Ind AS close pack and technical memos (Ind AS 115/116/109/12) Weeks 1–4 FAAS, financial reporting, controllership
2 Excel/Power Query automation (TB consolidation, data cleanup) Weeks 9–11 R2R, FP&A, GCC
3 Integrated 3-statement model of an NSE-listed company Weeks 13–15 FP&A, modelling, valuation
4 WACC and DCF valuation with sensitivities Week 16 Valuation, KPO, FAAS (PPA support)
5 Budget, rolling forecast and PVM variance analysis Weeks 17–19 FP&A
6 Power BI MIS/FP&A reporting pack with commentary Week 20 FP&A, controllership, GCC

Week 21 capital budgeting and the Week 23 capstone dossier can be folded into these or swapped in for a specific role variant.

One-line outcome format

Each entry is one line (two at most) with: project name, scope, key method/tool, headline output and a link. Template:

Project name — scope; method/tool; headline result. [Link]

Examples:

  • Ind AS 116 lease close pack — 14-lease portfolio of a retail company; lease liability, ROU and DTA schedules with journal entries and disclosure note; EBITDA impact +₹6.2 crore, PBT impact −₹0.9 crore in year 1. [Drive link]
  • 3-statement and DCF model, NSE-listed auto ancillary — 5-year forecast with WC, PPE and debt schedules, revolver and circularity switch; equity value ₹1,450–1,720/share across WACC 11–13%, g 4–6%. [GitHub link]
  • Power BI FP&A pack — star schema of 3 years' monthly data, DAX YTD/LY/budget measures, PVM bridge page, RLS by region; refresh under 2 minutes. [Video walkthrough link]

The outcome must be a number or a concrete artefact, not a description ("demonstrates my skills in modelling").

Hosting and link options

Option Best for Practical notes
Google Drive / OneDrive folder Excel models, PDFs Set "anyone with the link can view"; use a folder per project with a README PDF; disable download if you prefer view-only
GitHub repository Power Query M scripts, DAX, SQL, Python, versioned models Include a README with problem, method, screenshots and results; Excel files are binary, so add a PDF/PNG of key outputs
LinkedIn Featured Visibility to recruiters Add the best 3–4 items as links, documents (PDF carousel) or posts; title each with the outcome
Short video (Loom, YouTube unlisted) Power BI dashboards, model walkthroughs 2–3 minutes; shows you can explain your work
Personal Notion/website Single landing page Optional; one URL that links to all six projects

Use a link shortener or a clean folder name so the CV link is readable; on a PDF CV make links clickable. Test every link from a logged-out browser before sending.

Data hygiene and confidentiality

Use only public data (annual reports of NSE/BSE-listed companies, RBI/MOSPI data, Kaggle-style datasets) or synthetic data. Never upload client data from audit engagements, even anonymised, because confidentiality obligations and data protection law (the Digital Personal Data Protection Act, 2023, where personal data is involved) apply. State the data source in each README.

Quality checklist for each project

  • Opens without errors; no #REF! or broken links to other workbooks.
  • Inputs separated and colour-coded; checks visible (balance check, cash tie-out, variance sum check).
  • A cover sheet: purpose, structure, key assumptions with sources, checks, limitations.
  • File names with versions and dates (e.g. AutoAnc_3S_DCF_v3_2026-10.xlsx).
  • A one-page PDF summary for recruiters who will not open Excel.

Placement on the CV

Place the portfolio section after experience for experienced candidates; for those with under 2 years' relevant experience or a strong career switch, place it directly after the summary and core skills. Title it "Selected Projects" or "Portfolio (Ind AS, Modelling, Power BI)" and keep it to six lines. Avoid "Academic Projects" unless it was academic.

Edge cases & judgement calls

  • Recruiters who will not click links: the one-line outcome must stand alone; the link is supplementary.
  • Company policies on external links: some employers' systems strip links from uploaded CVs; keep the project title searchable (e.g. a GitHub username in the header).
  • Template-derived projects: if a project started from a course template, say so and describe what you extended; interviewers spot template structures.
  • Too many projects: six is the limit on the CV; extra projects go on LinkedIn or the landing page.
  • Ownership of course material: do not publish licensed course files or solutions verbatim; publish your own build.
  • Public company valuation views: add a disclaimer that the valuation is an educational exercise and not investment advice, given SEBI's research analyst regulations.

Key takeaways

  • Six projects, one line each: name, scope, method, numeric result, link.
  • Map each project to a role family and reorder per CV variant.
  • Host on Drive/GitHub with a README and a PDF summary; feature the best 3–4 on LinkedIn.
  • Use only public or synthetic data; never client data.
  • Test links logged-out and make sure each file opens cleanly with visible checks.

Practice Questions

Q1. Draft the section [L1]

Write the six-line portfolio section for your own projects using the one-line outcome format. Each line must include a number and a link placeholder.

Q2. README for a GitHub repo [L2]

Draft the README outline for a GitHub repository containing your Power Query TB consolidation project (8 entities, 3 years of monthly TBs, mapping table to Schedule III line items, refresh time 4 minutes). Include sections, the screenshots you would add, the data source statement and a limitations paragraph.

💡 Hint: Write it so a hiring manager can understand the project in 60 seconds without opening any file.

Q3. Reordering per role [L2]

For each target role — Big 4 FAAS Associate, FP&A Analyst at a Bengaluru SaaS GCC, Valuation Analyst at a KPO, R2R Senior Analyst — choose the top three projects from the six and justify the order in one sentence each.

Q4. Confidentiality judgement [L3]

A candidate wants to include an "Ind AS 109 ECL model" built during an audit engagement for an NBFC client, with the client name removed but the actual loan book data (₹1,200 crore, 18,000 borrowers) retained. Advise on whether this can be included, the professional and legal issues, and how to recreate an equivalent portfolio item.
