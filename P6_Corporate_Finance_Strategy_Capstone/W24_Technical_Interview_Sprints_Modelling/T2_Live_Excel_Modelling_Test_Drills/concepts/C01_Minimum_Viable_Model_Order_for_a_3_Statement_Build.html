Key concept

Minimum Viable Model Order for a 3-Statement Build

Concept: Minimum viable model order: IS → BS roll-forwards → CFS → balance check → outputs

Statement

In a timed test, build the integrated model in this sequence:

  1. Income statement (IS): revenue to PAT, using inputs for growth, margins, opex, depreciation (from the PPE schedule), interest (from the debt schedule) and tax.
  2. Balance sheet roll-forwards: for each non-cash BS line, closing = opening + additions − reductions, driven by IS items or inputs: PPE (opening + capex − depreciation), working capital items (days or % of revenue/COGS), debt (opening + drawdowns − repayments), equity (opening + PAT − dividends + issues).
  3. Cash flow statement (CFS): indirect method; CFO from PAT plus non-cash items minus increases in working capital; CFI from capex; CFF from debt and equity flows and dividends; closing cash = opening cash + net cash flow.
  4. Balance check: cash from the CFS feeds the BS; check \(\text{Assets} - \text{Liabilities} - \text{Equity} = 0\) for every period.
  5. Outputs: DCF, ratios, sensitivity tables, charts and summary, only after the balance check is zero.

Explanation

The order follows the direction of causality in an integrated model: the IS generates profit; BS roll-forwards translate profit, investment and financing decisions into closing balances; the CFS derives cash from those balance movements; cash closes the BS. Building in this order means each step only references things already built, which minimises forward references and broken links.

"Minimum viable" means building the simplest version of each piece that makes the model balance, then adding sophistication. For example, interest on opening debt first (no circularity); a single "other current assets" line rather than five; a simple revolver after the base model balances. Sophistication added before balance multiplies the places an error can hide.

Building the BS roll-forwards before the CFS is the key discipline. The CFS lines are then mechanical: each CFS line equals the movement in one BS line (or an IS non-cash item), so the CFS cannot introduce new numbers, which is the property that guarantees balance (c02). Candidates who build the CFS from IS items first and BS last often end up with a CFS that does not reconcile with BS movements.

Outputs come last because they depend on everything else. A DCF built on an unbalanced model inherits its errors, and time spent on a sensitivity table is wasted if the underlying FCFF changes during debugging.

Exceptions: in a DCF-only prompt with FCFF inputs given, there is no balance sheet; the order becomes inputs → FCFF → discounting → TV → EV → equity bridge → sensitivity. In a revenue-build prompt, the revenue engine is the IS's first block and may be built and checked before anything else.

Connections

Applies the Weeks 13–15 linkage logic in a test sequence. Works with c02 (cash as the only plug, which the CFS-after-BS order enforces), c03 (the 55-minute build window maps to steps 1–5), c05 (if the check fails, the order tells you where to look), and s06 (balance before formatting). In FP&A practice, the same order is used when building a quick reforecast model during a budgeting cycle.

Practice Questions

Q1. Sequence a build [L1]

A prompt gives: opening BS, revenue growth, gross margin, opex %, capex %, depreciation rate, days ratios, debt repayment schedule, tax rate, dividend payout and a DCF requirement. List every block you would build, in order, and for each block name the inputs and earlier blocks it references.

Q2. Minimum viable simplifications [L2]

For a 60-minute test, list five simplifications you would make in the first pass to reach a balancing model faster (e.g. interest basis), and for each state how you would upgrade it if time permits and what check you would rerun after the upgrade.

💡 Hint: Focus on features that create circularity or multiply line items.

Q3. Out-of-order build diagnosis [L2]

A candidate built the CFS first using IS items and guessed working capital changes from the prompt's days ratios, then built the BS with each line computed independently. The model is out by different amounts each year. Explain why this order makes imbalance likely and how rebuilding in the c01 order removes it.
