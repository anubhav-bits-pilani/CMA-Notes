Data Tasks Under Time Pressure: Lookups, SUMIFS, Pivots, Power Query

Scope: Data tasks: XLOOKUP/INDEX-MATCH, SUMIFS, pivot tables, Power Query cleanup under time pressure

Why it matters

FP&A, R2R and GCC analytics tests are often data tests disguised as finance tests: you receive a messy extract (ERP dump, sales register, GL detail) and must clean, map, aggregate and analyse it within the time limit. Platform tests (s01) ask directly about lookup and aggregation functions. The ability to choose the right tool quickly (formula vs pivot vs Power Query) and to execute it without errors determines whether you reach the analysis and commentary that carry most of the marks.

Core notes

Lookups: XLOOKUP and INDEX-MATCH

XLOOKUP (Microsoft 365/Excel 2021+):

=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])

Advantages: defaults to exact match; returns columns to the left; built-in not-found handling; can return multiple columns as a spill; supports approximate match for slabs (match_mode −1 for next smaller, 1 for next larger) and search from last to first (search_mode −1).

Example: map GL codes to Schedule III lines with a fallback flag:

=XLOOKUP([@GLCode],Map[GLCode],Map[SchIIILine],"UNMAPPED")

INDEX-MATCH (all versions, and the fallback where XLOOKUP is unavailable, e.g. some platform tests or older client environments):

=INDEX(Map!$C$2:$C$500,MATCH(A2,Map!$A$2:$A$500,0))

Two-way lookup (row and column):

=INDEX($B$2:$M$50,MATCH($P2,$A$2:$A$50,0),MATCH(Q$1,$B$1:$M$1,0))

Multi-criteria lookup without helper columns:

=INDEX(D:D,MATCH(1,(A:A=H2)*(B:B=I2),0))

(entered normally in Microsoft 365; as an array formula in older versions). In tests, prefer a helper key column (=A2&"|"&B2) for speed and transparency.

Traps. Trailing spaces and text-vs-number mismatches (e.g. "1001" vs 1001) cause false not-founds; fix with TRIM, VALUE or Power Query type changes. VLOOKUP with approximate match by default (omitted fourth argument) returns wrong values silently. Always count not-founds: =COUNTIF(F:F,"UNMAPPED").

SUMIFS and related aggregations

=SUMIFS(sum_range, criteria_range1, criteria1, [criteria_range2, criteria2], ...)

Use cases in tests: budget vs actual by cost centre and month; TB to Schedule III line aggregation; revenue by region and product for PVM.

=SUMIFS(Data[Revenue],Data[Region],$B5,Data[Month],C$4)

Criteria with operators and dates: ">="&$C$1, "<="&EOMONTH($C$1,0). Wildcards: "*Freight*". Related functions: COUNTIFS, AVERAGEIFS, MAXIFS, MINIFS. For weighted calculations, SUMPRODUCT (e.g. ECL matrix, weighted-average price).

Mixed references matter: anchor the column of row labels and the row of column headers ($B5, C$4) so one formula fills the whole grid with Ctrl+Enter or fill right/down.

Check. Total of the SUMIFS grid must equal the total of the source column; build =SUM(grid)-SUM(Data[Revenue]) and expect zero. A non-zero result means unmapped categories or date mismatches.

Pivot tables

Pivots are the fastest way to explore and summarise when the output layout is flexible. Under time pressure:

  • Convert data to a Table first (Ctrl+T) so the pivot source expands.
  • Insert pivot: Alt+N+V (Windows ribbon key sequence; varies by version).
  • Use Values settings for sum/count/average and "Show Values As" (% of grand total, % difference from) for quick mix and growth analysis.
  • Group dates by month/quarter; group numbers into ageing buckets.
  • Use GETPIVOTDATA only if the output must feed formulas; otherwise copy as values for the final table, or use SUMIFS on the source for a stable layout.

When not to use a pivot: when outputs must link into a model that will be changed live (pivots need refreshing and change shape) or when the reviewer expects formula traceability.

Power Query cleanup

Power Query is the right tool when the data needs structural cleaning (unpivoting, appending multiple files, splitting columns, fixing types) and when the task might be repeated. Typical sequence for a messy sales extract:

  1. Data → From Table/Range or From Text/CSV.
  2. Promote headers; remove top junk rows (Remove Rows → Remove Top Rows).
  3. Trim and clean text columns (Transform → Format → Trim, Clean); fix case (Capitalize Each Word / UPPERCASE).
  4. Change types explicitly (dates with locale if "Apr-24" style text: Using Locale → English (India)).
  5. Unpivot month columns into rows (select ID columns → Unpivot Other Columns).
  6. Merge with a mapping table (Merge Queries, left outer) and expand the mapped column; filter nulls to find unmapped items.
  7. Group By for aggregation if required; Close & Load to a Table.

Representative M for steps 3–5:

let
    Source = Excel.CurrentWorkbook(){[Name="RawSales"]}[Content],
    Promoted = Table.PromoteHeaders(Source, [PromoteAllScalars=true]),
    Trimmed = Table.TransformColumns(Promoted, {{"SKU", Text.Trim, type text}, {"Region", Text.Proper, type text}}),
    Unpivoted = Table.UnpivotOtherColumns(Trimmed, {"SKU", "Region"}, "Month", "Units"),
    Typed = Table.TransformColumnTypes(Unpivoted, {{"Units", type number}, {"Month", type date}}, "en-IN")
in
    Typed

Under time pressure: do only what the task needs; name queries clearly; check row counts after each major step (the status bar shows rows in the preview; a merge that duplicates rows means non-unique keys in the mapping table).

Choosing the tool in 30 seconds

Situation Best tool
One-off lookup of a few columns, clean data XLOOKUP
Messy text, multiple files, wide-to-long reshape Power Query
Exploratory summary, flexible layout Pivot table
Fixed-layout grid feeding a model or variance table SUMIFS
Weighted totals (ECL, weighted price) SUMPRODUCT

Edge cases & judgement calls

  • Duplicate keys in mapping tables: XLOOKUP returns the first match silently; Power Query merges duplicate rows. Check uniqueness with =COUNTIF(Map[Key],[@Key])>1.
  • Dates stored as text: SUMIFS on dates fails silently; convert with DATEVALUE or Power Query.
  • Volatile functions: OFFSET and INDIRECT slow large workbooks and obscure audit trails; avoid in tests.
  • Calculation mode: if the workbook is set to manual calculation, results look wrong; check Formulas → Calculation Options.
  • Platform tests without Power Query: be ready to do the same cleanup with TRIM, PROPER, TEXTSPLIT or Text to Columns.

Key takeaways

  • XLOOKUP for modern lookups with not-found handling; INDEX-MATCH as the universal fallback.
  • SUMIFS with mixed references fills a grid in one formula; always reconcile grid total to source.
  • Pivots for exploration; formulas for model-linked outputs.
  • Power Query for structural cleanup; check row counts after merges and unpivots.
  • Trailing spaces, text numbers and duplicate keys cause most data-test errors; test for them explicitly.

Practice Questions

Q1. Lookup design [L1]

A GL extract has 3,200 rows with columns GLCode (some stored as text with leading apostrophes), Description, Debit, Credit. A mapping table maps 410 GL codes to Schedule III line items, but 6 codes appear twice with different mappings. Write the formulas to map each row, flag unmapped and duplicate-mapped codes, and reconcile total debits and credits after mapping.

Q2. SUMIFS variance grid [L2]

Design a budget vs actual grid with cost centres (25) in rows and months (Apr–Mar) in columns, sourced from a 15,000-row actuals table (CostCentre, Month as a true date, Amount) and a budget table of the same structure. Write the single SUMIFS formula for the actual grid's first cell that can be filled across the whole grid, the variance formula, and the reconciliation check.

💡 Hint: Month criteria on true dates are easiest with a start-of-month header and EOMONTH for the end bound.

Q3. Power Query cleanup plan [L2]

You receive 12 monthly CSV files of sales (each with 3 junk header rows, SKU codes with trailing spaces, region names in mixed case, amounts with commas stored as text, and a "Total" row at the bottom). Describe the Power Query steps to combine and clean them into one table, the checks you would perform, and how you would handle a 13th file arriving later.

Q4. Tool choice under time pressure [L3]

In a 60-minute FP&A test, you must produce (a) revenue by region and month, (b) top 10 SKUs by growth, (c) PVM by region, and (d) a commentary. The data is 50,000 rows, clean except for inconsistent region names. Plan the time and tool for each part, and explain the trade-offs between pivots, SUMIFS and Power Query in this case.
