Keyboard Speed Drills for Modelling Tests

Scope: Speed drills: keyboard shortcuts (F2, F4, Ctrl+[, Ctrl+Shift+arrows, Alt shortcuts for formatting and paste special)

Why it matters

In a 90-minute test the difference between a mouse-driven and a keyboard-driven modeller is roughly 15–25 minutes, which is the difference between a balanced, checked model with a note and an unfinished one. In live screen-share tests, keyboard fluency is also visible evidence of experience: interviewers notice candidates who navigate, edit, trace and format without reaching for the mouse. The shortcuts below are the core set for Windows desktop Excel (Microsoft 365); Mac equivalents differ and are noted where common.

Core notes

Editing: F2 and F4

  • F2 enters edit mode in the active cell with the cursor at the end of the formula. In edit mode, pressing F2 again toggles between Edit and Point mode, so arrow keys move through the formula text instead of selecting cells. Use F2 to inspect a formula's precedents (they are colour-highlighted) and to fix a reference without retyping.
  • F4 in edit mode cycles the selected reference through absolute and relative forms: A1 → $A$1 → A$1 → $A1 → A1. Outside edit mode, F4 repeats the last action (e.g. apply the same format, insert another row), which is a major speed gain for formatting.
  • Related: Ctrl+Enter enters the same formula into all selected cells (combined with correct mixed references, this fills a grid at once); Ctrl+D fills down and Ctrl+R fills right from the first cell of the selection; Esc cancels an edit.

Mac: F2 often needs Fn+F2 or Ctrl+U; F4 is Cmd+T for reference cycling and Cmd+Y for repeat.

Auditing: Ctrl+[ and related

  • Ctrl+[ selects the direct precedents of the active cell's formula, jumping to them even on another sheet. Use it to trace where a number comes from.
  • Ctrl+] selects direct dependents on the same sheet.
  • F5 then Enter (Go To) returns to the previous cell after jumping with Ctrl+[ ; Go To keeps a list of recent references.
  • Ctrl+Shift+{ and Ctrl+Shift+} select all precedents/dependents (direct and indirect).
  • Alt+M+P (Trace Precedents arrows) and Alt+M+D (Trace Dependents), Alt+M+A+A (remove arrows) on the Formulas ribbon.
  • Ctrl+grave accent (key left of 1) toggles formula view to spot hard-codes and inconsistent formulas.
  • F9 within the formula bar evaluates a selected part of a formula (press Esc afterwards to avoid replacing it with a value).

Navigation and selection: Ctrl+arrows and Ctrl+Shift+arrows

  • Ctrl+arrow jumps to the edge of the current data region.
  • Ctrl+Shift+arrow extends the selection to the edge, e.g. select a forecast row from the first year to the last in one keystroke before Ctrl+R.
  • Shift+arrow extends by one cell; Shift+Space selects the row; Ctrl+Space selects the column.
  • Ctrl+Home / Ctrl+End go to A1 / last used cell; Ctrl+PgUp / Ctrl+PgDn switch sheets.
  • Ctrl+Shift+Plus / Ctrl+Minus insert/delete cells, rows or columns (after Shift+Space or Ctrl+Space).
  • Alt+Shift+Right / Left arrow groups/ungroups selected rows or columns (useful for collapsing historicals).

Alt ribbon shortcuts for formatting

Alt shortcuts activate the ribbon key tips and work by pressing keys in sequence (not together):

Increase/decrease decimals Alt+H+0 / Alt+H+9

Number format shortcuts Ctrl+Shift+1 (number), Ctrl+Shift+5 (%)

Building a custom number format once (Ctrl+1 → Custom, e.g. #,##0.0;(#,##0.0);"-") and repeating with F4 saves minutes.

Paste special

  • Ctrl+Alt+V opens Paste Special; then V for values, T for formats, F for formulas, R for formulas and number formats, W for column widths, E (transpose), D/S/M/I for add/subtract/multiply/divide operations. Confirm with Enter.
  • Legacy sequence Alt+E+S opens the same dialog and still works in Windows Excel.
  • Practical uses: paste values to freeze a pivot output; paste formats to copy styling across years; multiply by −1 to flip signs in a block (type −1 in a cell, copy, select block, Ctrl+Alt+V, M, Enter); divide by 100 to convert lakh to crore.

A 15-minute daily drill

  1. Five minutes: build a 5-year timeline and a revenue/COGS/gross profit block using only the keyboard (Ctrl+Shift+arrows, Ctrl+R, F4 for anchors).
  2. Five minutes: on an existing model, trace three outputs back to inputs using Ctrl+[ and F5, and list any hard-codes found with formula view.
  3. Five minutes: format a raw block to model standard (blue inputs, number format, borders, column widths, freeze panes) using Alt sequences and F4 repeats.

Time each drill and log it; aim to cut each by a third over four weeks.

Edge cases & judgement calls

  • Laptop function keys: many laptops require Fn for F2/F4; enable Fn Lock (often Fn+Esc) before a test.
  • Excel for the web and platform tests: Alt ribbon sequences and some Ctrl shortcuts differ or are captured by the browser; practise in the actual environment if known.
  • Keyboard layouts: Ctrl+[ relies on the US layout bracket key position; on other layouts the shortcut may differ.
  • Over-reliance on F4 repeat: it repeats the last action exactly; a misapplied format will be repeated across the model.
  • Shortcut theatre: in live tests, fluency matters, but correctness and narration matter more; do not rush shortcuts at the expense of accuracy.

Key takeaways

  • F2 edits and shows precedents; F4 cycles references in edit mode and repeats the last action otherwise.
  • Ctrl+[ traces precedents across sheets; F5 then Enter returns.
  • Ctrl+Shift+arrows plus Ctrl+R/Ctrl+D/Ctrl+Enter build rows and grids quickly.
  • Alt ribbon sequences and Ctrl+1 handle formatting; Ctrl+Alt+V handles paste special including operations.
  • Drill 15 minutes daily and log times; check function-key and environment differences before tests.

Practice Questions

Q1. Keyboard-only build [L1]

Using only the keyboard, build in a blank sheet: a timeline FY26–FY30 in C3:G3, revenue in row 5 starting at ₹500 crore growing at a rate in cell B5, COGS at a % in B6, and gross profit in row 7. List every keystroke sequence you used and record the time taken.

Q2. Reference anchoring [L2]

You need a single formula in C10 that can be filled across C10:G20 to compute volume (row headers in B10:B20 are products; volumes in a table on sheet Data with products in column A and years in row 1, columns B:F). Write the formula with correct mixed references using INDEX-MATCH, and describe the F4 presses needed to create the anchors.

💡 Hint: The product reference must lock its column; the year reference must lock its row.

Q3. Paste special operations [L2]

A pasted block of 40 × 12 cells is in ₹ lakh with costs as positive numbers; your model needs ₹ crore with costs negative. Describe the fastest paste special sequence to convert it, and how you would verify the result.

Q4. Drill log and target [L2]

Design a 4-week drill log in Excel for the three 5-minute drills described in this note: columns, formulas for improvement %, a target line and a chart. State a realistic target time for each drill at the end of week 4.
