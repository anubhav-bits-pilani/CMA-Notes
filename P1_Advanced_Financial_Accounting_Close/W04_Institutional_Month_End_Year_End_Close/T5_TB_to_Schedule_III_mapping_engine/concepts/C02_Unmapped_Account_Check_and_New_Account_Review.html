Key concept

Unmapped Account Check and New Account Review

Concept: Unmapped check: count of TB accounts missing from mapping = 0; new accounts trigger mapping review

Statement

Let \(\mathcal{A}_{TB}\) be the set of accounts in the final TB with a non-zero balance or activity in the current or comparative period, and \(\mathcal{A}_{Map}\) the set of accounts in the mapping table with all mandatory attributes populated. Then:

\[ U = \left\lvert \mathcal{A}_{TB} \setminus \mathcal{A}_{Map} \right\rvert = 0 \]

where \(U\) is the count of unmapped accounts. In addition, the set of new accounts \(N = \mathcal{A}_{TB}^{t} \setminus \mathcal{A}_{TB}^{t-1}\) (present this period, absent last period) and reactivated accounts (zero last period, non-zero now) must be reviewed and signed off even if a mapping exists.

Excel:

=SUM(--ISNA(XMATCH(FinalTB[Account], Map[Account])))

Power Query: a left anti-join of FinalTB to Map returns the unmapped list.

Explanation

The danger the check addresses is silent omission. With SUMIFS-based engines, an account that is not mapped simply contributes to no line: the BS may still balance if the omission is offset elsewhere, or fail with a difference that is hard to trace. With static mappings (hard-coded account lists in formulas), a new GL account opened mid-year is dropped without any error (topic pitfall). Making \(U = 0\) a gate in the master check flag converts omission into a visible failure.

Why also review new and reactivated accounts? Default mapping (e.g., by numeric range — s01) can map a new account to a plausible but wrong line: an account "520900 Capital creditors" in the trade payables range would default to trade payables, though Schedule III requires capital creditors under other financial liabilities. Review checks that each new account's line, note, C/NC, CF and DT attributes are right.

Operational rules:

  • Mapping is updated before the account is opened for posting (COA governance, s01); the close check is the backstop.
  • Mandatory attributes blank = unmapped (a mapping row with no Line ID is no mapping).
  • Accounts mapped to the "ERROR" line (suspense/clearing, w4_t4) count as mapped but must have nil balance — a separate check.
  • The comparative TB is included, so a mapping deleted for a now-dormant account does not break the prior-year column.

Illustration

March TB has 1,214 accounts with balances; mapping table has 1,209 rows.

Account Description Balance ₹ lakh Status
650450 Interest on income-tax refund (18.6) New — not in mapping (U +1)
521200 Trade payables – related parties (240.0) New — default mapped to TP; review OK, add related-party flag
890010 CSR expense 32.0 Mapped, but DT category blank → treated as unmapped (U +1)
590300 Migration suspense 4.2 Mapped to ERROR line → suspense check fails
742000 Packing material consumed 0.0 last year, 46.0 now Reactivated — review mapping (should it be in cost of materials consumed?)

\(U = 2\): the FS cannot be finalised until 650450 is mapped (other income; ensure interest on tax refund is shown separately where material) and the CSR DT category is set to "permanent".

Connections

Gate in s06 integrity checks; depends on s01 (COA governance) and s02 (mandatory attributes); fed by w4_t4 s07 automated TB checks (new/unmapped accounts) and the Project 1 assessment requirement "zero unmapped GL accounts". In modelling work, the same check protects historical data pulls into 3-statement templates.

Practice Questions

Q1. Write the check [L1]

Write an Excel formula (structured references only) that counts TB accounts with non-zero balances that are missing from the mapping table or have a blank Line ID, and a dynamic-array formula that lists them.

Q2. Static mapping failure [L2]

A workbook's trade payables line is calculated as =SUM(TB!F120:F128). In February, a new account 521300 "Trade payables – imports" with a balance of ₹3.8 crore is inserted at row 131. Explain what happens to the BS, the BS check and the payables note, and redesign the calculation so this cannot recur.

💡 Hint: Consider whether the BS check would detect the omission and what it would show.

Q3. New account review procedure [L2]

Design the monthly new-account review: report content, who reviews, the attributes they confirm, evidence retained, and how the review interacts with the auditor's walkthrough of the reporting process.
